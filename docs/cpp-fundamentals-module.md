# Основы C++

Модуль C++23 из 27 последовательных уроков после «Алгоритмов и структур данных». Рассчитан на ученика, который знает C: каждый урок показывает, что C++ берёт на себя по сравнению с C, и сравнивает код на обоих языках там, где это помогает. Переработан по стандарту урока из [аудита контента](content-audit.md): теория маленькими шагами с запускаемыми примерами и точным выводом, частые ошибки, 8 вопросов (включая «что выведет программа»), 4 задачи с 8–12 тестами, конкретными подсказками и разбором решения.

Итого: 27 уроков, 224 вопроса, 108 задач, из них 27 «Найди ошибку» с отрицательным контролем. Все задачи — C++23 с доверенным режимом ASan/UBSan; ID уроков прежней версии (`cpp20-…`) сохранены, новые уроки получили префикс `cpp23-`.

## Программа

| Раздел             | Уроки                                                                                                                                                                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Переход с C        | отличия от C, пространства имён, вывод `std::cout`, форматирование `std::format` и `std::print`, ввод `std::cin`, `std::string`, `std::string_view`                                                                                                          |
| Функции и значения | ссылки, константные ссылки, `auto` и лямбда-выражения, цикл по диапазону и итераторы, перегрузка и шаблоны функций, аргументы по умолчанию, `enum class`                                                                                                     |
| Контейнеры         | `std::vector`, `std::array`, `std::span`, диапазоны и представления `std::ranges`/`std::views`, `std::deque` со `std::stack` и `std::queue`, `std::pair` и структурные привязки, `std::tuple`, `std::optional`, `std::map`, `std::unordered_map`, `std::set` |
| Ошибки             | исключения и `std::expected`                                                                                                                                                                                                                                 |

ID уроков прежней версии сохранены, порядок изменён: `enum class` стоит перед контейнерами (он нужен в задачах о состояниях), `std::pair` и `std::tuple` — перед словарями (элемент `std::map` — пара), исключения завершают модуль. Отдельных уроков о лямбдах, итераторах и шаблонах нет — они раскрыты внутри уроков `auto`, цикла по диапазону и перегрузки: без них не объяснить `std::sort`, `std::find_if` и `std::erase_if`. Классы, конструкторы и владение — в модулях «ООП» и «Время жизни объектов»; здесь только использование готовых типов.

Без повторов с «Алгоритмами»: там стандартные контейнеры показаны как предпросмотр, здесь — интерфейс, инвалидация, стоимость операций и выбор контейнера. Реализация хеш-таблиц, деревьев и динамического массива не повторяется — уроки ссылаются на неё.

## Практика

- Задачи нарастают по сложности: разминка, основная задача, «Найди ошибку», задача повышенной сложности (конечный автомат для чисел, поиск в ширину 0-1 на деке, объединение интервалов, запросы по диапазону ключей, отрезки с заданной суммой, калькулятор с исключениями).
- «Найди ошибку» — типичные ошибки перехода с C: `malloc` без приведения, `using namespace std` и столкновение имён, `std::uint8_t` печатается символом, `getline` после `>>`, непроверенный `npos`, висячая ссылка на элемент вектора, неконстантная ссылка и временное значение, `auto` без `&`, `push_back` во время обхода, неоднозначная перегрузка, аргумент по умолчанию в определении, проваливание в `switch`, выход за границу вектора, `sizeof` массива-параметра, индекс после `push_front`, привязка без `&`, порядок распаковки кортежа, `operator[]` словаря при чтении, порядок обхода `unordered_map`, `multiset::erase` по значению, порядок обработчиков `catch`.
- Дефекты выбраны так, чтобы заготовка не зависала: бесконечный цикл с санитайзерами превысил бы общий лимит проверки задания.

## Авторинг

Каждый урок — `lesson.src.mjs` и `lesson.mdx`; сборка — `node --import tsx scripts/lessons/build.ts cpp-fundamentals/<урок>`. Скрипт проверяет эталоны на GCC и Clang с ASan/UBSan, вычисляет выводы скрытых тестов, сверяет примеры MDX (блоки ` ```cpp ` — C++23, сравнительные ` ```c ` — C23) и ответы вопросов с запуском, а для задач с `bug: true` убеждается, что дефектная заготовка не проходит тесты. Компиляция C++ с санитайзерами заметно медленнее C — на медленном Docker уменьшайте параллелизм: `LESSON_JOBS=2`.

## Проверки

- `npm test` — `tests/unit/cpp-fundamentals-content.test.ts`: порядок и цепочка уроков, стандарт урока, отчёт GCC/Clang, отрицательные контроли, индекс поиска и скрытие решений.
- `npm run test:cpp-fundamentals` — `scripts/verify-cpp-fundamentals.ts`: эталоны на GCC и Clang с ASan/UBSan, отрицательные контроли, все примеры MDX (`// Ошибка компиляции` — не собираются, `// Ошибка выполнения` — завершаются ошибкой, `// Ошибка памяти` — дают отчёт санитайзера). Отчёт — `docs/verification/cpp-fundamentals.json`, параллелизм — `CPP_JOBS`; аргументы — подстроки ID уроков для частичной проверки без записи отчёта.
