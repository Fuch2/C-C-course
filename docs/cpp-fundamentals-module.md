# Основы C++

Модуль `cpp-fundamentals` рассчитан на ученика, знающего C. 21 урок на C++20 показывает изменение модели программирования: значения владеют ресурсами, ссылки выражают заимствование, а контейнеры и потоки имеют проверяемые контракты.

Для каждого инструмента разобраны причина появления, аналог C, стоимость, память, invalidation, типичная ошибка и ситуация применения. Практика использует строки устройств, измерения, очереди команд, журналы, коды состояний и обработку некорректных токенов. Решения используют стандартную библиотеку и RAII; ручное копирование C-подхода не предлагается как стиль C++.

Задачи и примеры хранятся в `content/cpp-systems/cpp-fundamentals/`. Эталонные C++20-программы не публикуются API. Скрипт `scripts/author-cpp-fundamentals.mjs` пересобирает уроки, а `npm run test:cpp-fundamentals` компилирует решения GCC и Clang и выполняет тесты в sandbox. Этот Docker-прогон ожидает восстановления approval-лимита; причина отражена в `TODO.md`.

Технические объяснения сверены с рабочим текстом C++20: [`auto`](https://eel.is/c++draft/dcl.spec.auto), [ссылки](https://eel.is/c++draft/dcl.init.ref), [контейнеры](https://eel.is/c++draft/container.requirements.general), [исключения](https://eel.is/c++draft/except.ctor).
