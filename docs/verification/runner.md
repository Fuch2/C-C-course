Production-проверка: `/playground` — HTTP 200; `/api/health` — `{ "ok": true, "database": true, "runner": true }`. Новый runner выполнил C++20 на Clang с stdin `21`, stdout `42\n`, exitCode 0, статусом success и измеренным временем 199 мс. Этот контрольный запуск обращался к внутреннему runner и не менял пользовательский черновик.

Docker-набор проверяет все восемь комбинаций языка/стандарта/компилятора, ошибки компиляции и исполнения, stdin, разделение stdout/stderr, таймаут с закрытыми потоками, исчерпание памяти, переполнение вывода, fork bomb, запрет внешней сети и доступа к файлам хоста, отсутствие root и Docker socket, лимит размера файла, невозможность подделать статус через JSON в stdout, изоляцию файлов между тестами.

14 проверок нового HTTP-контракта запускают собранный JavaScript runner, а не только TypeScript через dev-loader. После каждого запроса проверяется отсутствие контейнеров этого экземпляра и временных папок исходников. Сквозной тест web → runner → Docker → SQLite подтверждает запуск из нового API playground и сохранение черновика/истории; учебные задания и скрытые тесты также работают.

Контроль времени/вывода расположен вне sandbox; ограничения выполняет Docker. Требования и границы модели безопасности описаны в [security.md](../security.md), HTTP-контракт — в [api.md](../api.md).
