# Историческая проверка Этапа 1

Дата: 9 сентября 2026 года.

Этот файл сохраняет снимок первоначальной проверки базового приложения. Актуальные результаты после добавления движка курса, Docker runner и grading находятся в [проверке runner](runner.md) и в `TODO.md`.

- На момент этого снимка `npm run check` включал 9 unit-тестов и 10 integration-тестов; эти числа относятся к первоначальному этапу и не описывают текущий набор проверок.
- На момент этого снимка `npm run test:runner` включал 15 тестов, включая реальные GCC/Clang, ограничения контейнера и сквозной учебный путь через HTTP API.
- На момент этого снимка опубликованное решение прошло 3/3 проверки на GCC и 3/3 на Clang. Текущий отчёт для пяти задач находится в `solutions.json`.
- `npm run format:check`: форматирование соответствует Prettier.
- Prisma: схема соответствует миграциям; тест обновления сохраняет прежние настройки, прогресс и историю попыток.
- Docker Compose: образы собраны, три миграции применены к новой SQLite, web и runner прошли healthcheck.
- Production API: C++20-пример вывел «Привет, система!» с кодом завершения 0. После перезапуска web сохранены та же попытка, исходник и локальный пользователь; `/api/health` подтверждает доступность базы и runner.

HTTP integration проверяет все восемь запрошенных страниц, неизвестные идентификаторы (404), перенаправление старого адреса урока, единственного пользователя, настройки, закладки, черновики, quiz и завершение демонстрационного урока. Тестовые базы изолированы от основной установки.

При проверке Compose исправлена публикация порта: web подключён к отдельной сети frontend и внутренней backend; runner остаётся только во внутренней сети. На хосте опубликован только web, адрес `127.0.0.1:3000`.

Визуальная проверка браузера и ручная проверка взаимодействий Monaco не выполнялись. Необязательный инструмент WebMCP включается по наличию браузерного API; его регистрация и вызов в поддерживающем браузере не проверены. Обычная работа приложения от него не зависит.
