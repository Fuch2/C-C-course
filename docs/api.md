# HTTP API

Изменяющие запросы используют `Content-Type: application/json` и тот же Origin, что `APP_ORIGIN`. Ошибки возвращаются как `{ "error": "сообщение на русском" }`, кроме API выполнения с фиксированным контрактом ниже. Профиль один локальный; регистрации, внешних аккаунтов и параметра выбора пользователя нет.

| Метод и маршрут                   | Назначение                                                        |
| --------------------------------- | ----------------------------------------------------------------- |
| `GET /api/profile`                | Автоматически создать/получить локального ученика и его состояние |
| `POST /api/profile`               | Идемпотентная инициализация интерфейса                            |
| `PATCH /api/profile`              | name, onboarded, dailyGoal, compiler, fontSize                    |
| `GET /api/course`                 | Метаданные опубликованного курса и краткие описания уроков        |
| `GET /api/search?q=...&tag=...`   | Поиск и пересечение выбранных тегов; повторяющийся параметр tag   |
| `GET /api/lessons/:id/content`    | Публичный урок без решений и скрытых тестов                       |
| `POST /api/lessons/:id/visit`     | Сохранить последний открытый урок                                 |
| `POST /api/lessons/:id/read`      | Сохранить чтение; завершить урок в режиме reading                 |
| `POST /api/lessons/:id/bookmark`  | `{ "saved": true/false }`                                         |
| `GET/POST /api/lessons/:id/draft` | Получить/сохранить source и stdin                                 |
| `POST /api/lessons/:id/quiz`      | Проверить массив answers и сохранить QuizAttempt                  |
| `POST /api/lessons/:id/submit`    | source, stdin, compiler, standard, mode: run/check                |
| `GET /api/lessons/:id/attempts`   | История: до 20 попыток, курсор before                             |
| `POST /api/lessons/:id/solution`  | `{ "confirmed": true }`: решение и разбор после проверки          |
| `GET /api/lessons/:id/stats`      | Число попыток, первая/последняя попытка, успех, hint/solution     |
| `POST /api/lessons/:id/hint`      | `{ "hintId": "..." }`: получить подсказку и отметить просмотр     |
| `GET/POST /api/playground/draft`  | Независимый черновик песочницы                                    |
| `POST /api/playground/submit`     | Свободный запуск с mode=run                                       |
| `POST /api/playground/execute`    | Выполнение по новому строгому контракту ниже                      |
| `GET /api/playground/attempts`    | История песочницы                                                 |
| `GET /api/health`                 | Состояние SQLite и runner                                         |

`GET /api/search?q=...` возвращает совместимое поле `results` со списком уроков и поле `items` со структурированными результатами типов `module`, `lesson`, `section` и `exercise`. Поисковый индекс содержит только опубликованные пользовательские данные; скрытые тесты, ответы, подсказки и эталонные решения в него не попадают.

HTTP-коды: 400 — неверные параметры, 403 — чужой Origin или рано открытый разбор, 404 — неизвестная сущность/операция, 413 — большой запрос, 415 — неподдерживаемый Content-Type, 429 — занятый слот/частые запросы, 503 — недоступный runner. Ошибка компиляции является результатом принятой попытки, а не ошибкой HTTP.

`GET /api/content-assets/...` выдаёт только разрешённые локальные изображения. Публичный урок содержит `sections`, `document`, `format`, metadata и quiz в формате `{ id, title, questions }`; правильные ответы и решения исключены.

## Выполнение C/C++

Playground отправляет `POST /api/playground/execute`. Web сохраняет черновик и попытку, передаёт запрос во внутренний `POST /execute` runner с секретным Bearer token. Ключ не передаётся браузеру или sandbox. Для проверки заданий сохранён внутренний `/check` с массивом stdin; каждый тест получает отдельный контейнер.

```json
{
  "language": "c",
  "standard": "c23",
  "sourceCode": "#include <stdio.h>\nint main(void){puts(\"Привет!\");}",
  "stdin": "",
  "compiler": "gcc",
  "timeoutMs": 2000
}
```

Все поля обязательны. `language`: `c` или `cpp`; стандарты `c11`/`c17`/`c23` для C, `c++17`/`c++20`/`c++23` для C++. Компилятор `gcc` или `clang`. Таймаут — целое число 100–10000 мс. Неизвестные поля и несовместимые язык/стандарт отклоняются. Исходник до 65536 байт UTF-8, stdin до 16384 байт.

```json
{
  "status": "success",
  "compilerOutput": "",
  "stdout": "Привет!\n",
  "stderr": "",
  "exitCode": 0,
  "executionTimeMs": 87
}
```

Время в примере условное; сервис всегда возвращает реальное измерение. `executionTimeMs` — время Docker exec программы, без компиляции и cleanup, с накладными расходами Docker. `exitCode` — код завершения программы через Docker exec; `null`, если исполнения не было либо канал остановлен лимитом. Диагностика GCC/Clang сохраняется. stdout/stderr разделены, их общий лимит 32768 байт; у диагностики компилятора отдельный такой же бюджет.

| status         | Значение                                                     |
| -------------- | ------------------------------------------------------------ |
| success        | Программа завершилась с кодом 0                              |
| compile_error  | Компилятор отклонил исходник                                 |
| runtime_error  | Ненулевой код или сигнал завершения программы                |
| timeout        | Истёк лимит времени компиляции/исполнения                    |
| resource_limit | Память, PID, размер файла, вывод или очередь превысили лимит |
| internal_error | Ошибка инфраструктуры или некорректный запрос                |

Результаты выполнения возвращаются с HTTP 200. Ошибки запроса/инфраструктуры используют HTTP 400/401/403/413/415/429/5xx и тот же фиксированный JSON ответа, с русским сообщением в stderr. Пользователь не может выбирать image, mount, environment, Docker args или compiler flags. При недоступности Docker возвращается ошибка; подмена выполнения отсутствует.

## Несколько задач в уроке

Необязательное поле `CodingExercise.diagnostics` задаёт авторский режим `sanitizers` либо `valgrind`. Сервер передаёт его только во внутренний аутентифицированный `/check`. Входной `submit` ученика и публичный `/execute` не разрешают это поле: переопределить режим нельзя. При проверке задания с диагностикой используется конечный бюджет 10 секунд на тест для санитайзеров и 30 секунд для Valgrind без изменения остальных ограничений sandbox. Подробности: [модуль памяти](memory-module.md).

Маршруты `/api/lessons/[lessonId]/draft|submit|stats|attempts|hint|solution` принимают `?exercise=ID`. Без параметра выбирается основная задача; неизвестный ID возвращает 404. `content` возвращает все публичные задачи, исключая решения, hidden tests и тексты ещё не открытых подсказок.

В SQLite основной задаче соответствует прежний ключ `lessonId`, дополнительной — `lessonId:exerciseId` в Draft, ExerciseStats и ExerciseAttempt. Схема не имеет внешней связи этих ключей с таблицей уроков; идентификаторы контента не содержат двоеточие. Закладки, quiz и LessonProgress всегда используют канонический ID урока. Практический прогресс выставляется транзакционно после наличия успешной проверки каждой задачи урока; прежний прогресс основной задачи сохраняется.
