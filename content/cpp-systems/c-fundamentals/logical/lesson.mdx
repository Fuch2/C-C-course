## Сложные условия

«Вход разрешён, если возраст не меньше 18 **и** есть билет». «Скидка, если покупатель студент **или** пенсионер». «Предупреждение, если пароль **не** содержит цифр». Реальные условия складываются из нескольких простых. Для этого в C есть три **логических оператора**.

## И, ИЛИ, НЕ

| Оператор | Название | Истина, когда…                   |
| -------- | -------- | -------------------------------- |
| `&&`     | И (AND)  | истинны **оба** операнда         |
| `\|\|`   | ИЛИ (OR) | истинен **хотя бы один** операнд |
| `!`      | НЕ (NOT) | операнд **ложен**                |

Как и сравнения, логические операторы возвращают 1 или 0. Полные таблицы истинности:

| `a` | `b` | `a && b` | `a \|\| b` | `!a` |
| --- | --- | -------- | ---------- | ---- |
| 0   | 0   | 0        | 0          | 1    |
| 0   | 1   | 0        | 1          | 1    |
| 1   | 0   | 0        | 1          | 0    |
| 1   | 1   | 1        | 1          | 0    |

```c
#include <stdio.h>

int main(void) {
    int age = 20, has_ticket = 1, is_student = 0, is_pensioner = 0;
    printf("%d\n", age >= 18 && has_ticket);
    printf("%d\n", is_student || is_pensioner);
    printf("%d\n", !has_ticket);
    return 0;
}
```

Вывод:

```text
1
0
0
```

Символ `||` — две вертикальные черты; на клавиатуре вертикальная черта обычно над клавишей Enter (Shift + обратная косая черта). Одиночные `&` и `|` — тоже операторы, но **побитовые**, с другим смыслом; о них в модуле «Углублённый C». Для условий всегда используйте двойные.

## Проверка диапазона

Самое частое применение `&&` — проверить, что значение лежит в диапазоне. Помните, что `1 <= x <= 10` в C не работает? Правильная запись:

```c
#include <stdio.h>

int main(void) {
    int x = 50;
    printf("%d\n", 1 <= x && x <= 10);   // внутри [1, 10]?
    printf("%d\n", x < 1 || x > 10);     // снаружи?
    return 0;
}
```

Вывод:

```text
0
1
```

Удобно записывать границы так, чтобы `x` стоял «между» ними, как на числовой прямой: `1 <= x && x <= 10`.

## Приоритет

Логические операторы имеют **более низкий** приоритет, чем сравнения и арифметика, поэтому `age >= 18 && has_ticket` вычисляется как `(age >= 18) && has_ticket` без скобок. Полный порядок от высшего к низшему:

| Приоритет | Операторы            |
| --------- | -------------------- |
| 1         | `!`, унарный минус   |
| 2         | `*`, `/`, `%`        |
| 3         | `+`, `-`             |
| 4         | `<`, `<=`, `>`, `>=` |
| 5         | `==`, `!=`           |
| 6         | `&&`                 |
| 7         | `\|\|`               |

Две ловушки:

1. **`&&` выполняется раньше `||`**, как умножение раньше сложения. `a || b && c` означает `a || (b && c)`. Когда в одном условии смешаны `&&` и `||`, ставьте скобки — GCC даже предупредит, если их нет.
2. **`!` выполняется раньше сравнения.** `!x == 5` означает `(!x) == 5`, а не `!(x == 5)`. Для отрицания сравнения используйте `!=` или скобки.

## Вычисление по короткой схеме

`&&` и `||` вычисляют правый операнд **только если он нужен**:

- если левая часть `&&` ложна, результат уже 0, правая часть не вычисляется;
- если левая часть `||` истинна, результат уже 1, правая часть не вычисляется.

Это не просто оптимизация — на этом строятся безопасные проверки:

```c
#include <stdio.h>

int main(void) {
    int a = 10, b = 0;
    printf("%d\n", b != 0 && a / b > 2);
    return 0;
}
```

Вывод:

```text
0
```

`b != 0` ложно, поэтому деление `a / b` даже не выполняется, и программа не падает. Если поменять операнды местами — `a / b > 2 && b != 0`, — деление на ноль произойдёт раньше проверки. **Порядок операндов имеет значение:** сначала проверка, потом действие, которое без неё опасно.

## Законы де Моргана

Как сформулировать «не (студент или пенсионер)»? Отрицание меняет `&&` на `||` и наоборот:

- `!(a && b)` — то же, что `!a || !b`;
- `!(a || b)` — то же, что `!a && !b`.

Пример: «x вне диапазона [1, 10]» — это `!(1 <= x && x <= 10)`, или, по де Моргану, `x < 1 || x > 10`. Второй вариант без отрицания читается легче.

## Классика: високосный год

Год високосный, если он делится на 4, но не на 100, **или** делится на 400. 2024 — високосный, 1900 — нет (делится на 100), 2000 — да (делится на 400).

```c
#include <stdio.h>

int main(void) {
    int year = 1900;
    int leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
    printf("%d\n", leap);
    return 0;
}
```

Вывод:

```text
0
```

Скобки вокруг `&&` здесь не обязательны по приоритету, но делают формулу понятной и убирают предупреждение компилятора.

## «Исключающее ИЛИ» для условий

Иногда нужно «ровно одно из двух»: ровно один из игроков сделал ход, ровно одна лампа горит. Отдельного логического оператора для этого в C нет, но есть простой приём: два логических значения различаются — значит, истинно ровно одно:

```c
#include <stdio.h>

int main(void) {
    int a = 4, b = 7;
    int exactly_one_even = (a % 2 == 0) != (b % 2 == 0);
    printf("%d\n", exactly_one_even);
    return 0;
}
```

Вывод:

```text
1
```

## Частые ошибки

<CommonMistake title="& вместо && и | вместо ||">

Одиночные операторы побитовые: они вычисляют обе части и работают с битами. `2 & 1` равно 0, хотя оба числа «истинны». Для условий — только `&&` и `||`.

</CommonMistake>

<CommonMistake title="Сравнение с несколькими значениями">

`x == 1 || 2` — это `(x == 1) || 2`, и такое выражение всегда истинно, ведь 2 ≠ 0. Нужно `x == 1 || x == 2`.

</CommonMistake>

<CommonMistake title="Проверка после опасного действия">

`a / b > 2 && b != 0` — деление на ноль случится до проверки. Сначала проверка, потом действие.

</CommonMistake>

<CommonMistake title="Смешивание && и || без скобок">

`a || b && c` — это `a || (b && c)`. Если вы имели в виду `(a || b) && c`, результат будет другим. Ставьте скобки всегда, когда смешиваете.

</CommonMistake>

## Практика

Результаты по-прежнему печатаются как 1 или 0.

1. **Високосный год**.
2. **Существует ли треугольник** — три неравенства.
3. **Точка в прямоугольнике** — проверка двух диапазонов.
4. **Ровно один чётный** — «исключающее ИЛИ».
5. **Безопасная делимость** — короткая схема вычисления.

## Итоги

- `&&` — И, `||` — ИЛИ, `!` — НЕ; результат 1 или 0.
- Диапазон: `low <= x && x <= high`; вне диапазона: `x < low || x > high`.
- Приоритет: `!` → арифметика → сравнения → `&&` → `||`. Смешивая `&&` и `||`, ставьте скобки.
- Короткая схема: правая часть `&&` не вычисляется, если левая ложна; правая часть `||` — если левая истинна. Сначала проверка, потом опасное действие.
- Де Морган: `!(a && b) == !a || !b`, `!(a || b) == !a && !b`.
- «Ровно одно из двух» — `(условие1) != (условие2)`.
