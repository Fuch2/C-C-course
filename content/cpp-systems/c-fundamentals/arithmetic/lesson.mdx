## Арифметика в C: знакомая и не очень

Сложение, вычитание и умножение в C работают как в школе. Сюрпризы начинаются с делением: у целых чисел оно отбрасывает дробную часть, а остаток от деления вычисляется отдельным оператором `%`. Эти два оператора — `/` и `%` — основа огромного количества задач: разбор числа на цифры, перевод секунд в часы, чётность, циклы по кругу. В этом уроке разберём их подробно.

## Пять арифметических операторов

| Оператор | Действие           | Пример  | Результат |
| -------- | ------------------ | ------- | --------- |
| `+`      | сложение           | `7 + 2` | `9`       |
| `-`      | вычитание          | `7 - 2` | `5`       |
| `*`      | умножение          | `7 * 2` | `14`      |
| `/`      | деление            | `7 / 2` | `3`       |
| `%`      | остаток от деления | `7 % 2` | `1`       |

```c
#include <stdio.h>

int main(void) {
    int a = 17, b = 5;
    printf("%d %d %d %d %d\n", a + b, a - b, a * b, a / b, a % b);
    return 0;
}
```

Вывод:

```text
22 12 85 3 2
```

## Целочисленное деление

Если оба операнда целые, результат деления тоже целый: **дробная часть отбрасывается**. Не округляется, а именно отбрасывается: `17 / 5` равно 3, хотя точное значение 3,4; `19 / 5` тоже равно 3, хотя 3,8 ближе к четырём.

С отрицательными числами отбрасывание идёт **в сторону нуля**: `-17 / 5` равно `-3`, а не `-4`.

```c
#include <stdio.h>

int main(void) {
    printf("%d %d %d\n", 19 / 5, -19 / 5, 4 / 5);
    return 0;
}
```

Вывод:

```text
3 -3 0
```

`4 / 5` равно нулю — частая причина ошибок вроде «процент всегда получается 0». Если нужен дробный результат, нужны дробные числа (урок «Дробные числа»). Если нужен целый процент, сначала умножайте, потом делите: `done * 100 / total`, а не `done / total * 100`.

## Остаток от деления `%`

`a % b` — остаток от деления `a` на `b`. Проверка всегда одна: `(a / b) * b + a % b == a`.

```c
#include <stdio.h>

int main(void) {
    printf("%d %d %d %d\n", 17 % 5, 20 % 5, 3 % 5, -17 % 5);
    return 0;
}
```

Вывод:

```text
2 0 3 -2
```

- `20 % 5 == 0` — 20 делится на 5 без остатка. Так проверяют делимость.
- `3 % 5 == 3` — если делимое меньше делителя, остаток равен самому делимому.
- `-17 % 5 == -2` — у отрицательного делимого остаток тоже отрицательный (так как `-17 / 5 == -3` и `-3 * 5 + (-2) == -17`).

Оператор `%` работает только с целыми числами.

<Concept title="Три главных применения %">

1. **Делимость:** `n % 2 == 0` — n чётное, `n % 3 == 0` — делится на 3.
2. **Последняя цифра:** `n % 10` — последняя цифра числа, `n % 100` — две последние.
3. **Движение по кругу:** часы (`% 24`), минуты (`% 60`), дни недели (`% 7`).

</Concept>

## Разбор числа на цифры

Комбинация `/ 10` и `% 10` позволяет разобрать число на цифры. `% 10` даёт последнюю цифру, `/ 10` — «отрезает» её:

```c
#include <stdio.h>

int main(void) {
    int n = 4725;
    int units = n % 10;            // 5
    int tens = n / 10 % 10;        // 472 % 10 = 2
    int hundreds = n / 100 % 10;   // 47 % 10 = 7
    int thousands = n / 1000;      // 4
    printf("%d %d %d %d\n", thousands, hundreds, tens, units);
    return 0;
}
```

Вывод:

```text
4 7 2 5
```

Формула `n / 10^k % 10` даёт k-ю цифру справа (считая с нуля). Запомните этот приём — он встретится в задачах про номера, даты, контрольные суммы и палиндромы.

## Перевод единиц: секунды в часы, минуты, секунды

```c
#include <stdio.h>

int main(void) {
    int total = 7384;                 // секунд
    int hours = total / 3600;         // 2
    int minutes = total % 3600 / 60;  // 184 / 60 = 3
    int seconds = total % 60;         // 4
    printf("%d:%02d:%02d\n", hours, minutes, seconds);
    return 0;
}
```

Вывод:

```text
2:03:04
```

`total % 3600` — секунды, оставшиеся после полных часов; делим их на 60 — получаем минуты. Секунды — остаток от деления общего числа на 60.

## Приоритет операций

Порядок вычислений в C такой же, как в математике:

| Приоритет | Операторы     | Порядок при равенстве |
| --------- | ------------- | --------------------- |
| высший    | `( )`         | изнутри наружу        |
|           | унарный `-`   | справа налево         |
|           | `*`, `/`, `%` | слева направо         |
| низший    | `+`, `-`      | слева направо         |

```c
#include <stdio.h>

int main(void) {
    printf("%d\n", 2 + 3 * 4);
    printf("%d\n", (2 + 3) * 4);
    printf("%d\n", 100 / 10 / 2);
    printf("%d\n", 7 - 3 - 2);
    printf("%d\n", 10 / 3 * 3);
    return 0;
}
```

Вывод:

```text
14
20
5
2
9
```

- `100 / 10 / 2` — слева направо: `(100 / 10) / 2 = 5`, а не `100 / 5 = 20`.
- `10 / 3 * 3` — сначала `10 / 3 = 3`, затем `3 * 3 = 9`. Целочисленное деление «съело» единицу.

Если сомневаетесь в порядке — ставьте скобки. Лишние скобки не замедляют программу, но делают намерение очевидным.

## Округление вверх при делении

Задача: 23 человека едут на экскурсию, в автобус помещается 10. Сколько нужно автобусов? `23 / 10` даёт 2 — а нужно 3. Чтобы округлить результат деления **вверх** (для неотрицательных чисел), используют приём:

```c
#include <stdio.h>

int main(void) {
    int people = 23, capacity = 10;
    int buses = (people + capacity - 1) / capacity;
    printf("%d\n", buses);
    return 0;
}
```

Вывод:

```text
3
```

Прибавление `capacity - 1` «докручивает» любой ненулевой остаток до следующего целого. Проверьте: для 20 человек получится `29 / 10 = 2` — ровно два автобуса, лишний не появляется.

## Деление на ноль

Деление и остаток от деления на ноль — ошибка. Для целых чисел программа аварийно завершится, как вы видели в модуле «Старт». Если делитель приходит из ввода и может оказаться нулём, его нужно проверить до деления — это вы научитесь делать в уроке `if`.

## Частые ошибки

<CommonMistake title="Деление раньше умножения при процентах">

`part / whole * 100` при `part < whole` даёт 0. Умножайте сначала: `part * 100 / whole`.

</CommonMistake>

<CommonMistake title="Ожидание округления">

`19 / 5` равно 3, а не 4. Целочисленное деление отбрасывает дробную часть, а не округляет по правилам математики.

</CommonMistake>

<CommonMistake title="Остаток отрицательного числа">

`-7 % 2` равно `-1`, а не `1`. Проверка нечётности `n % 2 == 1` не сработает для отрицательных чисел; надёжнее `n % 2 != 0`.

</CommonMistake>

<CommonMistake title="Забытые скобки в среднем">

`a + b / 2` — это `a + (b / 2)`. Среднее — `(a + b) / 2`.

</CommonMistake>

## Практика

1. **Цифры числа** — разберите трёхзначное число.
2. **Секундомер** — переведите секунды в часы, минуты и секунды.
3. **Сумма цифр** — четырёхзначного числа.
4. **Число задом наперёд** — переверните трёхзначное число.
5. **Автобусы** — деление с округлением вверх.

## Итоги

- Операторы: `+`, `-`, `*`, `/`, `%`. Приоритет как в математике; при равном приоритете — слева направо.
- Деление целых отбрасывает дробную часть в сторону нуля: `19 / 5 == 3`, `-19 / 5 == -3`.
- `%` — остаток: `n % 10` — последняя цифра, `n % 2 == 0` — чётность, `% 60` и `% 24` — движение по кругу.
- `n / 10` отбрасывает последнюю цифру; вместе с `% 10` это разбор числа на цифры.
- Округление вверх для неотрицательных: `(a + b - 1) / b`.
- Делить на ноль нельзя — программа аварийно завершится.
