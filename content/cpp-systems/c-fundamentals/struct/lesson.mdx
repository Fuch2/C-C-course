## Зачем объединять данные

Представьте программу, которая хранит учеников: имя, возраст и средний балл. С тем, что вы знаете, пришлось бы завести три массива:

```c
char names[30][32];
int ages[30];
double scores[30];
```

Ученик номер `i` «размазан» по трём массивам, и программист должен сам следить, чтобы индексы совпадали. Чтобы отсортировать учеников по баллу, придётся переставлять элементы во всех трёх массивах одновременно. А функция, печатающая ученика, получит три параметра вместо одного.

**Структура** (`struct`) решает эту проблему: она объединяет несколько значений разных типов в один новый тип. Ученик становится одной переменной, которую можно передать в функцию, положить в массив и скопировать целиком.

## Объявление структуры

Сначала описывают, из каких **полей** состоит структура, затем создают переменные этого типа:

```c
#include <stdio.h>

struct point {
    int x;
    int y;
};

int main(void) {
    struct point p;
    p.x = 3;
    p.y = 4;
    printf("(%d, %d)\n", p.x, p.y);
    p.x = p.x * 10;
    printf("x = %d\n", p.x);
    return 0;
}
```

Вывод:

```text
(3, 4)
x = 30
```

Разберём:

- `struct point { … };` — описание нового типа. `point` — имя структуры (его называют тегом), `x` и `y` — поля. **Точка с запятой после `}` обязательна.**
- Описание само по себе не создаёт переменных и не занимает памяти — это чертёж.
- `struct point p;` — переменная типа `struct point`. В C слово `struct` — часть имени типа, писать просто `point p;` нельзя.
- Оператор «точка» `p.x` даёт доступ к полю. С полем можно делать всё то же, что с обычной переменной того же типа: присваивать, читать, передавать в `scanf` как `&p.x`.

Описание структуры обычно ставят в начале файла, до функций, чтобы тип был виден везде.

## Инициализация

Как и массив, структуру можно заполнить сразу при объявлении:

```c
#include <stdio.h>

struct point {
    int x;
    int y;
};

int main(void) {
    struct point a = {3, 4};             // по порядку полей
    struct point b = {.y = 7, .x = -1};  // по именам полей
    struct point c = {.x = 5};           // y получит 0
    struct point origin = {0};           // все поля — нули
    printf("%d %d | %d %d | %d %d | %d %d\n",
           a.x, a.y, b.x, b.y, c.x, c.y, origin.x, origin.y);
    return 0;
}
```

Вывод:

```text
3 4 | -1 7 | 5 0 | 0 0
```

Запись `{.y = 7, .x = -1}` называется **назначенным инициализатором**: поля указаны по именам, поэтому порядок не важен, а код понятнее, особенно когда полей много. Поля, которые не упомянуты, становятся нулями — как элементы частично инициализированного массива.

Без инициализации локальная структура содержит мусор, как и любая локальная переменная.

## Присваивание копирует всё

Одну структуру можно присвоить другой — копируются все поля. Даже массивы внутри структуры, хотя сами массивы присваивать нельзя:

```c
#include <stdio.h>

struct student {
    char name[16];
    int score;
};

int main(void) {
    struct student a = {"Anna", 87};
    struct student b = a;       // полная копия, включая массив name
    b.score = 95;
    b.name[0] = 'H';
    printf("%s %d\n", a.name, a.score);
    printf("%s %d\n", b.name, b.score);
    return 0;
}
```

Вывод:

```text
Anna 87
Hnna 95
```

`b` — самостоятельная копия: изменения в ней не затрагивают `a`. Это важное отличие от массивов и указателей.

А вот сравнить структуры оператором `==` нельзя:

```c
#include <stdio.h>

struct point {
    int x;
    int y;
};

int main(void) {
    struct point a = {1, 2};
    struct point b = {1, 2};
    if (a == b) {          // Ошибка компиляции: invalid operands to binary ==
        printf("равны\n");
    }
    return 0;
}
```

Язык не знает, что значит «равны» для вашей структуры: может быть, у учеников достаточно совпадения имени? Сравнение пишут сами — функцией, сравнивающей нужные поля.

## Структура как параметр функции

Структуры передают в функции и возвращают из них, как обычные значения. При передаче **по значению** функция получает копию:

```c
#include <stdio.h>

struct point {
    int x;
    int y;
};

struct point shifted(struct point p, int dx, int dy) {
    p.x += dx;              // меняется копия
    p.y += dy;
    return p;
}

int manhattan(struct point a, struct point b) {
    int dx = a.x > b.x ? a.x - b.x : b.x - a.x;
    int dy = a.y > b.y ? a.y - b.y : b.y - a.y;
    return dx + dy;
}

int main(void) {
    struct point start = {1, 2};
    struct point finish = shifted(start, 3, -5);
    printf("start: (%d, %d)\n", start.x, start.y);
    printf("finish: (%d, %d)\n", finish.x, finish.y);
    printf("distance: %d\n", manhattan(start, finish));
    return 0;
}
```

Вывод:

```text
start: (1, 2)
finish: (4, -3)
distance: 8
```

`start` не изменилась: `shifted` работала с копией и вернула новую точку. Возврат структуры — простой способ вернуть из функции **несколько значений** сразу.

## Указатель на структуру и оператор `->`

Чтобы функция изменила саму структуру, ей передают указатель — как в уроке «Указатели и функции». Доступ к полю через указатель можно записать как `(*p).x`, но это неудобно, поэтому есть отдельный оператор `->`:

```c
#include <stdio.h>

struct account {
    int id;
    long long balance;
};

void deposit(struct account *acc, long long amount) {
    acc->balance += amount;      // то же, что (*acc).balance += amount
}

void print_account(const struct account *acc) {
    printf("#%d: %lld\n", acc->id, acc->balance);
}

int main(void) {
    struct account mine = {42, 1000};
    deposit(&mine, 250);
    deposit(&mine, -100);
    print_account(&mine);
    return 0;
}
```

Вывод:

```text
#42: 1150
```

- `acc->balance` читается «поле `balance` структуры, на которую указывает `acc`».
- Скобки в `(*acc).balance` обязательны: точка связывает сильнее звёздочки, и `*acc.balance` означало бы «разыменовать поле `balance`» — ошибка компиляции.
- `print_account` принимает `const struct account *`: функция только читает, и компилятор это гарантирует. Так передают и большие структуры — копировать указатель (8 байт) дешевле, чем всю структуру.

Правило выбора: **точка** — для самой структуры, **стрелка** — для указателя на структуру.

## Массив структур

Структуры особенно удобны в массивах: каждый элемент — запись целиком. Вот программа, читающая учеников и находящая лучшего:

```c
#include <stdio.h>

struct student {
    char name[32];
    int score;
};

int main(void) {
    struct student group[30];
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%31s %d", group[i].name, &group[i].score);
    }
    const struct student *best = &group[0];
    int total = 0;
    for (int i = 0; i < n; i++) {
        total += group[i].score;
        if (group[i].score > best->score) {
            best = &group[i];
        }
    }
    printf("Лучший: %s (%d)\n", best->name, best->score);
    printf("Средний балл: %.1f\n", (double)total / n);
    return 0;
}
```

Ввод:

```text
3
Anna 87
Boris 92
Vera 78
```

Вывод:

```text
Лучший: Boris (92)
Средний балл: 85.7
```

Обратите внимание на записи:

- `group[i].name` — массив `char`, поэтому в `scanf` он передаётся без `&`; `&group[i].score` — адрес поля `int`.
- `best` — указатель на элемент массива структур, поэтому к полям обращаемся через `->`.

## Структура внутри структуры

Полем структуры может быть другая структура. Прямоугольник со сторонами, параллельными осям, задаётся двумя углами:

```c
#include <stdio.h>

struct point {
    int x;
    int y;
};

struct rect {
    struct point min;   // левый нижний угол
    struct point max;   // правый верхний угол
};

int area(struct rect r) {
    return (r.max.x - r.min.x) * (r.max.y - r.min.y);
}

int contains(struct rect r, struct point p) {
    return r.min.x <= p.x && p.x <= r.max.x && r.min.y <= p.y && p.y <= r.max.y;
}

int main(void) {
    struct rect room = {{0, 0}, {5, 3}};
    struct point lamp = {.x = 2, .y = 4};
    printf("%d %d\n", area(room), contains(room, lamp));
    room.max.y = 4;
    printf("%d %d\n", area(room), contains(room, lamp));
    return 0;
}
```

Вывод:

```text
15 0
20 1
```

`room.max.y` читается слева направо: у прямоугольника `room` взять угол `max`, у угла — координату `y`. Вложенные фигурные скобки `{{0, 0}, {5, 3}}` инициализируют вложенные структуры по порядку.

## Размер структуры

Поля структуры лежат в памяти по порядку объявления. Но `sizeof` структуры может оказаться **больше** суммы размеров полей:

```c
#include <stdio.h>

struct sample {
    char tag;
    int value;
};

int main(void) {
    printf("%zu %zu %zu\n", sizeof(char), sizeof(int), sizeof(struct sample));
    return 0;
}
```

Вывод:

```text
1 4 8
```

Компилятор вставил между `tag` и `value` три неиспользуемых байта, чтобы `int` начинался с адреса, кратного 4: так процессор читает его быстрее. Это называется **выравниванием**; подробно оно разбирается в модуле «Память и указатели». Пока достаточно правила: размер структуры узнают через `sizeof`, а не складывают размеры полей вручную.

## Частые ошибки

<CommonMistake title="Нет точки с запятой после описания">

`struct point { int x; int y; }` без `;` в конце — компилятор посчитает, что следующая строка продолжает объявление, и выдаст ошибку в совсем другом месте. Если ошибка указывает на строку сразу после структуры, проверьте `;`.

</CommonMistake>

<CommonMistake title="Тип без слова struct">

`point p;` — ошибка компиляции `unknown type name ‘point’`. Тип называется `struct point`. В следующих уроках вы узнаете, как дать ему короткое имя через `typedef`.

</CommonMistake>

<CommonMistake title="Сравнение структур через ==">

Не компилируется. Сравнивайте нужные поля: `a.x == b.x && a.y == b.y`.

</CommonMistake>

<CommonMistake title="Точка вместо стрелки">

Если `p` — указатель на структуру, `p.x` не компилируется. Пишите `p->x`. И наоборот: для самой структуры `s->x` — ошибка, нужна точка.

</CommonMistake>

<CommonMistake title="Ожидание, что функция изменит структуру">

Функция `void reset(struct point p) { p.x = 0; }` меняет копию. Чтобы изменить оригинал, передайте указатель: `void reset(struct point *p) { p->x = 0; }` и вызов `reset(&pt)`.

</CommonMistake>

## Итоги

- `struct имя { поля };` описывает новый тип; переменная объявляется как `struct имя x;`.
- Поля доступны через точку: `p.x`; через указатель на структуру — стрелкой: `ptr->x`.
- Структуру инициализируют списком `{3, 4}` или по именам полей `{.x = 3, .y = 4}`; неуказанные поля становятся нулями.
- Присваивание и передача по значению копируют все поля, включая массивы; `==` для структур не работает.
- Чтобы функция изменила структуру, передайте указатель; для чтения больших структур — `const`-указатель.
- Структуры можно складывать в массивы и вкладывать друг в друга; размер узнают через `sizeof`.
