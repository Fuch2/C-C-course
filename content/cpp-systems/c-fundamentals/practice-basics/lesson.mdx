## Практикум: вычисления

Позади первый раздел модуля: вывод, переменные, арифметика, ввод, целые и дробные типы, константы. Этот урок целиком состоит из задач. Они сложнее упражнений в уроках: в условии не сказано, какой оператор применить, — это нужно понять самостоятельно. Именно так выглядят настоящие задачи.

## Как решать задачу

Опытные программисты не начинают с кода. Перед тем как писать, пройдите пять шагов:

1. **Вход и выход.** Что именно подаётся на вход, в каком формате? Что нужно напечатать — одно число, несколько, с каким разделителем?
2. **Решение на бумаге.** Решите пример из условия вручную, без компьютера. Если не получается вручную, не получится и программой.
3. **Формула.** Запишите, какими действиями вы получили ответ. Это и есть алгоритм.
4. **Типы.** Оцените самые большие значения, включая промежуточные. Поместится ли в `int`? Нужен ли `long long` или `double`?
5. **Особые случаи.** Ноль, минимальные и максимальные значения из ограничений, равные значения. Проверьте формулу на них до отправки.

<Tip title="Если решение не проходит тесты">

Запустите программу на своих данных из пункта 5 и сравните с ответом, который вы посчитали вручную. Найдите первый тест, на котором результаты расходятся, и сделайте трассировку именно для него.

</Tip>

## Разбор задачи-образца

**Условие.** Поезд отправляется в `h` часов `m` минут и идёт `t` минут. Во сколько он прибудет? Время в пути может быть больше суток; вывести время на часах в формате `Ч:ММ`.

1. **Вход:** три целых числа. **Выход:** время вида `9:05`.
2. **Вручную:** отправление 22:30, в пути 150 минут. 22:30 + 2 ч 30 мин = 25:00 — на часах 1:00.
3. **Формула:** переведём всё в минуты с полуночи: `start = h * 60 + m`, `arrival = start + t`. Часы на циферблате — `arrival / 60 % 24`, минуты — `arrival % 60`.
4. **Типы:** если `t` до миллиарда, `arrival` до 10⁹ + 1440 — помещается в `int`.
5. **Особые случаи:** `t = 0`; прибытие ровно в полночь; путь в несколько суток.

```c
#include <stdio.h>

int main(void) {
    int h, m, t;
    scanf("%d %d %d", &h, &m, &t);
    int arrival = h * 60 + m + t;
    printf("%d:%02d\n", arrival / 60 % 24, arrival % 60);
    return 0;
}
```

Ввод:

```text
22 30 150
```

Вывод:

```text
1:00
```

Главная идея — **перейти к единой единице измерения** (минутам), посчитать, а потом вернуться обратно. Этот приём решает почти все задачи про время, расстояния и деньги.

## Задачи

1. **Часы на табло** — время после большого числа минут.
2. **Сдача монетами** — наименьшее число монет.
3. **Парты** — округление вверх для трёх классов.
4. **День недели** — движение по кругу.
5. **Вклад** — сложные проценты с `pow`.
6. **Пешеход** — дробное время в пути и перевод в часы и минуты.
