## Программа, которая слушает

Вы уже не раз копировали строку `scanf("%d", &n);` из заготовок. Пришло время разобраться, как она работает. `scanf` — зеркало `printf`: `printf` превращает числа в текст и выводит его, а `scanf` читает текст из **стандартного ввода** (stdin) и превращает его в числа. Во всех задачах курса входные данные приходят именно через stdin — проверяющая система подаёт их программе так, будто их набрали на клавиатуре.

## Чтение одного числа

```c
#include <stdio.h>

int main(void) {
    int age;
    scanf("%d", &age);
    printf("Через год вам будет %d\n", age + 1);
    return 0;
}
```

Ввод:

```text
19
```

Вывод:

```text
Через год вам будет 20
```

Строка формата `"%d"` говорит: «прочитай целое число». После неё указывается, **куда** его положить: `&age`.

## Зачем нужен `&`

Когда вы пишете `printf("%d", age)`, функция получает **значение** переменной — число 19. Ей этого достаточно: она его просто печатает.

`scanf` нужно не значение, а **место** в памяти, куда записать прочитанное число. Знак `&` перед именем означает «адрес переменной» — номер ячейки памяти, где она хранится. Если написать `scanf("%d", age)` без `&`, функция получит текущее значение — мусор из неинициализированной переменной — и попытается записать число по этому случайному «адресу». Программа, скорее всего, аварийно завершится.

Компилятор в строгом режиме предупредит:

```text
warning: format '%d' expects argument of type 'int *', but argument 2 has type 'int'
```

`int *` — это тип «адрес переменной типа int». Подробно адреса и указатели разберём в последнем разделе модуля, а пока правило простое: **в scanf перед именем переменной ставится `&`**.

## Несколько значений и пробельные символы

Чтобы прочитать несколько чисел, указывают несколько спецификаторов и несколько адресов:

```c
#include <stdio.h>

int main(void) {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);
    printf("%d\n", a + b + c);
    return 0;
}
```

Ввод:

```text
10
20   30
```

Вывод:

```text
60
```

Обратите внимание на ввод: числа разделены и переводом строки, и несколькими пробелами, а программа всё равно прочитала их правильно. Спецификатор `%d` **пропускает любые пробельные символы** — пробелы, табуляции, переводы строк — перед числом. Поэтому `scanf("%d%d%d", ...)` и `scanf("%d %d %d", ...)` работают одинаково, а данные можно подавать хоть в одну строку, хоть в столбик.

Это удобно в задачах: если в условии сказано «в первой строке n, во второй — два числа», читать можно одним вызовом `scanf("%d %d %d", ...)`, не думая о строках.

## Обычные символы в строке формата

Если в строке формата стоит обычный символ, `scanf` ожидает **ровно этот символ** во вводе и пропускает его. Так читают время, даты, дроби:

```c
#include <stdio.h>

int main(void) {
    int hours, minutes;
    scanf("%d:%d", &hours, &minutes);
    printf("%d\n", hours * 60 + minutes);
    return 0;
}
```

Ввод:

```text
13:45
```

Вывод:

```text
825
```

```c
#include <stdio.h>

int main(void) {
    int day, month, year;
    scanf("%d.%d.%d", &day, &month, &year);
    printf("%d-%02d-%02d\n", year, month, day);
    return 0;
}
```

Ввод:

```text
09.10.2026
```

Вывод:

```text
2026-10-09
```

Точка в формате «съедает» точку во вводе. Ведущий ноль в `09` не мешает: `%d` читает десятичное число, и `09` — это просто 9.

## Сколько удалось прочитать

`scanf` не только записывает значения, но и **возвращает** число — сколько спецификаторов удалось успешно заполнить. Посмотрим на это значение:

```c
#include <stdio.h>

int main(void) {
    int a = 0, b = 0;
    int count = scanf("%d %d", &a, &b);
    printf("прочитано: %d, a = %d, b = %d\n", count, a, b);
    return 0;
}
```

Ввод:

```text
5 abc
```

Вывод:

```text
прочитано: 1, a = 5, b = 0
```

Первое число прочиталось, а на `abc` чтение остановилось: это не число. `scanf` вернул 1, а `b` осталась нетронутой. Попробуйте в поле ввода разные варианты: `5 7`, пустой ввод, `x`. При пустом вводе `scanf` вернёт особое значение `EOF` (обычно −1) — «ввод закончился».

Сейчас нам нечего делать с этим числом, но после урока `if` вы будете проверять его, чтобы программа не работала с мусором. А в уроке «Функция main и чтение до конца ввода» с помощью этого значения будете читать данные, количество которых заранее неизвестно.

## Чтение символа: `%c`

`%c` читает **один любой символ**, включая пробел и перевод строки. В отличие от `%d`, он не пропускает пробельные символы. Если перед `%c` нужно пропустить пробелы, ставят пробел в формате: `" %c"`.

```c
#include <stdio.h>

int main(void) {
    int a, b;
    char op;
    scanf("%d %c %d", &a, &op, &b);
    printf("%d %c %d\n", a, op, b);
    return 0;
}
```

Ввод:

```text
12 * 4
```

Вывод:

```text
12 * 4
```

Пробел перед `%c` в формате пропустил пробел после `12`, и в `op` попал символ `*`. Без этого пробела `op` получил бы сам пробел. Тип `char` и символы подробно разберём в уроке «Символы»; а превращать такой ввод в калькулятор вы научитесь в уроке `switch`.

## Чего не делать

<CommonMistake title="Забыть &">

`scanf("%d", n);` — функция получит значение вместо адреса. Это приводит к аварии или порче памяти. Компилятор предупреждает: `expects argument of type 'int *'`.

</CommonMistake>

<CommonMistake title="Поставить \n в конце формата">

`scanf("%d\n", &n);` — пробельный символ в формате означает «пропусти все пробельные символы». При вводе с клавиатуры программа будет ждать, пока вы не введёте что-то непробельное, и покажется зависшей. Перевод строки нужен в `printf`, а не в `scanf`.

</CommonMistake>

<CommonMistake title="Печатать приглашение к вводу">

`printf("Введите число: ");` перед `scanf` полезен в интерактивной программе, но в задачах курса это лишний текст в выводе, и тесты не пройдут.

</CommonMistake>

<CommonMistake title="Путать формат ввода">

Если во вводе время записано как `13:45`, а формат `"%d %d"`, второе число не прочитается: после 13 стоит двоеточие, а не число. Строка формата должна повторять структуру ввода.

</CommonMistake>

## Практика

1. **Время в минуты** — разбор записи ЧЧ:ММ.
2. **Дата в формате ISO** — переставьте день, месяц и год.
3. **Сумма пяти чисел** — данные в произвольных строках.
4. **Сложение дробей** — ввод вида `a/b c/d`.
5. **Координаты** — ввод с текстом `x=… y=…`.

## Итоги

- `scanf` читает из стандартного ввода и записывает значения по адресам переменных — перед именем нужен `&`.
- `%d` пропускает пробелы, табуляции и переводы строк перед числом, поэтому расположение данных по строкам не важно.
- Обычные символы в формате должны совпасть с вводом: `"%d:%d"` читает время, `"%d.%d.%d"` — дату.
- `scanf` возвращает количество успешно прочитанных значений или `EOF`, если ввод закончился.
- `%c` читает любой символ; чтобы пропустить пробелы перед ним, пишите `" %c"`.
- Не добавляйте `\n` в формат `scanf` и не печатайте приглашений в задачах.
