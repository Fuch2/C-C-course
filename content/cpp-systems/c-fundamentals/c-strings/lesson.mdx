## Как в C устроен текст

Во многих языках есть встроенный тип «строка». В C его нет. Строка в C — это **массив символов, в конце которого стоит символ с кодом 0**. Этот завершающий символ записывается как `'\0'` и называется **нуль-терминатором**. По нему все функции понимают, где строка заканчивается.

Такое устройство очень простое и эффективное, но требует аккуратности: о размере массива и о завершающем нуле программист заботится сам. Ошибки здесь — источник большинства уязвимостей в программах на C.

## Строковый литерал и массив символов

```c
#include <stdio.h>

int main(void) {
    char greeting[] = "Hello";
    printf("%s\n", greeting);
    printf("%zu\n", sizeof(greeting));
    printf("%c %d\n", greeting[1], greeting[5]);
    return 0;
}
```

Вывод:

```text
Hello
6
e 0
```

Строка `"Hello"` состоит из пяти букв, но массив занимает **6** байт: компилятор автоматически добавил `'\0'` в конец.

<MemoryDiagram title="Массив greeting в памяти">

| Индекс | 0   | 1   | 2   | 3   | 4   | 5    |
| ------ | --- | --- | --- | --- | --- | ---- |
| Символ | `H` | `e` | `l` | `l` | `o` | `\0` |
| Код    | 72  | 101 | 108 | 108 | 111 | 0    |

</MemoryDiagram>

`%s` в `printf` печатает символы, начиная с указанного места, **до первого `'\0'`**. Если нуля нет, `printf` пойдёт дальше по памяти и напечатает мусор — или программа упадёт.

## Объявление строк

```c
#include <stdio.h>

int main(void) {
    char a[] = "cat";          // размер 4 определяет компилятор
    char b[10] = "dog";        // 10 байт: "dog", '\0' и шесть нулей
    char c[10];                // мусор — пока это не строка
    c[0] = 'h';
    c[1] = 'i';
    c[2] = '\0';               // теперь c — строка "hi"
    printf("%s %s %s\n", a, b, c);
    return 0;
}
```

Вывод:

```text
cat dog hi
```

Массив `b` больше строки: в нём есть место, чтобы позже записать строку подлиннее. Главное правило — **в массиве из N байт помещается строка не длиннее N − 1 символа**: одно место всегда занимает `'\0'`.

## Обход строки

Длина строки заранее неизвестна, поэтому цикл идёт до нуль-терминатора:

```c
#include <stdio.h>

int main(void) {
    char word[] = "programming";
    int length = 0;
    int vowels = 0;
    for (int i = 0; word[i] != '\0'; i++) {
        length++;
        char c = word[i];
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            vowels++;
        }
    }
    printf("%d %d\n", length, vowels);
    return 0;
}
```

Вывод:

```text
11 3
```

Условие `word[i] != '\0'` — главный шаблон работы со строками в C. Его можно записать короче — `word[i]`, ведь `'\0'` равен нулю, то есть «ложь». Обе записи встречаются в реальном коде.

## Изменение строки

Строка в массиве — обычные символы, их можно менять:

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char name[] = "ada lovelace";
    name[0] = (char)toupper(name[0]);
    for (int i = 1; name[i] != '\0'; i++) {
        if (name[i - 1] == ' ') {
            name[i] = (char)toupper(name[i]);
        }
    }
    printf("%s\n", name);
    return 0;
}
```

Вывод:

```text
Ada Lovelace
```

## Ввод слова: `scanf("%s")`

`scanf` со спецификатором `%s` читает **одно слово** — последовательность символов до пробела или перевода строки — и сам дописывает `'\0'`. Знак `&` перед массивом не нужен: имя массива уже работает как адрес его начала (подробно — в уроке «Массивы и указатели»).

```c
#include <stdio.h>

int main(void) {
    char first[50], second[50];
    scanf("%49s %49s", first, second);
    printf("второе: %s, первое: %s\n", second, first);
    return 0;
}
```

Ввод:

```text
Hello C
```

Вывод:

```text
второе: C, первое: Hello
```

<Warning title="Всегда указывайте ширину в %s">

`scanf("%s", buf)` не знает размера массива. Если пользователь введёт слово длиннее, `scanf` запишет его за пределы массива и испортит память — это классическое переполнение буфера. Ширина `%49s` для массива из 50 байт ограничивает чтение 49 символами, оставляя место для `'\0'`.

</Warning>

## Ввод строки целиком: `fgets`

Чтобы прочитать строку с пробелами, используют `fgets(буфер, размер, stdin)`. Она читает до перевода строки включительно (или пока не заполнит буфер) и всегда добавляет `'\0'`:

```c
#include <stdio.h>

int main(void) {
    char line[100];
    if (fgets(line, sizeof(line), stdin) != NULL) {
        int i = 0;
        while (line[i] != '\0' && line[i] != '\n') {
            i++;
        }
        line[i] = '\0';     // убрали перевод строки
        printf("[%s]\n", line);
    }
    return 0;
}
```

Ввод:

```text
C is fun
```

Вывод:

```text
[C is fun]
```

Особенность `fgets`: перевод строки **остаётся** в буфере. Обычно его сразу удаляют, заменяя на `'\0'`, как в примере. `NULL` — специальное значение, которое `fgets` возвращает, если ввод закончился; подробно — в уроке о `NULL`.

<Tip title="Почему не gets">

В старых программах встречается функция `gets(buf)`. Она не знает размера буфера и поэтому всегда опасна — её исключили из стандарта C11. Используйте `fgets`.

</Tip>

## Чего со строками делать нельзя

- `char s[10]; s = "hello";` — ошибка: массивы не присваиваются. Строку копируют функцией `strcpy` (следующий урок) или посимвольно.
- `if (a == b)` для строк сравнивает **адреса** массивов, а не текст. Для сравнения текста — функция `strcmp`.
- `"abc" + "def"` не склеивает строки — это ошибка. Для склеивания есть `strcat` и `snprintf`.

Всё это — в следующем уроке о стандартной библиотеке `<string.h>`.

## Частые ошибки

<CommonMistake title="Нет места для '\0'">

`char code[4] = "abcd";` — четыре буквы в массиве из четырёх байт: для нуль-терминатора места нет, и это уже не строка. `printf("%s", code)` уйдёт за границу массива.

</CommonMistake>

<CommonMistake title="%s без ширины">

`scanf("%s", buf)` — переполнение буфера на длинном вводе. Пишите `%49s` для массива из 50 байт.

</CommonMistake>

<CommonMistake title="Забытый '\n' после fgets">

Строка, прочитанная `fgets`, заканчивается переводом строки. Сравнение с `"yes"` не сработает, пока его не удалить.

</CommonMistake>

<CommonMistake title="Смешивание scanf и fgets">

После `scanf("%d", &n)` во вводе остаётся перевод строки, и следующий `fgets` прочитает пустую строку. Перед `fgets` пропустите остаток строки, например циклом `getchar()` до `'\n'`.

</CommonMistake>

## Практика

1. **Длина слова** — обход до `'\0'` без библиотечных функций.
2. **Слово-палиндром** — два индекса навстречу.
3. **Количество слов** — строка с пробелами через `fgets`.
4. **Число из строки** — разбор цифр вручную.
5. **Инициалы** — изменение строки и вывод по частям.

## Итоги

- Строка в C — массив `char`, завершённый символом `'\0'`; в массиве из N байт помещается N − 1 символ.
- Строковый литерал `"abc"` занимает 4 байта; `%s` печатает до `'\0'`.
- Обход строки — цикл до `s[i] != '\0'`.
- `scanf("%49s", buf)` читает слово с ограничением длины; `fgets(buf, size, stdin)` — строку целиком вместе с `'\n'`.
- Строки нельзя присваивать через `=`, сравнивать через `==` и складывать через `+` — для этого есть функции `<string.h>`.
