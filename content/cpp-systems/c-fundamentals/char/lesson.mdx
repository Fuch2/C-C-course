## Буквы — это числа

Компьютер умеет хранить только числа. Чтобы работать с текстом, каждому символу сопоставлен числовой **код**: буква `A` — 65, `a` — 97, цифра `0` — 48, пробел — 32. Основу этой таблицы задаёт стандарт **ASCII**, принятый в 1963 году: 128 кодов для латинских букв, цифр, знаков препинания и управляющих символов вроде перевода строки.

В C для символов есть тип `char`. Это самый маленький целый тип — 1 байт, и хранит он именно код символа.

## Тип `char`

```c
#include <stdio.h>

int main(void) {
    char letter = 'A';
    printf("%c %d\n", letter, letter);
    char next = letter + 1;
    printf("%c %d\n", next, next);
    printf("%c\n", 97);
    return 0;
}
```

Вывод:

```text
A 65
B 66
a
```

- Символ в коде записывается в **одинарных** кавычках: `'A'`. Двойные кавычки `"A"` — это уже строка, о ней следующий урок.
- `%c` печатает символ по коду, `%d` — сам код.
- С символами можно делать арифметику: `'A' + 1` — это 66, то есть `'B'`.

## Таблица ASCII: что важно знать

Запоминать коды не нужно. Важно одно свойство: **цифры, заглавные и строчные латинские буквы идут подряд**.

| Символы     | Коды   |
| ----------- | ------ |
| `'0'`–`'9'` | 48–57  |
| `'A'`–`'Z'` | 65–90  |
| `'a'`–`'z'` | 97–122 |
| пробел      | 32     |
| `'\n'`      | 10     |

Отсюда несколько приёмов, которые встречаются постоянно:

```c
#include <stdio.h>

int main(void) {
    char digit = '7';
    int value = digit - '0';              // символ цифры → число
    char back = (char)('0' + 3);          // число → символ цифры
    char lower = 'q';
    char upper = (char)(lower - 'a' + 'A');   // строчная → заглавная
    int position = 'e' - 'a' + 1;         // номер буквы в алфавите
    printf("%d %c %c %d\n", value, back, upper, position);
    return 0;
}
```

Вывод:

```text
7 3 Q 5
```

`'7' - '0'` — это `55 - 48 = 7`. Код `'0'` вычитается, чтобы из символа получить значение цифры. Знать сами числа 55 и 48 не нужно — компилятор подставит их сам.

<Important title="Символ цифры и число — разные вещи">

`'7'` — символ с кодом 55, а `7` — число семь. `printf("%d", '7')` напечатает 55. Чтобы перейти от символа к числу, вычтите `'0'`, а обратно — прибавьте.

</Important>

## Проверки и преобразования: `<ctype.h>`

Писать `c >= 'a' && c <= 'z'` каждый раз неудобно. Заголовок `<ctype.h>` содержит готовые функции:

| Функция      | Возвращает истину, если символ…   |
| ------------ | --------------------------------- |
| `isdigit(c)` | цифра `0`–`9`                     |
| `isalpha(c)` | латинская буква                   |
| `isalnum(c)` | буква или цифра                   |
| `isspace(c)` | пробел, табуляция, перевод строки |
| `isupper(c)` | заглавная буква                   |
| `islower(c)` | строчная буква                    |
| `ispunct(c)` | знак препинания                   |

И две функции преобразования: `toupper(c)` и `tolower(c)` — возвращают символ в другом регистре; не-буквы возвращаются без изменений.

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char text[] = "Hi, C23!";
    for (int i = 0; text[i] != '\0'; i++) {
        char c = text[i];
        printf("%c: %s\n", c,
               isdigit(c) ? "цифра" : isalpha(c) ? "буква" : isspace(c) ? "пробел" : "знак");
    }
    printf("%c%c\n", toupper('x'), tolower('Y'));
    return 0;
}
```

Вывод:

```text
H: буква
i: буква
,: знак
 : пробел
C: буква
2: цифра
3: цифра
!: знак
Xy
```

(Строку `"Hi, C23!"` и условие `text[i] != '\0'` подробно разберём в следующем уроке.)

## Посимвольный ввод: `getchar` и `putchar`

`getchar()` читает **один символ** из стандартного ввода и возвращает его код. Когда ввод заканчивается, возвращается специальное значение `EOF`. `putchar(c)` печатает один символ.

Классический цикл посимвольной обработки текста:

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    int c;
    int letters = 0, lines = 0;
    while ((c = getchar()) != EOF) {
        if (isalpha(c)) {
            letters++;
        }
        if (c == '\n') {
            lines++;
        }
        putchar(toupper(c));
    }
    printf("букв: %d, строк: %d\n", letters, lines);
    return 0;
}
```

Ввод:

```text
hello world
c is fun
```

Вывод:

```text
HELLO WORLD
C IS FUN
букв: 16, строк: 2
```

Разберём условие `(c = getchar()) != EOF`: сначала символ читается и записывается в `c`, затем результат сравнивается с `EOF`. Скобки вокруг присваивания обязательны: без них `!=` выполнится раньше `=`.

<Warning title="Переменная для getchar — int, а не char">

`getchar` возвращает либо код символа (0–255), либо `EOF` (обычно −1). В `char` все эти 257 значений не помещаются, и `EOF` может совпасть с настоящим символом или никогда не распознаться. Поэтому `int c = getchar();`, а не `char c`.

</Warning>

## Русские буквы — не один символ

Таблица ASCII содержит только латиницу. Русские буквы в современных системах кодируются в **UTF-8**, где одна буква занимает **два байта**. Для C это два значения типа `char`. Поэтому `isalpha` не распознаёт русские буквы, `toupper` их не меняет, а `getchar` прочитает букву «ж» за два вызова. Корректная работа с Unicode требует специальных библиотек; в задачах этого модуля текст — латинский.

## Частые ошибки

<CommonMistake title="Двойные кавычки для символа">

`char c = "A";` — ошибка: `"A"` — строка, а не символ. Для символа — `'A'`.

</CommonMistake>

<CommonMistake title="Путаница символа цифры и числа">

`int d = '5';` — это 53, а не 5. Нужно `int d = '5' - '0';`.

</CommonMistake>

<CommonMistake title="char для getchar">

`char c; while ((c = getchar()) != EOF)` — на некоторых системах цикл никогда не закончится или оборвётся на символе с кодом 255. Используйте `int`.

</CommonMistake>

<CommonMistake title="Забытые скобки в условии">

`while (c = getchar() != EOF)` присваивает `c` результат сравнения (0 или 1), а не символ. Нужно `(c = getchar()) != EOF`.

</CommonMistake>

## Практика

Во всех задачах текст состоит из латинских букв, цифр, пробелов, знаков препинания и переводов строк.

1. **Код символа** — `%c` и `%d`.
2. **Статистика текста** — функции `<ctype.h>`.
3. **Заглавными** — посимвольное преобразование.
4. **Сумма цифр в тексте** — символ цифры в число.
5. **Шифр Цезаря** — арифметика по кругу на буквах.

## Итоги

- `char` хранит код символа; символ записывается в одинарных кавычках: `'A'`.
- `%c` печатает символ, `%d` — его код; с символами работает арифметика.
- Цифры и латинские буквы идут в таблице подряд: `c - '0'` — значение цифры, `c - 'a' + 'A'` — заглавная буква.
- `<ctype.h>`: `isdigit`, `isalpha`, `isspace`, `isupper`, `islower`, `toupper`, `tolower`.
- `getchar` читает символ, `putchar` печатает; переменная для `getchar` — `int`, конец ввода — `EOF`.
- Русские буквы в UTF-8 занимают по два байта и не обрабатываются функциями `<ctype.h>`.
