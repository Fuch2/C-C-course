## Тайна передачи массивов

В уроке о массивах осталась загадка: обычные переменные при передаче в функцию копируются, а массив — нет, и функция меняет оригинал. Кроме того, функции нужно отдельно передавать длину массива. Теперь, зная указатели, можно объяснить и то и другое. Ответ — в одном правиле языка C.

## Массив сводится к указателю

**В большинстве выражений имя массива превращается в указатель на его первый элемент.** Это правило называют сведением (decay). Вы уже видели его в `scanf("%s", word)`. А главное — так массив передаётся в функцию:

```c
#include <stdio.h>

void show(int *p, int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", p[i]);
    }
    printf("\n");
}

int main(void) {
    int data[4] = {1, 2, 3, 4};
    show(data, 4);         // передаётся &data[0]
    return 0;
}
```

Вывод:

```text
1 2 3 4
```

Функция получает **копию адреса** первого элемента, а не копию массива. Через этот адрес она обращается к элементам оригинала — поэтому и может их изменить.

Для параметров функции три записи означают одно и то же:

```c
void f(int a[]);
void f(int a[100]);    // число 100 компилятор игнорирует
void f(int *a);
```

Во всех трёх случаях `a` — указатель на `int`. Запись `int a[]` лишь подсказывает читателю, что ожидается массив.

## Индексация — это арифметика адресов

Если `p` — указатель на элемент массива, то `p + 1` — указатель на **следующий** элемент (адрес увеличивается на размер элемента, а не на 1 байт). А `p[i]` — по определению то же самое, что `*(p + i)`:

```c
#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;
    printf("%d %d %d\n", a[2], *(a + 2), p[2]);
    printf("%d %d\n", *(p + 4), *p + 4);
    return 0;
}
```

Вывод:

```text
30 30 30
50 14
```

- `a[2]`, `*(a + 2)`, `p[2]` — три записи одного и того же элемента.
- `*(p + 4)` — пятый элемент, 50. А `*p + 4` — первый элемент плюс 4: 14. Скобки решают всё.

## Ловушка: `sizeof` внутри функции

Раз параметр-«массив» на самом деле указатель, `sizeof` от него возвращает размер указателя, а не массива:

```c
#include <stdio.h>

void broken_length(int a[]) {
    printf("в функции: %zu\n", sizeof(a) / sizeof(a[0]));   // Предупреждение: sizeof указателя
}

int main(void) {
    int data[10] = {0};
    printf("в main: %zu\n", sizeof(data) / sizeof(data[0]));
    broken_length(data);
    return 0;
}
```

Вывод:

```text
в main: 10
в функции: 2
```

В `main` `data` — настоящий массив из 10 элементов (40 байт). В функции `a` — указатель (8 байт), и `8 / 4 = 2`. GCC даже предупреждает: `'sizeof' on array function parameter 'a' will return size of 'int *'`. Поэтому длину массива **всегда** передают отдельным параметром.

## Массив и указатель — не одно и то же

Несмотря на сведение, массив и указатель — разные вещи:

|                          | Массив `int a[5]` | Указатель `int *p`    |
| ------------------------ | ----------------- | --------------------- |
| Что хранит               | 5 значений        | один адрес            |
| `sizeof`                 | 20 (весь массив)  | 8 (размер адреса)     |
| Можно присвоить `a = …`? | нет               | да, `p = …`           |
| Где элементы             | в самом массиве   | где-то в другом месте |

Массив — это сама память с элементами. Указатель — переменная, которая знает, где лежат элементы. Сведение делает их похожими в выражениях, но не превращает одно в другое.

## Строки и указатели

Строки — массивы `char`, поэтому всё сказанное относится и к ним. Функции работы со строками принимают `const char *`:

```c
#include <stdio.h>

int count_char(const char *s, char c) {
    int count = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] == c) {
            count++;
        }
    }
    return count;
}

int main(void) {
    char text[] = "mississippi";
    printf("%d %d\n", count_char(text, 's'), count_char("hello", 'l'));
    return 0;
}
```

Вывод:

```text
4 2
```

Длину строки передавать не нужно: её конец отмечен `'\0'`. В этом главное удобство строк в C.

Обратите внимание на вызов `count_char("hello", 'l')`: строковый литерал тоже сводится к указателю на свой первый символ. Литералы хранятся в памяти **только для чтения**, поэтому указатель на них объявляют как `const char *`:

```c
const char *greeting = "hello";   // правильно: литерал нельзя менять
char copy[] = "hello";            // массив-копия: менять можно
```

Попытка изменить литерал через указатель (`char *s = "hello"; s[0] = 'H';`) — неопределённое поведение; в Linux программа обычно падает.

## Функция не может вернуть массив

`return` не умеет возвращать массивы, а возвращать указатель на локальный массив функции нельзя — он исчезнет. Поэтому в C принят шаблон: **вызывающий код предоставляет буфер, функция его заполняет**:

```c
#include <stdio.h>

void fill_powers(long long *out, int n, int base) {
    long long value = 1;
    for (int i = 0; i < n; i++) {
        out[i] = value;
        value *= base;
    }
}

int main(void) {
    long long powers[6];
    fill_powers(powers, 6, 3);
    for (int i = 0; i < 6; i++) {
        printf("%lld ", powers[i]);
    }
    printf("\n");
    return 0;
}
```

Вывод:

```text
1 3 9 27 81 243
```

Так устроены `fgets`, `snprintf`, `strcpy` — все они пишут в массив, который им передали.

## Частые ошибки

<CommonMistake title="sizeof параметра-массива">

Внутри функции `sizeof(a)` — размер указателя. Передавайте длину параметром.

</CommonMistake>

<CommonMistake title="Изменение строкового литерала">

`char *s = "text"; s[0] = 'T';` — неопределённое поведение. Для изменяемой строки объявите массив `char s[] = "text";`, а для указателя на литерал используйте `const char *`.

</CommonMistake>

<CommonMistake title="Возврат локального массива">

`int *make(void) { int a[10]; ...; return a; }` — после выхода массив исчезнет. Заполняйте массив, переданный вызывающим кодом.

</CommonMistake>

## Практика

1. **Длина без sizeof** — исправьте функцию с ловушкой.
2. **Заполнить буфер** — функция пишет в массив вызывающего кода.
3. **Сумма на отрезке** — передача части массива через `a + l`.
4. **Подсчёт гласных** — функция над `const char *`.

## Итоги

- Имя массива в выражениях сводится к указателю на первый элемент; в функцию передаётся адрес, а не копия.
- `int a[]` и `int *a` в параметрах — одно и то же; `p[i]` — это `*(p + i)`.
- `sizeof` параметра-массива — размер указателя: длину передают отдельно; строки отмечают конец `'\0'`.
- Массив и указатель различаются: размер, присваивание, место хранения элементов.
- Строковые литералы только для чтения — указатель на них `const char *`.
- Функция не возвращает массив: она заполняет буфер, который передал вызывающий код.
