## Практикум: ветвления

В этом уроке шесть задач на условия. В каждой придётся не просто выбрать между двумя вариантами, а продумать **все** случаи: какие бывают входные данные, какие из них особые, в каком порядке проверять условия. Именно здесь чаще всего «ломаются» скрытые тесты.

## Как не пропустить случай

Перед тем как писать цепочку условий, составьте **таблицу случаев**. Например, для задачи «по трём сторонам определить тип треугольника»:

| Случай                    | Пример   | Ответ          |
| ------------------------- | -------- | -------------- |
| треугольник не существует | `1 2 10` | не существует  |
| все стороны равны         | `5 5 5`  | равносторонний |
| ровно две стороны равны   | `5 5 8`  | равнобедренный |
| — в любом порядке         | `8 5 5`  | равнобедренный |
| все стороны разные        | `3 4 5`  | разносторонний |

Таблица сразу подсказывает и порядок проверок, и тесты:

1. Сначала исключаем невозможное — «не существует». Иначе `1 1 10` попадёт в «равнобедренные».
2. Затем самый узкий случай — «все равны». Равносторонний треугольник формально тоже равнобедренный, поэтому его нужно проверить раньше.
3. Затем «хотя бы две равны» — три пары сторон через `||`.
4. Всё остальное — `else`.

<Tip title="Тесты из таблицы">

Каждая строка таблицы — готовый тест. Прогоните программу на всех строках перед отправкой: если какой-то случай даёт не тот ответ, вы найдёте ошибку раньше проверяющей системы.

</Tip>

## Сравнение составных значений

В нескольких задачах нужно сравнивать время или даты. Сравнивать часы, потом минуты, потом секунды — долго и легко ошибиться. Проще перевести значение в **одно число**, сохраняющее порядок: время — в секунды с полуночи, дату — в число `год · 10000 + месяц · 100 + день`. Такие числа сравниваются обычными `<`, `==`, `>`.

```c
#include <stdio.h>

int main(void) {
    int d1, m1, y1, d2, m2, y2;
    scanf("%d.%d.%d %d.%d.%d", &d1, &m1, &y1, &d2, &m2, &y2);
    long long a = y1 * 10000LL + m1 * 100 + d1;
    long long b = y2 * 10000LL + m2 * 100 + d2;
    if (a < b) {
        printf("первая раньше\n");
    } else if (a > b) {
        printf("вторая раньше\n");
    } else {
        printf("совпадают\n");
    }
    return 0;
}
```

Ввод:

```text
31.12.2025 01.01.2026
```

Вывод:

```text
первая раньше
```

## Задачи

1. **Тип треугольника** — таблица случаев из разбора.
2. **Корни уравнения** — значения корней по возрастанию.
3. **Ход коня** — шахматная задача на модуль разности.
4. **Такси** — кусочный тариф.
5. **Кто раньше** — сравнение времени.
6. **Завтра** — следующая дата с учётом месяцев и високосных лет.
