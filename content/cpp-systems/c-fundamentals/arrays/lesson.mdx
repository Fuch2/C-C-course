## Много значений под одним именем

До сих пор каждая переменная хранила одно значение. Чтобы обработать последовательность чисел, мы читали их по одному и сразу накапливали результат. Но многие задачи так не решаются: «напечатать числа в обратном порядке», «сколько чисел больше среднего», «отсортировать». Чтобы ответить, нужно **помнить все числа сразу**. Заводить сто переменных `a1`, `a2`, …, `a100` невозможно. Для этого существуют **массивы**.

**Массив** — набор значений одного типа, расположенных в памяти подряд и доступных по номеру.

## Объявление и доступ к элементам

```c
#include <stdio.h>

int main(void) {
    int temps[5] = {12, 15, 9, 20, 17};
    printf("%d\n", temps[0]);
    printf("%d\n", temps[4]);
    temps[2] = 11;
    printf("%d\n", temps[2] + temps[3]);
    return 0;
}
```

Вывод:

```text
12
17
31
```

- `int temps[5]` — массив из 5 элементов типа `int`. Размер указывается в квадратных скобках.
- `temps[0]` — первый элемент. **Нумерация начинается с нуля**, поэтому последний элемент массива из 5 — `temps[4]`.
- Номер элемента называется **индексом**. Элемент массива — обычная переменная: его можно читать, присваивать, передавать в функции.

<MemoryDiagram title="Массив temps в памяти">

| Индекс   | 0   | 1   | 2   | 3   | 4   |
| -------- | --- | --- | --- | --- | --- |
| Значение | 12  | 15  | 11  | 20  | 17  |

</MemoryDiagram>

Элементы лежат в памяти вплотную друг к другу. Благодаря этому доступ к элементу по индексу мгновенный: компьютер вычисляет его адрес как «адрес начала + индекс × размер элемента».

## Индексы и циклы

Сила массивов — в сочетании с циклом. Индекс может быть переменной, поэтому один цикл обрабатывает все элементы:

```c
#include <stdio.h>

int main(void) {
    int scores[6] = {7, 3, 9, 4, 8, 5};
    int sum = 0;
    for (int i = 0; i < 6; i++) {
        sum += scores[i];
    }
    printf("сумма: %d\n", sum);
    for (int i = 5; i >= 0; i--) {
        printf("%d ", scores[i]);
    }
    printf("\n");
    return 0;
}
```

Вывод:

```text
сумма: 36
5 8 4 9 3 7
```

Обратите внимание на заголовок `for (int i = 0; i < 6; i++)`: индексы от 0 до 5 включительно. Именно поэтому в C так распространена форма цикла с `< n`.

## Инициализация

```c
#include <stdio.h>

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};   // все элементы
    int b[5] = {1, 2};            // остальные станут 0: {1, 2, 0, 0, 0}
    int c[5] = {};                // все нули (C23)
    int d[] = {10, 20, 30};       // размер 3 определит компилятор
    printf("%d %d %d %d\n", a[4], b[4], c[2], d[2]);
    return 0;
}
```

Вывод:

```text
5 0 0 30
```

Если инициализатор задан хотя бы частично, недостающие элементы обнуляются. Пустые фигурные скобки `{}` (появились в C23) обнуляют все элементы; в старом коде для того же пишут `{0}` — это работает в любом стандарте. Но массив **без** инициализатора, объявленный внутри функции, содержит мусор — как и обычная локальная переменная.

## Размер массива и чтение данных

Размер массива должен быть известен заранее. Обычный приём в задачах — объявить массив под **максимально возможное** количество элементов из ограничений и использовать первые `n`:

```c
#include <stdio.h>

#define MAX_N 1000

int main(void) {
    int a[MAX_N];
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        sum += a[i];
    }
    double average = (double)sum / n;
    int above = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] > average) {
            above++;
        }
    }
    printf("%d\n", above);
    return 0;
}
```

Ввод:

```text
5
1 2 3 4 10
```

Вывод:

```text
1
```

Программа делает **три прохода** по данным: чтение, сумма, подсчёт. Без массива второй проход был бы невозможен — числа уже «пролетели». `&a[i]` — адрес элемента, его нужно передать в `scanf`, как адрес обычной переменной.

Размер `MAX_N` задан через `#define`: так его легко поменять в одном месте. В C23 то же можно записать как `constexpr int MAX_N = 1000;` — константа с типом, о которой говорилось в уроке о константах. Можно объявить и массив с размером из переменной (`int a[n];`, «массив переменной длины»), но такие массивы создаются на стеке, и при большом `n` программа может упасть; многие проекты их запрещают. Для больших данных в модуле «Память» вы научитесь выделять память динамически.

## Выход за границы — ошибка, которую C не ловит

Что будет, если обратиться к `a[5]` у массива из 5 элементов? Или к `a[-1]`? **C не проверяет индексы.** Программа обратится к памяти рядом с массивом — там может оказаться другая переменная, служебные данные или чужая память. Это **неопределённое поведение**: программа может работать «как будто правильно», выдавать мусор, портить другие переменные или аварийно завершиться.

```c
int a[5] = {1, 2, 3, 4, 5};
for (int i = 0; i <= 5; i++) {   // ошибка: i == 5 выходит за границу
    printf("%d\n", a[i]);
}
```

Это одна из самых опасных ошибок в C — через неё происходит множество взломов программ. Инструмент **AddressSanitizer**, которому посвящён урок в модуле «Память», ловит такие обращения во время работы программы. В задачах курса проверка с ним включается для некоторых модулей. А пока главное правило: **индекс должен быть от 0 до размер − 1**, и проверяйте каждое условие цикла.

## Массивы нельзя присваивать целиком

`a = b;` для массивов — ошибка компиляции. Копируют поэлементно:

```c
#include <stdio.h>

int main(void) {
    int source[4] = {4, 3, 2, 1};
    int copy[4];
    for (int i = 0; i < 4; i++) {
        copy[i] = source[i];
    }
    copy[0] = 100;
    printf("%d %d\n", source[0], copy[0]);
    return 0;
}
```

Вывод:

```text
4 100
```

Сравнивать массивы через `==` тоже нельзя — это сравнит не содержимое, а адреса. Сравнивают поэлементно в цикле.

## Массивы и функции

Массив можно передать в функцию. Вместе с ним **всегда** передают количество элементов — сама функция его не узнает:

```c
#include <stdio.h>

int max_of(const int a[], int n) {
    int best = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > best) {
            best = a[i];
        }
    }
    return best;
}

void double_all(int a[], int n) {
    for (int i = 0; i < n; i++) {
        a[i] *= 2;
    }
}

int main(void) {
    int data[4] = {3, 9, 2, 5};
    printf("%d\n", max_of(data, 4));
    double_all(data, 4);
    printf("%d %d\n", data[0], data[1]);
    return 0;
}
```

Вывод:

```text
9
6 18
```

Важное отличие от обычных переменных: функция `double_all` **изменила** массив вызывающего кода. Массив не копируется при передаче — функция получает доступ к оригиналу. Почему так, станет ясно в уроке «Массивы и указатели». `const` в `max_of` обещает, что функция массив не меняет, и компилятор следит за этим обещанием.

## Частые ошибки

<CommonMistake title="Индекс на единицу больше">

`for (int i = 0; i <= n; i++)` с массивом из `n` элементов обращается к `a[n]` — за границей. Для массивов почти всегда `i < n`.

</CommonMistake>

<CommonMistake title="Нумерация с единицы">

Первый элемент — `a[0]`, не `a[1]`. Если условие задачи нумерует с единицы, переводите: элемент номер `k` хранится в `a[k - 1]`.

</CommonMistake>

<CommonMistake title="Массив меньше данных">

Если по ограничениям `n ≤ 1000`, массив `int a[100]` переполнится. Размер берите из ограничений задачи.

</CommonMistake>

<CommonMistake title="Присваивание массивов">

`b = a;` не компилируется. Копируйте в цикле.

</CommonMistake>

## Практика

1. **Наоборот** — печать в обратном порядке.
2. **Выше среднего** — два прохода по данным.
3. **Сдвиг по кругу** — индексы по модулю.
4. **Частоты оценок** — массив счётчиков.
5. **Без повторов** — поиск среди уже просмотренных.
6. **Поиск в массиве** — функция с массивом-параметром.

## Итоги

- Массив — набор элементов одного типа подряд в памяти; `тип имя[размер]`.
- Индексы от 0 до размер − 1; элемент `a[i]` — обычная переменная.
- Частичная инициализация обнуляет остальные элементы; `= {0}` — массив нулей.
- Размер выбирают по максимуму из ограничений; используют первые `n` элементов.
- C не проверяет границы: выход за массив — неопределённое поведение.
- Массивы копируют и сравнивают поэлементно; в функцию передают массив и его длину, функция работает с оригиналом.
