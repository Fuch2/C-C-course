## Программам нужно сравнивать

Все программы до сих пор выполняли одни и те же действия при любых данных. Но настоящие программы принимают решения: пропустить ли пользователя с таким паролем, хватит ли денег на счёте, превышена ли скорость. Любое решение начинается со **сравнения**. В этом разделе вы научитесь сравнивать значения, комбинировать условия и выбирать, какой код выполнять. Начнём с операторов сравнения.

## Шесть операторов сравнения

| Оператор | Смысл            | Пример   | Результат |
| -------- | ---------------- | -------- | --------- |
| `==`     | равно            | `5 == 5` | 1         |
| `!=`     | не равно         | `5 != 3` | 1         |
| `<`      | меньше           | `5 < 3`  | 0         |
| `>`      | больше           | `5 > 3`  | 1         |
| `<=`     | меньше или равно | `5 <= 5` | 1         |
| `>=`     | больше или равно | `3 >= 5` | 0         |

В C у сравнения нет особого «логического» результата: это обычное целое число. **1** означает «истина», **0** — «ложь». Поэтому результат сравнения можно напечатать через `%d`, сохранить в `int` и даже использовать в арифметике:

```c
#include <stdio.h>

int main(void) {
    int age = 17;
    int adult = age >= 18;
    printf("%d %d %d\n", adult, age < 18, age == 17);
    printf("%d\n", (age > 10) + (age > 15) + (age > 20));
    return 0;
}
```

Вывод:

```text
0 1 1
2
```

Вторая строка считает, сколько из трёх условий выполнено: два сравнения дали 1, одно 0.

<Concept title="Истина и ложь в C">

Любое ненулевое значение считается истиной, ноль — ложью. Операторы сравнения всегда возвращают ровно 1 или 0.

</Concept>

## `=` и `==` — главная опечатка

`=` — присваивание, `==` — сравнение. Перепутать их очень легко, а последствия неочевидны:

```c
#include <stdio.h>

int main(void) {
    int x = 3;
    printf("%d\n", x == 5);    // сравнение: 0, x не меняется
    printf("%d\n", x);
    printf("%d\n", x = 5);     // присваивание: x становится 5, результат 5
    printf("%d\n", x);
    return 0;
}
```

Вывод:

```text
0
3
5
5
```

`x = 5` — не вопрос «равно ли x пяти?», а команда «запиши 5 в x». Значение такого выражения — записанное число, и оно ненулевое, то есть «истинно». В следующих уроках, когда сравнения окажутся внутри `if`, такая опечатка превратит условие в «всегда истина». Компилятор в строгом режиме предупреждает об этом: `suggest parentheses around assignment used as truth value`.

## Цепочки сравнений не работают как в математике

В математике `1 < x < 10` означает «x между 1 и 10». В C это выражение вычисляется слева направо как `(1 < x) < 10`:

```c
#include <stdio.h>

int main(void) {
    int x = 50;
    printf("%d\n", 1 < x < 10);    // Предупреждение: не математический смысл
    return 0;
}
```

Вывод:

```text
1
```

`1 < 50` даёт 1, затем `1 < 10` — тоже 1. Программа «считает», что 50 лежит между 1 и 10. GCC предупреждает: `comparisons like ‘X<=Y<=Z’ do not have their mathematical meaning`. Правильная запись — два сравнения, объединённых логическим «И»: `1 < x && x < 10`. Логические операторы — тема следующего урока.

## Тип `bool`

Хранить истинность в `int` можно, но имя типа не говорит, что значение логическое. Заголовок `<stdbool.h>` вводит тип `bool` и константы `true` (1) и `false` (0):

```c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int temperature = 38;
    bool fever = temperature >= 37;
    bool frost = temperature < 0;
    printf("%d %d\n", fever, frost);
    return 0;
}
```

Вывод:

```text
1 0
```

`bool` печатается через `%d` как 1 или 0. Специального спецификатора для `bool` в `printf` нет.

## Сравнение дробных чисел

Как вы помните из урока о `double`, `0.1 + 0.2 == 0.3` — ложь из-за погрешности. Дробные числа сравнивают **с допуском** — проверяют, что разница меньше маленького числа, которое называют эпсилон:

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    double a = 0.1 + 0.2;
    double b = 0.3;
    printf("%d\n", a == b);
    printf("%d\n", fabs(a - b) < 1e-9);
    return 0;
}
```

Вывод:

```text
0
1
```

Допуск выбирают по смыслу задачи: для координат в метрах хватит `1e-6`, для денег в рублях — `1e-2`. Сравнения `<` и `>` дробных чисел работают как обычно; проблема только с точным равенством.

## Сравнение символов

Символы в C — маленькие целые числа (коды), поэтому их тоже можно сравнивать. Буквы латинского алфавита и цифры идут подряд:

```c
#include <stdio.h>

int main(void) {
    char c = 'g';
    printf("%d %d %d\n", c >= 'a', c <= 'z', 'A' < 'a');
    return 0;
}
```

Вывод:

```text
1 1 1
```

`'A'` имеет код 65, `'a'` — 97, поэтому заглавные латинские буквы «меньше» строчных. Подробно о кодах символов — в уроке «Символы».

## Максимум без условий

Поскольку сравнение — это число 0 или 1, им можно умножать. Это даёт трюк для выбора без условий:

```c
#include <stdio.h>

int main(void) {
    int a = 17, b = 42;
    int max = (a > b) * a + (a <= b) * b;
    printf("%d\n", max);
    return 0;
}
```

Вывод:

```text
42
```

Ровно одно из условий `a > b` и `a <= b` истинно, поэтому одно слагаемое — само число, другое — ноль. В обычном коде максимум пишут через `if` или тернарный оператор — следующие уроки, — но этот приём хорошо показывает, что сравнение в C — просто арифметика.

## Частые ошибки

<CommonMistake title="= вместо ==">

`x = 5` записывает пять, а не сравнивает. Читайте `==` как «равно ли?», а `=` — как «стало равно».

</CommonMistake>

<CommonMistake title="Двойное неравенство">

`a < x < b` компилируется, но проверяет не то. Нужно `a < x && x < b`.

</CommonMistake>

<CommonMistake title="Пробел внутри оператора">

`> =`, `= =`, `! =` — ошибка компиляции. Двухсимвольные операторы пишутся слитно: `>=`, `==`, `!=`.

</CommonMistake>

<CommonMistake title="Точное сравнение double">

`x == 0.3` после вычислений почти всегда ложно. Используйте `fabs(x - 0.3) < eps`.

</CommonMistake>

## Практика

Условного оператора `if` пока нет — результат каждого сравнения печатается как число 0 или 1.

1. **Три сравнения** — меньше, равно, больше.
2. **Делимость** — на 2, 3 и 5.
3. **Счастливый билет** — суммы цифр.
4. **Максимум и минимум** — без условий.
5. **Почти равны** — дробные числа с допуском.

## Итоги

- Операторы сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`. Результат — `int`: 1 (истина) или 0 (ложь).
- Ненулевое значение в C считается истиной, ноль — ложью.
- `=` — присваивание, `==` — сравнение. Компилятор предупреждает о присваивании там, где ждут условие.

- `bool`, `true`, `false` — из `<stdbool.h>`.
- Дробные числа сравнивают с допуском: `fabs(a - b) < eps`.
