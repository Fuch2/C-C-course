## Повторение — главная сила компьютера

Человек устанет складывать миллион чисел, а процессор сделает это за миллисекунду. Но писать миллион строк кода никто не будет: нужна конструкция, которая **повторяет** одни и те же инструкции нужное число раз. Такие конструкции называются **циклами**. В C их три: `while`, `do while` и `for`. Начнём с самого простого и универсального — `while`.

## Устройство `while`

```c
#include <stdio.h>

int main(void) {
    int i = 1;
    while (i <= 5) {
        printf("%d\n", i);
        i++;
    }
    printf("после цикла i = %d\n", i);
    return 0;
}
```

Вывод:

```text
1
2
3
4
5
после цикла i = 6
```

`while` (по-английски «пока») работает так:

1. Проверяется условие в скобках.
2. Если оно истинно — выполняется **тело** цикла (блок в фигурных скобках), и всё повторяется с шага 1.
3. Если ложно — цикл заканчивается, выполнение продолжается после блока.

Одно выполнение тела называют **итерацией**. Здесь пять итераций: при `i` от 1 до 5. Когда `i` стало 6, условие `6 <= 5` ложно, цикл завершился. Обратите внимание: после цикла `i` равно 6, а не 5.

<MemoryDiagram title="Трассировка цикла">

| Проверка `i <= 5`  | `i` до тела | Печать | `i` после тела |
| ------------------ | ----------- | ------ | -------------- |
| `1 <= 5` — да      | 1           | 1      | 2              |
| `2 <= 5` — да      | 2           | 2      | 3              |
| `3 <= 5` — да      | 3           | 3      | 4              |
| `4 <= 5` — да      | 4           | 4      | 5              |
| `5 <= 5` — да      | 5           | 5      | 6              |
| `6 <= 5` — **нет** | —           | —      | цикл окончен   |

</MemoryDiagram>

## Три части любого цикла со счётчиком

У цикла, который выполняется определённое число раз, всегда есть три части:

1. **Инициализация** до цикла: `int i = 1;`
2. **Условие продолжения**: `i <= 5`
3. **Изменение** внутри тела: `i++`

Если забыть третью часть, условие никогда не станет ложным, и цикл будет выполняться бесконечно. В песочнице курса программа остановится по лимиту времени с сообщением «превышено время», а на своём компьютере её придётся прерывать сочетанием клавиш Ctrl+C.

## Накопление: сумма

Главный шаблон работы с циклами — **накопление**. Заводится переменная-аккумулятор с начальным значением, и на каждой итерации к ней что-то добавляется:

```c
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);
    long long sum = 0;
    int i = 1;
    while (i <= n) {
        sum += i;
        i++;
    }
    printf("%lld\n", sum);
    return 0;
}
```

Ввод:

```text
100
```

Вывод:

```text
5050
```

Аккумулятор суммы начинается с 0 (прибавление нуля ничего не меняет), аккумулятор произведения — с 1. Если забыть инициализацию, к мусору будут прибавляться числа, и результат окажется случайным.

## Цикл до условия: цифры числа

`while` особенно хорош, когда число повторений **заранее неизвестно**. Например, нужно обработать все цифры числа произвольной длины. В уроке «Арифметика» вы доставали цифры по одной, зная длину числа. Цикл делает это для любой длины: пока число не стало нулём, отщепляем последнюю цифру.

```c
#include <stdio.h>

int main(void) {
    long long n;
    scanf("%lld", &n);
    int digit_sum = 0;
    int digits = 0;
    while (n > 0) {
        digit_sum += n % 10;
        n /= 10;
        digits++;
    }
    printf("%d %d\n", digits, digit_sum);
    return 0;
}
```

Ввод:

```text
90210
```

Вывод:

```text
5 12
```

Трассировка для 90210: последняя цифра 0, число 9021; цифра 1, число 902; цифра 2, число 90; цифра 0, число 9; цифра 9, число 0 — стоп. Пять цифр, сумма 12.

Попробуйте ввести `0`. Цикл не выполнится ни разу, и программа скажет, что у нуля 0 цифр. Это особый случай — его удобно решать циклом `do while` из следующего урока.

## Чтение до признака конца

Ещё один частый сценарий: данные вводятся, пока не встретится специальное значение — **признак конца** (sentinel). Например, «вводите покупки, 0 — конец списка»:

```c
#include <stdio.h>

int main(void) {
    int price;
    int total = 0, count = 0;
    scanf("%d", &price);
    while (price != 0) {
        total += price;
        count++;
        scanf("%d", &price);
    }
    printf("товаров: %d, сумма: %d\n", count, total);
    return 0;
}
```

Ввод:

```text
120 45 300 0
```

Вывод:

```text
товаров: 3, сумма: 465
```

Обратите внимание на структуру: первое число читается **до** цикла, следующее — **в конце** тела. Так условие всегда проверяет только что прочитанное значение, а признак конца 0 не попадает в сумму.

## Поиск максимума

Найти наибольшее значение в последовательности — тоже накопление, только вместо суммы хранится «лучшее на данный момент»:

```c
#include <stdio.h>

int main(void) {
    int x;
    scanf("%d", &x);
    int max = x;
    while (x != 0) {
        if (x > max) {
            max = x;
        }
        scanf("%d", &x);
    }
    printf("%d\n", max);
    return 0;
}
```

Ввод:

```text
-5 -2 -9 0
```

Вывод:

```text
-2
```

Максимум инициализируется **первым элементом**, а не нулём. Если бы `max` начинался с 0, для последовательности из одних отрицательных чисел программа напечатала бы 0, которого в данных нет (признак конца не считается).

<Concept title="Шаблон «лучший на данный момент»">

Хранить в переменной лучший результат среди уже просмотренных элементов и обновлять его, если очередной элемент лучше. Начальное значение — первый элемент. Тот же шаблон находит минимум, самое длинное слово, самого старшего человека.

</Concept>

## Частые ошибки

<CommonMistake title="Бесконечный цикл">

Счётчик не меняется (`i++` забыт) или меняется не в ту сторону. Перед запуском спросите себя: что в теле цикла приближает условие к ложному?

</CommonMistake>

<CommonMistake title="Ошибка на единицу">

`while (i < n)` вместо `while (i <= n)` — на одну итерацию меньше. Проверьте цикл на самом маленьком входе (n = 1) — сколько раз выполнится тело?

</CommonMistake>

<CommonMistake title="Точка с запятой после while">

`while (i <= 5);` — тело цикла пустое, а условие никогда не меняется: программа зависнет. Блок после точки с запятой к циклу не относится.

</CommonMistake>

<CommonMistake title="Неинициализированный аккумулятор">

`int sum; while (...) sum += x;` — сумма начнётся с мусора. Инициализируйте аккумулятор до цикла.

</CommonMistake>

## Практика

1. **Сумма от 1 до n** — накопление.
2. **Сколько цифр** — цикл до нуля.
3. **Число наоборот** — сборка числа из цифр.
4. **Степени двойки** — печать в одну строку.
5. **Покупки** — чтение до нуля.
6. **Максимум и сколько раз** — «лучший на данный момент».

## Итоги

- `while (условие) { тело }` повторяет тело, пока условие истинно; условие проверяется перед каждой итерацией.
- У цикла со счётчиком три части: инициализация, условие, изменение. Без изменения цикл бесконечен.
- Накопление: аккумулятор инициализируется до цикла (0 для суммы, 1 для произведения, первый элемент для максимума).
- `% 10` и `/ 10` в цикле обрабатывают все цифры числа любой длины.
- Чтение до признака конца: прочитать до цикла, обработать, прочитать в конце тела.
