## Программа выбирает путь

До этого урока программа выполнялась строго сверху вниз, и каждая строка выполнялась ровно один раз. Оператор `if` впервые позволяет **пропустить** часть кода в зависимости от данных. С ним программа может ответить «да» или «нет», выбрать один из вариантов и защититься от ошибочного ввода.

## `if`: выполнить, если условие истинно

```c
#include <stdio.h>

int main(void) {
    int temperature;
    scanf("%d", &temperature);
    if (temperature < 0) {
        printf("Гололёд! Будьте осторожны.\n");
    }
    printf("Температура: %d\n", temperature);
    return 0;
}
```

Ввод:

```text
-5
```

Вывод:

```text
Гололёд! Будьте осторожны.
Температура: -5
```

Устройство:

- `if (условие)` — условие в круглых скобках обязательно;
- блок в фигурных скобках выполняется, только если условие истинно (не равно нулю);
- после блока программа продолжается как обычно.

Запустите пример с вводом `12` — первая строка не появится, вторая напечатается в любом случае.

## `else`: иначе

`else` задаёт блок, который выполняется, если условие **ложно**. Ровно один из двух блоков выполнится всегда:

```c
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);
    if (n % 2 == 0) {
        printf("чётное\n");
    } else {
        printf("нечётное\n");
    }
    return 0;
}
```

Ввод:

```text
7
```

Вывод:

```text
нечётное
```

## Цепочка `else if`: несколько вариантов

Когда вариантов больше двух, условия выстраивают в цепочку. Проверка идёт сверху вниз и **останавливается на первом истинном** условии:

```c
#include <stdio.h>

int main(void) {
    int score;
    scanf("%d", &score);
    if (score >= 90) {
        printf("отлично\n");
    } else if (score >= 75) {
        printf("хорошо\n");
    } else if (score >= 60) {
        printf("удовлетворительно\n");
    } else {
        printf("неудовлетворительно\n");
    }
    return 0;
}
```

Ввод:

```text
82
```

Вывод:

```text
хорошо
```

Обратите внимание: во второй проверке не нужно писать `score >= 75 && score < 90`. Если выполнение дошло до неё, значит, первое условие уже оказалось ложным и `score` точно меньше 90. Цепочка `else if` использует результаты предыдущих проверок.

Из этого следует, что **порядок условий важен**. Если начать с `score >= 60`, то и 95, и 82 попадут в «удовлетворительно»: первое истинное условие остановит проверку.

<MemoryDiagram title="Как выполняется цепочка для score = 82">

| Проверка      | Результат | Действие                       |
| ------------- | --------- | ------------------------------ |
| `score >= 90` | ложь      | переходим к следующей проверке |
| `score >= 75` | истина    | печатаем «хорошо», выходим     |
| `score >= 60` | —         | не проверяется                 |
| `else`        | —         | не выполняется                 |

</MemoryDiagram>

## Вложенные условия

Внутри блока `if` может быть другой `if`. Например, классификация точки по четвертям координатной плоскости:

```c
#include <stdio.h>

int main(void) {
    int x, y;
    scanf("%d %d", &x, &y);
    if (x == 0 || y == 0) {
        printf("на оси\n");
    } else if (x > 0) {
        if (y > 0) {
            printf("I\n");
        } else {
            printf("IV\n");
        }
    } else {
        if (y > 0) {
            printf("II\n");
        } else {
            printf("III\n");
        }
    }
    return 0;
}
```

Ввод:

```text
-3 -2
```

Вывод:

```text
III
```

Глубокая вложенность быстро становится нечитаемой. Если условий много, часто удобнее объединить их через `&&` и выстроить плоскую цепочку `else if`.

## Всегда ставьте фигурные скобки

Если в блоке одна инструкция, скобки формально можно опустить: `if (x < 0) x = -x;`. Но это источник классической ошибки:

```c
if (balance < 0)
    printf("Долг!\n");
    balance = 0;          // выполняется ВСЕГДА, хотя отступ говорит обратное
```

Без скобок к `if` относится только **одна** следующая инструкция. Отступ ничего не значит для компилятора. Правило курса: **фигурные скобки у `if` и `else` всегда**, даже для одной строки.

## Ловушки условий

<Warning title="Точка с запятой после условия">

`if (x > 0);` — точка с запятой завершает `if` пустой инструкцией. Блок в скобках после неё выполняется всегда. GCC с флагом `-Wextra` предупреждает: `suggest braces around empty body in an ‘if’ statement`.

</Warning>

<Warning title="Присваивание вместо сравнения">

`if (x = 0)` записывает 0 в `x`, и условие всегда ложно. `if (x = 5)` — всегда истинно. Компилятор предупреждает: `suggest parentheses around assignment used as truth value`.

</Warning>

## Тернарный оператор `?:`

Для выбора одного из двух **значений** есть компактный оператор `условие ? значение_если_истина : значение_если_ложь`:

```c
#include <stdio.h>

int main(void) {
    int a, b;
    scanf("%d %d", &a, &b);
    int max = a > b ? a : b;
    printf("%d\n", max);
    printf("%d %s\n", a, a % 2 == 0 ? "чётное" : "нечётное");
    return 0;
}
```

Ввод:

```text
8 3
```

Вывод:

```text
8
8 чётное
```

Тернарный оператор хорош для коротких выборов значения. Если в ветвях нужно **выполнять действия** или условие сложное, используйте `if`: вложенные `?:` очень трудно читать.

## Проверка ввода и защита от ошибок

Теперь можно сделать то, что откладывали: проверить, что `scanf` действительно прочитал данные, и защититься от деления на ноль.

```c
#include <stdio.h>

int main(void) {
    int a, b;
    if (scanf("%d %d", &a, &b) != 2) {
        printf("ошибка ввода\n");
        return 1;
    }
    if (b == 0) {
        printf("деление на ноль\n");
        return 1;    // Код завершения 1 сообщает об ошибке
    }
    printf("%d\n", a / b);
    return 0;
}
```

Ввод:

```text
17 0
```

Вывод:

```text
деление на ноль
```

`return` внутри `main` сразу завершает программу. Такой стиль называют **ранним выходом**: обработали ошибку и вышли, а основной код остаётся без лишней вложенности. Код завершения 1 сообщает об ошибке. (В учебных задачах с тестами программа должна завершаться с кодом 0, поэтому там при особых случаях печатают сообщение и возвращают 0, как требует условие.)

## Частые ошибки

<CommonMistake title="Неверный порядок в цепочке else if">

Сначала проверяйте самые узкие или самые высокие диапазоны. Если первым поставить широкое условие, до остальных выполнение не дойдёт.

</CommonMistake>

<CommonMistake title="Лишние повторные проверки">

`if (x > 10) {...} else if (x <= 10 && x > 5) {...}` — часть `x <= 10` уже известна. Лишние условия не ломают программу, но мешают читать и легко расходятся при правках.

</CommonMistake>

<CommonMistake title="Отсутствие скобок">

Без фигурных скобок к `if` относится только одна инструкция. Добавив вторую строку «в блок», вы на самом деле добавите её после `if`.

</CommonMistake>

<CommonMistake title="else без своего if">

`else` относится к ближайшему предыдущему `if` без `else`. При вложенных условиях без скобок это может оказаться не тот `if`, который вы имели в виду.

</CommonMistake>

## Практика

1. **Модуль числа** — без функции `abs`.
2. **Оценка** — цепочка `else if`.
3. **Время суток** — диапазоны часов.
4. **Три числа по порядку** — упорядочивание.
5. **Корни квадратного уравнения** — сколько их.
6. **Деление с проверкой** — особый случай нуля.

## Итоги

- `if (условие) { ... }` выполняет блок, если условие истинно; `else` — если ложно.
- Цепочка `else if` проверяет условия сверху вниз до первого истинного; порядок важен, а ложность предыдущих условий можно использовать.
- Фигурные скобки ставятся всегда; `;` после `if (...)` и `=` вместо `==` — типичные ловушки.
- `условие ? a : b` выбирает одно из двух значений.
- Ранний выход через `return` упрощает обработку ошибок ввода и особых случаев.
