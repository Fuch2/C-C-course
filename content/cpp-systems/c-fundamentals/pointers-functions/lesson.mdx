## Как функция может изменить переменную

В уроке о параметрах вы видели: функция получает **копию** аргумента и не может изменить переменную вызывающего кода. Это защищает от случайных изменений, но иногда изменение — именно то, что нужно: поменять две переменные местами, вернуть два результата, прочитать данные из ввода. Решение — передать функции **адрес** переменной. Копия адреса указывает на тот же оригинал.

## Классика: `swap`

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void) {
    int x = 3, y = 8;
    swap(&x, &y);
    printf("%d %d\n", x, y);
    return 0;
}
```

Вывод:

```text
8 3
```

<MemoryDiagram title="Что видит swap">

| Имя   | Где живёт      | Значение  |
| ----- | -------------- | --------- |
| `x`   | `main`         | 3 → 8     |
| `y`   | `main`         | 8 → 3     |
| `a`   | `swap` (копия) | адрес `x` |
| `b`   | `swap` (копия) | адрес `y` |
| `tmp` | `swap`         | 3         |

</MemoryDiagram>

Аргументы по-прежнему передаются по значению — копируются **адреса**. Но копия адреса указывает на ту же переменную, и запись `*a = …` меняет `x` в `main`.

Сравните с неработающей версией из урока о параметрах: `void swap(int a, int b)` меняла местами свои копии, а `x` и `y` оставались прежними.

## Выходные параметры: несколько результатов

`return` возвращает одно значение. Если результатов несколько, функция может записать их по переданным адресам. Такие параметры называют **выходными**:

```c
#include <stdio.h>

void split_time(int total_seconds, int *hours, int *minutes, int *seconds) {
    *hours = total_seconds / 3600;
    *minutes = total_seconds % 3600 / 60;
    *seconds = total_seconds % 60;
}

int main(void) {
    int h, m, s;
    split_time(7384, &h, &m, &s);
    printf("%d:%02d:%02d\n", h, m, s);
    return 0;
}
```

Вывод:

```text
2:03:04
```

Именно так устроен `scanf`: вы передаёте адреса, и функция записывает в них прочитанные значения. А её `return` сообщает другое — сколько значений удалось прочитать.

## Результат и признак успеха

Частый шаблон в C: функция **возвращает признак успеха**, а полезный результат пишет через указатель. Тогда вызывающий код может проверить, всё ли получилось:

```c
#include <stdio.h>

bool safe_divide(int a, int b, int *result) {
    if (b == 0) {
        return false;      // результат не записываем
    }
    *result = a / b;
    return true;
}

int main(void) {
    int q;
    if (safe_divide(17, 5, &q)) {
        printf("%d\n", q);
    }
    if (!safe_divide(1, 0, &q)) {
        printf("деление на ноль\n");
    }
    return 0;
}
```

Вывод:

```text
3
деление на ноль
```

Этот шаблон решает проблему специальных значений: результат может быть любым числом, включая −1, а успех сообщается отдельно.

## `const`-указатели в параметрах

Указатель передают не только для изменения, но и чтобы **не копировать** большие данные — массивы и, как вы увидите в уроке `struct`, структуры. Если функция только читает данные, параметр объявляют с `const`:

```c
#include <stdio.h>

double average(const int *values, int n) {
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        sum += values[i];
    }
    return (double)sum / n;
}

int main(void) {
    int temps[5] = {12, 15, 9, 20, 17};
    printf("%.1f\n", average(temps, 5));
    return 0;
}
```

Вывод:

```text
14.6
```

`const int *values` — обещание: «функция не изменит ваш массив». По сигнатуре функции читатель сразу понимает, какие параметры входные (`const`), а какие — выходные (без `const`).

Обратите внимание: параметр объявлен как `const int *values`, а к элементам обращаются `values[i]` — как к массиву. Для параметров функции записи `int a[]` и `int *a` означают одно и то же. Почему — в следующем уроке.

## Проверка указателей-параметров

Если указатель-параметр может быть `NULL` («этот результат мне не нужен»), функция должна это проверить:

```c
#include <stdio.h>

void min_max(const int *a, int n, int *min, int *max) {
    int lo = a[0], hi = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < lo) {
            lo = a[i];
        }
        if (a[i] > hi) {
            hi = a[i];
        }
    }
    if (min != NULL) {
        *min = lo;
    }
    if (max != NULL) {
        *max = hi;
    }
}

int main(void) {
    int data[4] = {4, -2, 9, 0};
    int hi;
    min_max(data, 4, NULL, &hi);   // минимум не нужен
    printf("%d\n", hi);
    return 0;
}
```

Вывод:

```text
9
```

## Частые ошибки

<CommonMistake title="Забыли & при вызове">

`swap(x, y)` вместо `swap(&x, &y)` — функция получит числа вместо адресов. Компилятор предупредит: `passing argument 1 of 'swap' makes pointer from integer without a cast`. Это всегда ошибка.

</CommonMistake>

<CommonMistake title="Присваивание указателю вместо значения">

`void set_zero(int *p) { p = 0; }` обнуляет копию указателя, а не переменную. Нужно `*p = 0;`.

</CommonMistake>

<CommonMistake title="Выходной параметр не заполнен">

Если функция при ошибке не пишет результат, а вызывающий код использует его без проверки, получится мусор. Проверяйте признак успеха.

</CommonMistake>

## Практика

1. **Упорядочить три числа** — функция `swap`.
2. **Деление с остатком** — два выходных параметра и математический остаток.
3. **Минимум и максимум** — `const`-массив и выходные параметры.
4. **Разбор времени** — признак успеха и результат через указатели.

## Итоги

- Чтобы функция изменила переменную вызывающего кода, ей передают адрес: `f(&x)`, параметр `int *p`, запись `*p = …`.
- Выходные параметры позволяют вернуть несколько результатов; `return` при этом часто сообщает об успехе.
- `const T *p` — входной параметр только для чтения; так передают большие данные без копирования.
- Указатель-параметр, который может быть `NULL`, проверяют перед записью.
- Присваивание `p = …` внутри функции меняет копию указателя, а `*p = …` — данные вызывающего кода.
