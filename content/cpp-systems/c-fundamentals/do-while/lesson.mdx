## Сначала сделать, потом проверить

Цикл `while` проверяет условие **до** каждой итерации. Если условие ложно с самого начала, тело не выполнится ни разу. Обычно это правильно, но бывают задачи, где действие нужно выполнить хотя бы один раз, а решение «повторять ли» принимается по его результату:

- спросить у пользователя число и повторять вопрос, пока ответ не корректен;
- посчитать цифры числа — у нуля тоже есть одна цифра;
- бросить кубик и бросать снова, пока не выпадет шестёрка.

Для этого есть цикл `do while` — цикл с **постусловием**.

## Устройство `do while`

```c
#include <stdio.h>

int main(void) {
    int i = 10;
    do {
        printf("%d\n", i);
        i++;
    } while (i <= 5);
    printf("после цикла i = %d\n", i);
    return 0;
}
```

Вывод:

```text
10
после цикла i = 11
```

Условие `10 <= 5` ложно с самого начала, но тело выполнилось один раз: проверка происходит **после** тела. Порядок:

1. Выполняется тело.
2. Проверяется условие.
3. Если истинно — снова шаг 1; если ложно — выход.

Обратите внимание на **точку с запятой** после `while (...)` в конце: у `do while` она обязательна, в отличие от обычного `while`.

|                               | `while` | `do while`  |
| ----------------------------- | ------- | ----------- |
| Когда проверяется условие     | до тела | после тела  |
| Минимум итераций              | 0       | 1           |
| Точка с запятой после условия | нельзя  | обязательна |

## Цифры числа, включая ноль

Вспомните программу подсчёта цифр из прошлого урока: для `0` она отвечала «0 цифр». С `do while` первая итерация выполняется всегда, и у нуля корректно оказывается одна цифра:

```c
#include <stdio.h>

int main(void) {
    long long n;
    scanf("%lld", &n);
    int digits = 0;
    do {
        digits++;
        n /= 10;
    } while (n != 0);
    printf("%d\n", digits);
    return 0;
}
```

Ввод:

```text
0
```

Вывод:

```text
1
```

Условие `n != 0`, а не `n > 0`, — чтобы цикл работал и для отрицательных чисел: `-305 / 10` даёт `-30`, затем `-3`, затем `0`.

## Проверка ввода

Самое типичное применение `do while` — повторять запрос, пока данные не станут допустимыми. Например, оценка от 1 до 5:

```c
#include <stdio.h>

int main(void) {
    int grade;
    int attempts = 0;
    do {
        scanf("%d", &grade);
        attempts++;
    } while (grade < 1 || grade > 5);
    printf("оценка %d, попыток: %d\n", grade, attempts);
    return 0;
}
```

Ввод:

```text
0 7 -2 4
```

Вывод:

```text
оценка 4, попыток: 4
```

С обычным `while` пришлось бы читать первое значение до цикла и ещё раз внутри — дублирование, которого `do while` избегает.

В настоящей интерактивной программе здесь нужно ещё проверять результат `scanf`: если ввод закончился или вместо числа введены буквы, `scanf` вернёт не 1, и цикл станет бесконечным. В задачах курса гарантируется, что подходящее значение во вводе есть.

## Повторять, пока результат не станет нужным

**Цифровой корень** числа — результат многократного сложения цифр, пока не останется одна цифра: `9875 → 29 → 11 → 2`. Здесь удобно вложить `while` в `do while`:

```c
#include <stdio.h>

int main(void) {
    long long n = 9875;
    do {
        long long sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        n = sum;
        printf("%lld\n", n);
    } while (n >= 10);
    return 0;
}
```

Вывод:

```text
29
11
2
```

Внешний цикл повторяет «сложить цифры», внутренний — проходит по цифрам. Внешний цикл с постусловием: сложение выполняется хотя бы раз, а продолжать ли, решает результат. (Для однозначного `n` программа напечатает его само: сумма цифр однозначного числа равна ему.)

## Когда какой цикл выбрать

- Число повторений известно заранее (от 1 до n) — `for` из следующего урока.
- Повторять, пока выполняется условие, и возможно ни разу — `while`.
- Действие обязательно хотя бы раз, а условие зависит от его результата — `do while`.

На практике `do while` встречается реже двух других, но там, где он уместен, код становится заметно проще.

## Частые ошибки

<CommonMistake title="Нет точки с запятой после while">

`} while (n != 0)` без `;` — ошибка компиляции. У `do while` это единственное место, где после закрывающей скобки условия ставится точка с запятой.

</CommonMistake>

<CommonMistake title="Переменная условия объявлена внутри тела">

`do { int x; scanf("%d", &x); } while (x < 0);` — ошибка: `x` существует только внутри фигурных скобок, а условие находится снаружи. Объявляйте такую переменную до `do`.

</CommonMistake>

<CommonMistake title="do while там, где нужно «ни разу»">

Если для пустого входа тело выполнять нельзя (например, деление на количество элементов), `do while` выполнит его всё равно. Выбирайте цикл по тому, допустимо ли ноль итераций.

</CommonMistake>

## Практика

1. **Цифры любого числа** — включая ноль и отрицательные.
2. **Допустимое значение** — проверка ввода.
3. **Цифровой корень** — повторение до одной цифры.
4. **Угадай число** — диалог с подсказками.

## Итоги

- `do { тело } while (условие);` выполняет тело хотя бы один раз и проверяет условие после.
- После `while (условие)` в `do while` обязательна точка с запятой.
- Переменные, участвующие в условии, объявляются до `do`.
- Типичные применения: проверка ввода, обработка числа, у которого есть хотя бы одна цифра, повторение действия до нужного результата.
