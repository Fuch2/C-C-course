## Числа, у которых есть имя

Посмотрите на строку `total = price * 120 / 100;`. Что такое 120? Через месяц даже автор не вспомнит, что это цена с налогом 20 %. Такие необъяснённые числа в коде называют **магическими числами**. Их опасно не только читать, но и менять: если ставка налога изменится, придётся найти и исправить каждое «120», не задев случайно другое «120», которое означает что-то совсем иное.

В этом уроке разберём, как записывать константы в C: литералы разных видов, константы с именами через `const` и `#define`, а заодно шестнадцатеричную систему, которая постоянно встречается в системном программировании.

## Литералы

**Литерал** — значение, записанное прямо в коде. Вы уже встречали многие из них:

| Литерал        | Тип                 | Значение                    |
| -------------- | ------------------- | --------------------------- |
| `42`           | `int`               | сорок два                   |
| `-7`           | `int`               | минус и литерал 7           |
| `3000000000LL` | `long long`         | три миллиарда               |
| `42u`          | `unsigned int`      | беззнаковое 42              |
| `3.14`         | `double`            | дробное                     |
| `2.5f`         | `float`             | дробное одинарной точности  |
| `1e6`          | `double`            | 1 · 10⁶ = 1000000.0         |
| `2.5e-3`       | `double`            | 2,5 · 10⁻³ = 0.0025         |
| `'A'`          | `int` (код символа) | 65                          |
| `"текст"`      | строка              | последовательность символов |

Запись `1e6` — экспоненциальная: число до `e` умножается на 10 в степени после `e`. Она удобна для очень больших и очень маленьких величин. Обратите внимание: `1e6` — это `double`, даже если число целое.

## Шестнадцатеричная и восьмеричная запись

Целые литералы можно записывать не только в десятичной системе:

- префикс `0x` — **шестнадцатеричная** система (основание 16): цифры 0–9 и буквы a–f (10–15);
- префикс `0` — **восьмеричная** (основание 8).

```c
#include <stdio.h>

int main(void) {
    int a = 255;
    int b = 0xFF;
    int c = 0377;
    printf("%d %d %d\n", a, b, c);
    printf("%x %X %#x %o\n", 255, 255, 255, 255);
    return 0;
}
```

Вывод:

```text
255 255 255
ff FF 0xff 377
```

Все три переменные хранят одно и то же число 255. Система счисления — только способ **записи** числа в коде или при выводе; в памяти число одно и то же.

Для вывода и ввода в шестнадцатеричном виде используются `%x` (строчные буквы), `%X` (заглавные), `%#x` (с префиксом `0x`); восьмеричная — `%o`.

Зачем это нужно? Одна шестнадцатеричная цифра — ровно 4 бита, две — ровно байт. Поэтому адреса памяти, цвета (`#FF8800`), коды символов и битовые маски почти всегда записывают в шестнадцатеричном виде. Вы будете встречать `0x` постоянно.

<Warning title="Ведущий ноль — это восьмеричная система">

`int code = 012;` — это не двенадцать, а **десять** (1 · 8 + 2). Никогда не дополняйте десятичные литералы нулями слева «для красоты». А `09` вообще ошибка компиляции: в восьмеричной системе нет цифры 9.

</Warning>

## Двоичная запись и разделители разрядов

C23 добавил ещё два удобства, которые давно были в других языках:

- префикс `0b` — **двоичная** запись: `0b1010` — это 10;
- одиночная кавычка `'` между цифрами — **разделитель разрядов**. Компилятор её просто пропускает, а человеку проще прочитать `146'000'000`, чем `146000000`.

```c
#include <stdio.h>

int main(void) {
    int population = 146'000'000;
    unsigned flags = 0b1010'0001;
    printf("%d\n", population);
    printf("%u %#x %b\n", flags, flags, flags);
    return 0;
}
```

Вывод:

```text
146000000
161 0xa1 10100001
```

Спецификатор `%b` печатает число в двоичной системе — он тоже появился в C23. Двоичная запись пригодится в уроках о битовых операциях, где каждый бит числа что-то означает.

<Tip title="В старом коде">

До C23 двоичные литералы и `%b` были расширениями отдельных компиляторов, а разделителей разрядов не было вовсе. В коде, который должен собираться по C17, вместо `0b1010'0001` пишут `0xA1`.

</Tip>

## Константы через `const`

Самый простой способ дать числу имя — объявить переменную со словом `const`. Её значение нельзя изменить после инициализации:

```c
#include <stdio.h>

int main(void) {
    const int VAT_PERCENT = 20;
    const int SECONDS_PER_DAY = 24 * 60 * 60;

    int price = 1500;
    int with_vat = price * (100 + VAT_PERCENT) / 100;
    printf("%d %d\n", with_vat, SECONDS_PER_DAY);
    return 0;
}
```

Вывод:

```text
1800 86400
```

Попытка изменить константу — ошибка компиляции:

```c
#include <stdio.h>

int main(void) {
    const int LIMIT = 10;
    LIMIT = 20;    // Ошибка компиляции: assignment of read-only variable 'LIMIT'
    printf("%d\n", LIMIT);
    return 0;
}
```

Компилятор защищает от случайной перезаписи. Константы принято называть заглавными буквами с подчёркиваниями: `MAX_USERS`, `VAT_PERCENT`. Так их сразу видно в коде.

Выражение `24 * 60 * 60` вместо `86400` — тоже хороший приём: формула объясняет себя, а вычислит её компилятор, программа от этого не замедлится.

## Константы через `#define`

Второй способ — директива препроцессора `#define`. Вы уже знаете одну директиву — `#include`. Перед компиляцией **препроцессор** просматривает текст программы и выполняет директивы. `#define` задаёт текстовую замену: везде, где встречается имя, подставляется указанный текст.

```c
#include <stdio.h>

#define MAX_SCORE 100
#define PI 3.141592653589793

int main(void) {
    int score = 87;
    printf("%d%%\n", score * 100 / MAX_SCORE);
    printf("%.4f\n", PI * 2);
    return 0;
}
```

Вывод:

```text
87%
6.2832
```

После строк `#define` нет точки с запятой и знака `=`: это не инструкция C, а команда препроцессору «замени `MAX_SCORE` на `100`».

### Ловушка текстовой замены

Препроцессор не понимает выражений, он подставляет **текст как есть**. Это приводит к классической ошибке:

```c
#include <stdio.h>

#define BORDER 10 + 2

int main(void) {
    int total = BORDER * 3;    // ожидаем 36
    printf("%d\n", total);
    return 0;
}
```

Вывод:

```text
16
```

После подстановки строка выглядит так: `int total = 10 + 2 * 3;` — умножение выполняется раньше сложения. Правило: **выражение в `#define` всегда заключайте в скобки**: `#define BORDER (10 + 2)`.

## `constexpr` — настоящая константа (C23)

У `const` есть неожиданное ограничение: в C это «переменная, которую нельзя менять», а не константа в полном смысле. Например, массив размером `const int N = 7;` компилятор считает массивом переменной длины, и инициализировать его списком `{…}` нельзя.

C23 добавил слово `constexpr`. Такая константа вычисляется при компиляции, её значение известно заранее, и её можно использовать везде, где нужно число: в размере массива, в метке `case`, вне функций:

```c
#include <stdio.h>

constexpr int DAYS = 7;
constexpr double HOURS_PER_DAY = 24.0;

int main(void) {
    int temps[DAYS] = {3, 5, 2, -1, 0, 4, 6};
    int sum = 0;
    for (int i = 0; i < DAYS; i++) {
        sum += temps[i];
    }
    printf("часов в неделе: %.0f\n", DAYS * HOURS_PER_DAY);
    printf("средняя температура: %.2f\n", sum / (double)DAYS);
    return 0;
}
```

Вывод:

```text
часов в неделе: 168
средняя температура: 2.71
```

Замените в этом примере `constexpr` на `const` — GCC сообщит `variable-sized object may not be initialized except with an empty initializer`: массив с размером из `const`-переменной в C считается массивом переменной длины. Clang такой код соберёт, но с `-Wpedantic` предупредит, что «свернул» размер в константу в виде расширения — то есть по стандарту это всё равно ошибка. С `constexpr` такой проблемы нет ни в одном компиляторе.

Инициализатор `constexpr` обязан быть известен при компиляции: `constexpr int N = 24 * 60;` — можно, а `constexpr int n = read_number();` — ошибка. Для значений, которые появляются только во время работы программы (например, прочитанных `scanf`), по-прежнему используют `const`.

## `const`, `constexpr` или `#define`?

|                                       | `const int X = 5;` | `constexpr int X = 5;` | `#define X 5`                 |
| ------------------------------------- | ------------------ | ---------------------- | ----------------------------- |
| Есть тип, компилятор проверяет        | да                 | да                     | нет, это текст                |
| Подчиняется областям видимости        | да                 | да                     | нет, действует до конца файла |
| Видна в отладчике                     | да                 | да                     | нет                           |
| Размер массива, `case`, вне функций   | не всегда          | да                     | да                            |
| Значение может прийти во время работы | да                 | нет                    | нет                           |

В новом коде на C23 для числовых констант лучший выбор — `constexpr`: у неё есть тип и область видимости, и работает она везде. `const` нужен для неизменяемых значений, которые вычисляются во время работы. `#define` по-прежнему повсюду в существующем коде и заголовках библиотек — его нужно уметь читать, а в новом коде он остаётся для условной компиляции (о ней — в модуле «Углублённый C»). В уроке `enum` вы узнаете ещё один способ — именованные целые константы.

## Частые ошибки

<CommonMistake title="Точка с запятой в #define">

`#define LIMIT 100;` — точка с запятой станет частью замены. Выражение `if (x > LIMIT)` превратится в `if (x > 100;)` — ошибка компиляции в неожиданном месте.

</CommonMistake>

<CommonMistake title="Выражение без скобок">

`#define DOUBLE_BORDER 2 * 5 + 1` и затем `DOUBLE_BORDER * 2` — получится `2 * 5 + 1 * 2 = 12`, а не 22. Скобки вокруг выражения обязательны.

</CommonMistake>

<CommonMistake title="Ведущий ноль">

`int month = 08;` — ошибка компиляции, `int month = 07;` — работает «случайно». Не пишите ведущие нули в десятичных числах.

</CommonMistake>

## Итоги

- Литералы: `42`, `42u`, `42LL`, `3.14`, `1e6`, `'A'`, `"текст"`. `1e6` имеет тип `double`.
- `0x` — шестнадцатеричная запись, ведущий `0` — восьмеричная, `0b` — двоичная (C23); `%x`, `%X`, `%#x`, `%o`, `%b` печатают в этих системах. Разделитель `'` делает длинные числа читаемыми: `1'000'000`.
- `const` создаёт неизменяемую переменную с типом; имена констант пишут ЗАГЛАВНЫМИ.
- `constexpr` (C23) — константа, известная при компиляции: годится для размеров массивов и `case`.
- `#define` — текстовая замена до компиляции: без `=` и `;`, выражения заключаются в скобки.
- Магические числа заменяйте именованными константами.
