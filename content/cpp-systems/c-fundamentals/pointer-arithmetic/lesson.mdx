## Указатель как курсор

В прошлом уроке выяснилось, что `p[i]` — это `*(p + i)`. Значит, к указателю можно прибавлять числа. Но указатель можно и **двигать**: сдвинуть на следующий элемент, на два назад, сравнить с концом массива. Получается курсор, который ходит по массиву.

Так устроены функции стандартной библиотеки: `strchr` возвращает указатель на найденный символ, `fgets` пишет символы, двигаясь по буферу. В этом уроке разберём все операции с указателями на элементы массива и научимся передавать в функцию **диапазон** — пару указателей «начало» и «конец».

## Сложение указателя с числом

Если `p` указывает на элемент массива, то `p + 1` указывает на следующий элемент, `p + 3` — на элемент через три, а `p - 1` — на предыдущий:

```c
#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a;
    printf("%d %d %d\n", *p, *(p + 1), *(p + 3));
    p += 2;                 // теперь p указывает на a[2]
    printf("%d %d %d\n", *p, *(p - 1), p[2]);
    return 0;
}
```

Вывод:

```text
10 20 40
30 20 50
```

После `p += 2` указатель смотрит на `a[2]`, и все смещения отсчитываются уже от него: `*(p - 1)` — это `a[1]`, а `p[2]` — это `a[4]`.

| --------- | ------- | ------- | ------- | ------- | ------- |

## Шаг измеряется в элементах

Число, которое прибавляют к указателю, — это количество **элементов**, а не байтов. Компилятор сам умножает его на размер типа: для `int *` шаг равен 4 байтам, для `double *` — 8. Проверим тем же приёмом, что в уроке «Адреса и массивы»: разность указателей на `char` показывает расстояние в байтах.

```c
#include <stdio.h>

int main(void) {
    int numbers[3] = {1, 2, 3};
    double values[3] = {1.5, 2.5, 3.5};
    int *ip = numbers;
    double *dp = values;
    printf("%td %td\n", (char *)(ip + 1) - (char *)ip, (char *)(dp + 1) - (char *)dp);
    printf("%d %.1f\n", *(ip + 2), *(dp + 2));
    return 0;
}
```

Вывод:

```text
4 8
3 3.5
```

Именно поэтому тип указателя так важен: он задаёт не только то, как читать значение, но и длину шага. Запись `ip + 2` означает «на два `int` дальше» независимо от того, сколько байтов занимает `int`.

## Обход массива указателем

Указатель можно увеличивать операторами `++` и `+=`. Вот сумма массива, где вместо индекса по массиву идёт сам указатель:

```c
#include <stdio.h>

int main(void) {
    int a[5] = {3, 1, 4, 1, 5};
    int sum = 0;
    for (const int *p = a; p < a + 5; p++) {
        sum += *p;
    }
    printf("%d\n", sum);
    return 0;
}
```

Вывод:

```text
14
```

Цикл читается так: «начни с первого элемента; пока `p` не дошёл до позиции `a + 5`, прибавь значение и шагни дальше». Указатель объявлен как `const int *`: цикл только читает элементы, и компилятор не даст случайно их изменить.

`a + 5` — позиция **сразу за последним элементом**. Там нет элемента, но сам адрес вычислять можно — именно с ним цикл сравнивает `p`, чтобы остановиться.

## Диапазон: начало и конец

Позицию «сразу за последним» называют **концом** массива (end). Пара указателей `begin` и `end` задаёт **диапазон**: элементы от `begin` включительно до `end` не включительно. Математики записывают это как `[begin, end)`.

Функция, принимающая диапазон, работает с целым массивом и с любой его частью:

```c
#include <stdio.h>

int sum_range(const int *begin, const int *end) {
    int total = 0;
    for (const int *p = begin; p != end; p++) {
        total += *p;
    }
    return total;
}

int main(void) {
    int a[6] = {1, 2, 3, 4, 5, 6};
    printf("%d\n", sum_range(a, a + 6));      // весь массив
    printf("%d\n", sum_range(a, a + 3));      // a[0], a[1], a[2]
    printf("%d\n", sum_range(a + 3, a + 6));  // a[3], a[4], a[5]
    printf("%d\n", sum_range(a + 2, a + 2));  // пустой диапазон
    return 0;
}
```

Вывод:

```text
21
6
15
0
```

У полуоткрытых диапазонов три удобных свойства:

- количество элементов равно `end - begin`;
- пустой диапазон — это `begin == end`, никаких особых случаев;
- соседние части стыкуются без пересечений: `[a, a + 3)` и `[a + 3, a + 6)` вместе дают весь массив.

Правило безопасности: указатель можно двигать только в пределах массива и на одну позицию за его конец. Читать `*end` нельзя — там уже не элемент массива. Вычислять `a + 7` для массива из шести элементов тоже нельзя, даже без чтения: это неопределённое поведение.

## Разность указателей

Если два указателя смотрят в один массив, их разность — количество элементов между ними. У результата специальный тип `ptrdiff_t`, а печатают его спецификатором `%td`.

Разность превращает указатель обратно в индекс: если `p` указывает в массив `a`, то `p - a` — индекс элемента. Это пригодится функции поиска, которая возвращает указатель на найденное:

```c
#include <stdio.h>

int *find(int *begin, int *end, int value) {
    for (int *p = begin; p != end; p++) {
        if (*p == value) {
            return p;
        }
    }
    return end;
}

int main(void) {
    int a[6] = {7, 3, 9, 3, 5, 1};
    int *end = a + 6;
    int *p = find(a, end, 3);
    printf("3 найдено на позиции %td\n", p - a);
    p = find(p + 1, end, 3);
    printf("следующее 3 — на позиции %td\n", p - a);
    p = find(a, end, 8);
    if (p == end) {
        printf("8 не найдено\n");
    }
    printf("элементов в массиве: %td\n", end - a);
    return 0;
}
```

Вывод:

```text
3 найдено на позиции 1
следующее 3 — на позиции 3
8 не найдено
элементов в массиве: 6
```

Разберём:

- Если элемент не найден, функция возвращает `end`. Это удобная договорённость для диапазонов: «не найдено» — значит «дошли до конца». В уроке про `NULL` для этого возвращали нулевой указатель — оба способа встречаются на практике.
- Второй поиск начинается с `p + 1` — сразу за первым найденным элементом. Так находят все вхождения по очереди.
- `end - a` — длина массива в элементах.

Вычитать можно только указатели в **один и тот же** массив. Разность указателей на две разные переменные или два разных массива не имеет смысла и является неопределённым поведением.

## Строки: идём до нуль-терминатора

У строки конец отмечен символом `'\0'`, поэтому указатель на `char` можно двигать до него, не зная длину заранее. Вот собственная версия `strlen` и подсчёт пробелов:

```c
#include <stdio.h>

int length(const char *s) {
    const char *p = s;
    while (*p != '\0') {
        p++;
    }
    return (int)(p - s);
}

int count_spaces(const char *s) {
    int count = 0;
    while (*s != '\0') {
        if (*s++ == ' ') {
            count++;
        }
    }
    return count;
}

int main(void) {
    printf("%d %d\n", length("hello world"), count_spaces("a b c d"));
    return 0;
}
```

Вывод:

```text
11 3
```

В `length` указатель `p` уходит до `'\0'`, а разность `p - s` — количество пройденных символов. Приведение `(int)` переводит `ptrdiff_t` в тип результата функции.

В `count_spaces` используется знаменитая идиома `*s++`. Из урока о разыменовании вы помните: `*s++` означает «прочитай символ, на который указывает `s`, а потом сдвинь `s`». Чтение и шаг выполняются в одном выражении. Параметр `s` — копия указателя, поэтому сдвигать его внутри функции безопасно: у вызывающего кода указатель не изменится.

## Два указателя навстречу

Чтобы развернуть массив на месте, удобно взять два указателя: один идёт от начала, другой от конца, и на каждом шаге элементы под ними меняются местами:

```c
#include <stdio.h>

void reverse(int *begin, int *end) {
    while (end - begin > 1) {
        end--;
        int tmp = *begin;
        *begin = *end;
        *end = tmp;
        begin++;
    }
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    reverse(a, a + 5);
    for (const int *p = a; p != a + 5; p++) {
        printf("%d ", *p);
    }
    printf("\n");
    reverse(a + 1, a + 4);  // разворачиваем только середину
    for (const int *p = a; p != a + 5; p++) {
        printf("%d ", *p);
    }
    printf("\n");
    return 0;
}
```

Вывод:

```text
5 4 3 2 1
5 2 3 4 1
```

Пока между указателями больше одного элемента, `end` сначала отступает на последний элемент диапазона, затем значения меняются, а `begin` шагает вперёд. Указатели сходятся к середине. Порядок «сначала `end--`, потом обмен» нужен потому, что `end` указывает **за** последний элемент.

Обратите внимание: функция ни разу не вычисляет `begin - 1` или `end - 1` для пустого диапазона, поэтому указатели не выходят за допустимые позиции даже при `begin == end`.

## Индексы или указатели?

`a[i]` и `*(a + i)` — одно и то же, и компилятор превращает оба цикла в одинаковый машинный код. Выбирайте запись, которая понятнее:

- **Индексы** удобны, когда важен сам номер элемента: «вывести позицию», «сравнить `a[i]` с `a[i + 1]`», обход таблиц.
- **Указатели** удобны для диапазонов `[begin, end)`, для строк (идти до `'\0'`) и когда функция возвращает «место» в массиве, как `find` или `strchr`.

Многие функции стандартной библиотеки C и вся библиотека алгоритмов C++ построены на диапазонах — эти знания пригодятся дальше в курсе.

## Частые ошибки

<CommonMistake title="Чтение по указателю end">

```c
for (const int *p = a; p <= a + n; p++) {   // ошибка: <=
    sum += *p;
}
```

На последнем шаге `p == a + n`, и `*p` читает память за массивом. Условие обхода — `p < a + n` или `p != a + n`.

</CommonMistake>

<CommonMistake title="Двойное масштабирование">

`int *q = p + i * sizeof(int);` — ошибка: компилятор сам умножает смещение на размер элемента, и указатель уйдёт в четыре раза дальше. Пишите `p + i`.

</CommonMistake>

<CommonMistake title="Указатель за пределами массива">

Для `int a[5]` допустимы указатели от `a` до `a + 5`. Вычислить `a + 6` или `a - 1` — уже неопределённое поведение, даже если по ним ничего не читать.

</CommonMistake>

<CommonMistake title="Разность указателей на разные массивы">

`p - q`, где `p` указывает в один массив, а `q` в другой, не имеет смысла. Расстояние определено только внутри одного массива.

</CommonMistake>

<CommonMistake title="*p++ вместо (*p)++">

`*p++` сдвигает указатель, `(*p)++` увеличивает значение. Если нужно увеличить элемент, ставьте скобки.

</CommonMistake>

## Практика

1. **Разворот на месте** — два указателя навстречу.
2. **Поиск в диапазоне** — функция возвращает указатель, индекс вычисляется разностью.
3. **Нули в конец** — «читающий» и «пишущий» указатели.
4. **Лишние пробелы** — те же два указателя, но по строке.

## Итоги

- `p + n` и `p - n` сдвигают указатель на `n` **элементов**; шаг в байтах задаёт тип указателя.
- По массиву можно идти указателем: `for (const int *p = a; p < a + n; p++)`.
- Диапазон `[begin, end)` — пара указателей; `end` указывает за последний элемент, его можно сравнивать, но нельзя разыменовывать.
- Разность указателей в одном массиве — число элементов типа `ptrdiff_t` (`%td`); `p - a` — индекс элемента.
- Строку проходят указателем до `'\0'`; `*s++` читает символ и сдвигает указатель.
- Указатели допустимы только внутри массива и на одну позицию за ним.
