## Управление ходом цикла

Обычный цикл проверяет условие только в одном месте — в заголовке. Но иногда решение «хватит» или «этот элемент пропустить» удобнее принимать прямо посреди тела: нашли то, что искали, — можно не перебирать остальное; встретили некорректное значение — пропустить его. Для этого есть два оператора: `break` и `continue`.

## `break`: досрочный выход

`break` немедленно завершает **ближайший** цикл, в котором находится. Выполнение продолжается с первой инструкции после цикла.

Классическое применение — поиск: нашли нужный элемент, дальше искать незачем.

```c
#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);
    int smallest = n;
    for (int d = 2; d <= n; d++) {
        if (n % d == 0) {
            smallest = d;
            break;
        }
    }
    printf("%d\n", smallest);
    return 0;
}
```

Ввод:

```text
91
```

Вывод:

```text
7
```

Наименьший делитель 91 (больше единицы) — 7. Как только он найден, `break` прекращает перебор: проверять 8, 9, …, 91 не нужно.

## Проверка на простоту

Число простое, если у него ровно два делителя: 1 и оно само. Достаточно проверить делители от 2 до √n: если у `n` есть делитель больше корня, то есть и парный ему меньше корня. Условие `d * d <= n` проверяет это без дробного `sqrt`:

```c
#include <stdio.h>

int main(void) {
    long long n;
    scanf("%lld", &n);
    int prime = n >= 2;
    for (long long d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            prime = 0;
            break;
        }
    }
    printf("%s\n", prime ? "простое" : "не простое");
    return 0;
}
```

Ввод:

```text
1000000007
```

Вывод:

```text
простое
```

1 000 000 007 — простое число, его любят использовать в олимпиадных задачах. Благодаря границе `d * d <= n` цикл выполнил около 31 600 итераций вместо миллиарда. Попробуйте ввести `1000000008` — `break` сработает уже на первой итерации, при `d = 2`.

<Tip title="Флаг и break вместе">

Переменная `prime` — **флаг**: она запоминает результат проверки. `break` экономит время, а флаг сообщает коду после цикла, чем закончился поиск — нашли делитель или перебрали всё.

</Tip>

## `continue`: к следующей итерации

`continue` пропускает остаток тела и переходит к **следующей итерации**. В цикле `for` перед этим выполняется изменение счётчика из заголовка; в `while` — сразу проверка условия.

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) {
            continue;
        }
        sum += i;
    }
    printf("%d\n", sum);
    return 0;
}
```

Вывод:

```text
37
```

Сумма чисел от 1 до 10 без 3, 6, 9: 55 − 18 = 37.

`continue` полезен, когда нужно отбросить «неинтересные» элементы в начале тела и не вкладывать всю основную логику в `if`. Код остаётся плоским: «если элемент не подходит — пропустить», а дальше обычная обработка.

<Warning title="continue в while и счётчик">

В `while` изменение счётчика находится в теле. Если `continue` стоит до него, счётчик не изменится, и цикл станет бесконечным:

```c
int i = 0;
while (i < 10) {
    if (i % 2 == 0) {
        continue;    // i++ ниже не выполнится — зависание
    }
    i++;
}
```

В `for` такой проблемы нет: изменение в заголовке выполняется и после `continue`.

</Warning>

## Бесконечный цикл с выходом из середины

Иногда условие выхода естественно проверять в середине тела — например, при чтении данных: прочитали, проверили признак конца, обработали. Тогда пишут намеренно бесконечный цикл `while (1)` и выходят через `break`:

```c
#include <stdio.h>

int main(void) {
    int sum = 0;
    while (1) {
        int x;
        if (scanf("%d", &x) != 1) {
            break;          // ввод закончился
        }
        if (x < 0) {
            continue;       // отрицательные пропускаем
        }
        sum += x;
    }
    printf("%d\n", sum);
    return 0;
}
```

Ввод:

```text
5 -3 10 -1 2
```

Вывод:

```text
17
```

Цикл читает числа до конца ввода — сколько бы их ни было — и складывает только неотрицательные. Такой шаблон «читать, пока читается» понадобится в уроке о `main` и вводе до конца.

## `break` внутри `switch` в цикле

`break` выходит из ближайшей конструкции — цикла **или** `switch`. Если `switch` находится внутри цикла, `break` в ветке `case` выйдет только из `switch`, а цикл продолжится:

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 3; i++) {
        switch (i) {
        case 2:
            printf("два\n");
            break;          // выход из switch, не из цикла
        default:
            printf("%d\n", i);
            break;
        }
    }
    return 0;
}
```

Вывод:

```text
1
два
3
```

Чтобы прервать цикл из `switch`, обычно используют флаг: установить его в ветке, а в условии цикла проверять.

## Не злоупотребляйте

`break` и `continue` делают код короче, но если их много, следить за ходом выполнения становится трудно. Хорошее правило: один-два выхода из цикла, и каждый — в очевидном месте, обычно в начале тела.

## Частые ошибки

<CommonMistake title="break выходит только из ближайшего цикла">

Во вложенных циклах `break` во внутреннем цикле не завершает внешний. Для выхода из обоих нужен флаг — об этом в уроке о вложенных циклах.

</CommonMistake>

<CommonMistake title="Бесконечный цикл с continue в while">

`continue` перепрыгивает через изменение счётчика в конце тела. Меняйте счётчик до `continue` или используйте `for`.

</CommonMistake>

<CommonMistake title="Проверка простоты с ошибкой границ">

Числа 0 и 1 не простые, 2 — простое. Цикл `d * d <= n` для них не выполняется, поэтому результат определяет начальное значение флага. Пишите `prime = n >= 2`, а не `prime = 1`.

</CommonMistake>

## Практика

1. **Первый отрицательный** — поиск с досрочным выходом.
2. **Простое ли число** — делители до корня.
3. **Без кратных трём** — `continue`.
4. **Пин-код** — не больше трёх попыток.
5. **Сумма до переполнения** — когда остановиться.

## Итоги

- `break` немедленно завершает ближайший цикл (или `switch`).
- `continue` переходит к следующей итерации; в `for` перед этим выполняется изменение счётчика.
- Поиск: перебор с `break` на первом найденном и флаг для результата.
- Проверка простоты: делители `d` от 2, пока `d * d <= n`; 0 и 1 не простые.
- `while (1)` с `break` в середине — для циклов, где условие выхода удобно проверять после чтения данных.
