## Зачем отдельный урок про printf

До сих пор `printf` печатал готовый текст. Но программы почти всегда выводят **вычисленные** значения: сумму покупки, время, температуру. Буква `f` в названии `printf` означает formatted — «форматированный»: функция умеет вставлять числа в текст и оформлять их — выравнивать по ширине, дополнять нулями, ставить знак. В этом уроке разберём, как это работает. Почти каждая задача курса заканчивается вызовом `printf`, поэтому этот урок окупится много раз.

## Строка формата и спецификаторы

Первый аргумент `printf` — **строка формата**. Это обычный текст, в котором встречаются **спецификаторы** — места для подстановки значений. Спецификатор начинается со знака процента. Для целых чисел используется `%d` (от decimal — десятичное):

```c
#include <stdio.h>

int main(void) {
    printf("В корзине %d товара\n", 3);
    printf("%d + %d = %d\n", 2, 5, 2 + 5);
    return 0;
}
```

Вывод:

```text
В корзине 3 товара
2 + 5 = 7
```

После строки формата через запятую перечисляются значения. Первый спецификатор заменяется первым значением, второй — вторым и так далее. Во второй строке три спецификатора и три значения: `2`, `5` и результат выражения `2 + 5`. Значением может быть число, переменная или целое выражение — `printf` получит уже вычисленный результат.

<Important title="Число спецификаторов = число значений">

Каждому спецификатору должно соответствовать ровно одно значение подходящего типа. Если значений меньше, `printf` напечатает мусор из памяти; компилятор в строгом режиме предупредит об этом.

</Important>

## Переменные в выводе

Чаще всего печатают значения переменных:

```c
#include <stdio.h>

int main(void) {
    int hours = 2;
    int minutes = 45;
    int total = hours * 60 + minutes;
    printf("%d ч %d мин = %d мин\n", hours, minutes, total);
    return 0;
}
```

Вывод:

```text
2 ч 45 мин = 165 мин
```

Обратите внимание: всё, что не является спецификатором, печатается как есть — буквы, пробелы, знак равенства. Пробелы между числами и словами нужно ставить в строке формата самому.

## Основные спецификаторы

| Спецификатор | Что печатает                         | Пример вызова         | Результат  |
| ------------ | ------------------------------------ | --------------------- | ---------- |
| `%d`         | Целое число со знаком                | `printf("%d", -42)`   | `-42`      |
| `%c`         | Один символ                          | `printf("%c", 'A')`   | `A`        |
| `%s`         | Строку                               | `printf("%s", "кот")` | `кот`      |
| `%f`         | Дробное число (6 знаков после точки) | `printf("%f", 2.5)`   | `2.500000` |
| `%%`         | Сам знак процента                    | `printf("100%%")`     | `100%`     |

Дробные числа и символы подробно разберём в отдельных уроках. Сейчас главное — `%d` и `%%`. Знак процента в строке формата всегда начинает спецификатор, поэтому, чтобы напечатать сам процент, его удваивают:

```c
#include <stdio.h>

int main(void) {
    int done = 3, total = 4;
    printf("Выполнено %d из %d задач, это %d%%\n", done, total, done * 100 / total);
    printf("Курс: %s, уровень %c\n", "C17", 'A');
    return 0;
}
```

Вывод:

```text
Выполнено 3 из 4 задач, это 75%
Курс: C17, уровень A
```

## Ширина поля: выравнивание столбиком

Между `%` и буквой можно указать **ширину поля** — минимальное число символов, которое займёт значение. Если число короче, слева добавятся пробелы:

```c
#include <stdio.h>

int main(void) {
    printf("[%5d]\n", 42);
    printf("[%5d]\n", 12345);
    printf("[%5d]\n", 1234567);
    printf("[%-5d]\n", 42);
    return 0;
}
```

Вывод:

```text
[   42]
[12345]
[1234567]
[42   ]
```

- `%5d` выравнивает число по правому краю поля из 5 символов.
- Если число длиннее поля, оно печатается целиком — ширина никогда не обрезает значение.
- Минус `%-5d` выравнивает по левому краю: пробелы добавляются справа.

Квадратные скобки здесь только для того, чтобы были видны пробелы. Ширина поля нужна, чтобы печатать аккуратные таблицы — числа в столбце выравниваются по правому краю, как в бухгалтерской книге:

```c
#include <stdio.h>

int main(void) {
    printf("Цена  Товар\n");
    printf("%4d  Хлеб\n", 45);
    printf("%4d  Сыр\n", 520);
    printf("%4d  Чай\n", 1250);
    return 0;
}
```

Вывод:

```text
Цена  Товар
  45  Хлеб
 520  Сыр
1250  Чай
```

<Warning title="Ширина считается в байтах, а не в буквах">

Для строк `%s` ширина отсчитывается в **байтах**. Латинская буква занимает один байт, а русская в кодировке UTF-8 — два. Поэтому `printf("%-8s|", "Сыр")` добавит не пять пробелов, а только два: слово «Сыр» уже занимает 6 байт. Чтобы таблицы с русским текстом выглядели ровно, выравнивайте числа, а текст ставьте в конец строки, как в примере выше.

</Warning>

## Дополнение нулями и знак

Флаг `0` перед шириной заполняет поле нулями вместо пробелов. Это нужно для времени, дат и номеров:

```c
#include <stdio.h>

int main(void) {
    int h = 7, m = 5, s = 9;
    printf("%02d:%02d:%02d\n", h, m, s);
    printf("Заказ №%06d\n", 314);
    printf("%+d %+d\n", 5, -5);
    return 0;
}
```

Вывод:

```text
07:05:09
Заказ №000314
+5 -5
```

`%02d` — «минимум два символа, недостающие заполнить нулями». Флаг `+` заставляет печатать знак даже у положительных чисел — удобно для изменений: `+5` градусов, `-3` балла.

<Concept title="Полная запись спецификатора">

`%` → флаги (`-`, `0`, `+`) → ширина → буква типа. Например, `%-6d`, `%05d`, `%+4d`. В уроке о дробных числах добавится точность: `%.2f`.

</Concept>

## Типичные ошибки и что о них скажет компилятор

Если тип значения не совпадает со спецификатором, компилятор выдаст предупреждение. Например, `printf("%d\n", "текст")` — строка вместо числа:

```text
warning: format ‘%d’ expects argument of type ‘int’, but argument 2 has type ‘char *’
```

Сообщение дословно: «формат `%d` ожидает аргумент типа `int`, а аргумент 2 имеет тип `char *`». Такие предупреждения нельзя игнорировать: программа напечатает мусор.

<CommonMistake title="Забыли значение для спецификатора">

`printf("%d + %d\n", a);` — второму `%d` нечего подставить. Компилятор предупредит: `format ‘%d’ expects a matching ‘int’ argument`. Программа при этом напечатает непредсказуемое число.

</CommonMistake>

<CommonMistake title="Знак процента без удвоения">

`printf("Скидка 10%\n");` — после `%` идёт перевод строки, и компилятор не понимает, что это за спецификатор. Пишите `10%%`.

</CommonMistake>

<CommonMistake title="Переменная вместо строки формата">

Первым аргументом всегда идёт строка формата: `printf("%d\n", x)`, а не `printf(x)`. Даже если нужно напечатать одно число, спецификатор обязателен.

</CommonMistake>

<CommonMistake title="Нет пробелов между значениями">

`printf("%d%d\n", 12, 34)` печатает `1234`: printf не добавляет разделителей. Пробелы, запятые и переводы строк пишите в строке формата сами.

</CommonMistake>

## Итоги

- Строка формата — текст со спецификаторами; значения подставляются по порядку.
- `%d` — целое число, `%c` — символ, `%s` — строка, `%f` — дробное, `%%` — знак процента.
- Ширина поля `%5d` выравнивает вправо, `%-5d` — влево, `%05d` дополняет нулями, `%+d` печатает знак.
- Число значений и их типы должны совпадать со спецификаторами — следите за предупреждениями компилятора.
- printf не добавляет пробелов и переводов строк: всё оформление пишется в строке формата.
