## Практикум: массивы и строки

Массивы и строки — основа почти любой программы, обрабатывающей данные. В этом практикуме шесть задач, в которых нужно не только пройти по массиву, но и придумать, **какие** вспомогательные массивы завести и **как** двигать индексы.

## Три приёма для задач на массивы

**1. Массив счётчиков.** Если значения — небольшие целые числа или буквы, их удобно использовать как индексы: `count[x]++` или `count[c - 'a']++`. Так за один проход считаются частоты, проверяются анаграммы, находится самый частый элемент.

**2. Два индекса.** Многие задачи решаются двумя «указателями» на позиции: навстречу друг другу (палиндромы, разворот), друг за другом (слияние двух отсортированных массивов), «читающий» и «пишущий» (удаление элементов на месте).

**3. Границы диапазона.** В задачах обхода таблиц (спираль, змейка) храните текущие границы — верхнюю, нижнюю, левую и правую — и сужайте их по мере обхода.

## Разбор: сортировка выбором

Отсортировать массив — расположить элементы по возрастанию. Самый понятный способ — **сортировка выбором**: найти минимум, поставить его на первое место; среди оставшихся найти минимум, поставить на второе; и так далее.

```c
#include <stdio.h>

int main(void) {
    int a[] = {29, 10, 14, 37, 13};
    int n = 5;
    for (int i = 0; i < n - 1; i++) {
        int min_index = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[min_index]) {
                min_index = j;
            }
        }
        int tmp = a[i];
        a[i] = a[min_index];
        a[min_index] = tmp;
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
```

Вывод:

```text
10 13 14 29 37
```

Инвариант внешнего цикла: перед шагом `i` первые `i` элементов отсортированы и не больше любого из оставшихся. Сортировка делает примерно n²/2 сравнений: для тысячи элементов это полмиллиона — быстро, а для миллиона — уже слишком долго. В модуле «Алгоритмы и структуры данных» вы изучите сортировки, работающие за n · log n.

## Задачи

1. **Сортировка** — реализуйте сортировку выбором.
2. **Анаграммы** — массив счётчиков букв.
3. **Сжатие строки** — серии одинаковых символов.
4. **Слияние** — два индекса по двум отсортированным массивам.
5. **Спираль** — обход таблицы с сужающимися границами.
6. **Самая частая буква** — частоты и выбор максимума.
