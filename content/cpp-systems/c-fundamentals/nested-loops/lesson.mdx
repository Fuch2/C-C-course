## Цикл внутри цикла

Тело цикла может содержать любые инструкции — в том числе другой цикл. Такие циклы называются **вложенными**. Они нужны везде, где данные имеют два измерения или нужно перебрать **пары**: строки и столбцы таблицы, пиксели изображения, клетки шахматной доски, все пары чисел для проверки условия.

## Как выполняются вложенные циклы

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 4; j++) {
            printf("(%d,%d) ", i, j);
        }
        printf("\n");
    }
    return 0;
}
```

Вывод:

```text
(1,1) (1,2) (1,3) (1,4)
(2,1) (2,2) (2,3) (2,4)
(3,1) (3,2) (3,3) (3,4)
```

На **каждой** итерации внешнего цикла внутренний выполняется **полностью**, от начала до конца. Внешний счётчик `i` меняется медленно — как часовая стрелка, внутренний `j` — быстро, как минутная. Тело внутреннего цикла выполняется 3 · 4 = 12 раз.

Обратите внимание на `printf("\n")`: он стоит во внешнем цикле **после** внутреннего, поэтому переводит строку один раз на каждую строку таблицы.

<Important title="Разные имена счётчиков">

У вложенных циклов должны быть разные счётчики: `i` и `j`, или `row` и `col`. Если внутренний цикл тоже использует `i`, он испортит счётчик внешнего — и внешний цикл либо завершится раньше, либо станет бесконечным.

</Important>

## Таблица умножения

```c
#include <stdio.h>

int main(void) {
    int n = 5;
    for (int row = 1; row <= n; row++) {
        for (int col = 1; col <= n; col++) {
            printf("%4d", row * col);
        }
        printf("\n");
    }
    return 0;
}
```

Вывод:

```text
   1   2   3   4   5
   2   4   6   8  10
   3   6   9  12  15
   4   8  12  16  20
   5  10  15  20  25
```

Ширина поля `%4d` выравнивает столбцы — в каждой ячейке 4 символа, независимо от количества цифр.

## Узоры: когда внутренний цикл зависит от внешнего

Граница внутреннего цикла может зависеть от счётчика внешнего. Так рисуют треугольники и другие фигуры:

```c
#include <stdio.h>

int main(void) {
    int n = 4;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            printf("*");
        }
        printf("\n");
    }
    return 0;
}
```

Вывод:

```text
*
**
***
****
```

В строке номер `i` печатается `i` звёздочек: внутренний цикл идёт до `i`, а не до `n`. Всего звёздочек 1 + 2 + 3 + 4 = 10.

Для фигуры, выровненной вправо, в каждой строке сначала печатают пробелы, потом звёздочки — два внутренних цикла подряд:

```c
#include <stdio.h>

int main(void) {
    int n = 4;
    for (int i = 1; i <= n; i++) {
        for (int s = 1; s <= n - i; s++) {
            printf(" ");
        }
        for (int j = 1; j <= 2 * i - 1; j++) {
            printf("*");
        }
        printf("\n");
    }
    return 0;
}
```

Вывод:

```text
   *
  ***
 *****
*******
```

<Tip title="Как придумать узор">

Выпишите для каждой строки `i`: сколько пробелов, сколько символов. Найдите формулу через `i` и `n` (здесь пробелов `n − i`, звёздочек `2i − 1`). Формулы и становятся границами внутренних циклов.

</Tip>

## Перебор пар

Вложенные циклы перебирают все пары значений. Например, найдём все способы разменять 10 рублей монетами по 2 и 5:

```c
#include <stdio.h>

int main(void) {
    int sum = 10;
    for (int twos = 0; twos * 2 <= sum; twos++) {
        for (int fives = 0; fives * 5 <= sum; fives++) {
            if (twos * 2 + fives * 5 == sum) {
                printf("%d по 2 + %d по 5\n", twos, fives);
            }
        }
    }
    return 0;
}
```

Вывод:

```text
0 по 2 + 2 по 5
5 по 2 + 0 по 5
```

Если важны только **неупорядоченные** пары различных элементов (пара 1–2 и пара 2–1 — одна и та же), внутренний цикл начинают со следующего за внешним: `for (int j = i + 1; ...)`. Так каждая пара рассматривается ровно один раз.

## Сколько это стоит

Если внешний цикл выполняется `n` раз, а внутренний — `m` раз, тело выполнится `n · m` раз. При `n = m = 1000` это миллион — быстро. При `n = m = 100 000` — десять миллиардов, это уже десятки секунд. Вложенные циклы — первое место, где программа может стать слишком медленной. Подробно скорость алгоритмов изучается в модуле «Алгоритмы и структуры данных», а пока прикидывайте: число итераций до ~10⁸ выполняется примерно за секунду.

## Выход из вложенных циклов

`break` во внутреннем цикле прерывает только его. Чтобы выйти из обоих циклов, используют флаг, который проверяет внешний цикл:

```c
#include <stdio.h>

int main(void) {
    int target = 42;
    int found = 0;
    for (int a = 1; a <= 9 && !found; a++) {
        for (int b = a; b <= 9; b++) {
            if (a * b == target) {
                printf("%d * %d = %d\n", a, b, target);
                found = 1;
                break;
            }
        }
    }
    return 0;
}
```

Вывод:

```text
6 * 7 = 42
```

`break` завершает внутренний цикл, а условие `!found` в заголовке внешнего — внешний. Другой способ — вынести циклы в отдельную функцию и выйти из неё оператором `return`: так вы сможете делать после урока «Функции».

## Частые ошибки

<CommonMistake title="Один и тот же счётчик">

`for (int i ...) { for (int i ...) }` — внутреннее объявление «закрывает» внешнее, и это работает, но читать такой код очень трудно, а без `int` во внутреннем цикле внешний счётчик будет испорчен. Используйте разные имена.

</CommonMistake>

<CommonMistake title="Перевод строки не в том цикле">

`printf("\n")` внутри внутреннего цикла переводит строку после каждого элемента. Для таблицы он должен стоять во внешнем цикле после внутреннего.

</CommonMistake>

<CommonMistake title="Пары, посчитанные дважды">

Если нужно перебрать неупорядоченные пары, внутренний цикл должен начинаться с `i + 1`, а не с 0. Иначе каждая пара встретится дважды, плюс «пары» элемента с самим собой.

</CommonMistake>

## Практика

1. **Прямоугольник** — рамка из символов.
2. **Лесенка чисел** — треугольник из чисел.
3. **Таблица умножения n × n** — выравнивание.
4. **Пары с суммой** — перебор неупорядоченных пар.
5. **Простые до n** — проверка каждого числа.

## Итоги

- Во вложенных циклах внутренний выполняется полностью на каждой итерации внешнего; тело внутреннего выполняется `n · m` раз.
- Счётчики вложенных циклов называются по-разному.
- Граница внутреннего цикла может зависеть от внешнего счётчика — так строятся узоры и перебираются пары `j > i`.
- `break` прерывает только ближайший цикл; для выхода из обоих нужен флаг или функция с `return`.
- Вложенные циклы быстро увеличивают время работы: прикидывайте число итераций заранее.
