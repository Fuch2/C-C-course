## Зачем нужны функции

Программы из прошлых разделов помещались целиком в `main`. Когда программа растёт до сотен строк, такой подход перестаёт работать: один и тот же код повторяется в нескольких местах, а чтобы понять, что делает фрагмент, приходится читать его целиком.

**Функция** — именованный фрагмент кода, который можно вызвать из другого места программы. Функции решают сразу три задачи:

1. **Повторное использование.** Код пишется один раз и вызывается сколько угодно.
2. **Имя вместо деталей.** `if (is_prime(n))` читается как обычная фраза, хотя за ней стоит цикл с делителями.
3. **Проверка по частям.** Маленькую функцию легко протестировать отдельно и быть уверенным, что она работает.

Вы уже пользовались функциями: `printf`, `scanf`, `sqrt`, `abs` — это функции стандартной библиотеки. Теперь научимся писать свои.

## Первая функция

```c
#include <stdio.h>

int square(int x) {
    return x * x;
}

int main(void) {
    int a = square(7);
    printf("%d\n", a);
    printf("%d\n", square(3) + square(4));
    return 0;
}
```

Вывод:

```text
49
25
```

Разберём определение `int square(int x) { return x * x; }`:

| Часть           | Значение                                                                    |
| --------------- | --------------------------------------------------------------------------- |
| `int`           | **тип результата**: функция вернёт целое число                              |
| `square`        | **имя** функции                                                             |
| `(int x)`       | **параметр**: функция принимает одно целое число, внутри оно называется `x` |
| `{ ... }`       | **тело** функции                                                            |
| `return x * x;` | вычислить результат и **вернуть** его вызвавшему коду                       |

Запись `square(7)` — **вызов** функции. Значение 7 называется **аргументом**: оно копируется в параметр `x`, выполняется тело, и выражение `square(7)` заменяется возвращённым значением 49. Вызов можно использовать везде, где допустимо число: в присваивании, в выражении, в аргументе другой функции.

## Как выполняется вызов

Когда программа доходит до вызова, выполнение **переходит** в функцию, а по `return` — **возвращается** в точку вызова:

```c
#include <stdio.h>

int add_tax(int price) {
    printf("  вошли в add_tax с price = %d\n", price);
    int result = price + price / 5;
    printf("  выходим с результатом %d\n", result);
    return result;
}

int main(void) {
    printf("начало main\n");
    int total = add_tax(100);
    printf("в main получили %d\n", total);
    return 0;
}
```

Вывод:

```text
начало main
  вошли в add_tax с price = 100
  выходим с результатом 120
в main получили 120
```

`main` «ждёт», пока `add_tax` не закончит работу, и продолжает со следующей инструкции. Переменная `result` существует только во время выполнения функции — после `return` её больше нет.

## Функции без результата: `void`

Не каждая функция что-то вычисляет. Некоторые просто выполняют действие — например, печатают. Тип результата у них `void` («пусто»), а `return` либо отсутствует, либо пишется без значения:

```c
#include <stdio.h>

void print_line(int length) {
    for (int i = 0; i < length; i++) {
        printf("-");
    }
    printf("\n");
}

int main(void) {
    print_line(10);
    printf("Отчёт\n");
    print_line(10);
    return 0;
}
```

Вывод:

```text
----------
Отчёт
----------
```

Вызов `void`-функции — отдельная инструкция: `print_line(10);`. Использовать его в выражении (`int x = print_line(10);`) нельзя — значения нет, и компилятор выдаст ошибку.

Функция без параметров объявляется с `void` в скобках, как `main`: `void print_header(void)`. Вызывается с пустыми скобками: `print_header();`.

## Порядок в файле и прототипы

Компилятор читает файл сверху вниз. Если вызов встречается раньше определения функции, компилятор ещё не знает, какие у неё параметры и результат. Поэтому функции определяют **выше** `main` — как в примерах выше.

Если хочется, чтобы `main` стоял в начале файла, функцию можно **объявить** заранее — написать её **прототип**: заголовок без тела, с точкой с запятой.

```c
#include <stdio.h>

int cube(int x);   // прототип: обещание, что функция будет определена

int main(void) {
    printf("%d\n", cube(5));
    return 0;
}

int cube(int x) {  // определение
    return x * x * x;
}
```

Вывод:

```text
125
```

Прототипы особенно важны, когда программа состоит из нескольких файлов: их выносят в заголовочные файлы `.h`. Именно прототипы `printf` и `scanf` находятся в `stdio.h` — поэтому без `#include` компилятор и жалуется на «неявное объявление».

## Функция как «чёрный ящик»

Хорошую функцию можно использовать, не заглядывая внутрь: по имени, параметрам и типу результата понятно, что она делает. Сравните:

```c
#include <stdio.h>

int is_even(int n) {
    return n % 2 == 0;
}

int count_digits(long long n) {
    int count = 0;
    do {
        count++;
        n /= 10;
    } while (n != 0);
    return count;
}

int main(void) {
    long long n = 2026;
    printf("%d %d\n", is_even(2026), count_digits(n));
    return 0;
}
```

Вывод:

```text
1 4
```

`main` теперь читается почти как текст: «чётное ли», «сколько цифр». Детали спрятаны в функциях и проверены один раз.

<Concept title="Одна функция — одна задача">

Если описание функции требует слова «и» («читает данные **и** считает **и** печатает»), её стоит разделить. Маленькие функции с ясными именами легче понимать, тестировать и использовать повторно.

</Concept>

## Как проверяются задачи с функциями

В части задач этого раздела нужно написать **только функцию**, без `main`. Проверяющая система сама добавит `main`, прочитает аргументы теста, вызовет вашу функцию и напечатает результат. Если в такой задаче написать свою функцию `main`, программа не соберётся: `main` окажется в ней дважды.

Чтобы запустить такую функцию кнопкой «Запустить», впишите аргументы через пробел в поле ввода.

## Частые ошибки

<CommonMistake title="Вызов до объявления">

Функция определена ниже `main`, а прототипа нет. Компилятор C17 выдаст предупреждение о неявном объявлении, а в C++ — ошибку. Определяйте функции выше или пишите прототип.

</CommonMistake>

<CommonMistake title="Забытый return">

Функция с типом `int` должна вернуть значение на любом пути выполнения. Если выполнение дошло до `}` без `return`, результат не определён. GCC предупреждает: `control reaches end of non-void function`.

</CommonMistake>

<CommonMistake title="Печать вместо возврата">

`int square(int x) { printf("%d", x * x); }` — функция печатает, но ничего не возвращает. Тот, кто вызовет `square(3) + 1`, получит мусор. Если от функции нужно значение — `return`, печать оставьте вызывающему коду.

</CommonMistake>

<CommonMistake title="Точка с запятой после заголовка определения">

`int square(int x); { return x * x; }` — точка с запятой превращает заголовок в прототип, а блок после него оказывается вне функции. Ошибка компиляции.

</CommonMistake>

## Практика

1. **Куб числа** — первая функция с результатом.
2. **Максимум из трёх** — функция с тремя параметрами.
3. **Лесенка из символов** — `void`-функция печати.
4. **Сумма цифр** — цикл внутри функции.
5. **Високосный год** — функция, возвращающая `bool`.

## Итоги

- Функция — именованный фрагмент кода: `тип имя(параметры) { тело }`.
- `return значение;` завершает функцию и передаёт результат в точку вызова; вызов можно использовать в выражениях.
- `void` — функция без результата; её вызов — отдельная инструкция.
- Функция должна быть объявлена до вызова: определите её выше или напишите прототип.
- Одна функция — одна задача; понятное имя делает код вызывающей функции читаемым.
