## Самая важная тема языка C

Указатели — то, что отличает C от большинства языков, и то, чего больше всего боятся начинающие. Бояться не нужно: идея указателя очень простая. Но без неё невозможно понять, как устроены массивы, строки, динамическая память, структуры данных и почти вся системная библиотека. В этом и следующих уроках разберём указатели по шагам, с картинками памяти.

## Память — длинная улица с номерами домов

Оперативная память — это последовательность **байтов**, и у каждого байта есть номер — **адрес**. Как дома на очень длинной улице: дом 1000, дом 1001, дом 1002…

Каждая переменная занимает несколько соседних байтов: `char` — один, `int` — обычно четыре, `double` — восемь. **Адрес переменной** — это адрес её первого байта.

<MemoryDiagram title="Переменные в памяти (адреса условные)">

| Адрес    | 1000–1003 | 1004–1007  | 1008–1015      |
| -------- | --------- | ---------- | -------------- |
| Имя      | `int age` | `int year` | `double price` |
| Значение | 19        | 2026       | 99.9           |

</MemoryDiagram>

Имя переменной существует только в исходном коде — для удобства программиста. Скомпилированная программа работает с адресами.

## Узнаём адрес: оператор `&`

Оператор `&` перед именем переменной даёт её адрес. Печатают адреса спецификатором `%p`:

```c
#include <stdio.h>

int main(void) {
    int age = 19;
    double price = 99.9;
    printf("age   = %d, адрес %p\n", age, (void *)&age);
    printf("price = %.1f, адрес %p\n", price, (void *)&price);
    return 0;
}
```

Запустите пример. Вы увидите что-то вроде `0x7ffd5e8a3c4c` — большое шестнадцатеричное число. Конкретные значения меняются от запуска к запуску: операционная система размещает программу в памяти по-разному, чтобы затруднить атаки. Поэтому адреса никогда не используют как «данные» — только как способ добраться до переменной.

Запись `(void *)` перед адресом — требование `%p`: он ожидает «адрес чего угодно». Подробнее о `void *` — в модуле «Память и указатели».

Вы уже встречали `&` — в `scanf("%d", &age)`. Теперь понятно, что там происходит: `scanf` получает **адрес** переменной и записывает прочитанное число по этому адресу.

## Указатель — переменная, хранящая адрес

**Указатель** — это переменная, значение которой — адрес другой переменной. Объявляется со звёздочкой:

```c
#include <stdio.h>

int main(void) {
    int age = 19;
    int *p = &age;          // p — указатель на int, в нём адрес age
    printf("%d\n", *p);     // * — взять значение по адресу
    *p = 20;                // записать по адресу: меняется age!
    printf("%d\n", age);
    return 0;
}
```

Вывод:

```text
19
20
```

- `int *p` — «p — указатель на `int`». Тип указателя говорит, данные какого типа лежат по адресу.
- `p = &age` — в `p` записан адрес `age`. Говорят: «`p` указывает на `age`».
- `*p` — **разыменование**: «значение, лежащее по адресу из `p`». Читать `*p` — то же, что читать `age`; записать в `*p` — то же, что записать в `age`.

<MemoryDiagram title="p указывает на age">

| Адрес    | 1000–1003 | 2000–2007          |
| -------- | --------- | ------------------ |
| Имя      | `int age` | `int *p`           |
| Значение | 19 → 20   | 1000 (адрес `age`) |

</MemoryDiagram>

Указатель — сам по себе обычная переменная: у него есть свой адрес (2000 на схеме) и своё значение — адрес другой переменной (1000).

<Concept title="Две звёздочки — два смысла">

В объявлении `int *p` звёздочка означает «p — указатель». В выражении `*p` звёздочка означает «значение по адресу». Это разные роли одного символа, и их легко спутать в начале. Читайте `int *p` как «`*p` имеет тип `int`» — тогда оба смысла сходятся.

</Concept>

## Зачем нужны указатели

Если `*p` — это просто `age`, зачем такие сложности? Указатели решают задачи, которые иначе не решаются:

1. **Функция может изменить переменную вызывающего кода.** Помните, что аргументы копируются? Передав адрес, функция получает доступ к оригиналу. Так работает `scanf`, так меняют местами две переменные.
2. **Работа с массивами и строками.** Имя массива — это, по сути, адрес первого элемента. Передача массива в функцию — передача адреса, поэтому массив не копируется.
3. **Динамическая память.** Память, выделенная во время работы программы (`malloc`), доступна только через указатель на неё.
4. **Связанные структуры данных.** Списки, деревья, графы строятся из элементов, указывающих друг на друга.

Каждой из этих тем посвящены отдельные уроки. А сейчас — основа.

## Тип указателя важен

Указатель на `int` и указатель на `double` — разные типы. Тип нужен, чтобы при разыменовании компьютер знал, сколько байтов читать и как их толковать:

```c
#include <stdio.h>

int main(void) {
    double price = 9.5;
    double *dp = &price;
    int count = 3;
    int *ip = &count;
    *dp = *dp * *ip;         // 9.5 * 3
    printf("%.1f\n", price);
    printf("%zu %zu\n", sizeof(dp), sizeof(ip));
    return 0;
}
```

Вывод:

```text
28.5
8 8
```

Выражение `*dp * *ip` выглядит запутанно, но читается по шагам: значение по адресу `dp` умножить на значение по адресу `ip`.

Сами указатели любого типа на 64-битной системе занимают 8 байт: адрес — это всегда число одной и той же длины, неважно, на что он указывает.

Присвоить указателю на `int` адрес `double` — ошибка: компилятор предупредит `incompatible pointer types`. Такие предупреждения означают настоящую ошибку в программе.

## Частые ошибки

<CommonMistake title="Звёздочка в объявлении нескольких переменных">

`int *a, b;` — указатель только `a`, а `b` — обычный `int`. Звёздочка относится к имени, а не к типу. Объявляйте указатели по одному в строке.

</CommonMistake>

<CommonMistake title="Указатель без адреса">

`int *p; *p = 5;` — в `p` мусор, и запись идёт по случайному адресу. Это неопределённое поведение, часто — аварийное завершение. Указатель нужно инициализировать до разыменования.

</CommonMistake>

<CommonMistake title="Присваивание адреса вместо значения">

`*p = &x;` — попытка записать адрес в `int`. А `p = 5;` — попытка записать число вместо адреса. Следите, где нужна звёздочка, а где нет: `p` — адрес, `*p` — значение.

</CommonMistake>

## Практика

Адреса меняются от запуска к запуску, поэтому в задачах печатаются только значения.

1. **Изменить через указатель** — запись по адресу.
2. **Указатель на большее** — выбор цели указателя.
3. **Обмен через указатели** — меняем значения двух переменных, не называя их по имени.

## Итоги

- Каждый байт памяти имеет адрес; адрес переменной — адрес её первого байта.
- `&x` — адрес `x`; печатается через `%p` с приведением `(void *)`.
- Указатель — переменная, хранящая адрес: `int *p = &x;`.
- `*p` — значение по адресу: чтение `*p` читает `x`, запись в `*p` меняет `x`.
- Тип указателя определяет, как читать данные по адресу; указатель нельзя разыменовывать, пока в нём нет корректного адреса.
