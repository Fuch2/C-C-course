## Адреса элементов массива

В прошлом уроке указатель указывал на отдельную переменную. Но гораздо чаще указатели указывают на **элементы массивов**: так функции обрабатывают данные, так устроены строки, так программы проходят по большим блокам памяти. В этом уроке разберём, как связаны массивы и адреса, и снова вернёмся к `scanf` — теперь уже понимая, что происходит.

## Элементы массива лежат вплотную

Оператор `&` применим к любому элементу массива: `&a[2]` — адрес третьего элемента. Посмотрим, как отличаются адреса соседних элементов:

```c
#include <stdio.h>

int main(void) {
    int numbers[4] = {10, 20, 30, 40};
    double values[3] = {1.5, 2.5, 3.5};
    for (int i = 0; i < 4; i++) {
        printf("numbers[%d]: %p\n", i, (void *)&numbers[i]);
    }
    for (int i = 0; i < 3; i++) {
        printf("values[%d]:  %p\n", i, (void *)&values[i]);
    }
    return 0;
}
```

Запустите пример и посмотрите на последние цифры адресов. Адреса элементов `numbers` отличаются на **4** — размер `int`, а элементов `values` — на **8**, размер `double`. Элементы массива лежат в памяти вплотную, без промежутков: адрес элемента `i` равен адресу начала плюс `i * sizeof(элемент)`.

Сами адреса меняются от запуска к запуску, а **разности** — нет. Их можно вычислить в программе, если привести адреса к указателям на байты:

```c
#include <stdio.h>

int main(void) {
    int numbers[4] = {10, 20, 30, 40};
    char *start = (char *)&numbers[0];
    char *third = (char *)&numbers[2];
    printf("%td\n", third - start);
    return 0;
}
```

Вывод:

```text
8
```

`char` занимает 1 байт, поэтому разность указателей на `char` — расстояние в байтах. Третий элемент `int` отстоит от первого на 2 · 4 = 8 байт.

## Имя массива — адрес первого элемента

В большинстве выражений имя массива автоматически превращается в адрес его первого элемента: `numbers` — то же, что `&numbers[0]`.

```c
#include <stdio.h>

int main(void) {
    int numbers[4] = {10, 20, 30, 40};
    int *p = numbers;                 // то же, что &numbers[0]
    printf("%d\n", p == &numbers[0]);
    printf("%d\n", *p);
    return 0;
}
```

Вывод:

```text
1
10
```

Теперь понятно, почему в `scanf("%49s", word)` для строки не нужен `&`: имя массива `word` уже является адресом, и `scanf` пишет символы, начиная с него. А для числа `scanf("%d", &n)` нужен `&`: `n` — обычная переменная, и её адрес нужно получить явно.

Это превращение массива в указатель называется **сведением массива к указателю** (array decay). Подробно о нём, и о том, что из этого следует, — в уроке «Массивы и указатели».

## Указатель на элемент массива

Указатель можно направить на любой элемент и работать через него:

```c
#include <stdio.h>

int main(void) {
    int scores[5] = {70, 85, 90, 60, 75};
    int *best = &scores[0];
    for (int i = 1; i < 5; i++) {
        if (scores[i] > *best) {
            best = &scores[i];
        }
    }
    *best += 5;     // бонус лучшему результату
    for (int i = 0; i < 5; i++) {
        printf("%d ", scores[i]);
    }
    printf("\n");
    return 0;
}
```

Вывод:

```text
70 85 95 60 75
```

Вместо индекса лучшего элемента мы храним указатель на него. Оба способа равноценны, но указатель позволяет сразу менять найденный элемент, не помня, из какого он массива. В больших программах функции поиска часто возвращают именно указатель на найденное.

## `&` и `*` — взаимно обратные

`&` превращает переменную в адрес, `*` — адрес обратно в переменную. Поэтому `*&x` — это просто `x`, а `&*p` — это `p`:

```c
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;
    printf("%d %d\n", *&x, *p);
    printf("%d\n", &*p == p);
    return 0;
}
```

Вывод:

```text
42 42
1
```

На практике такие записи не пишут, но понимание этой симметрии помогает читать сложные выражения: каждое `&` «поднимает» уровень на ссылку, каждое `*` — «опускает».

## Сравнение указателей

Два указателя равны (`==`), если указывают на одно и то же место. Это не то же самое, что равенство значений:

```c
#include <stdio.h>

int main(void) {
    int a = 5, b = 5;
    int *p = &a, *q = &b, *r = &a;
    printf("%d %d %d\n", p == q, *p == *q, p == r);
    return 0;
}
```

Вывод:

```text
0 1 1
```

`p` и `q` указывают на разные переменные с одинаковым значением: сами указатели не равны, а значения по ним равны. `p` и `r` указывают на одну переменную.

Указатели на элементы **одного массива** можно сравнивать и через `<`, `>`: элемент с меньшим индексом имеет меньший адрес. Сравнивать так указатели на разные массивы или переменные нельзя — результат не определён.

## Частые ошибки

<CommonMistake title="Лишний & для строк в scanf">

`scanf("%49s", &word)` при `char word[50]` — тип аргумента «указатель на массив» вместо «указатель на char». Обычно работает, но компилятор предупреждает о несовпадении типов. Пишите `scanf("%49s", word)`.

</CommonMistake>

<CommonMistake title="Сравнение указателей вместо значений">

`if (p == q)` проверяет, что это одно место в памяти. Если нужно сравнить значения — `*p == *q`.

</CommonMistake>

<CommonMistake title="Использование адресов как данных">

Конкретные адреса меняются от запуска к запуску. Не печатайте их в ответе и не сохраняйте в файлы — сохраняйте значения или индексы.

</CommonMistake>

## Практика

1. **Изменить элемент через указатель** — указатель на элемент по индексу.
2. **Указатель на минимум** — хранить указатель на лучший элемент.
3. **Расстояние в байтах** — разность адресов.

## Итоги

- Элементы массива лежат вплотную: адрес `a[i]` = адрес `a[0]` + `i * sizeof(a[0])`.
- Имя массива в выражениях — адрес первого элемента: `a == &a[0]`; поэтому для строк в `scanf` не нужен `&`.
- Указатель можно направить на любой элемент массива и изменять элемент через него.
- `*&x` — это `x`, `&*p` — это `p`.
- `p == q` сравнивает адреса, `*p == *q` — значения.
