## Практикум: функции

Функции меняют сам подход к решению задач. Вместо того чтобы сразу писать длинный `main`, можно сначала разбить задачу на понятные шаги, дать каждому шагу имя и только потом реализовывать шаги по одному. Этот практикум тренирует именно такой подход.

## Проектирование сверху вниз

Возьмём задачу: «Напечатать все пары простых чисел-близнецов до `n`» (близнецы — простые числа, отличающиеся на 2: 3 и 5, 11 и 13).

**Шаг 1. Пишем решение так, будто нужные функции уже есть:**

```c
for (int p = 2; p + 2 <= n; p++) {
    if (is_prime(p) && is_prime(p + 2)) {
        printf("%d %d\n", p, p + 2);
    }
}
```

Код читается как условие задачи. Осталось одно неизвестное — `is_prime`.

**Шаг 2. Реализуем недостающие функции** — каждая решает маленькую, хорошо понятную задачу:

```c
#include <stdio.h>

bool is_prime(int n) {
    if (n < 2) {
        return false;
    }
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            return false;
        }
    }
    return true;
}

int main(void) {
    int n = 50;
    for (int p = 2; p + 2 <= n; p++) {
        if (is_prime(p) && is_prime(p + 2)) {
            printf("%d %d\n", p, p + 2);
        }
    }
    return 0;
}
```

Вывод:

```text
3 5
5 7
11 13
17 19
29 31
41 43
```

**Шаг 3. Проверяем функции по отдельности** на крайних случаях: `is_prime(0)`, `is_prime(1)`, `is_prime(2)`, `is_prime(4)`, большое простое. Если функции верны, верна и программа, собранная из них.

Такой подход называется проектированием **сверху вниз**: от общего плана к деталям. Он особенно ценен в больших задачах, где удержать всё в голове сразу невозможно.

## Признаки хорошей функции

- **Имя описывает результат:** `reverse_number`, `is_palindrome`, `days_in_month`.
- **Одна задача:** функция либо вычисляет, либо печатает, но не всё сразу.
- **Все данные — через параметры, результат — через `return`:** никаких глобальных переменных.
- **Короткая:** если функция не помещается на экран, вероятно, её стоит разделить.

## Задачи

В задачах с проверкой функции пишите только функцию (и вспомогательные функции, если нужны), без `main`.

1. **Перевёрнутое число** — функция-строительный блок.
2. **Палиндромы** — функция, использующая другую функцию.
3. **НОК** — через НОД.
4. **Цифровой корень** — функция с циклом.
5. **Числа-близнецы** — проектирование сверху вниз.
6. **Любая система счисления** — функция преобразования цифры в символ.
