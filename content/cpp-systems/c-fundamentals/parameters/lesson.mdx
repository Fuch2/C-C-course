## Как данные попадают в функцию

В прошлом уроке вы писали функции с параметрами. Теперь разберёмся, что именно происходит с аргументом при вызове. От этого зависит ответ на вопрос, который рано или поздно задаёт каждый начинающий: «Почему моя функция меняет переменную, а в `main` ничего не меняется?»

## Передача по значению

В C аргументы передаются **по значению**: при вызове значение аргумента **копируется** в параметр. Параметр — это обычная локальная переменная функции, которая получила начальное значение из аргумента. Изменение параметра меняет копию, а не оригинал:

```c
#include <stdio.h>

void try_to_double(int x) {
    x = x * 2;
    printf("внутри функции x = %d\n", x);
}

int main(void) {
    int score = 10;
    try_to_double(score);
    printf("в main score = %d\n", score);
    return 0;
}
```

Вывод:

```text
внутри функции x = 20
в main score = 10
```

<MemoryDiagram title="Две разные переменные">

| Момент                    | `score` в main | `x` в функции        |
| ------------------------- | -------------- | -------------------- |
| до вызова                 | 10             | не существует        |
| вход в функцию            | 10             | 10 (копия)           |
| после `x = x * 2`         | 10             | 20                   |
| после возврата из функции | 10             | больше не существует |

</MemoryDiagram>

Если функция должна «изменить» значение, правильный способ — **вернуть** новое значение и присвоить его в вызывающем коде:

```c
#include <stdio.h>

int doubled(int x) {
    return x * 2;
}

int main(void) {
    int score = 10;
    score = doubled(score);
    printf("%d\n", score);
    return 0;
}
```

Вывод:

```text
20
```

Передача по значению — это защита: функция не может случайно испортить переменные вызывающего кода. Когда изменить переменную снаружи действительно нужно (например, поменять местами две переменные), используют **указатели** — им посвящён последний раздел модуля.

## Изменять параметр внутри функции — нормально

Раз параметр — собственная копия функции, его можно свободно использовать как рабочую переменную:

```c
#include <stdio.h>

int count_digits(long long n) {
    int count = 0;
    do {
        count++;
        n /= 10;        // меняем копию — исходное число в main цело
    } while (n != 0);
    return count;
}

int main(void) {
    long long number = 123456;
    int d = count_digits(number);
    printf("%lld %d\n", number, d);
    return 0;
}
```

Вывод:

```text
123456 6
```

## Несколько параметров и порядок аргументов

Аргументы сопоставляются с параметрами **по позиции**, а не по именам. Если переставить аргументы, функция получит не те значения:

```c
#include <stdio.h>

int power(int base, int exponent) {
    int result = 1;
    for (int i = 0; i < exponent; i++) {
        result *= base;
    }
    return result;
}

int main(void) {
    int base = 2, exponent = 10;
    printf("%d\n", power(base, exponent));
    printf("%d\n", power(exponent, base));
    return 0;
}
```

Вывод:

```text
1024
100
```

Во втором вызове имена переменных совпадают с именами параметров, но в обратном порядке — функция получила `base = 10`, `exponent = 2`. Компилятор не предупредит: оба значения имеют тип `int`. Поэтому порядок параметров выбирают естественным («основание, показатель»; «откуда, куда»; «значение, нижняя граница, верхняя граница») и не меняют без нужды.

## Преобразование типов аргументов

Если тип аргумента не совпадает с типом параметра, значение **преобразуется** — так же, как при присваивании:

```c
#include <stdio.h>

double half(double x) {
    return x / 2;
}

int truncate_to_int(int x) {
    return x;
}

int main(void) {
    printf("%.1f\n", half(7));             // int 7 → double 7.0
    printf("%d\n", truncate_to_int(3.9));  // Предупреждение: double 3.9 → int 3
    return 0;
}
```

Вывод:

```text
3.5
3
```

Целое в дробное преобразуется без потерь. Дробное в целое теряет дробную часть — с флагом `-Wconversion` компилятор предупредит об этом. Следите, чтобы аргумент имел ожидаемый тип.

## `const` у параметра

Если параметр внутри функции менять не нужно, его можно пометить `const`. Компилятор не даст случайно его изменить:

```c
int area(const int width, const int height) {
    return width * height;
}
```

Для параметров, передаваемых по значению, `const` используется редко — копию и так никто не увидит. Но в уроках об указателях и строках `const` станет очень важным: он будет показывать, что функция не меняет данные, на которые ей дали ссылку.

## Функции, вызывающие функции

Функция может вызывать другие функции — и строить из простых частей сложные:

```c
#include <stdio.h>

int is_prime(int n) {
    if (n < 2) {
        return 0;
    }
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            return 0;
        }
    }
    return 1;
}

int count_primes(int from, int to) {
    int count = 0;
    for (int k = from; k <= to; k++) {
        if (is_prime(k)) {
            count++;
        }
    }
    return count;
}

int main(void) {
    printf("%d\n", count_primes(1, 100));
    return 0;
}
```

Вывод:

```text
25
```

Заметьте, как `return` внутри цикла в `is_prime` заменяет флаг и `break`: как только найден делитель, функция сразу возвращает ответ. Это один из главных плюсов функций — ранний выход вместо флагов.

## Частые ошибки

<CommonMistake title="Ожидание, что функция изменит аргумент">

`void reset(int x) { x = 0; }` не обнуляет переменную вызывающего кода. Верните значение (`x = reset_value();`) или — позже — используйте указатель.

</CommonMistake>

<CommonMistake title="Аргументы не в том порядке">

`power(exponent, base)` компилируется, но считает другое. Сверяйтесь с объявлением функции.

</CommonMistake>

<CommonMistake title="Порядок вычисления аргументов">

В вызове `f(i++, i++)` порядок вычисления аргументов не определён стандартом: разные компиляторы дадут разные результаты. Не изменяйте одну переменную в нескольких аргументах одного вызова.

</CommonMistake>

## Практика

1. **Степень** — цикл в функции с двумя параметрами.
2. **НОД как функция** — Евклид без изменения переменных вызывающего кода.
3. **Ограничение диапазоном** — три параметра и порядок аргументов.
4. **Кратные на отрезке** — формула вместо медленного цикла.
5. **Бонус к счёту** — исправьте функцию, которая «ничего не меняет».

## Итоги

- Аргументы передаются по значению: параметр — копия, изменение параметра не меняет аргумент.
- Чтобы получить новое значение, функция возвращает его, а вызывающий код присваивает.
- Аргументы сопоставляются с параметрами по позиции; порядок важен.
- При несовпадении типов аргумент преобразуется, дробная часть при переходе к `int` теряется.
- `return` внутри цикла позволяет выйти из функции сразу, без флагов и `break`.
