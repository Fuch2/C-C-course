## Результат функции

Функция с результатом — как маленький калькулятор: на входе аргументы, на выходе одно значение. В этом уроке разберём, как функции возвращают результат: несколько `return` в одной функции, функции-вопросы с ответом «да/нет», специальные значения для «не найдено» и что делать, когда результатов нужно несколько.

## `return` завершает функцию сразу

`return` не просто задаёт результат — он **немедленно** завершает функцию. Код после выполненного `return` не выполняется. Поэтому в функции может быть несколько `return` в разных ветках:

```c
#include <stdio.h>

int sign(int x) {
    if (x > 0) {
        return 1;
    }
    if (x < 0) {
        return -1;
    }
    return 0;
}

int main(void) {
    printf("%d %d %d\n", sign(42), sign(-7), sign(0));
    return 0;
}
```

Вывод:

```text
1 -1 0
```

Каждый путь выполнения заканчивается своим `return`. Компилятор следит, чтобы ни один путь не дошёл до конца функции без возврата значения: иначе предупреждение `control reaches end of non-void function`, а вызывающий код получит мусор.

## Ранний выход: сначала особые случаи

Удобный стиль — обрабатывать особые случаи в начале функции и сразу возвращать результат. Такие проверки называют **сторожевыми** (guard clauses). Основная логика остаётся без вложенности:

```c
#include <stdio.h>

int is_prime(long long n) {
    if (n < 2) {
        return 0;               // особый случай
    }
    for (long long d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            return 0;           // нашли делитель — ответ известен
        }
    }
    return 1;                   // делителей нет
}

int main(void) {
    printf("%d %d %d %d\n", is_prime(1), is_prime(2), is_prime(91), is_prime(97));
    return 0;
}
```

Вывод:

```text
0 1 0 1
```

Сравните с вариантом из урока `break`: там был флаг и `break`, здесь `return` делает то же короче.

## Функции-вопросы

Функции, отвечающие «да» или «нет», возвращают `bool` (или `int` 1/0) и называются с префиксом `is_`, `has_`, `can_`. Тогда условия читаются как обычные фразы:

```c
#include <stdio.h>

bool is_leap(int year) {
    return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
}

int days_in_year(int year) {
    return is_leap(year) ? 366 : 365;
}

int main(void) {
    printf("%d %d\n", days_in_year(2024), days_in_year(2025));
    return 0;
}
```

Вывод:

```text
366 365
```

Обратите внимание: `is_leap` возвращает значение логического выражения напрямую. Не нужно писать `if (условие) return true; else return false;` — выражение и так даёт `true` или `false`.

## Тип результата и преобразования

Возвращаемое значение преобразуется к типу результата функции — как при присваивании. Если функция объявлена с `int`, а вычисляет дробное значение, дробная часть будет потеряна:

```c
#include <stdio.h>

int average_wrong(int a, int b) {
    return (a + b) / 2.0;     // 3.5 превращается в int 3
}

double average(int a, int b) {
    return (a + b) / 2.0;
}

int main(void) {
    printf("%d %.1f\n", average_wrong(3, 4), average(3, 4));
    return 0;
}
```

Вывод:

```text
3 3.5
```

Тип результата — часть «обещания» функции. Выбирайте его по тому, какое значение должно получиться.

## Специальные значения: «не найдено»

Что вернуть, если результат не существует? Например, функция ищет позицию цифры в числе, а цифры там нет. Частое решение — **специальное значение**, которое не может быть настоящим ответом. Для позиций и индексов это обычно `-1`:

```c
#include <stdio.h>

// Позиция цифры digit в числе n, считая справа с 1; -1, если цифры нет.
int digit_position(long long n, int digit) {
    int position = 1;
    do {
        if (n % 10 == digit) {
            return position;
        }
        n /= 10;
        position++;
    } while (n > 0);
    return -1;
}

int main(void) {
    printf("%d %d\n", digit_position(90210, 2), digit_position(90210, 7));
    return 0;
}
```

Вывод:

```text
3 -1
```

Вызывающий код обязан проверить специальное значение: `if (pos == -1) { ... }`. Опишите такое значение в комментарии к функции — иначе о нём никто не узнает.

## Если результатов нужно несколько

`return` возвращает **одно** значение. Как быть, если функция должна выдать, например, и частное, и остаток? Есть три пути, и вы изучите их по порядку:

1. Две отдельные функции — самый простой вариант, когда вычисления независимы.
2. Указатели на переменные вызывающего кода — урок «Указатели и функции».
3. Структура, объединяющая несколько значений, — урок `struct`.

## Игнорирование результата

Вызвать функцию и не использовать результат — законно: `square(5);` скомпилируется. Но обычно это ошибка: результат потерян. Особенно опасно игнорировать результаты, сообщающие об ошибках, — например, значение `scanf`. Привыкайте проверять результат каждой функции, которая может сообщить о неудаче.

## Частые ошибки

<CommonMistake title="Не все пути возвращают значение">

Цепочка `if`, где последний случай не покрыт, оставляет путь без `return`. Добавьте завершающий `return` или `else`.

</CommonMistake>

<CommonMistake title="Код после return">

Инструкции после выполненного `return` недостижимы. Если «код не выполняется», проверьте, не стоит ли выше `return`.

</CommonMistake>

<CommonMistake title="Лишний if вокруг логического выражения">

`if (n % 2 == 0) return 1; else return 0;` — то же, что `return n % 2 == 0;`. Короткий вариант понятнее и не даёт ошибиться в ветках.

</CommonMistake>

<CommonMistake title="Специальное значение совпадает с настоящим">

Если функция может вернуть любое целое, `-1` уже не подходит для «не найдено». Тогда используют отдельный флаг или указатель — об этом позже.

</CommonMistake>

## Практика

1. **Знак числа** — три ветки с `return`.
2. **Дней в месяце** — функция, использующая другую функцию.
3. **Первая цифра** — цикл внутри функции.
4. **Где цифра** — специальное значение −1.
5. **Код треугольника** — сторожевые проверки и коды результата.

## Итоги

- `return` задаёт результат и сразу завершает функцию; в функции может быть несколько `return`.
- Каждый путь выполнения функции с результатом должен заканчиваться `return`.
- Сторожевые проверки в начале функции обрабатывают особые случаи и упрощают основную логику.
- Функции-вопросы возвращают `bool` и называются `is_…`, `has_…`; логическое выражение возвращается напрямую.
- Возвращаемое значение преобразуется к типу результата функции.
- Для «нет результата» используют специальное значение вроде −1 и описывают его в комментарии.
