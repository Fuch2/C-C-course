## `main` — обычная функция с особой ролью

Вы писали `int main(void)` в каждой программе, теперь можно разобраться, что это значит. `main` — обычная функция, только вызывает её не ваш код, а **операционная система** при запуске программы. Её результат получает тоже операционная система: это **код завершения**, с которым вы познакомились в модуле «Старт». В этом уроке — как правильно сообщать об успехе и ошибке, что такое аргументы командной строки и как читать данные, количество которых заранее неизвестно.

## Код завершения: успех и ошибка

`return` из `main` завершает программу, а возвращённое число становится кодом завершения. По соглашению:

- `0` — успех;
- любое ненулевое значение — ошибка; разные числа могут обозначать разные причины.

Заголовок `<stdlib.h>` даёт именованные константы `EXIT_SUCCESS` (равна 0) и `EXIT_FAILURE` (обычно 1). Они делают намерение явным:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int age;
    if (scanf("%d", &age) != 1) {
        fprintf(stderr, "ошибка: ожидалось число\n");
        return EXIT_FAILURE;    // Код завершения 1
    }
    if (age < 0) {
        fprintf(stderr, "ошибка: возраст не может быть отрицательным\n");
        return EXIT_FAILURE;    // Код завершения 1
    }
    printf("через 10 лет: %d\n", age + 10);
    return EXIT_SUCCESS;
}
```

Ввод:

```text
25
```

Вывод:

```text
через 10 лет: 35
```

Попробуйте ввести `-3` или `abc`: программа напечатает сообщение в поток ошибок и завершится с кодом 1.

Кто читает код завершения? Скрипты и другие программы. Например, в терминале команда `gcc main.c && ./a.out` запустит программу, только если компиляция вернула 0. Системы сборки, тестирования и непрерывной интеграции останавливаются, когда какой-то шаг вернул ненулевой код. Поэтому сообщать о неудаче правильным кодом — признак добросовестной программы.

<Tip title="Сообщения об ошибках — в stderr">

Результат программы пишут в стандартный вывод (`stdout`), а сообщения об ошибках — в стандартный поток ошибок (`stderr`) через `fprintf(stderr, ...)`. Тогда сообщения не перемешаются с данными, если вывод программы передаётся дальше другой программе.

</Tip>

## Завершение из любого места: `exit`

`return` в `main` завершает программу, а `return` в другой функции — только эту функцию. Чтобы завершить программу из глубины вызовов, есть функция `exit(код)` из `<stdlib.h>`:

```c
#include <stdio.h>
#include <stdlib.h>

int read_positive(void) {
    int x;
    if (scanf("%d", &x) != 1 || x <= 0) {
        fprintf(stderr, "нужно положительное число\n");
        exit(EXIT_FAILURE);     // Код завершения 1 — выход из всей программы
    }
    return x;
}

int main(void) {
    int a = read_positive();
    int b = read_positive();
    printf("%d\n", a * b);
    return EXIT_SUCCESS;
}
```

Ввод:

```text
6 7
```

Вывод:

```text
42
```

Используйте `exit` для фатальных ошибок, после которых продолжать бессмысленно. Для обычной логики лучше возвращать коды ошибок из функций: так вызывающий код сам решает, что делать.

## Аргументы командной строки

У `main` есть вторая допустимая форма — с параметрами:

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("аргументов: %d\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("%d: %s\n", i, argv[i]);
    }
    return 0;
}
```

Если запустить такую программу в терминале командой `./program report.txt 5`, она напечатает:

```text
аргументов: 3
0: ./program
1: report.txt
2: 5
```

- `argc` (argument count) — количество аргументов, включая имя самой программы;
- `argv` (argument vector) — массив строк-аргументов; `argv[0]` — имя программы.

Так работают все программы командной строки: `gcc main.c -o hello` — это `gcc` с тремя аргументами. Массивы и строки вы изучите в следующем разделе, а запись `char *argv[]` станет понятной после уроков об указателях. В песочнице курса аргументы не передаются, поэтому задачи используют только стандартный ввод.

## Чтение до конца ввода

Во многих задачах количество чисел заранее не известно: нет ни `n` в начале, ни признака конца вроде нуля. Программа должна читать, **пока данные не закончатся**. Для этого используют значение, которое возвращает `scanf`:

```c
#include <stdio.h>

int main(void) {
    int x;
    long long sum = 0;
    int count = 0;
    while (scanf("%d", &x) == 1) {
        sum += x;
        count++;
    }
    printf("чисел: %d, сумма: %lld\n", count, sum);
    return 0;
}
```

Ввод:

```text
10 20
30
40
```

Вывод:

```text
чисел: 4, сумма: 100
```

Условие `scanf("%d", &x) == 1` совмещает чтение и проверку: пока удаётся прочитать очередное число, цикл продолжается. Когда ввод заканчивается, `scanf` возвращает `EOF`, условие становится ложным, цикл завершается.

Как «закончить ввод» с клавиатуры? В Linux и macOS — сочетание Ctrl+D в начале строки, в Windows — Ctrl+Z и Enter. Проверяющая система курса подаёт данные из файла, и конец файла наступает сам.

<Important title="Сравнивайте с количеством, а не с EOF">

Условие `scanf(...) != EOF` кажется естественным, но ненадёжно: если во вводе встретится не число (например, буква), `scanf` вернёт 0, а не `EOF`, и цикл станет бесконечным — буква так и останется непрочитанной. Сравнивайте результат с числом ожидаемых значений: `== 1`, `== 2`.

</Important>

Тот же приём работает и для нескольких значений за раз: `while (scanf("%d %d", &a, &b) == 2)` читает пары до конца ввода.

## Частые ошибки

<CommonMistake title="Ненулевой код при успешной работе">

Задачи курса ожидают код завершения 0: ненулевой код считается ошибкой выполнения, даже если вывод верный. Возвращайте ненулевой код только при настоящей ошибке.

</CommonMistake>

<CommonMistake title="Цикл до EOF с проверкой != EOF">

Некорректный ввод превращает такой цикл в бесконечный. Проверяйте, что прочитано ожидаемое количество значений.

</CommonMistake>

<CommonMistake title="Обработка до проверки">

`while (1) { scanf("%d", &x); sum += x; ... }` — последнее значение прибавится, даже если чтение не удалось. Проверка результата `scanf` должна предшествовать использованию значения.

</CommonMistake>

## Практика

Во всех задачах количество чисел заранее неизвестно — читайте до конца ввода.

1. **Сумма всего** — простой цикл до конца ввода.
2. **Среднее** — особый случай пустого ввода.
3. **Чётные и нечётные** — счётчики.
4. **Наибольший перепад** — разность соседних значений.
5. **Пары** — чтение по два числа.

## Итоги

- `main` вызывает операционная система; результат `main` — код завершения: 0 — успех, ненулевой — ошибка.
- `EXIT_SUCCESS` и `EXIT_FAILURE` из `<stdlib.h>` делают код завершения явным; `exit(код)` завершает программу из любой функции.
- Сообщения об ошибках выводят в `stderr`, результат — в `stdout`.
- `int main(int argc, char *argv[])` получает аргументы командной строки.
- Чтение до конца ввода: `while (scanf(...) == количество_значений)`.
