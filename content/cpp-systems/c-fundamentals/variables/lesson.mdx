## Зачем нужны переменные

Программа из прошлого урока печатала `printf("%d\n", 2 + 5)`. Но если число вводит пользователь, мы не знаем его заранее и не можем записать в коде. Нужно место, где программа сохранит значение, чтобы потом с ним работать. Такое место называется **переменной**.

Переменную удобно представлять как подписанную коробку в памяти компьютера. На коробке — **имя**, внутри — **значение**, а размер и форма коробки определяются **типом**: в коробку для целых чисел нельзя положить дробное число или текст.

## Объявление и инициализация

Чтобы создать переменную, её **объявляют**: пишут тип и имя.

```c
#include <stdio.h>

int main(void) {
    int age = 19;           // объявление с инициализацией
    int year;               // объявление без значения
    year = 2026;            // присваивание
    printf("%d %d\n", age, year);
    return 0;
}
```

Вывод:

```text
19 2026
```

- `int` — тип «целое число» (integer). Другие типы — в следующих уроках.
- `age` — имя переменной.
- `= 19` при объявлении — **инициализация**: переменная сразу получает начальное значение.
- `year = 2026;` — **присваивание**: в уже существующую переменную записывается новое значение.

Несколько переменных одного типа можно объявить в одной строке через запятую: `int width = 3, height = 4;`. Но не злоупотребляйте этим: одна переменная на строку читается легче.

## Переменная без значения содержит мусор

Что будет, если объявить переменную и сразу напечатать, ничего в неё не записав?

```c
int count;
printf("%d\n", count);   // ошибка: значение не определено
```

В C локальная переменная **не обнуляется** автоматически. В ней лежит то, что осталось в памяти от предыдущих вычислений, — случайное число. Программа может напечатать 0 на вашем компьютере и 32767 на сервере проверки. Компилятор в строгом режиме обычно предупреждает: `'count' is used uninitialized` — «используется без инициализации».

<Important title="Правило">

Давайте переменной значение до того, как её читать. Лучше всего — сразу при объявлении. Но не ставьте `= 0` «на всякий случай», если правильное значение появится позже (например, после ввода): ноль может скрыть ошибку, когда ввод забыли прочитать.

</Important>

## Присваивание — это не равенство

Знак `=` в C означает не «равно», а «записать»: вычислить выражение справа и положить результат в переменную слева. Поэтому запись, бессмысленная в математике, в программе совершенно нормальна:

```c
#include <stdio.h>

int main(void) {
    int x = 5;
    x = x + 1;
    printf("%d\n", x);
    return 0;
}
```

Вывод:

```text
6
```

Компьютер берёт **текущее** значение `x` (5), прибавляет 1 и записывает результат 6 обратно в `x`. Старое значение при этом теряется навсегда.

Слева от `=` всегда должна стоять переменная. Запись `5 = x;` бессмысленна: в число нельзя ничего записать, и компилятор выдаст ошибку.

## Значение копируется, а не связывается

Присваивание копирует **значение на текущий момент**. После этого переменные живут независимо:

```c
#include <stdio.h>

int main(void) {
    int price = 100;
    int old_price = price;   // копия: 100
    price = 120;             // меняется только price
    printf("%d %d\n", price, old_price);
    return 0;
}
```

Вывод:

```text
120 100
```

Если вы привыкли к электронным таблицам, это может удивить: в Excel ячейка с формулой `=A1` пересчитывается при изменении A1. В C такого нет. `old_price = price` — это не формула, а однократное копирование числа.

## Обмен значений

Классическая задача: поменять местами значения двух переменных. Наивная попытка не работает:

```c
#include <stdio.h>

int main(void) {
    int a = 3, b = 8;
    a = b;   // теперь a = 8, старое 3 потеряно
    b = a;   // b = 8
    printf("%d %d\n", a, b);
    return 0;
}
```

Вывод:

```text
8 8
```

Первое присваивание уничтожило старое значение `a`. Нужна **временная переменная**, как третий стакан, чтобы поменять местами сок и молоко:

```c
#include <stdio.h>

int main(void) {
    int a = 3, b = 8;
    int tmp = a;   // сохранили 3
    a = b;         // a = 8
    b = tmp;       // b = 3
    printf("%d %d\n", a, b);
    return 0;
}
```

Вывод:

```text
8 3
```

<MemoryDiagram title="Трассировка обмена">

| После строки        | `a` | `b` | `tmp` |
| ------------------- | --- | --- | ----- |
| `int a = 3, b = 8;` | 3   | 8   | —     |
| `int tmp = a;`      | 3   | 8   | 3     |
| `a = b;`            | 8   | 8   | 3     |
| `b = tmp;`          | 8   | 3   | 3     |

</MemoryDiagram>

## Составное присваивание

Изменение переменной относительно её же значения встречается так часто, что для него есть сокращения:

| Полная запись | Сокращённая | Смысл                      |
| ------------- | ----------- | -------------------------- |
| `x = x + 5;`  | `x += 5;`   | увеличить на 5             |
| `x = x - 5;`  | `x -= 5;`   | уменьшить на 5             |
| `x = x * 5;`  | `x *= 5;`   | умножить на 5              |
| `x = x / 5;`  | `x /= 5;`   | разделить на 5             |
| `x = x + 1;`  | `x++;`      | увеличить на 1 (инкремент) |
| `x = x - 1;`  | `x--;`      | уменьшить на 1 (декремент) |

```c
#include <stdio.h>

int main(void) {
    int score = 10;
    score += 5;     // 15
    score *= 2;     // 30
    score -= 4;     // 26
    score++;        // 27
    score /= 3;     // 9
    printf("%d\n", score);
    return 0;
}
```

Вывод:

```text
9
```

Справа от `+=` может стоять любое выражение: `x *= a + b` означает `x = x * (a + b)` — сначала вычисляется вся правая часть.

<Tip title="Инкремент отдельной строкой">

У `x++` есть вторая форма — `++x`. Внутри сложных выражений они ведут себя по-разному, и это частый источник ошибок. Пока используйте `x++` и `x--` только как отдельные инструкции, тогда разницы нет.

</Tip>

## Как назвать переменную

Имя должно отвечать на вопрос «что здесь хранится?». Сравните:

| Плохо  | Хорошо          | Почему                                   |
| ------ | --------------- | ---------------------------------------- |
| `a`    | `apples`        | Понятно, что считаем                     |
| `t`    | `temperature_c` | Видна единица измерения: градусы Цельсия |
| `n2`   | `next_number`   | Не нужно вспоминать, что такое n2        |
| `data` | `total_price`   | «Данные» — всё что угодно                |

Короткие имена уместны в коротких формулах (`x`, `y` для координат) и для счётчиков циклов (`i`, `j`), о которых пойдёт речь позже.

## Частые ошибки

<CommonMistake title="Чтение переменной без значения">

`int sum; sum = sum + 5;` — к случайному числу прибавили 5. Нужно `int sum = 0;` перед накоплением.

</CommonMistake>

<CommonMistake title="Обмен без временной переменной">

`a = b; b = a;` делает обе переменные равными `b`. Сохраните старое значение `a` во временную переменную.

</CommonMistake>

<CommonMistake title="Повторное объявление">

`int x = 1; int x = 2;` — ошибка `redefinition of 'x'`. Переменную объявляют один раз, дальше только присваивают: `x = 2;`.

</CommonMistake>

<CommonMistake title="Ожидание «живой формулы»">

`int total = price * count;` вычисляется один раз. Если потом изменить `count`, `total` останется прежним — его нужно пересчитать явно.

</CommonMistake>

## Практика

1. **Обмен** — поменяйте значения двух переменных.
2. **Три стакана** — циклически сдвиньте три значения.
3. **Снимок** — сохраните значение до изменения.
4. **Счёт в игре** — серия составных присваиваний.

## Итоги

- Переменная — именованное место в памяти с типом и значением.
- Инициализация задаёт значение при создании, присваивание меняет значение существующей переменной.
- Локальная переменная без инициализации содержит мусор — не читайте её до записи.
- `=` означает «вычислить справа и записать влево»; `x = x + 1` увеличивает `x`.
- Присваивание копирует значение; переменные потом меняются независимо.
- Для обмена нужна временная переменная. Сокращения `+=`, `-=`, `*=`, `/=`, `++`, `--` изменяют переменную относительно её текущего значения.
