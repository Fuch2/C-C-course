## Готовые инструменты для строк

В прошлом уроке вы считали длину строки циклом и переворачивали её вручную. Для частых операций стандартная библиотека C предлагает готовые функции в заголовке `<string.h>`. Они быстрые и проверенные, но у них есть общая особенность: **ни одна из них не знает размера вашего массива**. Ответственность за то, чтобы результат поместился, лежит на программисте. В этом уроке — главные функции и безопасные приёмы работы с ними.

## Длина: `strlen`

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char word[50] = "compiler";
    size_t n = strlen(word);
    printf("%zu %zu\n", n, sizeof(word));
    return 0;
}
```

Вывод:

```text
8 50
```

`strlen` возвращает количество символов **до** `'\0'` — 8. А `sizeof` — размер всего массива, 50 байт. Не путайте их: длина строки — величина, которая меняется, размер массива — постоянная.

`strlen` возвращает `size_t`, печатается через `%zu`. Каждый вызов проходит всю строку, поэтому не пишите `for (i = 0; i < strlen(s); i++)` — длина будет вычисляться на каждой итерации. Сохраните её в переменную до цикла.

## Копирование и склеивание: `strcpy`, `strcat`

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char path[64];
    strcpy(path, "/home");
    strcat(path, "/student");
    strcat(path, "/main.c");
    printf("%s (%zu)\n", path, strlen(path));
    return 0;
}
```

Вывод:

```text
/home/student/main.c (20)
```

- `strcpy(куда, откуда)` копирует строку вместе с `'\0'`. Это замена недопустимого `path = "/home"`.
- `strcat(куда, что)` дописывает строку в конец существующей.

Обе функции пишут в массив столько, сколько нужно, **не проверяя** его размер. Если результат не поместится — переполнение буфера. Перед вызовом убедитесь, что места достаточно: `strlen(path) + strlen(part) + 1 <= sizeof(path)`.

## Безопасная сборка строк: `snprintf`

Надёжнее собирать строки функцией `snprintf` — она как `printf`, только пишет в массив и **никогда** не выходит за указанный размер:

```c
#include <stdio.h>

int main(void) {
    char label[16];
    int needed = snprintf(label, sizeof(label), "user-%d-%s", 42, "admin");
    printf("%s %d\n", label, needed);
    // Предупреждение: GCC заранее видит, что текст не поместится
    snprintf(label, sizeof(label), "%s", "a very long text that does not fit");
    printf("%s\n", label);
    return 0;
}
```

Вывод:

```text
user-42-admin 13
a very long tex
```

GCC в этом примере даже предупреждает заранее: `output truncated`, — потому что видит длину текста. `snprintf` обрезает результат так, чтобы поместился `'\0'`, и возвращает длину, которая **получилась бы** без обрезки. Если это число не меньше размера буфера, значит, строка обрезана — так это и проверяют.

<Concept title="Правило безопасной работы со строками">

Любая функция, которая пишет в массив, должна знать его размер. Предпочитайте `snprintf` для сборки строк, `fgets` для ввода, ширину в `scanf("%49s")`. Функции без размера (`strcpy`, `strcat`, `sprintf`) используйте, только когда заранее проверили, что результат поместится.

</Concept>

## Сравнение: `strcmp`

`strcmp(a, b)` сравнивает строки **посимвольно по кодам** и возвращает:

- отрицательное число, если `a` идёт раньше `b`;
- 0, если строки равны;
- положительное число, если `a` идёт позже.

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    printf("%d\n", strcmp("apple", "apple") == 0);
    printf("%d\n", strcmp("apple", "banana") < 0);
    printf("%d\n", strcmp("apple", "app") > 0);
    printf("%d\n", strcmp("Zebra", "apple") < 0);
    return 0;
}
```

Вывод:

```text
1
1
1
1
```

- `"app"` — начало `"apple"`, а более короткая строка идёт раньше.
- `"Zebra" < "apple"`: код заглавной `'Z'` (90) меньше кода строчной `'a'` (97). Сравнение по кодам — не то же самое, что алфавитный порядок в словаре.

Проверяйте результат только сравнением с нулём: `strcmp(a, b) == 0`, `< 0`, `> 0`. Конкретные значения (−1, −25) стандарт не гарантирует.

`strncmp(a, b, n)` сравнивает только первые `n` символов — удобно проверять префиксы: `strncmp(line, "GET ", 4) == 0`.

## Поиск: `strchr` и `strstr`

`strchr(s, c)` ищет символ, `strstr(s, sub)` — подстроку. Обе возвращают **указатель** на найденное место или `NULL`, если ничего не найдено. Указатели — тема последнего раздела, а пока достаточно двух приёмов: проверка «нашлось ли» и номер позиции через вычитание:

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char text[] = "find the needle in the haystack";
    char *found = strstr(text, "needle");
    if (found != NULL) {
        printf("позиция %td\n", found - text);
    }
    if (strchr(text, 'z') == NULL) {
        printf("буквы z нет\n");
    }
    return 0;
}
```

Вывод:

```text
позиция 9
буквы z нет
```

`found - text` — разность адресов, то есть номер символа, с которого начинается найденная подстрока. Спецификатор `%td` предназначен для такой разности. Подробно, почему это работает, — в уроке «Арифметика указателей».

## Строка в число

Чтобы превратить строку цифр в число, есть функции в `<stdlib.h>`: `atoi(s)` — просто, но не сообщает об ошибках; `strtol(s, &end, 10)` — надёжнее, позволяет проверить, что разобрана вся строка. В учебных задачах обычно удобнее сразу читать число через `scanf`, но при разборе текстовых форматов эти функции незаменимы.

## Частые ошибки

<CommonMistake title="Сравнение строк через ==">

`if (answer == "yes")` сравнивает адреса и почти всегда ложно. Нужно `strcmp(answer, "yes") == 0`.

</CommonMistake>

<CommonMistake title="Проверка strcmp как логического значения">

`if (strcmp(a, b))` истинно, когда строки **различаются** (результат ненулевой). Это легко прочитать наоборот. Пишите явно: `== 0` или `!= 0`.

</CommonMistake>

<CommonMistake title="strcat в неинициализированный массив">

`char buf[50]; strcat(buf, "x");` — `strcat` ищет конец строки `buf`, а там мусор. Сначала `buf[0] = '\0';` или `strcpy`.

</CommonMistake>

<CommonMistake title="Нет места под результат">

`char small[5]; strcpy(small, "hello");` — 6 байт в массив из 5. Переполнение буфера. Считайте место заранее или используйте `snprintf`.

</CommonMistake>

## Практика

1. **Какое слово раньше** — `strcmp`.
2. **Самое длинное слово** — `strlen` и `strcpy`.
3. **Сколько раз встречается** — `strstr` в цикле.
4. **Склейка через дефис** — `strcat` с проверкой размера.
5. **Три слова по порядку** — сортировка строк.

## Итоги

- `strlen` — длина до `'\0'` (не размер массива); результат `size_t`.
- `strcpy` и `strcat` копируют и дописывают, не проверяя размер; `snprintf` собирает строку безопасно.
- `strcmp` сравнивает по кодам символов; результат сравнивают с нулём.
- `strchr` и `strstr` возвращают место находки или `NULL`.
- Любая запись в массив требует уверенности, что места достаточно.
