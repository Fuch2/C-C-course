## Практикум: указатели и структуры

Это последний практикум модуля. Задачи в нём ближе к настоящим программам: данные описываются собственными типами, функции получают записи через указатели, поиск возвращает указатель на найденное, а состояния задаются перечислениями. Почти в каждой задаче пригодится всё, что вы изучили в модуле.

## Четыре приёма

**1. Запись вместо параллельных массивов.** Если у объекта несколько свойств — имя, количество, цена, — опишите структуру. Один массив структур проще читать, сортировать и передавать в функции, чем три массива с общими индексами.

**2. Поиск возвращает указатель.** Функция `Item *find(Item *items, int n, const char *name)` возвращает адрес найденной записи или `NULL`. Через полученный указатель запись можно сразу изменить: `p->qty += 5`. Перед обращением к полям обязательно проверьте указатель на `NULL`.

**3. Функция порядка.** Чтобы отсортировать записи по нескольким правилам, напишите функцию `int goes_before(const T *a, const T *b)`, а сортировку оставьте прежней — сортировкой выбором из практикума по массивам. Записи переставляются присваиванием целиком.

**4. Перечисление для состояний.** Если запись может находиться в нескольких состояниях — «выдана / на месте», «открыта / закрыта», — храните состояние полем типа `enum`, а не числом или парой флагов.

## Разбор: библиотека

Библиотека хранит книги. Команды `borrow id` и `return id` выдают и принимают книги; в конце нужно назвать самую популярную книгу.

```c
#include <stdio.h>
#include <string.h>

typedef enum { AVAILABLE, BORROWED } Status;

typedef struct {
    int id;
    char title[32];
    Status status;
    int times_borrowed;
} Book;

Book *find_book(Book *books, int n, int id) {
    for (Book *p = books; p != books + n; p++) {
        if (p->id == id) {
            return p;
        }
    }
    return NULL;
}

const char *borrow(Book *b) {
    if (b == NULL) {
        return "нет такой книги";
    }
    if (b->status == BORROWED) {
        return "уже выдана";
    }
    b->status = BORROWED;
    b->times_borrowed++;
    return "выдана";
}

const char *give_back(Book *b) {
    if (b == NULL) {
        return "нет такой книги";
    }
    if (b->status == AVAILABLE) {
        return "не была выдана";
    }
    b->status = AVAILABLE;
    return "возвращена";
}

int main(void) {
    Book books[] = {
        {1, "Dune", AVAILABLE, 0},
        {2, "Solaris", AVAILABLE, 0},
        {3, "Hyperion", AVAILABLE, 0},
    };
    int n = sizeof(books) / sizeof(books[0]);
    char command[16];
    int id;
    while (scanf("%15s %d", command, &id) == 2) {
        Book *b = find_book(books, n, id);
        const char *result = strcmp(command, "borrow") == 0 ? borrow(b) : give_back(b);
        printf("%s %d: %s\n", command, id, result);
    }
    const Book *popular = &books[0];
    for (int i = 1; i < n; i++) {
        if (books[i].times_borrowed > popular->times_borrowed) {
            popular = &books[i];
        }
    }
    printf("Самая популярная: %s (%d)\n", popular->title, popular->times_borrowed);
    return 0;
}
```

Ввод:

```text
borrow 2
borrow 2
return 2
borrow 2
borrow 5
return 1
borrow 3
```

Вывод:

```text
borrow 2: выдана
borrow 2: уже выдана
return 2: возвращена
borrow 2: выдана
borrow 5: нет такой книги
return 1: не была выдана
borrow 3: выдана
Самая популярная: Solaris (2)
```

Обратите внимание на устройство программы:

- **Тип данных** (`Book`) собирает всё, что известно о книге, включая состояние типа `Status`.
- **Поиск** (`find_book`) идёт по массиву указателем и возвращает адрес найденной книги или `NULL`.
- **Операции** (`borrow`, `give_back`) получают указатель, сами проверяют его на `NULL` и меняют запись на месте. Они возвращают строку-результат, поэтому `main` только печатает её.
- **`main`** читает команды и связывает части вместе. Количество книг вычисляется через `sizeof`, потому что массив объявлен прямо здесь, а не получен параметром.

Такое разделение — данные, поиск, операции, ввод-вывод — подходит для большинства задач этого практикума.

## Задачи

1. **Чек** — массив структур и денежная арифметика в копейках.
2. **Турнирная таблица** — поиск записи с добавлением и сортировка по трём правилам.
3. **Объединение отрезков** — сортировка структур и проход с текущим отрезком.
4. **Склад** — команды, поиск через указатель и сообщения об ошибках.
5. **Переговорные** — события начала и конца и правильный порядок при совпадении времени.
6. **Длинная сумма** — структура с массивом цифр для чисел, которые не помещаются ни в один тип.
