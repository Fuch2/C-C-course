## Когда целых чисел мало

Средний балл, температура 36,6, цена 99,90, расстояние 1,41 метра — в жизни полно нецелых чисел. Целочисленное деление, которое отбрасывает дробную часть, здесь не годится. Для дробных значений в C есть **типы с плавающей точкой**. Название означает, что положение десятичной точки в числе может «плавать»: один и тот же тип хранит и 0,000001, и 6 000 000 000.

## Тип `double`

Основной дробный тип — `double`. Дробная часть в коде отделяется **точкой**, а не запятой:

```c
#include <stdio.h>

int main(void) {
    double temperature = 36.6;
    double price = 99.9;
    double total = price * 3;
    printf("%f\n", temperature);
    printf("%f\n", total);
    return 0;
}
```

Вывод:

```text
36.600000
299.700000
```

Спецификатор `%f` печатает число с шестью знаками после точки. Обычно столько не нужно — количество знаков задают **точностью**: `%.2f` — два знака, `%.0f` — ни одного. При этом число **округляется** по обычным правилам.

```c
#include <stdio.h>

int main(void) {
    double x = 2.0 / 3.0;
    printf("%f\n", x);
    printf("%.2f\n", x);
    printf("%.0f\n", x);
    printf("%8.3f|\n", x);
    return 0;
}
```

Вывод:

```text
0.666667
0.67
1
   0.667|
```

Как и для `%d`, перед точностью можно указать ширину поля: `%8.3f` — всего 8 символов, из них 3 после точки.

Есть ещё тип `float` — он занимает вдвое меньше памяти, но хранит лишь 6–7 значащих цифр. В обычных программах используйте `double` (15–16 значащих цифр), а `float` оставьте для графики и массивов на миллионы элементов.

## Ввод дробных чисел: `%lf`

Для чтения `double` в `scanf` используется `%lf` (long float). Это важная асимметрия:

| Функция  | Спецификатор для `double` |
| -------- | ------------------------- |
| `printf` | `%f`                      |
| `scanf`  | `%lf`                     |

```c
#include <stdio.h>

int main(void) {
    double weight, height_m;
    scanf("%lf %lf", &weight, &height_m);
    printf("%.1f\n", weight / (height_m * height_m));
    return 0;
}
```

Ввод:

```text
70 1.75
```

Вывод:

```text
22.9
```

`%lf` читает и `70`, и `1.75` — целые числа во вводе тоже подходят. А вот с `%f` в `scanf` программа прочитает `double` неправильно: `%f` в `scanf` означает `float`, и компилятор предупредит о несоответствии типов.

## Целое или дробное деление

Тип деления определяется типами операндов. Если оба целые — деление целочисленное. Если хотя бы один дробный — дробное:

```c
#include <stdio.h>

int main(void) {
    int a = 7, b = 2;
    printf("%d\n", a / b);
    printf("%f\n", 7.0 / 2);
    printf("%f\n", (double)a / b);
    printf("%f\n", (double)(a / b));
    return 0;
}
```

Вывод:

```text
3
3.500000
3.500000
3.000000
```

- `7.0 / 2` — литерал `7.0` дробный, поэтому деление дробное.
- `(double)a / b` — приведение превращает `a` в `double` **до** деления.
- `(double)(a / b)` — сначала целочисленное деление даёт 3, потом 3 превращается в 3.0. Дробная часть уже потеряна.

Это та же ловушка, что с `long long` в прошлом уроке: тип выражения определяется операндами, а не переменной, куда запишется результат. `double avg = sum / count;` при целых `sum` и `count` даст целую часть.

## Из дробного в целое

Присваивание `double` в `int` **отбрасывает** дробную часть (в сторону нуля), а не округляет:

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    double x = 2.7;
    int truncated = (int)x;
    printf("%d\n", truncated);
    printf("%.0f %.0f %.0f\n", floor(x), ceil(x), round(x));
    printf("%.0f %.0f %.0f\n", floor(-x), ceil(-x), round(-x));
    return 0;
}
```

Вывод:

```text
2
2 3 3
-3 -2 -3
```

Функции из `<math.h>`:

| Функция    | Что делает                 | `2.7` | `-2.7` |
| ---------- | -------------------------- | ----- | ------ |
| `floor(x)` | округление вниз            | 2     | −3     |
| `ceil(x)`  | округление вверх           | 3     | −2     |
| `round(x)` | к ближайшему целому        | 3     | −3     |
| `(int)x`   | отбрасывание дробной части | 2     | −2     |

Результат `floor`, `ceil`, `round` — тоже `double`. Чтобы получить целое число, его приводят: `(long long)round(x)`.

## Математические функции

В `<math.h>` собраны и другие функции:

| Функция             | Значение                          |
| ------------------- | --------------------------------- |
| `sqrt(x)`           | квадратный корень                 |
| `pow(x, y)`         | x в степени y                     |
| `fabs(x)`           | модуль дробного числа             |
| `sin`, `cos`, `tan` | тригонометрия (угол в радианах)   |
| `exp`, `log`        | экспонента и натуральный логарифм |

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    double dx = 3.0, dy = 4.0;
    double distance = sqrt(dx * dx + dy * dy);
    printf("%.1f\n", distance);
    printf("%.0f\n", pow(2, 10));
    return 0;
}
```

Вывод:

```text
5.0
1024
```

Для `abs` — модуля **целого** числа — нужен `<stdlib.h>`, а для дробного используйте `fabs` из `<math.h>`. Если перепутать, `abs(-2.5)` вернёт `2`.

## Дробные числа хранятся приближённо

Компьютер хранит дробные числа в двоичной системе. Многие простые десятичные дроби, например 0,1, в двоичной записи бесконечны, как 1/3 в десятичной. Поэтому они хранятся с крошечной погрешностью:

```c
#include <stdio.h>

int main(void) {
    double x = 0.1 + 0.2;
    printf("%.2f\n", x);
    printf("%.17f\n", x);
    return 0;
}
```

Вывод:

```text
0.30
0.30000000000000004
```

При печати с двумя знаками всё выглядит идеально, но на самом деле `0.1 + 0.2` не равно `0.3` в точности. Отсюда два правила:

1. **Не сравнивайте дробные числа через `==`.** Проверяйте, что разница достаточно мала: `fabs(x - 0.3) < 1e-9`. Запись `1e-9` означает 1 · 10⁻⁹.
2. **Не храните деньги в `double`.** Сто сложений по 0,1 рубля не дадут ровно 10 рублей. Деньги хранят целыми копейками в `long long`.

<UnderTheHood title="Почему погрешность такая">

`double` хранит число как мантиссу из 53 двоичных цифр и порядок — степень двойки, похоже на запись 1,2345 · 10⁶, только по основанию 2. 53 двоичные цифры — это примерно 15–16 десятичных. Всё, что не помещается, округляется до ближайшего представимого числа. Стандарт, описывающий этот формат, называется IEEE 754; его используют практически все процессоры.

</UnderTheHood>

## Частые ошибки

<CommonMistake title="%f в scanf для double">

`scanf("%f", &x)` при `double x` записывает число неправильного размера. Для `double` в `scanf` нужен `%lf`.

</CommonMistake>

<CommonMistake title="Целочисленное деление в формуле">

`double half = 1 / 2;` — это 0. Пишите `1.0 / 2` или приводите тип: `(double)a / b`.

</CommonMistake>

<CommonMistake title="Запятая вместо точки">

`double x = 3,14;` — в C запятая не является десятичным разделителем. Компилятор поймёт эту строку иначе и выдаст предупреждение. Всегда `3.14`.

</CommonMistake>

<CommonMistake title="Сравнение через ==">

`0.1 + 0.2 == 0.3` — ложь. Сравнивайте с допуском: `fabs(a - b) < 1e-9`.

</CommonMistake>

## Практика

1. **Средний балл** — три оценки, два знака после точки.
2. **Площадь круга** — константа π и степень.
3. **Расстояние между точками** — `sqrt`.
4. **Цена со скидкой** — проценты и округление до копеек.
5. **Округления** — `floor`, `ceil`, `round` и отбрасывание.

## Итоги

- `double` — основной тип для дробных чисел; дробная часть пишется через точку.
- `printf`: `%f`, `%.2f`, `%8.3f`. `scanf`: `%lf`.
- Деление дробное, если хотя бы один операнд дробный; приводите тип до деления: `(double)a / b`.
- `(int)x` отбрасывает дробную часть; `floor`, `ceil`, `round` из `<math.h>` округляют вниз, вверх и к ближайшему.
- Дробные числа хранятся приближённо: не сравнивайте их через `==` и не храните в них деньги.
