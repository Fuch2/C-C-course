## Выбор по значению

Цепочка `else if` подходит для любых условий. Но часто выбор делается по **конкретному значению**: номер месяца, код команды, символ операции. Писать `if (op == '+') ... else if (op == '-') ... else if (op == '*') ...` можно, но длинно. Для таких случаев в C есть оператор `switch` — «переключатель».

## Устройство `switch`

```c
#include <stdio.h>

int main(void) {
    int day;
    scanf("%d", &day);
    switch (day) {
    case 1:
        printf("понедельник\n");
        break;
    case 2:
        printf("вторник\n");
        break;
    case 3:
        printf("среда\n");
        break;
    default:
        printf("другой день\n");
        break;
    }
    return 0;
}
```

Ввод:

```text
2
```

Вывод:

```text
вторник
```

Как это работает:

1. Вычисляется выражение в скобках `switch (day)`.
2. Выполнение **переходит** к метке `case`, значение которой совпало, и продолжается оттуда.
3. `break` выходит из `switch`.
4. Если ни одна метка не совпала, выполнение переходит к `default`. Если `default` нет — `switch` просто ничего не делает.

Метки `case` — это именно **метки**, точки входа, а не отдельные блоки. Это объясняет главную особенность `switch`.

## Без `break` выполнение «проваливается»

Если забыть `break`, выполнение продолжится со следующей строки — через все последующие метки — до первого `break` или конца `switch`:

```c
#include <stdio.h>

int main(void) {
    int level = 2;
    switch (level) {
    case 1:
        printf("один\n");
    case 2:
        printf("два\n");     // Предупреждение: провал в следующую метку
    case 3:
        printf("три\n");
        break;
    case 4:
        printf("четыре\n");
        break;
    }
    return 0;
}
```

Вывод:

```text
два
три
```

Вход на `case 2`, затем без остановки выполнился код `case 3` — до первого `break`. Это называется **проваливанием** (fall-through). В 99 % случаев это ошибка, и GCC с `-Wextra` предупреждает: `this statement may fall through`.

<Important title="Правило">

Заканчивайте каждую ветку `case` оператором `break`. Даже последнюю — тогда при добавлении новой ветки ниже не появится провал.

</Important>

## Группировка меток

Но у провала есть одно полезное и безопасное применение — несколько меток **подряд без кода между ними**. Так одна ветка обрабатывает несколько значений:

```c
#include <stdio.h>

int main(void) {
    int month;
    scanf("%d", &month);
    switch (month) {
    case 12:
    case 1:
    case 2:
        printf("зима\n");
        break;
    case 3:
    case 4:
    case 5:
        printf("весна\n");
        break;
    case 6:
    case 7:
    case 8:
        printf("лето\n");
        break;
    case 9:
    case 10:
    case 11:
        printf("осень\n");
        break;
    default:
        printf("нет такого месяца\n");
        break;
    }
    return 0;
}
```

Ввод:

```text
1
```

Вывод:

```text
зима
```

Пустые метки подряд компилятор не считает подозрительными: намерение очевидно.

## `switch` по символам

Символы в C — целые числа, поэтому `switch` отлично работает с `char`. Вот калькулятор:

```c
#include <stdio.h>

int main(void) {
    int a, b;
    char op;
    scanf("%d %c %d", &a, &op, &b);
    switch (op) {
    case '+':
        printf("%d\n", a + b);
        break;
    case '-':
        printf("%d\n", a - b);
        break;
    case '*':
    case 'x':
        printf("%d\n", a * b);
        break;
    default:
        printf("неизвестная операция\n");
        break;
    }
    return 0;
}
```

Ввод:

```text
6 x 7
```

Вывод:

```text
42
```

Символ в метке записывается в одинарных кавычках: `case '+':`. Умножение принимается и как `*`, и как буква `x` — снова группировка.

## Ограничения `switch`

`switch` подходит не для всего:

| Можно                                      | Нельзя                                     |
| ------------------------------------------ | ------------------------------------------ |
| целые числа: `int`, `char`, `long long`    | дробные числа: `double`                    |
| константы в метках: `case 5:`, `case 'a':` | переменные в метках: `case limit:`         |
| константные выражения: `case 2 * 3:`       | диапазоны: `case 1..10:` (в стандартном C) |
|                                            | строки: `case "да":`                       |

Если нужно проверить диапазон, сравнить с переменной или работать с дробными числами — используйте `if`. В уроке `enum` вы увидите, как `switch` работает с именованными константами.

<Tip title="Переменная внутри case">

Если в ветке нужно объявить переменную, заключите код ветки в фигурные скобки: `case 1: { int t = a * 2; ... break; }`. Без скобок объявление после метки вызывает ошибку компиляции в стандарте C17.

</Tip>

## `switch` или `if`?

- Выбор по **конкретным значениям** одной целочисленной переменной — `switch`. Он нагляднее и не даёт случайно проверить разные переменные в разных ветках.
- **Диапазоны**, сложные условия, разные переменные, дробные числа — цепочка `if`/`else if`.

## Частые ошибки

<CommonMistake title="Забытый break">

Самая частая ошибка: выполняется не одна ветка, а несколько. Читайте предупреждения `-Wimplicit-fallthrough`.

</CommonMistake>

<CommonMistake title="Двойные кавычки у символа">

`case "+":` — строка, а не символ; это ошибка компиляции. Для символа нужны одинарные кавычки: `case '+':`.

</CommonMistake>

<CommonMistake title="Отсутствие default">

Если не обработать неожиданное значение, программа молча ничего не сделает. `default` с сообщением об ошибке помогает заметить неверные данные.

</CommonMistake>

<CommonMistake title="Повторяющиеся метки">

Две метки с одинаковым значением — ошибка компиляции `duplicate case value`. Каждое значение может встречаться в `switch` только один раз.

</CommonMistake>

4. **Робот** — команда-символ меняет координаты.

## Итоги

- `switch` вычисляет выражение и переходит к совпавшей метке `case`; `default` — если ничего не совпало.
- `break` выходит из `switch`; без него выполнение проваливается в следующие метки.
- Несколько пустых меток подряд — безопасный способ обработать несколько значений одной веткой.
- `switch` работает с целыми типами и символами; метки — константы. Для диапазонов, строк и `double` используйте `if`.
