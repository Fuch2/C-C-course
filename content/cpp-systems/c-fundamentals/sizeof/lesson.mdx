## Сколько места занимают данные

Вы уже знаете, что `int` занимает 32 бита, а `long long` — 64. Но откуда программа может это узнать? И как посчитать, сколько памяти понадобится, чтобы хранить миллион измерений? Для этого в C есть оператор `sizeof`. Он понадобится вам постоянно: при работе с массивами, файлами и особенно с динамической памятью в следующем модуле.

## Оператор `sizeof`

`sizeof` возвращает размер типа или переменной **в байтах**:

```c
#include <stdio.h>

int main(void) {
    printf("char:      %zu\n", sizeof(char));
    printf("int:       %zu\n", sizeof(int));
    printf("long long: %zu\n", sizeof(long long));
    printf("float:     %zu\n", sizeof(float));
    printf("double:    %zu\n", sizeof(double));
    return 0;
}
```

Вывод:

```text
char:      1
int:       4
long long: 8
float:     4
double:    8
```

Это размеры на сервере проверки курса (64-битный Linux) и почти на всех современных компьютерах. Но стандарт C гарантирует только некоторые соотношения:

- `sizeof(char)` всегда равен **1** — байт в C по определению размер `char`;
- `int` не меньше 16 бит, `long long` — не меньше 64;
- `sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)`.

Поэтому вместо того, чтобы писать в коде «4», пишут `sizeof(int)`. Программа останется правильной на любой платформе.

## Тип `size_t` и спецификатор `%zu`

Результат `sizeof` имеет особый тип — **`size_t`**. Это беззнаковый целый тип, достаточно большой, чтобы хранить размер любого объекта в памяти. На 64-битных системах — 64 бита. Для печати `size_t` используется спецификатор `%zu`.

```c
#include <stdio.h>

int main(void) {
    size_t count = 1000000;
    size_t bytes = count * sizeof(double);
    printf("%zu измерений займут %zu байт\n", count, bytes);
    return 0;
}
```

Вывод:

```text
1000000 измерений займут 8000000 байт
```

Именно так рассчитывают память для массивов: количество элементов умножается на размер одного элемента. В модуле «Память и указатели» эта формула будет в каждой второй программе: `malloc(count * sizeof(double))`.

<Tip title="size_t — беззнаковый">

Помните прошлый урок: `size_t` не бывает отрицательным. Вычитание двух размеров `a - b` при `a < b` даст огромное число, а сравнение с отрицательным `int` — неожиданный результат.

</Tip>

## `sizeof` от переменной и выражения

`sizeof` можно применять не только к типу, но и к переменной или выражению. Тогда скобки не обязательны: `sizeof x`. Но в курсе мы всегда ставим скобки — так единообразнее.

```c
#include <stdio.h>

int main(void) {
    double price = 9.99;
    int count = 3;
    printf("%zu %zu %zu\n", sizeof(price), sizeof(count), sizeof(price * count));
    return 0;
}
```

Вывод:

```text
8 4 8
```

`price * count` имеет тип `double` (один операнд дробный), поэтому его размер 8. Важная деталь: `sizeof` **не вычисляет** выражение, а только определяет его тип. `sizeof(count++)` не увеличит `count`. Не пишите так: читатель кода будет ожидать, что инкремент произойдёт.

<Concept title="Привычка: sizeof от переменной">

Запись `count * sizeof(price)` лучше, чем `count * sizeof(double)`: если тип `price` поменяется на `float`, расчёт размера останется верным автоматически.

</Concept>

## `sizeof` и массивы — анонс

Самое частое применение `sizeof` — узнать число элементов массива. Массивам посвящён отдельный урок, а пока посмотрите на приём:

```c
#include <stdio.h>

int main(void) {
    int days[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    printf("%zu %zu\n", sizeof(days), sizeof(days) / sizeof(days[0]));
    return 0;
}
```

Вывод:

```text
48 12
```

Весь массив занимает 48 байт, один элемент — 4, значит, элементов 12. Формула `sizeof(arr) / sizeof(arr[0])` работает только для настоящего массива, объявленного в этом же месте. Почему — узнаете в уроке «Массивы и указатели».

## Оценка памяти

Понимание размеров помогает заранее увидеть, поместится ли задача в память. Например, кадр Full HD — 1920 × 1080 пикселей по 3 байта цвета:

```c
#include <stdio.h>

int main(void) {
    size_t width = 1920, height = 1080, channels = 3;
    size_t bytes = width * height * channels;
    printf("%zu байт = %.2f МиБ\n", bytes, bytes / (1024.0 * 1024.0));
    return 0;
}
```

Вывод:

```text
6220800 байт = 5.93 МиБ
```

Минута видео при 30 кадрах в секунду без сжатия — уже больше 10 гигабайт. Поэтому видео всегда сжимают.

1 кибибайт (КиБ) = 1024 байта, 1 мебибайт (МиБ) = 1024 КиБ. Приставки «кило-» и «мега-» в информатике исторически означали то 1000, то 1024; «киби» и «меби» однозначно означают 1024.

## Частые ошибки

<CommonMistake title="%d для size_t">

`printf("%d", sizeof(int))` — несоответствие типов: `size_t` беззнаковый и обычно 64-битный. Компилятор предупредит. Используйте `%zu`.

</CommonMistake>

<CommonMistake title="Числа вместо sizeof">

`count * 4` вместо `count * sizeof(int)` сломается, как только тип изменится или программа окажется на другой платформе.

</CommonMistake>

<CommonMistake title="Ожидание, что sizeof вычислит выражение">

`sizeof(x = 5)` не присваивает 5. Внутри `sizeof` выражения не выполняются.

</CommonMistake>

## Практика

Во всех задачах считайте размеры через `sizeof`, а не подставляйте числа вручную. На сервере проверки `int` и `float` занимают 4 байта, `long long` и `double` — 8, `char` — 1.

1. **Сколько памяти** — для массивов разных типов.
2. **Сколько поместится** — обратная задача.
3. **Страницы памяти** — округление вверх.
4. **Размер изображения** — байты и мебибайты.

## Итоги

- `sizeof` возвращает размер типа, переменной или выражения в байтах; `sizeof(char)` всегда 1.
- Результат имеет тип `size_t` (беззнаковый), печатается через `%zu`.
- `sizeof` не вычисляет выражение, только определяет его тип.
- Память для n элементов — `n * sizeof(элемент)`; число элементов массива — `sizeof(arr) / sizeof(arr[0])`.
- Пишите `sizeof(тип)` вместо чисел — программа останется правильной на других платформах.
