## Задача и модель

Гетерогенная коллекция содержит разные конкретные типы за общим интерфейсом. vector&lt;unique_ptr&lt;Sensor>> владеет датчиками, сохраняя их динамические типы. unique_ptr — единственный владелец; std::make_unique создаёт объект, а std::move передаёт владение. Копировать unique_ptr нельзя. Перемещение не копирует сам датчик и оставляет исходный указатель пустым.

## Как это работает в C++

Алгоритм проходит по коллекции и вызывает read без switch по типам. Новый класс датчика не требует изменения цикла. Цена — косвенный вызов, отдельные размещения объектов и возможное ухудшение локальности. Если набор типов закрыт и значения малы, другие представления могут быть выгоднее; здесь нужен открытый интерфейс. Для заимствованной коллекции подойдут ссылки или указатели с внешним владельцем, но это другой контракт времени жизни.

## Запускаемый пример

```cpp
#include <iostream>
#include <memory>
#include <vector>

struct Source { virtual int read() const = 0; virtual ~Source() = default; };
struct A : Source { int read() const override { return 3; } }; struct B : Source { int read() const override { return 8; } };
int main() { std::vector<std::unique_ptr<Source>> v; v.push_back(std::make_unique<A>()); v.push_back(std::make_unique<B>()); int total=0; for(const auto& s:v) total+=s->read(); std::cout << total << '\n'; }
```

Ожидаемый вывод:

```text
11
```

## Разбор и эксперимент

Добавьте третий источник и оставьте цикл неизменным. После std::move(ptr) нельзя разыменовывать исходный unique_ptr без проверки: он пуст. reserve для вектора переносит владельцев, но сами отдельно выделенные Sensor сохраняют адреса до удаления.

<CommonMistake title="Ошибка, которую нужно заметить">

Не храните производные значения в vector&lt;Base>: это либо невозможно для абстрактной базы, либо приводит к срезке. Не используйте голый new как способ избежать размышления о владельце.

## Практика

Source имеет pure virtual read() const и виртуальный деструктор. Direct(int) возвращает сохранённое число, Doubled(int) — удвоенное. solve(a,b) создаёт vector&lt;unique_ptr&lt;Source>>, добавляет Direct&#123;a&#125; и Doubled&#123;b&#125; через make_unique, затем возвращает сумму read в одном цикле. Аргументы a,b — целые −1000…1000. Не добавляйте main: его создаёт система.
