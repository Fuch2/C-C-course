## Задача и модель

Объявление class объединяет представление и операции. Его члены по умолчанию private. Это позволяет требовать, чтобы все изменения проходили через согласованный набор методов. Инвариант — условие, истинное после создания объекта и после каждой успешно завершённой публичной операции. Например, счётчик принятых измерений никогда не отрицателен.

## Как это работает в C++

Клиент работает с обещанием типа, а не с расположением полей. Сначала сформулируйте допустимые состояния, затем операции перехода между ними. В примере счётчик начинается с нуля, increment увеличивает значение, value только наблюдает. Отсутствие конструктора в тексте не означает отсутствие создания объекта: при таком объявлении компилятор обеспечивает подходящую инициализацию. Реализация маленького метода внутри класса не требует отдельной функции на каждый объект.

## Запускаемый пример

```cpp
#include <iostream>
#include <memory>
#include <vector>

class Counter { int count_{}; public: void increment() { ++count_; } int value() const { return count_; } };
int main() { Counter c; c.increment(); c.increment(); std::cout << c.value() << '\n'; }
```

Ожидаемый вывод:

```text
2
```

## Разбор и эксперимент

Попробуйте добавить decrement. До написания метода решите, что делать при нулевом счётчике: отказ, насыщение или исключение. Добавьте тест последовательности increment, decrement, decrement. Это проверяет достижимые состояния, а не только арифметику одного вызова.
