## Задача и модель

Инкапсуляция — контроль допустимых изменений, а не количество private строк. Для диапазона low &lt;= high изменение обеих границ является одной операцией. Два независимых setter создают промежуточные ошибочные состояния. Метод try_configure проверяет весь запрос и фиксирует его целиком либо сохраняет старый диапазон.

## Как это работает в C++

Сформулируйте предусловия, результат и состояние при отказе. Так тесты могут проверять не только счастливый путь. Не отдавайте изменяемые ссылки на границы: это обходит проверку. Значение состояния можно вернуть копией небольшого struct. Класс не обязан скрывать каждый факт; он скрывает способ представления и защищает отношения между данными. В проекте фильтр будет хранить согласованные границы и единую политику включения крайних значений.

## Запускаемый пример

```cpp
#include <iostream>
#include <memory>
#include <vector>

class Range { int low_{0}, high_{10}; public: bool configure(int l,int h) { if (l > h) return false; low_=l; high_=h; return true; } bool contains(int x) const { return low_ <= x && x <= high_; } };
int main() { Range r; std::cout << r.configure(9,2) << ' ' << r.contains(5) << '\n'; }
```

Ожидаемый вывод:

```text
0 1
```

## Разбор и эксперимент

Предложите тест, который сначала устанавливает новый корректный диапазон, затем отправляет обратные границы. Старый диапазон должен сохраниться целиком. Условие low&lt;=high не гарантирует корректность единиц: это отдельная часть контракта, которую нельзя вывести из int.
