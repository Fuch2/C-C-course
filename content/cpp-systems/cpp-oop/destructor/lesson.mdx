## Задача и модель

Деструктор ~Type() завершает жизнь объекта. Автоматический объект разрушается при выходе из области видимости, в том числе при раскрутке стека исключением. Объекты одной области разрушаются в обратном порядке завершения создания. RAII связывает ресурс со временем жизни владельца: конструктор устанавливает владение, деструктор завершает его.

## Как это работает в C++

Чаще всего собственный деструктор не нужен: string, vector и unique_ptr уже управляют своими ресурсами. Это правило нуля — не писать специальные операции без необходимости. Учебный Guard ниже временно изменяет внешнее значение и восстанавливает его. Его копирование запрещено, иначе два владельца пытались бы восстанавливать одно состояние. Ссылка на внешнее значение безопасна лишь потому, что это значение живёт дольше Guard. Деструктор не должен выбрасывать исключения.

## Запускаемый пример

```cpp
#include <iostream>
#include <memory>
#include <vector>

class Guard { int& x_; int old_; public: explicit Guard(int& x) : x_(x), old_(x) { x_ = 9; } Guard(const Guard&) = delete; Guard& operator=(const Guard&) = delete; ~Guard() { x_ = old_; } };
int main() { int x = 4; { Guard g{x}; std::cout << x << ' '; } std::cout << x << '\n'; }
```

Ожидаемый вывод:

```text
9 4
```

## Разбор и эксперимент

Проследите две вложенные области с двумя Guard. Восстановление идёт от внутренней к внешней. Подумайте, что случится, если защищённое значение уничтожится раньше Guard. Именно порядок объявления, а не имя типа Guard, обеспечивает корректное заимствование.

<CommonMistake title="Ошибка, которую нужно заметить">

Не вызывайте деструктор автоматического объекта вручную ради ранней очистки: обычный выход из области попытается разрушить его снова. Используйте вложенную область.

</CommonMistake>

## Практика

Реализуйте неперекопируемый Guard(int&amp; value,int delta), который прибавляет delta при создании и вычитает ту же delta в деструкторе. solve(a,b) создаёт int value=a, во вложенной области Guard(value,b), сохраняет during=value, выходит из области и возвращает during + value. Копирование запретите через = delete. Аргументы a,b — целые −1000…1000. Не добавляйте main: его создаёт система.
