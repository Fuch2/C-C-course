## Задача и модель

Секция public определяет операции, которыми может пользоваться внешний код. Хороший публичный интерфейс выражает предметные действия: принять измерение, сбросить статистику, узнать количество. Чем больше деталей становится публичными, тем труднее менять внутреннее представление без правок клиентов. Публичный метод может возвращать значение, не предоставляя доступ к его изменению.

## Как это работает в C++

Разделяйте команды и наблюдения. Наблюдение обычно отмечается const, что позволяет вызывать его для const объекта или const ссылки. Публичный метод с говорящим именем задаёт единицы и смысл возвращаемого значения. Метод getData(), возвращающий изменяемую ссылку на весь контейнер, оставляет клиенту слишком много способов нарушить инварианты. const не делает объект автоматически потокобезопасным: в этом модуле операции выполняются последовательно.

## Запускаемый пример

```cpp
#include <iostream>
#include <memory>
#include <vector>

class Status { bool ready_{true}; public: bool ready() const { return ready_; } void stop() { ready_ = false; } };
int main() { Status s; std::cout << s.ready() << ' '; s.stop(); std::cout << s.ready() << '\n'; }
```

Ожидаемый вывод:

```text
1 0
```
