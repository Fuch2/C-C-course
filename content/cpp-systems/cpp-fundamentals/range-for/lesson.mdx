## Цикл по элементам

В C, чтобы пройти по массиву, пишут цикл по индексу: `for (int i = 0; i < n; i++) sum += a[i];`. Индекс здесь — служебная деталь, и в ней легко ошибиться: `<=` вместо `<`, не тот размер. В C++ есть цикл **по диапазону** (range-based for), который проходит по всем элементам контейнера сам:

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<int> numbers = {3, 1, 4, 1, 5};
    int sum = 0;
    for (int x : numbers) {
        sum += x;
    }
    std::string word = "range";
    for (char c : word) {
        std::cout << c << '-';
    }
    std::cout << '\n' << sum << '\n';
    int raw[] = {10, 20, 30};                  // работает и с обычным массивом
    for (int x : raw) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

Вывод:

```text
r-a-n-g-e-
14
10 20 30
```

Читается как «для каждого `x` из `numbers`». Цикл работает с любым контейнером стандартной библиотеки, строкой, массивом фиксированного размера и даже со списком в фигурных скобках: `for (int x : {2, 3, 5, 7})`.

## Копия, ссылка или константная ссылка

Переменная цикла объявляется как любая другая, и от её типа зависит, что происходит:

| Запись                    | Что такое `x`     | Когда использовать                                  |
| ------------------------- | ----------------- | --------------------------------------------------- |
| `for (int x : v)`         | копия элемента    | маленькие типы, только чтение                       |
| `for (int &x : v)`        | ссылка на элемент | нужно изменить элементы                             |
| `for (const auto &x : v)` | ссылка для чтения | большие элементы (строки, структуры), только чтение |

С `auto` писать короче: `for (auto &x : v)` — изменить, `for (const auto &x : v)` — прочитать без копий.

## Как это устроено: итераторы

Цикл по диапазону — сокращение для цикла с **итераторами**. Итератор — объект, который указывает на элемент контейнера и умеет переходить к следующему; для вектора он ведёт себя как указатель на элемент массива. У каждого контейнера есть:

- `begin()` — итератор на первый элемент;
- `end()` — итератор на позицию **за последним** элементом (полуинтервал, как в модуле «Алгоритмы»).

Цикл `for (int x : v)` компилятор превращает примерно в такой:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {7, 8, 9};
    for (auto it = v.begin(); it != v.end(); ++it) {
        int x = *it;                     // * — элемент, на который указывает итератор
        std::cout << x << ' ';
    }
    std::cout << '\n';
    auto second = v.begin() + 1;          // для вектора — арифметика, как у указателей
    std::cout << *second << ' ' << v.end() - v.begin() << '\n';
    for (auto it = v.rbegin(); it != v.rend(); ++it) {   // обратный обход
        std::cout << *it << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

Вывод:

```text
7 8 9
8 3
9 8 7
```

Операции те же, что у указателей в C: `*it` — элемент, `++it` — следующий, `it != end` — конец не достигнут. Для вектора и строки работают и `it + k`, и разность итераторов. `rbegin()`/`rend()` дают обратный обход. `end()` нельзя разыменовывать — за ним нет элемента.

## Итераторы и алгоритмы

Пара итераторов `[begin, end)` — это **диапазон**, и на нём работают алгоритмы стандартной библиотеки. Их десятки, и почти каждый заменяет цикл, который в C пришлось бы писать самому:

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> v = {4, 8, 15, 16, 23, 42};
    int total = std::accumulate(v.begin(), v.end(), 0);               // <numeric>
    auto biggest = std::max_element(v.begin(), v.end());
    auto found = std::find(v.begin(), v.end(), 16);
    std::cout << total << ' ' << *biggest << ' ' << (found - v.begin()) << '\n';
    std::reverse(v.begin(), v.end());
    std::cout << v.front() << ' ' << v.back() << '\n';
    std::sort(v.begin() + 1, v.end() - 1);                              // только середину
    for (int x : v) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

Вывод:

```text
108 42 3
42 4
42 8 15 16 23 4
```

- `std::accumulate(first, last, init)` — сумма диапазона, начиная с `init`. Тип результата — тип `init`: для суммы больших чисел пишите `0LL`.
- `std::max_element` и `std::min_element` возвращают **итератор** на элемент, `std::find` — итератор на первое совпадение или `end()`.
- `std::reverse`, `std::sort` работают с любым диапазоном — хоть с частью вектора.

Возвращённый итератор сравнивают с `end()`, прежде чем разыменовать, — это аналог проверки `npos` у строк.

## Удаление по условию

В C++20 появились функции `std::erase` и `std::erase_if`, которые удаляют из контейнера элементы, равные значению или подходящие под условие, за один проход:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {5, -2, 7, -1, 0, 3};
    auto removed = std::erase_if(v, [](int x) { return x < 0; });
    std::erase(v, 0);
    std::cout << removed << ':';
    for (int x : v) {
        std::cout << ' ' << x;
    }
    std::cout << '\n';
    return 0;
}
```

Вывод:

```text
2: 5 7 3
```

Это та же схема «чтение и запись двумя индексами», которую вы писали вручную в уроке о квадратичной сложности, — только готовая.

## Нельзя менять размер во время обхода

Цикл по диапазону запоминает `begin()` и `end()` в начале. Если внутри цикла добавить элемент в тот же вектор, вектор может перенести элементы в новый блок, и итератор цикла повиснет:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2};
    for (int x : v) {
        if (x == 1) {
            v.push_back(10);            // Ошибка памяти: итератор цикла станет висячим
        }
    }
    std::cout << v.size() << '\n';
    return 0;
}
```

AddressSanitizer сообщает `heap-use-after-free`. Правило: в цикле по диапазону элементы можно **менять**, но нельзя **добавлять и удалять**. Если нужно добавлять, обходите по индексу до исходного размера или собирайте новые элементы в отдельный вектор.

<Concept title="Цикл по диапазону и итераторы">

`for (x : контейнер)` проходит по всем элементам; переменная цикла — копия, ссылка (`auto &`) или ссылка для чтения (`const auto &`). Цикл построен на итераторах: `begin()` указывает на первый элемент, `end()` — за последний; `*it` — элемент, `++it` — следующий. Пара итераторов — диапазон для алгоритмов `<algorithm>` и `<numeric>`. Добавлять и удалять элементы контейнера во время обхода нельзя.

</Concept>

## Частые ошибки

<CommonMistake title="Изменение копии">

`for (auto x : v) x *= 2;` ничего не меняет в векторе: `x` — копия. Нужно `for (auto &x : v)`.

</CommonMistake>

<CommonMistake title="push_back внутри цикла по тому же вектору">

После роста вектора итератор цикла указывает в освобождённую память. Добавляйте в другой вектор или обходите по индексу.

</CommonMistake>

<CommonMistake title="Разыменование end()">

`*std::max_element(v.begin(), v.end())` для пустого вектора разыменовывает `end()` — неопределённое поведение. Проверяйте, что диапазон не пуст, а результат `find` — что он не равен `end()`.

</CommonMistake>

## Практика

1. **Итоги массива** — `accumulate`, `min_element`, `max_element`.
2. **Зеркальные слова** — `std::reverse` для строк и векторов.
3. **Найди ошибку: добавление при обходе** — висячий итератор.
4. **Чистка данных** — `erase_if`, `sort` и `unique`.

## Итоги

- `for (x : c)` проходит по всем элементам контейнера, строки или массива.
- `auto x` — копия, `auto &x` — изменение, `const auto &x` — чтение без копий.
- Итераторы: `begin()` — первый элемент, `end()` — за последним; `*it`, `++it`, `it != end`.
- Пара итераторов — диапазон для алгоритмов: `accumulate`, `max_element`, `find`, `reverse`, `sort`.
- `std::erase_if` удаляет элементы по условию за один проход.
- Во время обхода нельзя добавлять и удалять элементы контейнера.
