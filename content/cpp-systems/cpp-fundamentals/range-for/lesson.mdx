## Зачем инструмент нужен

Цикл по диапазону выражает обход контейнера и уменьшает ошибки индексов. Нужна ссылка для изменения и const-ссылка для чтения без копирования.

## Пример C++20

```cpp
#include <iostream>
#include <string>

void uppercase_ascii(std::string& text) {
    for (char& ch : text) {
        if (ch >= 'a' && ch <= 'z') ch = static_cast<char>(ch - 'a' + 'A');
    }
}
int main() {
    std::string command{"start x1"};
    uppercase_ascii(command);
    std::cout << command << '\n';
}

```

Ожидаемый вывод:

```text
START X1

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте range-based for как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Практика

Прочитайте ASCII-строку длиной до 200. В range-based for через char&amp; замените a…z на соответствующие заглавные. Остальные ASCII-символы сохраните. Выведите результат. Не используйте индексы и locale-зависимое преобразование.

## Краткое резюме

Инструмент range-based for выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
