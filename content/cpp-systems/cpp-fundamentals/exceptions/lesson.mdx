## Теория

## Зачем инструмент нужен

Исключения отделяют нормальный путь от редкой ошибки и автоматически раскручивают стек. Они не должны заменять проверку ожидаемого пользовательского ввода в горячем цикле.

## Пример C++20

```cpp
#include <iostream>
#include <string>
#include <stdexcept>


int main() {
    try { std::cout<<std::stoi("12x")<<'\n'; } catch(const std::exception&) { std::cout<<"ОШИБКА\n"; }
}

```

Ожидаемый вывод:

```text
ОШИБКА

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте Exceptions: основы как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Краткое резюме

Инструмент Exceptions: основы выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
