## Теория

## Пошаговый разбор

На небольшом примере проследите вход, изменение состояния объекта и результат. Для контейнера отметьте размер, вместимость и порядок элементов.

## Зачем инструмент нужен

const-ссылка передаёт большой объект без копии и запрещает изменение через параметр. Временные значения можно безопасно привязать на время вызова.

## Пример C++20

```cpp
#include <iostream>
#include <string>

unsigned long long checksum(const std::string& text) {
    unsigned long long sum = 0;
    for (unsigned char byte : text) sum += byte;
    return sum;
}
int main() {
    std::cout << checksum("AB") << '\n';
}

```

Ожидаемый вывод:

```text
131

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте const references как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Практика

Прочитайте ASCII-строку длиной 0…200 с пробелами. checksum(const std::string&amp; text) суммирует коды байтов в unsigned long long. Выведите сумму, затем исходную строку. Пустой stdin — пустая строка. При передаче в функцию строка не копируется и не изменяется.

## Краткое резюме

Инструмент const references выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
