## Зачем инструмент нужен

В C++ типы и классы позволяют связывать данные с операциями, а RAII — автоматически завершать владение ресурсами. Это меняет вопрос с «как освободить память» на «кто владеет объектом».

## Пример C++20

```cpp
#include <iostream>
#include <string>


int main() {
    std::string original{"sensor"};
    auto copy = original;
    copy += "-backup";
    std::cout << original << '\n' << copy << '\n';
}

```

Ожидаемый вывод:

```text
sensor
sensor-backup

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте Чем C++ отличается от C как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>
