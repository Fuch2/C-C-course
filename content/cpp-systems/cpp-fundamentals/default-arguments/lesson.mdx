## Пошаговый разбор

На небольшом примере проследите вход, изменение состояния объекта и результат. Для контейнера отметьте размер, вместимость и порядок элементов.

## Зачем инструмент нужен

Значение по умолчанию сокращает повторяющиеся вызовы. Оно подставляется в месте компиляции, поэтому меняйте декларации осторожно в публичных заголовках.

## Пример C++20

```cpp
#include <iostream>

bool above(int value, int threshold = 80) { return value > threshold; }
int main() {
    std::cout << above(90) << ' ' << above(90, 100) << '\n';
}

```

Ожидаемый вывод:

```text
1 0

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте Default arguments как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Краткое резюме

Инструмент Default arguments выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
