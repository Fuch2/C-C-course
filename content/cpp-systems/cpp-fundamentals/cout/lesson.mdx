## Зачем инструмент нужен

Поток вывода форматирует типы через оператор &lt;&lt; и сохраняет состояние форматирования. Он безопаснее printf по типам, но может быть медленнее без буферизации.

## Пример C++20

```cpp
#include <iostream>
#include <iomanip>

void print_amount(long long cents) {
    if (cents < 0) { std::cout << '-'; cents = -cents; }
    std::cout << cents / 100 << '.' << std::setfill('0')
              << std::setw(2) << cents % 100 << '\n';
}
int main() {
    print_amount(5);
    print_amount(-1234);
}

```

Ожидаемый вывод:

```text
0.05
-12.34

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте std::cout как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

## Практика

Ввод: целое cents от −1000000 до 1000000. Выведите сумму с точкой и ровно двумя цифрами после неё, например −5 → -0.05. Используйте std::cout, std::setw и std::setfill; храните сумму в целых единицах, без double.

## Краткое резюме

Инструмент std::cout выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
