## Вывод без строки формата

В C вывод — это `printf` со строкой формата: `printf("%s: %d\n", name, score)`. Компилятор не обязан проверять, что `%d` соответствует `int`; если перепутать спецификатор — `printf("%d", 3.5)` — получится неопределённое поведение. В C++ вывод устроен иначе: **поток** `std::cout` и оператор `<<`, который сам знает, как печатать значение каждого типа.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "Ада";
    int score = 97;
    double ratio = 0.97;
    char grade = 'A';
    std::cout << name << ": " << score << " баллов, доля " << ratio << ", оценка " << grade << '\n';
    return 0;
}
```

Вывод:

```text
Ада: 97 баллов, доля 0.97, оценка A
```

Каждый `<<` выводит одно значение и возвращает тот же поток, поэтому вызовы выстраиваются в цепочку. Тип определяется во время компиляции: строка печатается как текст, `int` — как целое, `double` — как число с точкой, `char` — как символ. Перепутать спецификатор невозможно — спецификаторов нет.

## '\n' или std::endl

Перевод строки можно вывести символом `'\n'` или манипулятором `std::endl`. Разница: `std::endl` ещё и **сбрасывает буфер** — заставляет поток немедленно отдать накопленный текст операционной системе. При выводе миллиона строк сброс после каждой замедляет программу в разы. Пишите `'\n'`, а сброс оставьте для случаев, когда вывод нужно увидеть сразу, — например, перед долгим вычислением.

Для сообщений об ошибках есть отдельный поток `std::cerr` — аналог `stderr`. Он не буферизуется, и его вывод не смешивается с основным, если вывод программы перенаправлен в файл.

## Числа с плавающей точкой

По умолчанию `double` печатается с шестью **значащими** цифрами, а слишком большие и маленькие — в экспоненциальной записи. Чтобы управлять видом, используют **манипуляторы** из `<iomanip>`:

```cpp
#include <iomanip>
#include <iostream>

int main() {
    double pi = 3.14159265358979;
    std::cout << pi << ' ' << 1e10 / 3 << ' ' << 0.0000123 << '\n';
    std::cout << std::fixed << std::setprecision(2);
    std::cout << pi << ' ' << 1e10 / 3 << ' ' << 0.0000123 << '\n';
    std::cout << std::setprecision(5) << pi << '\n';
    return 0;
}
```

Вывод:

```text
3.14159 3.33333e+09 1.23e-05
3.14 3333333333.33 0.00
3.14159
```

`std::fixed` переключает на запись с фиксированным числом знаков **после точки**, а `std::setprecision(n)` задаёт это число — аналог `%.2f`. Эти манипуляторы **запоминаются**: поток остаётся в режиме `fixed` с точностью 2, пока его не переключат, — поэтому третья строка печатает пять знаков после точки.

## Ширина и выравнивание

Для таблиц нужна ширина поля — аналог `%10s` и `%5d`:

```cpp
#include <iomanip>
#include <iostream>
#include <string>

int main() {
    std::string names[] = {"Ann", "Boris", "Vera"};
    int scores[] = {91, 7, 100};
    for (int i = 0; i < 3; i++) {
        std::cout << std::left << std::setw(8) << names[i]
                  << std::right << std::setw(5) << scores[i] << '\n';
    }
    std::cout << std::setfill('0') << std::setw(6) << 42 << '\n';
    return 0;
}
```

Вывод:

```text
Ann        91
Boris       7
Vera      100
000042
```

- `std::setw(n)` задаёт минимальную ширину **только следующего** выводимого значения — его нужно повторять перед каждым полем;
- `std::left` и `std::right` выравнивают внутри поля и **запоминаются**;
- `std::setfill(c)` задаёт символ-заполнитель вместо пробела, тоже запоминается.

`std::setw` считает **байты**, а не буквы. Для латиницы это одно и то же, а русская буква в UTF-8 занимает два байта: «Аня» — это 6 байт, и при ширине 8 к ней добавится всего 2 пробела вместо 5. Колонки с кириллицей поэтому разъезжаются, и ширину приходится считать вручную. В следующем уроке вы увидите `std::format` и `std::print` из C++20 и C++23 — они считают ширину в символах и решают эту проблему.

## Логические значения и системы счисления

```cpp
#include <iostream>

int main() {
    bool ready = true;
    std::cout << ready << ' ' << std::boolalpha << ready << ' ' << false << '\n';
    std::cout << std::hex << 255 << ' ' << std::uppercase << 255 << ' ' << std::dec << 255 << '\n';
    return 0;
}
```

Вывод:

```text
1 true false
ff FF 255
```

`std::boolalpha` печатает `bool` словами, `std::hex`, `std::oct` и `std::dec` переключают систему счисления, `std::uppercase` — регистр шестнадцатеричных цифр. Все они запоминаются до обратного переключения.

## Символы и маленькие числа

`<<` различает типы — и иногда это сюрприз. `char` всегда печатается **как символ**. А тип `std::uint8_t`, удобный для байтов, на практике — это `unsigned char`, и он тоже печатается как символ:

```cpp
#include <cstdint>
#include <iostream>

int main() {
    std::uint8_t brightness = 65;
    char letter = 66;
    std::cout << brightness << ' ' << letter << '\n';
    std::cout << static_cast<int>(brightness) << ' ' << +letter << '\n';
    return 0;
}
```

Вывод:

```text
A B
65 66
```

Чтобы напечатать байт как число, его приводят к `int`: `static_cast<int>(x)` или коротко `+x` — унарный плюс превращает маленький целый тип в `int`.

<Concept title="Поток вывода">

`std::cout << значение` печатает значение в соответствии с его типом — без строки формата и без риска перепутать спецификатор. Цепочки `<<` выводят несколько значений подряд. Манипуляторы из `<iomanip>` управляют видом: `fixed` и `setprecision` для дробных, `setw` (только для следующего значения), `left`/`right` и `setfill` для таблиц, `boolalpha` и `hex` для логических значений и систем счисления. Большинство манипуляторов запоминаются потоком.

</Concept>

## Частые ошибки

<CommonMistake title="setw действует один раз">

`std::cout << std::setw(5) << a << b;` выравнивает только `a`. Ширину нужно ставить перед каждым полем. Остальные манипуляторы, наоборот, «залипают»: забытый `std::hex` превратит в шестнадцатеричные все следующие числа программы.

</CommonMistake>

<CommonMistake title="Байт печатается символом">

`std::uint8_t` и `char` выводятся как символы: значение 10 напечатает перевод строки, 0 — невидимый нулевой символ. Приводите к `int` перед выводом.

</CommonMistake>

<CommonMistake title="std::endl в каждой строке">

`std::endl` сбрасывает буфер. В цикле на миллион строк это заметно замедляет программу. Пишите `'\n'`.

</CommonMistake>

## Практика

1. **Таблица результатов** — ширина и выравнивание.
2. **Чек** — два знака после точки.
3. **Найди ошибку: яркость пикселей** — байт печатается символом.
4. **Шестнадцатеричный дамп** — `hex`, `setw` и `setfill` вместе.

## Итоги

- `std::cout << x` печатает значение по его типу; цепочки `<<` выводят несколько значений.
- `'\n'` переводит строку, `std::endl` ещё и сбрасывает буфер — обычно это не нужно.
- `std::fixed` и `std::setprecision(n)` — фиксированное число знаков после точки.
- `std::setw(n)` действует на одно значение; `left`, `right`, `setfill`, `boolalpha`, `hex` запоминаются.
- `char` и `std::uint8_t` печатаются символами — для числа приводите к `int`.
- `std::cerr` — поток для сообщений об ошибках.
- Потоками написано огромное количество кода, но в C++23 для нового кода появился более удобный вывод — `std::print`, о нём следующий урок.
