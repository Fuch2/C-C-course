## Пусть тип выведет компилятор

Типы в C++ бывают длинными: `std::vector<std::string>::const_iterator`, `std::map<std::string, std::vector<int>>::iterator`. Когда тип очевиден из выражения справа, писать его ещё раз — лишняя работа. Ключевое слово `auto` просит компилятор **вывести тип** переменной из инициализатора:

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    auto count = 10;                     // int
    auto ratio = 0.75;                   // double
    auto letter = 'x';                   // char
    auto name = std::string("Ada");      // std::string
    std::vector<int> v = {4, 8, 15};
    auto n = v.size();                   // std::size_t
    std::cout << count * ratio << ' ' << letter << ' ' << name.size() << ' ' << n << '\n';
    return 0;
}
```

Вывод:

```text
7.5 x 3 3
```

Тип выводится **при компиляции** и дальше не меняется: `auto` — не «переменная любого типа», как в языках с динамической типизацией. `count` — обычный `int`, и присвоить ему строку нельзя.

## Ловушки вывода типа

`auto` берёт тип выражения буквально — и иногда это не тот тип, который вы ожидали:

```cpp
#include <iostream>
#include <string>

int main() {
    auto a = "text";                     // const char *, а не std::string!
    auto b = std::string("text");        // std::string
    using namespace std::string_literals;
    auto c = "text"s;                    // std::string: суффикс s
    auto big = 3'000'000'000;            // long: не помещается в int
    auto u = 10u;                        // unsigned int
    std::cout << sizeof(a) << ' ' << b.size() << ' ' << c.size() << ' ' << big << ' ' << u - 11 << '\n';
    return 0;
}
```

Вывод:

```text
8 4 4 3000000000 4294967295
```

- Строковый литерал — это массив `char`, и `auto` выводит из него `const char *`. Чтобы получить `std::string`, пишут `std::string("…")` или литерал с суффиксом `s`.
- Целый литерал получает наименьший подходящий тип из `int`, `long`, `long long`. Апострофы `3'000'000'000` — просто разделители разрядов для читаемости (C++14).
- `10u` — `unsigned`, и `u - 11` не даёт −1, а переполняется по модулю.

Есть и правило, которое запомнить важнее всего: **`auto` отбрасывает ссылки и `const`**. Если функция возвращает ссылку, `auto x = f();` создаст **копию**. Чтобы получить ссылку, пишут `auto &` или `const auto &`:

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3};
    auto copy = v[0];                    // int — копия
    auto &ref = v[1];                    // int & — ссылка
    copy = 100;
    ref = 200;
    std::cout << copy << ' ' << v[0] << ' ' << v[1] << '\n';
    return 0;
}
```

Вывод:

```text
100 1 200
```

## Где auto уместен

Хорошее правило: используйте `auto`, когда тип **очевиден** из правой части или **неважен** читателю — итераторы, результаты `make_…`, лямбды. Не используйте, когда тип важен для понимания: `auto total = compute();` заставит читателя искать, что возвращает `compute`. И помните о литералах: `auto x = 0;` — `int`, даже если дальше в `x` будут складываться миллиарды.

## Лямбда-выражения

Многие функции стандартной библиотеки принимают **функцию как параметр**: сортировка — функцию сравнения, поиск — условие. В модуле «Углублённый C» вы передавали указатели на функции в `qsort`. В C++ такую функцию можно написать прямо на месте вызова — это **лямбда-выражение**:

```cpp
#include <iostream>

int main() {
    auto square = [](int x) { return x * x; };
    auto is_even = [](int x) { return x % 2 == 0; };
    std::cout << square(7) << ' ' << is_even(7) << ' ' << is_even(square(4)) << '\n';
    return 0;
}
```

Вывод:

```text
49 0 1
```

Синтаксис: `[захват](параметры) { тело }`. Тип возвращаемого значения выводится из `return`. У каждой лямбды свой уникальный тип, у которого нет имени, — поэтому сохранить лямбду в переменную можно только через `auto`.

## Лямбды и алгоритмы

Главное применение лямбд — передача условия в алгоритмы из `<algorithm>`:

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> words = {"pear", "fig", "banana", "kiwi", "apple"};
    std::sort(words.begin(), words.end(), [](const std::string &a, const std::string &b) {
        if (a.size() != b.size()) {
            return a.size() < b.size();          // сначала по длине
        }
        return a < b;                            // потом по алфавиту
    });
    for (const auto &w : words) {
        std::cout << w << ' ';
    }
    std::cout << '\n';
    auto long_words = std::count_if(words.begin(), words.end(),
                                    [](const std::string &w) { return w.size() > 4; });
    std::cout << long_words << '\n';
    return 0;
}
```

Вывод:

```text
fig kiwi pear apple banana
2
```

`std::sort` получает функцию «должен ли `a` стоять раньше `b`» — та же идея, что в функциях сравнения для `qsort`, только без указателей `void *` и приведений типов. `std::count_if` считает элементы, для которых условие истинно. Запись `words.begin(), words.end()` задаёт диапазон «весь вектор» — об этих **итераторах** подробно в следующем уроке.

## Захват переменных

Лямбде часто нужны переменные из окружающего кода — например, порог. Их перечисляют в квадратных скобках:

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores = {55, 72, 90, 41, 88};
    int threshold = 70;
    auto passed = std::count_if(scores.begin(), scores.end(),
                                [threshold](int s) { return s >= threshold; });
    int total = 0;
    std::for_each(scores.begin(), scores.end(), [&total](int s) { total += s; });
    std::cout << passed << ' ' << total << '\n';
    return 0;
}
```

Вывод:

```text
3 346
```

- `[threshold]` — захват **по значению**: лямбда получает копию переменной в момент создания.
- `[&total]` — захват **по ссылке**: лямбда работает с самой переменной и может её изменить.
- `[=]` и `[&]` захватывают все используемые переменные по значению или по ссылке соответственно; явный список нагляднее.

Захват по ссылке подчиняется тем же правилам, что и ссылки: если лямбда переживёт переменную, ссылка повиснет.

<Concept title="auto и лямбды">

`auto` выводит тип переменной из инициализатора при компиляции; он отбрасывает ссылки и `const` — для ссылки пишут `auto &`. Строковый литерал через `auto` — это `const char *`. Лямбда `[захват](параметры) { тело }` — функция, написанная на месте; её сохраняют в `auto` и передают в алгоритмы: `std::sort`, `std::count_if`, `std::find_if`. Захват `[x]` копирует переменную, `[&x]` ссылается на неё.

</Concept>

## Частые ошибки

<CommonMistake title="auto из строкового литерала">

`auto s = "hello"; s += " world";` не компилируется: `s` — `const char *`. Нужен `std::string s = "hello";` или `auto s = "hello"s;`.

</CommonMistake>

<CommonMistake title="Копия вместо ссылки">

`auto x = v[0]; x = 5;` не меняет вектор: `auto` отбросил ссылку. Чтобы изменить элемент, пишите `auto &x = v[0];`.

</CommonMistake>

<CommonMistake title="Функция сравнения с <=">

Функция сравнения для `std::sort` должна отвечать «строго раньше». С `<=` для равных элементов она возвращает `true` в обе стороны, и это неопределённое поведение: сортировка может выйти за границы массива.

</CommonMistake>

## Итоги

- `auto` выводит тип из инициализатора при компиляции; тип не меняется.
- Строковый литерал через `auto` — `const char *`; для строки — `std::string` или суффикс `s`.
- `auto` отбрасывает ссылки и `const`: для ссылки — `auto &`, для чтения без копии — `const auto &`.
- Лямбда `[](параметры) { тело }` — функция на месте вызова; хранится в `auto`.
- Лямбды передают в алгоритмы: `std::sort`, `std::count_if`, `std::for_each`.
- `[x]` захватывает копию, `[&x]` — ссылку.
