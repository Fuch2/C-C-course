## Теория

Перегрузки связывают одно понятие с разными статическими типами. Они удобнее макросов C, но неоднозначные преобразования дают ошибку компиляции.

<Concept title="Ментальная модель">

Инструмент Function overload выражает намерение программы через типы и границы владения.

</Concept>

## Зачем инструмент нужен

Перегрузки связывают одно понятие с разными статическими типами. Они удобнее макросов C, но неоднозначные преобразования дают ошибку компиляции.

## Пример C++20

```cpp
#include <iostream>
#include <iomanip>

int scale(int value) { return value * 2; }
double scale(double value) { return value * 0.5; }
int main() {
    std::cout << scale(7) << ' ' << scale(7.0) << '\n';
}

```

Ожидаемый вывод:

```text
14 3.5

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте Function overload как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Практика

Ввод: I и int −1000…1000 либо D и конечное double в том же диапазоне, кратное 1. Создайте scale(int) → value×2 и scale(double) → value×0.5. Вызовите нужную через аргумент соответствующего типа. Для I выведите целое, для D — fixed с одной цифрой после точки.

## Краткое резюме

Инструмент Function overload выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
