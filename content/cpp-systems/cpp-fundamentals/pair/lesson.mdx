## Два значения вместе

Часто два значения связаны: координаты `x` и `y`, имя и балл, начало и конец отрезка, слово и число его вхождений. В C для этого объявляют структуру. В C++ для пары значений есть готовый шаблон `std::pair<A, B>` из `<utility>`:

```cpp
#include <iostream>
#include <string>
#include <utility>

int main() {
    std::pair<std::string, int> student = {"Ада", 97};
    std::cout << student.first << ": " << student.second << '\n';
    student.second += 2;
    auto point = std::make_pair(3, 4.5);           // std::pair<int, double>
    std::pair copy{10, 'z'};                        // типы выведены: std::pair<int, char>
    std::cout << student.second << ' ' << point.first + point.second << ' ' << copy.second << '\n';
    return 0;
}
```

Вывод:

```text
Ада: 97
99 7.5 z
```

У пары два поля — `first` и `second`. Создать её можно фигурными скобками, функцией `std::make_pair` (типы выводятся из аргументов) или конструктором без указания типов — компилятор выведет их сам (C++17).

## Сравнение пар

Пары сравниваются **лексикографически**: сначала по `first`, а при равенстве — по `second`. Поэтому сортировка вектора пар упорядочивает по первому элементу, а равные — по второму, без всякой функции сравнения:

```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>

int main() {
    std::vector<std::pair<int, int>> points = {{3, 1}, {1, 9}, {3, 0}, {1, 2}};
    std::sort(points.begin(), points.end());
    for (const auto &p : points) {
        std::cout << '(' << p.first << ',' << p.second << ") ";
    }
    std::cout << '\n';
    std::cout << (std::make_pair(1, 5) < std::make_pair(2, 0)) << '\n';
    return 0;
}
```

Вывод:

```text
(1,2) (1,9) (3,0) (3,1)
1
```

Этим часто пользуются, чтобы сортировать по нескольким ключам: положить ключи в пару в нужном порядке. Например, чтобы отсортировать слова по убыванию частоты, а при равенстве — по алфавиту, можно сортировать пары `(-частота, слово)`.

## Функция возвращает два значения

В уроке о ссылках функция возвращала несколько результатов через параметры-ссылки. Пара — второй способ: функция возвращает оба значения сразу.

```cpp
#include <iostream>
#include <utility>
#include <vector>

std::pair<int, int> min_max(const std::vector<int> &v) {
    int lo = v[0], hi = v[0];
    for (int x : v) {
        if (x < lo) lo = x;
        if (x > hi) hi = x;
    }
    return {lo, hi};
}

int main() {
    std::vector<int> v = {4, -2, 9, 0};
    std::pair<int, int> result = min_max(v);
    std::cout << result.first << ' ' << result.second << '\n';
    return 0;
}
```

Вывод:

```text
-2 9
```

`return {lo, hi};` создаёт пару из фигурных скобок — тип известен из объявления функции. В стандартной библиотеке так устроена `std::minmax_element` — она возвращает пару итераторов.

## Структурные привязки

Обращения `result.first` и `result.second` не говорят, что где лежит. **Структурные привязки** (C++17) раскладывают пару по переменным с понятными именами:

```cpp
#include <iostream>
#include <string>
#include <utility>
#include <vector>

std::pair<int, int> divide(int a, int b) {
    return {a / b, a % b};
}

int main() {
    auto [quotient, remainder] = divide(17, 5);
    std::cout << quotient << ' ' << remainder << '\n';

    std::vector<std::pair<std::string, int>> scores = {{"Ада", 97}, {"Алан", 88}};
    for (const auto &[name, score] : scores) {
        std::cout << name << " — " << score << '\n';
    }

    int arr[3] = {7, 8, 9};
    auto [a, b, c] = arr;                     // работает и с массивами, и со структурами
    std::cout << a + b + c << '\n';
    return 0;
}
```

Вывод:

```text
3 2
Ада — 97
Алан — 88
24
```

`auto [quotient, remainder] = …` объявляет две переменные и раскладывает в них поля пары по порядку. Привязки работают с парами, кортежами (следующий урок), массивами фиксированного размера и структурами с открытыми полями.

Как и с обычным `auto`, важно, копия это или ссылка:

- `auto [x, y] = p;` — копия пары, изменения `x` не затронут `p`;
- `auto &[x, y] = p;` — `x` и `y` ссылаются на поля `p`;
- `const auto &[x, y] = p;` — чтение без копирования.

В цикле `for (auto [name, score] : scores)` каждая пара копируется, и изменение `score` пропадает. Чтобы изменить элементы, нужно `auto &[name, score]`.

<Concept title="std::pair и структурные привязки">

`std::pair<A, B>` хранит два значения в полях `first` и `second`; создаётся скобками, `std::make_pair` или с выводом типов. Пары сравниваются лексикографически, поэтому вектор пар сортируется по первому полю, затем по второму. Функция может вернуть пару — два результата сразу. Структурные привязки `auto [a, b] = p` раскладывают пару по переменным с именами; `auto &[a, b]` даёт ссылки на поля.

</Concept>

## Частые ошибки

<CommonMistake title="Изменение копии в привязке">

`for (auto [name, score] : scores) score += 10;` ничего не меняет: каждая пара скопирована. Пишите `for (auto &[name, score] : scores)`.

</CommonMistake>

<CommonMistake title="first и second вместо имён">

Код вида `p.second.first + q.first.second` невозможно читать. Если у значений есть смысл, дайте им имена: структурные привязки или своя структура с понятными полями.

</CommonMistake>

<CommonMistake title="Неожиданный порядок сортировки">

Пары сортируются по `first`, а не по тому полю, которое вы считаете главным. Если нужен порядок по `second`, передайте `std::sort` лямбду или переставьте поля.

</CommonMistake>

## Итоги

- `std::pair<A, B>` — два значения в полях `first` и `second`.
- Пары сравниваются лексикографически; сортировка вектора пар — по первому полю, затем по второму.
- Функция может вернуть пару: `return {a, b};`.
- Структурные привязки `auto [a, b] = p` дают полям имена; `auto &` — ссылки, `const auto &` — чтение без копии.
- В цикле по контейнеру пар без `&` привязка работает с копиями.
