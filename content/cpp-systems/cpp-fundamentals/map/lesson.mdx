## Словарь: ключ → значение

Многие задачи требуют находить значение по **ключу**: телефон по имени, цену по артикулу, число вхождений по слову. В C для этого пришлось бы писать дерево поиска или хеш-таблицу (вы делали это в модуле «Алгоритмы»). В C++ есть готовые **ассоциативные контейнеры**. Первый из них — `std::map<Key, Value>` из `<map>`:

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> age;
    age["Ада"] = 36;
    age["Алан"] = 41;
    age["Грейс"] = 85;
    age["Ада"] = 37;                         // ключ уже есть — значение заменится
    std::cout << age["Алан"] << ' ' << age.size() << '\n';
    for (const auto &[name, years] : age) {
        std::cout << name << ": " << years << '\n';
    }
    return 0;
}
```

Вывод:

```text
41 3
Ада: 37
Алан: 41
Грейс: 85
```

Каждый ключ встречается в `map` не больше одного раза. Элемент контейнера — пара `std::pair<const Key, Value>`, поэтому обход удобно писать со структурной привязкой. Обход идёт **в порядке возрастания ключей** — для строк это алфавитный порядок по кодам символов.

Внутри `std::map` — сбалансированное дерево поиска (обычно красно-чёрное, урок о деревьях поиска в модуле «Алгоритмы»). Поэтому поиск, вставка и удаление стоят `O(log n)`, а ключи всегда упорядочены.

## Поиск без побочных эффектов

`m[key]` удобен для записи, но у него есть ловушка: если ключа нет, `operator[]` **создаёт** элемент со значением по умолчанию (0 для чисел, пустая строка для строк). Просто «посмотреть» через `[]` нельзя — словарь от этого растёт:

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> stock = {{"apple", 5}, {"pear", 0}};
    if (stock["banana"] == 0) {                   // ловушка: banana создан
        std::cout << "нет бананов, размер " << stock.size() << '\n';
    }
    std::cout << stock.contains("kiwi") << ' ' << stock.count("apple") << '\n';
    auto it = stock.find("pear");
    if (it != stock.end()) {
        std::cout << it->first << " = " << it->second << '\n';
    }
    std::cout << stock.at("apple") << ' ' << stock.size() << '\n';
    return 0;
}
```

Вывод:

```text
нет бананов, размер 3
0 1
pear = 0
5 3
```

Способы узнать о ключе, не меняя словарь:

| Способ                  | Результат                                                           |
| ----------------------- | ------------------------------------------------------------------- |
| `m.contains(k)` (C++20) | `true` или `false`                                                  |
| `m.count(k)`            | 0 или 1                                                             |
| `m.find(k)`             | итератор на элемент или `m.end()`; `it->first`, `it->second`        |
| `m.at(k)`               | ссылка на значение; если ключа нет — исключение `std::out_of_range` |

Правило: `[]` — для записи и для подсчёта (`++count[word]`), `find`/`contains`/`at` — для чтения.

## Подсчёт частот

Самое частое применение `map` — подсчёт. Здесь создание элемента по `[]` как раз полезно: новый ключ начинается с нуля, и `++` сразу даёт 1.

```cpp
#include <iostream>
#include <map>
#include <sstream>
#include <string>

int main() {
    std::istringstream text("to be or not to be");
    std::map<std::string, int> count;
    std::string word;
    while (text >> word) {
        ++count[word];
    }
    for (const auto &[w, c] : count) {
        std::cout << w << ' ' << c << '\n';
    }
    return 0;
}
```

Вывод:

```text
be 2
not 1
or 1
to 2
```

Сравните с хеш-таблицей, которую вы писали в модуле «Алгоритмы»: здесь те же несколько строк дают ещё и алфавитный порядок.

## Вставка и удаление

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<int, std::string> codes = {{404, "Not Found"}};
    auto [it, inserted] = codes.insert({200, "OK"});
    std::cout << it->second << ' ' << inserted << '\n';
    auto [it2, inserted2] = codes.insert({404, "Другое"});   // ключ есть — вставки нет
    std::cout << it2->second << ' ' << inserted2 << '\n';
    codes.erase(404);
    codes[500] = "Server Error";
    for (const auto &[code, text] : codes) {
        std::cout << code << ' ' << text << '\n';
    }
    return 0;
}
```

Вывод:

```text
OK 1
Not Found 0
200 OK
500 Server Error
```

`insert` не заменяет существующее значение и возвращает пару: итератор на элемент и признак, была ли вставка. `erase(key)` удаляет по ключу, `erase(it)` — по итератору.

## Запросы по диапазону ключей

Раз ключи упорядочены, `map` отвечает на вопросы, недоступные хеш-таблице: «первый ключ не меньше `x`», «все ключи от `a` до `b`». Это те же нижняя и верхняя границы, что у двоичного поиска:

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<int, std::string> log = {{900, "старт"}, {930, "отчёт"}, {1015, "обед"}, {1200, "конец"}};
    for (auto it = log.lower_bound(930); it != log.upper_bound(1100); ++it) {
        std::cout << it->first << ' ' << it->second << '\n';
    }
    auto next = log.upper_bound(1015);
    std::cout << "после 1015: " << next->second << '\n';
    return 0;
}
```

Вывод:

```text
930 отчёт
1015 обед
после 1015: конец
```

`lower_bound(k)` — первый элемент с ключом `≥ k`, `upper_bound(k)` — первый с ключом `> k`. Обход между ними — все ключи диапазона за `O(log n + k)`.

<Concept title="std::map">

Упорядоченный словарь «ключ → значение» на сбалансированном дереве поиска: поиск, вставка и удаление за `O(log n)`, обход в порядке ключей. `m[k]` создаёт отсутствующий ключ — используйте его для записи и подсчёта, а для чтения — `find`, `contains`, `count` или `at`. `insert` не заменяет существующее значение. `lower_bound` и `upper_bound` дают запросы по диапазону ключей.

</Concept>

## Частые ошибки

<CommonMistake title="Чтение через []">

`if (m[key] > 0)` добавляет `key` в словарь, если его не было. Размер растёт, а обход начинает выдавать «призрачные» нулевые записи. Для проверки — `contains` или `find`.

</CommonMistake>

<CommonMistake title="Изменение ключа">

Ключ элемента — `const`: `it->first = …` не компилируется, ведь изменение ключа сломало бы порядок дерева. Чтобы «переименовать» ключ, удалите элемент и вставьте новый.

</CommonMistake>

<CommonMistake title="Разыменование find без проверки">

`m.find(k)->second` для отсутствующего ключа разыменовывает `end()` — неопределённое поведение. Сначала `if (it != m.end())`.

</CommonMistake>

## Итоги

- `std::map<K, V>` — упорядоченный словарь; операции `O(log n)`, обход по возрастанию ключей.
- Элементы — пары `(const K, V)`; удобно обходить через `const auto &[k, v]`.
- `m[k]` создаёт отсутствующий ключ: для записи и подсчёта.
- Для чтения: `contains`, `count`, `find` (с проверкой `end()`), `at` (исключение при отсутствии).
- `insert` не перезаписывает; `erase` удаляет по ключу или итератору.
- `lower_bound` и `upper_bound` — запросы по диапазону ключей.
