## Третий способ вывода

Вы знаете уже два способа печатать. У каждого свои слабости:

- `printf("%s: %d\n", name, score)` компактен, но не проверяет типы: перепутанный спецификатор — неопределённое поведение;
- `std::cout << name << ": " << score << '\n'` проверяет типы, но многословен, а манипуляторы вроде `std::setprecision` «залипают» в потоке и действуют на весь последующий вывод.

C++20 добавил `std::format`, а C++23 — `std::print` и `std::println`. Они берут лучшее от обоих подходов: строку-шаблон, как у `printf`, и проверку типов, как у потоков. Причём проверка происходит **при компиляции**: если в шаблоне два места для значений, а передано одно, программа не соберётся. В новом коде на C++23 это основной способ вывода.

## `std::format`: строка по шаблону

`std::format` из `<format>` собирает строку: каждая пара фигурных скобок `{}` в шаблоне заменяется очередным аргументом. Тип аргумента не нужно указывать — его знает компилятор:

```cpp
#include <format>
#include <iostream>
#include <string>

int main() {
    std::string name = "Ада";
    int score = 97;
    std::string line = std::format("{}: {} баллов из {}", name, score, 100);
    std::cout << line << '\n';
    std::cout << line.size() << '\n';
    return 0;
}
```

Вывод:

```text
Ада: 97 баллов из 100
32
```

Результат — обычная `std::string`: её можно сохранить, передать в функцию, дописать к другой строке. Длина 32 — в **байтах**: каждая русская буква в UTF-8 занимает два байта.

## `std::print` и `std::println`

Чтобы сразу напечатать результат, есть `std::print` и `std::println` из `<print>`. `println` добавляет перевод строки в конце, `print` — нет:

```cpp
#include <print>

int main() {
    int done = 3, total = 5;
    std::print("Готово {} из {}", done, total);
    std::print("...");
    std::println(" осталось {}", total - done);
    std::println("{} + {} = {}", 2, 3, 2 + 3);
    std::println(stderr, "предупреждение: {}", "мало места");
    return 0;
}
```

Вывод:

```text
Готово 3 из 5... осталось 2
2 + 3 = 5
```

Если первым аргументом передать `stderr`, текст уйдёт в поток ошибок — поэтому последней строки нет среди вывода программы. `std::println()` без аргументов печатает пустую строку.

## Спецификация формата

Внутри фигурных скобок после двоеточия можно указать, **как** печатать значение. Общий вид: `{:заполнитель выравнивание знак # 0 ширина .точность тип}` — все части необязательны.

| Запись    | Что означает                               | `42` или `3.14159` превращается в |
| --------- | ------------------------------------------ | --------------------------------- |
| `{:>6}`   | ширина 6, выравнивание вправо              | `    42`                          |
| `{:<6}`   | ширина 6, выравнивание влево               | `42    `                          |
| `{:^6}`   | ширина 6, по центру                        | `  42  `                          |
| `{:*^6}`  | по центру, заполнитель `*`                 | `**42**`                          |
| `{:06}`   | ширина 6, ведущие нули                     | `000042`                          |
| `{:+}`    | всегда печатать знак                       | `+42`                             |
| `{:x}`    | шестнадцатеричная запись (`X` — заглавные) | `2a`                              |
| `{:#x}`   | с префиксом                                | `0x2a`                            |
| `{:b}`    | двоичная запись                            | `101010`                          |
| `{:.2f}`  | фиксированная точка, 2 знака после точки   | `3.14`                            |
| `{:8.3f}` | ширина 8, 3 знака после точки              | `   3.142`                        |
| `{:e}`    | экспоненциальная запись                    | `3.141590e+00`                    |

Числа по умолчанию выравниваются вправо, строки — влево. Спецификация действует **только на своё значение** — никакого «залипания», как у манипуляторов потока:

```cpp
#include <print>

int main() {
    std::println("[{:>6}] [{:<6}] [{:^6}] [{:*^7}]", 42, 42, 42, "ok");
    std::println("[{:06}] [{:+}] [{:+}]", -42, 7, -7);
    std::println("{:x} {:#x} {:X} {:b} {:#o} {:08b}", 255, 255, 255, 5, 8, 5);
    std::println("{:.2f} {:8.3f} {:e}", 3.14159, 2.0 / 3, 12345.678);
    return 0;
}
```

Вывод:

```text
[    42] [42    ] [  42  ] [**ok***]
[-00042] [+7] [-7]
ff 0xff FF 101 010 00000101
3.14    0.667 1.234568e+04
```

Если центрирование невозможно поровну, лишний заполнитель уходит вправо: `**ok***`. Ведущие нули ставятся после знака: `-00042`.

## Дробные числа без сюрпризов

Пустые скобки `{}` печатают дробное число **кратчайшей записью, по которой его можно восстановить точно**. Не нужно гадать с `setprecision`:

```cpp
#include <print>

int main() {
    std::println("{} {} {}", 0.1, 100.0, 1.0 / 3);
    std::println("{} {}", 0.1 + 0.2, 2.5e-8);
    std::println("{:.2f} {:.0f} {:.3e}", 2.0 / 3, 2.5, 123456.0);
    return 0;
}
```

Вывод:

```text
0.1 100 0.3333333333333333
0.30000000000000004 2.5e-08
0.67 2 1.235e+05
```

Обратите внимание на `{:.0f}` для `2.5`: результат `2`, а не `3`. Как и `printf`, `std::format` округляет «до чётного», когда число ровно посередине. А `0.1 + 0.2` честно показывает, что сумма не равна `0.3`, — та самая погрешность из урока о `double`.

## Номера аргументов и фигурные скобки

В скобках можно указать **номер** аргумента, начиная с нуля. Так одно значение можно напечатать несколько раз или поменять порядок. Ширину можно взять из аргумента — вложенными скобками. А чтобы напечатать саму фигурную скобку, её удваивают:

```cpp
#include <print>

int main() {
    std::println("{0} в шестнадцатеричной: {0:#x}, в двоичной: {0:#b}", 10);
    std::println("{1} {0} {1}", "мир", "привет");
    int width = 8;
    std::println("[{:>{}}]", 3.5, width);
    std::println("{{}} — это пара скобок, а {} — значение", 7);
    return 0;
}
```

Вывод:

```text
10 в шестнадцатеричной: 0xa, в двоичной: 0b1010
привет мир привет
[     3.5]
{} — это пара скобок, а 7 — значение
```

Номера и пустые скобки в одном шаблоне смешивать нельзя: либо `{} {}`, либо `{0} {1}`.

## Ширина и русские буквы

У потоков есть неприятность, которую сразу замечают русскоязычные программисты. `std::setw` считает ширину в **байтах**, а русская буква в UTF-8 — два байта. Поэтому таблица с кириллицей «разъезжается». `std::format` считает ширину в символах:

```cpp
#include <format>
#include <iomanip>
#include <iostream>
#include <print>

int main() {
    std::cout << '[' << std::setw(8) << "кот" << "]\n";
    std::println("[{:>8}]", "кот");
    std::println("[{:<10}|{:>7.2f}]", "яблоки", 12.5);
    std::println("[{:<10}|{:>7.2f}]", "kiwi", 3.0);
    return 0;
}
```

Вывод:

```text
[  кот]
[     кот]
[яблоки    |  12.50]
[kiwi      |   3.00]
```

`setw(8)` увидел шесть байтов и добавил всего два пробела. `std::format` выровнял слово по-настоящему, и столбцы русских и латинских названий совпали.

## Ошибки — при компиляции

Строка формата проверяется компилятором. Сравните с `printf`, где ошибка в формате — неопределённое поведение во время работы:

```cpp
#include <print>

int main() {
    int apples = 5;
    std::println("яблок: {}, груш: {}", apples);   // Ошибка компиляции: аргументов меньше, чем {}
    return 0;
}
```

Сообщение GCC длинное, но главное в нём — `call to consteval function ... is not a constant expression`: проверка шаблона не прошла. Так же не соберётся `std::println("{:d}", "текст")` — спецификатор `d` не подходит строке.

Из этого следует правило: шаблон должен быть **известен при компиляции** — строковый литерал. `std::println(text)`, где `text` — переменная, не скомпилируется. Чтобы напечатать строку из переменной, пишите `std::println("{}", text)`.

## `char`, `bool` и байты

Правила для разных типов продуманы лучше, чем у потоков:

```cpp
#include <cstdint>
#include <iostream>
#include <print>

int main() {
    std::uint8_t level = 65;
    char letter = 'A';
    bool ready = true;
    std::cout << level << ' ' << ready << '\n';
    std::println("{} {} {:d} {} {:d}", level, letter, letter, ready, ready);
    return 0;
}
```

Вывод:

```text
A 1
65 A 65 true 1
```

`std::uint8_t` — это `unsigned char`, и `std::cout` печатает его как символ: ловушка из урока о выводе. `std::format` печатает его как число — символом считается только `char`. Код символа даёт `{:d}`. `bool` печатается словами `true`/`false`, а `{:d}` превращает его в `1`/`0`.

## Что выбирать

| Задача                                      | Инструмент                   |
| ------------------------------------------- | ---------------------------- |
| напечатать результат в новом коде на C++23  | `std::println`, `std::print` |
| собрать строку, сохранить, передать дальше  | `std::format`                |
| вывод в существующем коде, свои типы с `<<` | `std::cout`                  |
| код на C                                    | `printf`                     |

`std::cout` никуда не денется: им написаны миллионы строк кода, а печать собственных типов через `operator<<` вы встретите в модуле об ООП. Но для новых программ `std::println` проще и надёжнее. В курсе вы будете встречать оба способа.

<Tip title="Контейнеры и версии компиляторов">

C++23 разрешает печатать контейнеры целиком: `std::println("{}", v)` для `std::vector<int>` даёт `[1, 2, 3]`. Эту часть стандарта поддерживают GCC 15 и новее; в GCC 14 из песочницы курса такая строка не скомпилируется — элементы печатают циклом.

</Tip>

<Concept title="std::format и std::print">

`std::format("шаблон", аргументы…)` возвращает `std::string`, `std::print` и `std::println` печатают сразу. `{}` подставляет очередной аргумент, `{0}` — аргумент по номеру, после двоеточия — спецификация: заполнитель, выравнивание `<` `>` `^`, знак, ширина, точность и тип (`d`, `x`, `b`, `o`, `f`, `e`). Шаблон проверяется при компиляции, ширина считается в символах, спецификация действует только на своё значение.

</Concept>

## Частые ошибки

<CommonMistake title="{:.2} вместо {:.2f}">

`std::println("{:.2}", 12.345)` печатает `12`, а не `12.35`: без буквы `f` точность означает число **значащих цифр**, как у `%g`. Для «двух знаков после точки» нужна `{:.2f}`.

</CommonMistake>

<CommonMistake title="Переменная вместо шаблона">

`std::println(message);` не компилируется: шаблон должен быть литералом. Пишите `std::println("{}", message);`. Это не каприз: если бы шаблон брался из данных, фигурные скобки внутри них ломали бы вывод.

</CommonMistake>

<CommonMistake title="Склейка строки с числом">

`std::println("Итого: " + total);` — не склейка, а арифметика указателя: `"Итого: " + 5` — адрес шестого байта строки. С `std::println` это ошибка компиляции, а с `std::cout << "Итого: " + total` — тихий вывод обрывка строки. Число подставляют через `{}`.

</CommonMistake>

<CommonMistake title="Одна фигурная скобка в тексте">

`std::println("множество {1, 2}");` — компилятор попытается разобрать `{1, 2}` как место для аргумента и выдаст ошибку. Скобки в тексте удваивают: `"множество {{1, 2}}"`.

</CommonMistake>

## Итоги

- `std::format` (C++20) возвращает строку по шаблону, `std::print` и `std::println` (C++23) печатают сразу; `println` добавляет `\n`, первым аргументом можно передать `stderr`.
- `{}` — очередной аргумент, `{0}` — по номеру, `{{` и `}}` — сами скобки.
- Спецификация после двоеточия: заполнитель и выравнивание `<` `>` `^`, знак `+`, `#`, ведущие `0`, ширина, `.точность`, тип `d` `x` `X` `b` `o` `f` `e`. Ширина может прийти из аргумента: `{:>{}}`.
- `{}` для дробного — кратчайшая точная запись; `{:.2f}` — два знака после точки, `{:.2}` — две значащие цифры.
- Шаблон — литерал, его проверяет компилятор: лишние или неподходящие аргументы — ошибка компиляции.
- Ширина считается в символах, поэтому кириллица выравнивается правильно; `uint8_t` печатается числом, `bool` — словом.
