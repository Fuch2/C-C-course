## Множество уникальных значений

Иногда значения не нужно ни с чем связывать — важно лишь, **есть ли** значение и какие значения различны: посещённые вершины графа, уникальные слова текста, занятые места. Для этого есть **множество** `std::set<T>` из `<set>` — словарь, у которого есть только ключи:

```cpp
#include <iostream>
#include <set>

int main() {
    std::set<int> s = {5, 1, 4, 1, 5, 9};
    auto [it, added] = s.insert(4);              // 4 уже есть
    s.insert(2);
    std::cout << added << ' ' << s.size() << ' ' << s.contains(9) << ' ' << s.count(7) << '\n';
    s.erase(1);
    for (int x : s) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
    std::cout << *s.begin() << ' ' << *s.rbegin() << '\n';
    return 0;
}
```

Вывод:

```text
0 5 1 0
2 4 5 9
2 9
```

Свойства `std::set`:

- каждое значение хранится **один раз** — повторная вставка ничего не делает, а `insert` сообщает об этом вторым элементом возвращаемой пары;
- значения **упорядочены**: обход выдаёт их по возрастанию, `*begin()` — минимум, `*rbegin()` — максимум;
- внутри — то же сбалансированное дерево поиска, что у `std::map`: вставка, удаление и поиск за `O(log n)`;
- элементы менять нельзя (они — ключи дерева): чтобы «изменить» значение, его удаляют и вставляют новое.

## Поиск ближайших значений

Как и у `std::map`, у множества есть `lower_bound` и `upper_bound`. Они отвечают на вопросы «наименьшее значение не меньше `x`» и «наибольшее значение меньше `x`» за `O(log n)` — даже когда множество меняется между запросами:

```cpp
#include <iostream>
#include <iterator>
#include <set>

int main() {
    std::set<int> seats = {3, 8, 15, 21};                  // занятые места
    int wanted = 10;
    auto after = seats.lower_bound(wanted);                 // первое ≥ 10
    std::cout << "ближайшее справа: " << *after << '\n';
    if (after != seats.begin()) {
        std::cout << "ближайшее слева: " << *std::prev(after) << '\n';
    }
    seats.insert(10);
    std::cout << *seats.upper_bound(8) << '\n';
    return 0;
}
```

Вывод:

```text
ближайшее справа: 15
ближайшее слева: 8
10
```

`std::prev(it)` — итератор на предыдущий элемент (то же, что `--it`, но без изменения `it`). Отсортированный массив отвечает на такие запросы двоичным поиском, но вставка в него — `O(n)`; у множества и вставка, и запрос — `O(log n)`.

## multiset: повторы разрешены

`std::multiset<T>` — упорядоченное множество, в котором значение может встречаться несколько раз. Это удобно, например, для набора цен или оценок, где важны и порядок, и количество:

```cpp
#include <iostream>
#include <set>

int main() {
    std::multiset<int> prices = {100, 50, 100, 70, 100};
    std::cout << prices.size() << ' ' << prices.count(100) << '\n';
    prices.erase(prices.find(100));                // удалить ОДНУ сотню
    std::cout << prices.count(100) << '\n';
    prices.erase(100);                             // удалить ВСЕ сотни
    for (int p : prices) {
        std::cout << p << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

Вывод:

```text
5 3
2
50 70
```

Ловушка `multiset`: `erase(значение)` удаляет **все** копии значения. Чтобы удалить одну, удаляют по итератору: `erase(find(значение))` — предварительно проверив, что `find` не вернул `end()`.

## unordered_set

Если порядок не нужен, есть хеш-множество `std::unordered_set<T>` из `<unordered_set>`: `insert`, `contains`, `erase` за `O(1)` в среднем, порядок обхода не определён — всё как у `std::unordered_map`.

```cpp
#include <iostream>
#include <string>
#include <unordered_set>

int main() {
    std::unordered_set<std::string> seen;
    for (const char *w : {"red", "green", "red", "blue", "green"}) {
        if (!seen.insert(w).second) {
            std::cout << "повтор: " << w << '\n';
        }
    }
    std::cout << seen.size() << '\n';
    return 0;
}
```

Вывод:

```text
повтор: red
повтор: green
3
```

`insert(…).second` — признак, что значение было новым: проверка и вставка за одну операцию.

## Операции над множествами

Пересечение, объединение и разность упорядоченных наборов вычисляются алгоритмами из `<algorithm>` за один проход — тем же слиянием, что в сортировке слиянием:

```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <set>
#include <vector>

int main() {
    std::set<int> a = {1, 2, 3, 4, 5}, b = {4, 5, 6, 7};
    std::vector<int> both, only_a;
    std::set_intersection(a.begin(), a.end(), b.begin(), b.end(), std::back_inserter(both));
    std::set_difference(a.begin(), a.end(), b.begin(), b.end(), std::back_inserter(only_a));
    for (int x : both) std::cout << x << ' ';
    std::cout << "| ";
    for (int x : only_a) std::cout << x << ' ';
    std::cout << '\n';
    return 0;
}
```

Вывод:

```text
4 5 | 1 2 3
```

`std::back_inserter(v)` — «итератор вывода», который каждое записанное значение добавляет в конец вектора через `push_back`. Эти алгоритмы работают с любыми **отсортированными** диапазонами — в том числе с отсортированными векторами.

<Concept title="Множества">

`std::set` хранит уникальные значения упорядоченно на дереве поиска: `insert`, `erase`, `contains` за `O(log n)`, обход по возрастанию, `lower_bound`/`upper_bound` для ближайших значений. `std::multiset` разрешает повторы; `erase(значение)` удаляет все копии, `erase(итератор)` — одну. `std::unordered_set` — хеш-множество без порядка за `O(1)` в среднем. Пересечение и разность отсортированных наборов — `std::set_intersection` и `std::set_difference`.

</Concept>

## Частые ошибки

<CommonMistake title="erase по значению в multiset">

`ms.erase(100)` удаляет все сотни. Если нужно удалить одну — `auto it = ms.find(100); if (it != ms.end()) ms.erase(it);`.

</CommonMistake>

<CommonMistake title="Изменение элемента множества">

`*s.begin() = 10;` не компилируется: элементы множества константные, ведь от них зависит порядок дерева. Удалите старое значение и вставьте новое.

</CommonMistake>

<CommonMistake title="set_intersection для неотсортированных данных">

Алгоритмы операций над множествами предполагают отсортированные диапазоны. Для неотсортированного вектора результат будет неверным — сначала `std::sort`.

</CommonMistake>

## Итоги

- `std::set` — упорядоченное множество уникальных значений, операции `O(log n)`.
- `insert` возвращает пару: итератор и признак вставки; повтор не добавляется.
- `lower_bound` и `upper_bound` находят ближайшие значения; `begin()` и `rbegin()` — минимум и максимум.
- `std::multiset` разрешает повторы: `erase(значение)` удаляет все, `erase(find(значение))` — одно.
- `std::unordered_set` — хеш-множество без порядка, `O(1)` в среднем.
- Операции над множествами — `std::set_intersection`, `std::set_difference`, `std::set_union` на отсортированных диапазонах.
