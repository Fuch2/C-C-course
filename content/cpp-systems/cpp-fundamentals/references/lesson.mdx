## Теория

Ссылка — обязательный псевдоним существующего объекта. Она выражает заимствование яснее указателя, но не может быть пустой и не продлевает время жизни.

## Пошаговый разбор

На небольшом примере проследите вход, изменение состояния объекта и результат. Для контейнера отметьте размер, вместимость и порядок элементов.

## Зачем инструмент нужен

Ссылка — обязательный псевдоним существующего объекта. Она выражает заимствование яснее указателя, но не может быть пустой и не продлевает время жизни.

## Пример C++20

```cpp
#include <iostream>

void calibrate(int& value, int offset) { value += offset; }
int main() {
    int measurement = 10;
    calibrate(measurement, 2);
    std::cout << measurement << '\n';
}

```

Ожидаемый вывод:

```text
12

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте Ссылки как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Практика

Ввод: value и offset, целые −1000…1000. Создайте calibrate(int&amp; value, int offset), прибавляющую offset к исходной переменной. Вызовите дважды и выведите значение после каждого вызова через пробел. Не возвращайте новое значение вместо изменения аргумента.

## Краткое резюме

Инструмент Ссылки выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
