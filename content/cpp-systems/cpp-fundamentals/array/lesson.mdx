## Чем неудобен массив C

Массив C фиксированного размера быстрый и простой, но у него есть неприятные свойства:

- переданный в функцию, он **превращается в указатель** и теряет размер — `sizeof(a)` внутри функции вернёт размер указателя;
- его нельзя присвоить другому массиву (`a = b` — ошибка) и нельзя сравнить (`a == b` сравнивает адреса);
- индекс не проверяется.

`std::array<T, N>` из `<array>` — массив фиксированного размера, у которого этих недостатков нет. Он хранит элементы прямо внутри себя, как массив C, — без кучи и без накладных расходов, — но ведёт себя как нормальный объект.

## Основы

```cpp
#include <array>
#include <iostream>

int main() {
    std::array<int, 5> a = {3, 1, 4, 1, 5};
    std::array<int, 5> b = a;               // копия всех элементов
    b[0] = 9;
    std::cout << a[0] << ' ' << b[0] << ' ' << a.size() << '\n';
    std::cout << (a == b) << ' ' << (a < b) << '\n';
    std::array<int, 3> zeros{};              // все элементы — 0
    zeros.fill(7);
    for (int x : zeros) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

Вывод:

```text
3 9 5
0 1
7 7 7
```

Размер — часть **типа**: `std::array<int, 5>` и `std::array<int, 3>` — разные типы. Присваивание копирует все элементы, `==` и `<` сравнивают содержимое (лексикографически, как строки). Пустые фигурные скобки `{}` обнуляют все элементы; без инициализатора элементы-числа, как и в C, содержат мусор.

## Размер не теряется

Главное преимущество — `std::array` можно передать в функцию, и размер останется известен:

```cpp
#include <array>
#include <iostream>

double average(const std::array<int, 4> &values) {
    int sum = 0;
    for (int x : values) {
        sum += x;
    }
    return static_cast<double>(sum) / values.size();
}

int main() {
    std::array<int, 4> scores = {90, 85, 70, 95};
    std::cout << average(scores) << '\n';
    return 0;
}
```

Вывод:

```text
85
```

Сравните с C, где пришлось бы передавать размер отдельным параметром — и следить, чтобы он совпадал с настоящим. Если функция должна принимать массивы разных размеров, её делают шаблоном: `template <std::size_t N> double average(const std::array<int, N> &values)` — компилятор выведет `N` сам. А если она должна работать и с `std::array`, и с `std::vector`, и с массивом C, параметр делают `std::span` — о нём урок после следующего.

## Всё, что умеет контейнер

У `std::array` те же удобства, что у `std::vector`, кроме изменения размера: `size()`, `at()` с проверкой индекса, `front()`, `back()`, итераторы `begin()`/`end()`, работа с алгоритмами.

```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <numeric>

int main() {
    std::array<int, 6> data = {42, 7, 19, 3, 25, 11};
    std::sort(data.begin(), data.end());
    std::cout << data.front() << ' ' << data.back() << ' '
              << std::accumulate(data.begin(), data.end(), 0) << '\n';
    auto it = std::find(data.begin(), data.end(), 19);
    std::cout << (it - data.begin()) << '\n';
    return 0;
}
```

Вывод:

```text
3 42 107
3
```

## Таблицы заранее известного размера

`std::array` хорош там, где размер — свойство задачи, а не данных: 12 месяцев, 7 дней недели, 10 цифр, доска 8 × 8. Двумерная таблица — массив массивов, и вся она лежит одним блоком памяти:

```cpp
#include <array>
#include <iostream>

int main() {
    const std::array<int, 12> days = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    int total = 0;
    for (int d : days) {
        total += d;
    }
    std::cout << days[1] << ' ' << total << '\n';

    std::array<std::array<char, 3>, 3> board{};
    for (auto &row : board) {
        row.fill('.');
    }
    board[1][1] = 'X';
    for (const auto &row : board) {
        for (char c : row) {
            std::cout << c;
        }
        std::cout << '\n';
    }
    return 0;
}
```

Вывод:

```text
28 365
...
.X.
...
```

## array или vector

|              | `std::array<T, N>`                                      | `std::vector<T>`                            |
| ------------ | ------------------------------------------------------- | ------------------------------------------- |
| размер       | фиксирован при компиляции                               | меняется во время работы                    |
| память       | внутри объекта (например, на стеке)                     | в куче                                      |
| копирование  | все `N` элементов                                       | все элементы + выделение памяти             |
| подходит для | таблиц известного размера, координат, маленьких буферов | данных, количество которых зависит от входа |

Если размер известен заранее и невелик — `std::array`. Если зависит от входа или большой — `std::vector`: большой `std::array` на стеке может его переполнить.

<Concept title="std::array">

Массив фиксированного размера с интерфейсом контейнера: размер — часть типа и не теряется при передаче в функцию, присваивание копирует элементы, `==` и `<` сравнивают содержимое, есть `size()`, `at()`, итераторы и алгоритмы. Элементы хранятся внутри объекта, без кучи. Для данных переменного размера — `std::vector`.

</Concept>

## Частые ошибки

<CommonMistake title="sizeof массива-параметра">

```c
double average(int values[]) {
    int n = sizeof(values) / sizeof(values[0]);   // размер указателя, а не массива
    ...
}
```

Параметр `int values[]` — на самом деле `int *`. `sizeof(values)` равен 8 на 64-битной системе, и `n` окажется 2 при любом массиве. GCC предупреждает об этом (`-Wsizeof-array-argument`). С `std::array` размер всегда доступен через `size()`.

</CommonMistake>

<CommonMistake title="Мусор без инициализации">

`std::array<int, 5> a;` содержит неопределённые значения, как массив C. Пишите `std::array<int, 5> a{};`, чтобы получить нули.

</CommonMistake>

<CommonMistake title="Огромный array на стеке">

`std::array<int, 10'000'000> big;` внутри функции — 40 МБ на стеке, который обычно меньше 8 МБ. Программа упадёт при запуске. Большие массивы — в `std::vector`.

</CommonMistake>

## Практика

1. **Дни в месяце** — таблица на `std::array`.
2. **Частоты цифр** — счётчики в массиве.
3. **Найди ошибку: среднее значение** — массив, превратившийся в указатель.
4. **Крестики-нолики** — двумерный `std::array`.

## Итоги

- `std::array<T, N>` — массив фиксированного размера с интерфейсом контейнера.
- Размер — часть типа, он не теряется при передаче в функцию.
- Присваивание копирует элементы, `==` и `<` сравнивают содержимое.
- `{}` обнуляет элементы; без инициализации — мусор.
- Элементы хранятся внутри объекта, без кучи; большие массивы — в `std::vector`.
