## Теория

array хранит фиксированный размер в объекте и совместим с алгоритмами. Он не умеет расти, зато не делает heap-аллокаций сам по себе.

</Concept>

На небольшом примере проследите вход, изменение состояния объекта и результат. Для контейнера отметьте размер, вместимость и порядок элементов.

## Зачем инструмент нужен

array хранит фиксированный размер в объекте и совместим с алгоритмами. Он не умеет расти, зато не делает heap-аллокаций сам по себе.

## Пример C++20

```cpp
#include <iostream>
#include <array>
#include <algorithm>


int main() {
    std::array<int,4> a{1,2,3,4}; std::rotate(a.begin(),a.begin()+1,a.end()); for(int x:a)std::cout<<x<<' '; std::cout<<'\n';
}

```

Ожидаемый вывод:

```text
2 3 4 1

```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте std::array как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Краткое резюме

Инструмент std::array выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
