## Теория

Строка C++ владеет буфером и знает размер, в отличие от char\* с sentinel\0. Это снижает риск выхода за границы, но копирование всё ещё стоит O(n).

## Зачем инструмент нужен

Строка C++ владеет буфером и знает размер, в отличие от char\* с sentinel\0. Это снижает риск выхода за границы, но копирование всё ещё стоит O(n).

## Пример C++20

```cpp
#include <iostream>
#include <string>

void split_command(const std::string& text) {
    std::size_t count = 1;
    for (char ch : text) if (ch == ';') ++count;
    std::cout << count << '\n';
    std::size_t start = 0;
    while (true) {
        const auto end = text.find(';', start);
        std::cout << text.substr(start, end == std::string::npos ? end : end - start) << '\n';
        if (end == std::string::npos) break;
        start = end + 1;
    }
}
int main() {
    split_command("a;;b;");
}

```

Ожидаемый вывод:

```text
4
a

b


```

## Стоимость и ограничения

| Аспект     | Разбор                                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Время      | Стоимость определяется размером данных и выбранной операцией; фиксированные операции O(1), обходы O(n), дерево map/set O(log n) в среднем по высоте. |
| Память     | Объекты хранят состояние явно; контейнеры могут выделять память и инвалидировать ссылки при росте.                                                   |
| Компромисс | Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.                       |

## Сравнение с C

Используйте std::string как стандартный компонент, когда его контракт совпадает с задачей. Проверяйте invalidation, порядок и исключения. Аналог C может дать больше ручного контроля, но требует самостоятельно поддерживать размеры, ошибки и время жизни. В C++ используйте абстракцию по её контракту, а не копируйте C-код в новом синтаксисе.

<CommonMistake title="Типичная ошибка">

Не переносите привычный C-подход автоматически: сначала определите владение, инвариант и стоимость операции.

</CommonMistake>

## Краткое резюме

Инструмент std::string выражает намерение программы через типы и границы владения. Безопасность и выразительность типов уменьшают ручную работу, но добавляют правила времени жизни и иногда стоимость аллокаций.
