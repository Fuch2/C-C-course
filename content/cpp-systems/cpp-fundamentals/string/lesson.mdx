## Строка, которая помнит свою длину

Строка в C — массив `char` с нулевым байтом в конце. Длину узнают `strlen` (проходом по строке), копируют `strcpy` в заранее выделенный буфер, сравнивают `strcmp`, а ошибка в размере буфера — переполнение и уязвимость. `std::string` из заголовка `<string>` — это строка, которая сама хранит длину и сама управляет памятью:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Hello";
    s += ", ";                           // дописать
    s += "world";
    s.push_back('!');                    // один символ
    std::cout << s << " — " << s.size() << " символов\n";
    std::cout << s[0] << s[s.size() - 1] << '\n';
    s[0] = 'J';
    std::cout << s << '\n';
    return 0;
}
```

Вывод:

```text
Hello, world! — 13 символов
H!
Jello, world!
```

`size()` (или `length()`) возвращает длину за `O(1)` — она хранится, а не вычисляется. `+=` и `push_back` дописывают в конец, при необходимости увеличивая буфер, как динамический массив. `s[i]` даёт доступ к символу — и для чтения, и для записи.

## Сравнение и склеивание

```cpp
#include <iostream>
#include <string>

int main() {
    std::string a = "apple", b = "banana";
    std::string c = a + " & " + b;
    std::cout << c << '\n';
    std::cout << std::boolalpha << (a == "apple") << ' ' << (a < b) << ' ' << (a > "Apple") << '\n';
    std::cout << (a.compare(b) < 0) << ' ' << a.compare("apple") << '\n';
    return 0;
}
```

Вывод:

```text
apple & banana
true true true
true 0
```

Операторы `==`, `!=`, `<`, `>` сравнивают **содержимое** строк лексикографически, по кодам символов — как `strcmp`, только без вызова функции. Поэтому `"apple" > "Apple"`: строчная `a` имеет больший код, чем заглавная `A`. Метод `compare` возвращает отрицательное число, ноль или положительное — точно как `strcmp`.

Склеивать можно строку со строкой, строку с литералом и строку с символом. Но не два литерала: `"a" + "b"` — это сложение двух указателей `const char *`, и компилятор его не допустит.

## Поиск и подстроки

```cpp
#include <iostream>
#include <string>

int main() {
    std::string path = "/home/ada/notes/today.txt";
    std::size_t slash = path.rfind('/');                 // последний '/'
    std::size_t dot = path.find('.');
    std::string file = path.substr(slash + 1);           // от позиции до конца
    std::string ext = path.substr(dot + 1, 3);           // позиция и длина
    std::cout << file << ' ' << ext << '\n';
    std::cout << path.find("ada") << ' ' << (path.find("bob") == std::string::npos) << '\n';
    return 0;
}
```

Вывод:

```text
today.txt txt
6 1
```

- `find(x)` ищет символ или подстроку и возвращает позицию первого вхождения, `rfind` — последнего; можно передать позицию, с которой начинать поиск: `find(x, from)`.
- Если ничего не найдено, возвращается специальное значение **`std::string::npos`** — самое большое значение типа `std::size_t`. Его обязательно проверяют, прежде чем использовать позицию.
- `substr(pos, len)` возвращает новую строку из `len` символов начиная с `pos`; без `len` — до конца.
- Для частых вопросов есть готовые проверки без позиций: `s.starts_with("http")` и `s.ends_with(".txt")` (C++20), `s.contains("ошибка")` (C++23). Подробнее — в уроке о `std::string_view`, где вы узнаете и как получать подстроки без копирования.

## Изменение строки

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "I like C";
    s.insert(7, "modern ");             // вставить перед позицией 7
    std::cout << s << '\n';
    s.replace(s.find("C"), 1, "C++");   // заменить 1 символ с найденной позиции
    std::cout << s << '\n';
    s.erase(0, 2);                       // удалить 2 символа с начала
    std::cout << s << '\n';
    std::cout << s.empty() << ' ';
    s.clear();
    std::cout << s.empty() << '\n';
    return 0;
}
```

Вывод:

```text
I like modern C
I like modern C++
like modern C++
0 1
```

Все эти операции сдвигают символы после места изменения, поэтому стоят `O(n)`, как вставка в середину массива.

## Числа и строки

```cpp
#include <iostream>
#include <string>

int main() {
    int year = 1985;
    std::string title = "C++ появился в " + std::to_string(year) + " году";
    std::cout << title << '\n';
    int n = std::stoi("42");
    double x = std::stod("2.5");
    std::cout << n * x << '\n';
    return 0;
}
```

Вывод:

```text
C++ появился в 1985 году
105
```

`std::to_string` превращает число в строку, `std::stoi`, `std::stol`, `std::stoll` и `std::stod` — строку в число. Если строку нельзя разобрать, `stoi` сообщает об ошибке **исключением** — об этом механизме будет отдельный урок.

## Безопасный доступ и связь с C

`s[i]` не проверяет индекс — как и массив в C, выход за границы — неопределённое поведение. Метод `s.at(i)` делает то же, но проверяет индекс и при ошибке бросает исключение `std::out_of_range` вместо порчи памяти.

Функции C принимают `const char *`. Получить такой указатель из строки позволяет `s.c_str()`: он указывает на внутренний буфер, который всегда завершён нулём. Указатель действителен, пока строка существует и не изменяется: после `+=` буфер может переехать, как у динамического массива.

```cpp
#include <cstdio>
#include <string>

int main() {
    std::string name = "Ada";
    std::printf("%s, %zu\n", name.c_str(), name.size());
    return 0;
}
```

Вывод:

```text
Ada, 3
```

## Стоимость

Строка владеет своими символами, поэтому **копирование строки копирует все символы** — `O(n)`. `std::string b = a;` создаёт независимую копию: изменение `b` не затронет `a`. Передавать строку в функцию по значению — значит копировать её при каждом вызове. Как этого избежать, — в уроке о константных ссылках.

Короткие строки (обычно до 15 символов) реализации хранят прямо внутри объекта, без выделения памяти в куче, — это называют оптимизацией коротких строк. Длинные строки выделяют буфер в куче.

## Частые ошибки

<CommonMistake title="Не проверить npos">

```cpp
std::size_t eq = line.find('=');
std::string value = line.substr(eq + 1);   // при eq == npos это substr(0)
```

`npos + 1` переполняется в 0, и «значение» оказывается всей строкой. Всегда сравнивайте результат `find` с `std::string::npos`.

</CommonMistake>

<CommonMistake title="Позиция в int">

`int pos = s.find(x);` превращает `npos` в −1 или другое неожиданное число. Храните позиции в `std::size_t`.

</CommonMistake>

<CommonMistake title="Склеивание двух литералов">

`std::string s = "Hello, " + "world";` не компилируется — это два указателя. Нужен хотя бы один `std::string`: `std::string("Hello, ") + "world"`.

</CommonMistake>

## Итоги

- `std::string` хранит длину (`size()` за `O(1)`) и сам управляет памятью.
- `==`, `<` сравнивают содержимое; `+` и `+=` склеивают; два литерала склеить нельзя.
- `find` возвращает позицию или `std::string::npos` — проверяйте; позиции храните в `std::size_t`. `starts_with`, `ends_with`, `contains` проверяют начало, конец и вхождение.
- `substr`, `insert`, `replace`, `erase` — подстроки и изменения за `O(n)`.
- `std::to_string` и `std::stoi` переводят между числами и строками.
- `s.at(i)` проверяет индекс; `c_str()` — указатель для функций C.
- Копирование строки копирует символы.
