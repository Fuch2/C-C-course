## Теория и инвариант

Разделяем диапазон пополам, сортируем половины и сливаем два упорядоченных потока. На каждом шаге слияния выбирается меньший из первых ещё не использованных элементов. Если левый и правый ключ равны, берём левый: так сохраняется стабильность. После исчерпания половины переносим остаток другой.

На каждом уровне рекурсии суммарно обрабатывается n элементов, уровней порядка log n. Один общий временный буфер выделяется до рекурсивных вызовов и переиспользуется; выделение нового буфера на каждом узле усложняет cleanup. Если память получить не удалось, функция сообщает отказ, не начиная сортировку.

## Пошаговый разбор

[4,1,3,2] → [1,4] и [2,3] → 1,2,3,4. При равенстве левый поток имеет приоритет.

## Реализация и запускаемый пример на C17

Пример не требует stdin. Сначала предскажите результат; затем выполните код и измените данные. Функции демонстрируют алгоритм, а практика ниже требует самостоятельного ввода и обработки граничных состояний.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <limits.h>

static void merge_range(int *a,int *temp,int left,int right){
    if(right-left<2) return;
    int middle=left+(right-left)/2;
    merge_range(a,temp,left,middle);merge_range(a,temp,middle,right);
    int i=left,j=middle,k=left;
    while(i<middle && j<right) temp[k++]=a[i]<=a[j]?a[i++]:a[j++];
    while(i<middle) temp[k++]=a[i++];
    while(j<right) temp[k++]=a[j++];
    for(i=left;i<right;++i) a[i]=temp[i];
}
static int sort(int *a,int n){
    if(n<2)return 1;
    int *temp=malloc((size_t)n*sizeof *temp);
    if(!temp)return 0;
    merge_range(a,temp,0,n);free(temp);return 1;
}
int main(void) {
int a[]={4,1,3,2};int n=4;if(!sort(a,n))return 1;for(int i=0;i<n;++i) printf("%s%d", i?" ":"",a[i]); puts("");
return 0;
}
```

Ожидаемый вывод:

```text
1 2 3 4
```

## Почему реализация корректна

Разделение [4,1,3,2] даёт две половины, после рекурсивной сортировки — [1,4] и [2,3]. Слияние сравнивает головы: берёт 1, затем 2, затем 3, после исчерпания правой половины переносит 4. Индексы двух входов только растут; повторного поиска места для каждого элемента нет.

Если слева и справа равные ключи, выбор левого через &lt;= сохраняет исходный порядок равных записей. Один общий временный буфер выделяется до рекурсии и освобождается после неё. У каждого уровня суммарно O(n) работы, уровней O(log n), отсюда O(n log n). Буфер O(n) и стек O(log n) учитываются отдельно; последовательное слияние хорошо использует кеш, но требует дополнительной записи.
