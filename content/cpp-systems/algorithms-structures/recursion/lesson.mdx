## Теория и инвариант

Рекурсивная функция решает задачу через меньшие экземпляры и базовый случай. Корректность требует двух доказательств: базовый ответ правильный, а разбиение действительно уменьшает задачу. Для суммы полуинтервала пустой диапазон даёт ноль, один элемент — его значение, остальные делятся пополам.

Глубина вызовов и число вызовов — разные величины. Дерево деления суммы имеет O(n) узлов, но O(log n) высоту. Наивный Fibonacci повторно вычисляет одинаковые подзадачи и создаёт экспоненциальную работу. Компилятор C не обязан устранять хвостовую рекурсию. При глубине, зависящей от недоверенного n, нужен предел либо явный стек.

## Пошаговый разбор

sum([2,4,6,8]) = sum([2,4])+sum([6,8]) = (2+4)+(6+8)=20.

## Реализация и запускаемый пример на C17

Пример не требует stdin. Сначала предскажите результат; затем выполните код и измените данные. Функции демонстрируют алгоритм, а практика ниже требует самостоятельного ввода и обработки граничных состояний.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <limits.h>

static int sum_range(const int *a,int left,int right){
    if(left==right)return 0;
    if(right-left==1)return a[left];
    int middle=left+(right-left)/2;
    return sum_range(a,left,middle)+sum_range(a,middle,right);
}
int main(void) {
int a[]={2,4,6,8};printf("%d\n",sum_range(a,0,4));
return 0;
}
```

Ожидаемый вывод:

```text
20
```

## Почему реализация корректна

Вызов для диапазона [0,4) сохраняет свою точку возврата и ждёт суммы [0,2), затем [2,4). Каждый из этих диапазонов делится на единичные. Для [2,4,6,8] листья возвращают 2,4,6,8, внутренние вызовы — 6 и 14, корень — 20. При пустом диапазоне возвращается нейтральное значение 0.

Докажите завершение: длина каждого непустого рекурсивного поддиапазона меньше исходной, а базовый случай обрабатывает длины ноль и один. Общее число вызовов линейно, хотя глубина сбалансированного дерева вызовов логарифмична. Это разные метрики. Рекурсивное суммирование здесь учебное: обычный цикл проще и требует постоянную рабочую память.

## Cache locality и компромиссы

Листовые вызовы обходят соседние значения, но накладные расходы вызовов выше простого цикла.

Рекурсия отражает дерево задачи, цикл проще и экономнее для обычного накопления.

Практическое применение: Деревья, divide-and-conquer и обход вложенных объектов.

<CommonMistake title="Типичная ошибка">

Глубина дерева вызовов не равна общему числу выполненных вызовов.

</CommonMistake>
