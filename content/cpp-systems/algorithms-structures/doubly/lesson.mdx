## Цели обучения

- Объяснить инвариант: Каждый вагон связан с соседом спереди и сзади; нужно поддерживать обе сцепки.
- Обосновать время: Добавление/удаление на концах O(1), поиск O(n).
- Оценить память и компромиссы: Дешёвое удаление известного узла против памяти и медленного случайного доступа.

## Теория и инвариант

У каждого узла есть prev и next, а контейнер хранит head и tail. Для соседних узлов требуется согласованность обеих ссылок. Удаление известного узла не требует искать предшественника: перенастраиваются максимум два соседа. Но пустой список и единственный элемент меняют также концы контейнера.

Обновляйте ссылки до освобождения узла. После удаления последнего элемента и head, и tail должны стать NULL. Для проверки полезно пройти список в обе стороны: ошибка обратной ссылки может не проявиться при прямом выводе. Два указателя на узел увеличивают расход памяти; allocator и padding добавляют ещё. Адреса других узлов обычно остаются действительными, но удалённый итератор недействителен.

## Пошаговый разбор

После L 1 и R 2: NULL ← 1 ⇄ 2 → NULL. Удаление слева оставляет head=tail=узел 2 с двумя NULL-ссылками.

## Реализация и запускаемый пример на C17

Пример не требует stdin. Сначала предскажите результат; затем выполните код и измените данные. Функции демонстрируют алгоритм, а практика ниже требует самостоятельного ввода и обработки граничных состояний.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <limits.h>

typedef struct Node { int value; struct Node *prev,*next; } Node;
typedef struct { Node *head,*tail; } List;
static int push(List *list,int value,int left){
    Node *node=malloc(sizeof *node);if(!node)return 0;
    *node=(Node){value,NULL,NULL};
    if(!list->head)list->head=list->tail=node;
    else if(left){node->next=list->head;list->head->prev=node;list->head=node;}
    else {node->prev=list->tail;list->tail->next=node;list->tail=node;}
    return 1;
}
static int pop(List *list,int left,int *out){
    Node *node=left?list->head:list->tail;if(!node)return 0;
    *out=node->value;
    if(node->prev)node->prev->next=node->next;else list->head=node->next;
    if(node->next)node->next->prev=node->prev;else list->tail=node->prev;
    free(node);return 1;
}
static void destroy(List *list){int value;while(pop(list,1,&value)){} }
int main(void) {
List list={0};if(!push(&list,1,1)||!push(&list,2,0)){destroy(&list);return 1;}int x;pop(&list,1,&x);printf("%d %d\n",x,list.tail->value);destroy(&list);
return 0;
}
```

Ожидаемый вывод:

```text
1 2
```

## Почему реализация корректна

Пустой список имеет head=tail=NULL. При вставке первого узла обе границы указывают на него, его prev и next равны NULL. При добавлении справа связываем старый tail с новым узлом в обоих направлениях и только затем переносим tail. Одна забытая обратная ссылка может оставить прямой обход правильным, а обратный — сломанным.

При удалении последнего узла необходимо обнулить обе границы. В остальных случаях новая голова получает prev=NULL либо новый хвост next=NULL. Поэтому тесты проверяют оба направления и повторную вставку после опустошения. Цена такой симметрии — дополнительный указатель в каждом узле и больше записей при каждой операции.

| Что оцениваем | Гарантия                                             |

| Время         | Добавление/удаление на концах O(1), поиск O(n).      |
| Память        | O(n), два указателя на узел плюс overhead allocator. |

Размеры в учебном коде ограничены ради безопасного запуска. При анализе представляйте масштабируемый вариант той же структуры; фиксированный тестовый предел не превращает любой алгоритм в полезное «O(1)».

## Cache locality и компромиссы

Последовательность логическая, а не физическая: обратные ссылки не делают память непрерывной.

Дешёвое удаление известного узла против памяти и медленного случайного доступа.

Практическое применение: LRU-кеш вместе с хеш-таблицей; список активных событий.

## Связь со STL C++

std::list допускает стабильные итераторы живых узлов; std::sort не работает с его итераторами, нужен list.sort().

Запускаемый вариант C++20:

```cpp
#include <iostream>
#include <list>
int main(){
std::list<int> a{1,2};a.push_front(3);a.pop_back();bool first=true;for(int x:a){std::cout<<(first?"":" ")<<x;first=false;}std::cout<<"\n";
return 0;
}
```

Вывод:

```text
3 1
```
