## Зачем другая структура

Динамический массив хорош почти во всём, кроме одного: вставка и удаление в середине сдвигают все последующие элементы — `O(n)`. **Связный список** (linked list) устроен иначе: каждый элемент хранится в отдельном блоке памяти — **узле** — и знает адрес следующего. Чтобы вставить элемент между двумя узлами, достаточно поменять пару указателей; ничего не сдвигается.

```c
typedef struct Node {
    int value;
    struct Node *next;      // следующий узел или NULL в конце списка
} Node;
```

Список задаётся указателем на первый узел — **голову** (head). Пустой список — `head == NULL`.

```text
head → [3 | •] → [7 | •] → [1 | NULL]
```

Структура ссылается сама на себя, поэтому внутри неё пишут `struct Node *`: имя `Node` из `typedef` ещё не объявлено.

## Создание и обход

Новый узел выделяется `malloc`. Проще всего добавлять в **начало**: новый узел указывает на старую голову и сам становится головой — `O(1)`.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

static Node *push_front(Node *head, int value) {
    Node *node = malloc(sizeof *node);
    if (node == NULL) {
        exit(1);
    }
    node->value = value;
    node->next = head;
    return node;                         // новая голова
}

static void print(const Node *head) {
    for (const Node *p = head; p != NULL; p = p->next) {
        printf("%d ", p->value);
    }
    printf("\n");
}

static void free_list(Node *head) {
    while (head != NULL) {
        Node *next = head->next;         // запомнить до free
        free(head);
        head = next;
    }
}

int main(void) {
    Node *head = NULL;
    for (int i = 1; i <= 4; i++) {
        head = push_front(head, i * 10);
    }
    print(head);
    free_list(head);
    return 0;
}
```

Вывод:

```text
40 30 20 10
```

Цикл `for (p = head; p != NULL; p = p->next)` — стандартный обход списка. Освобождение требует аккуратности: после `free(head)` обращаться к `head->next` нельзя, поэтому следующий узел запоминается заранее.

## Добавление в конец

Чтобы добавить в конец, нужно дойти до последнего узла — `O(n)`. Если добавлять в конец часто, храните ещё и указатель на последний узел — **хвост** (tail): тогда добавление становится `O(1)`.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

typedef struct {
    Node *head;
    Node *tail;
} List;

static void push_back(List *list, int value) {
    Node *node = malloc(sizeof *node);
    if (node == NULL) {
        exit(1);
    }
    node->value = value;
    node->next = NULL;
    if (list->tail == NULL) {            // список был пуст
        list->head = node;
    } else {
        list->tail->next = node;
    }
    list->tail = node;
}

int main(void) {
    List list = {NULL, NULL};
    for (int i = 1; i <= 4; i++) {
        push_back(&list, i * 10);
    }
    for (Node *p = list.head; p != NULL; p = p->next) {
        printf("%d ", p->value);
    }
    printf("\n");
    while (list.head != NULL) {
        Node *next = list.head->next;
        free(list.head);
        list.head = next;
    }
    return 0;
}
```

Вывод:

```text
10 20 30 40
```

## Удаление и указатель на указатель

Чтобы удалить узел, нужно переставить указатель, который **на него указывает**: у предыдущего узла это поле `next`, а у первого узла — сама переменная `head`. Чтобы не разбирать эти случаи отдельно, используют **указатель на указатель** `Node **link` — адрес того места, где лежит указатель на текущий узел:

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

static void remove_all(Node **head, int value) {
    Node **link = head;                  // где лежит указатель на текущий узел
    while (*link != NULL) {
        Node *node = *link;
        if (node->value == value) {
            *link = node->next;          // обойти узел
            free(node);
        } else {
            link = &node->next;          // перейти к полю next этого узла
        }
    }
}

int main(void) {
    int data[] = {5, 1, 5, 5, 2, 5};
    Node *head = NULL;
    for (int i = 5; i >= 0; i--) {
        Node *node = malloc(sizeof *node);
        if (node == NULL) {
            return 1;
        }
        node->value = data[i];
        node->next = head;
        head = node;
    }
    remove_all(&head, 5);
    for (Node *p = head; p != NULL; p = p->next) {
        printf("%d ", p->value);
    }
    printf("\n");
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
    return 0;
}
```

Вывод:

```text
1 2
```

Сначала `link` — адрес переменной `head`, затем — адрес поля `next` очередного узла. Присваивание `*link = node->next` одинаково работает и для головы, и для середины списка. Пятёрки в начале, подряд и в конце удаляются без особых случаев.

## Разворот списка

Классическая задача — развернуть список на месте, не выделяя новых узлов. Идём по списку и переворачиваем каждую стрелку, помня три узла: предыдущий, текущий и следующий.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *next;
} Node;

static Node *reverse(Node *head) {
    Node *prev = NULL;
    while (head != NULL) {
        Node *next = head->next;     // не потерять продолжение
        head->next = prev;           // перевернуть стрелку
        prev = head;
        head = next;
    }
    return prev;                     // бывший последний — новая голова
}

int main(void) {
    Node *head = NULL;
    for (int i = 5; i >= 1; i--) {
        Node *node = malloc(sizeof *node);
        if (node == NULL) {
            return 1;
        }
        node->value = i;
        node->next = head;
        head = node;
    }
    head = reverse(head);
    for (Node *p = head; p != NULL; p = p->next) {
        printf("%d ", p->value);
    }
    printf("\n");
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
    return 0;
}
```

Вывод:

```text
5 4 3 2 1
```

**Инвариант:** `prev` — голова уже развёрнутой части, `head` — голова ещё не развёрнутой. На каждом шаге один узел переходит из второй части в первую. `O(n)` времени и `O(1)` памяти.

## Массив или список

| Операция                               | Динамический массив     | Односвязный список                              |
| -------------------------------------- | ----------------------- | ----------------------------------------------- |
| доступ к `i`-му элементу               | `O(1)`                  | `O(i)` — идти от головы                         |
| добавление в начало                    | `O(n)`                  | `O(1)`                                          |
| добавление в конец                     | амортизированное `O(1)` | `O(1)` с указателем на хвост                    |
| вставка/удаление после известного узла | `O(n)`                  | `O(1)`                                          |
| память на элемент                      | сам элемент             | элемент + указатель + служебные данные `malloc` |

На бумаге список выигрывает вставками. На практике массив часто быстрее даже там: его элементы лежат подряд и попадают в кэш процессора пачками, а узлы списка разбросаны по куче, и переход по `next` — это ожидание памяти. Список оправдан, когда вставки и удаления в середине действительно частые, когда элементы нельзя перемещать в памяти или когда узлы уже существуют и их нужно связать.

<Concept title="Односвязный список">

Узлы в куче, каждый хранит значение и указатель на следующий; список задаётся указателем на голову. Добавление в начало и вставка или удаление после известного узла — `O(1)`, доступ по номеру — `O(n)`. Указатель на указатель убирает особый случай головы. При освобождении следующий узел запоминается до `free`.

</Concept>

## Частые ошибки

<CommonMistake title="Обращение к узлу после free">

```c
for (Node *p = head; p != NULL; p = p->next) {
    free(p);              // p->next читается уже после освобождения
}
```

Шаг цикла `p = p->next` выполняется после тела, когда узел уже освобождён. Запоминайте `next` до `free`.

</CommonMistake>

<CommonMistake title="Потерянная голова">

Функция `void push_front(Node *head, int value)` меняет свою **копию** указателя, и у вызывающего `head` остаётся прежним — новый узел потерян, память утекла. Возвращайте новую голову или принимайте `Node **head`.

</CommonMistake>

<CommonMistake title="Разыменование NULL">

`head->value` для пустого списка — разыменование нулевого указателя. Перед обращением к полям проверяйте, что узел существует, — особенно в условиях вида `p->next->value`.

</CommonMistake>

## Практика

1. **Список задом наперёд** — добавление в начало.
2. **Удаление по значению** — указатель на указатель.
3. **Найди ошибку: освобождение списка** — использование после `free`.
4. **Поиск цикла** — два указателя с разной скоростью.

## Итоги

- Узел списка хранит значение и указатель на следующий; пустой список — `NULL`.
- Добавление в начало — `O(1)`; в конец — `O(1)` с указателем на хвост.
- Удаление удобно писать через `Node **link` — без особого случая для головы.
- Разворот на месте — три указателя, `O(n)` времени и `O(1)` памяти.
- Доступ по номеру — `O(n)`; узлы разбросаны по памяти, поэтому обход медленнее, чем у массива.
- При освобождении запоминайте следующий узел до `free`.
