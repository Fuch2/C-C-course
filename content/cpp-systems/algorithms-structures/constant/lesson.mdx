## Константное время

Операция работает за **O(1)**, если число её шагов не зависит от размера входа. Массив из десяти элементов или из миллиона — всё равно.

Самый важный пример — **доступ к элементу массива по индексу**. Элементы массива лежат в памяти подряд, поэтому адрес `values[i]` вычисляется одной формулой: адрес начала плюс `i`, умноженное на размер элемента. Компьютеру не нужно перебирать элементы с начала — он сразу идёт по адресу.

```c
#include <stdio.h>

static int values[1000000];

int main(void) {
    for (int i = 0; i < 1000000; i++) {
        values[i] = i * 3;
    }
    printf("%d %d\n", values[7], values[999999]);   // одинаково быстро
    printf("%td\n", &values[10] - &values[0]);      // 10 элементов
    printf("%td\n", (char *)&values[10] - (char *)&values[0]);  // 40 байт
    return 0;
}
```

Вывод:

```text
21 2999997
10
40
```

Заполнение массива — цикл на миллион шагов, это `O(n)`. А каждое отдельное обращение по индексу — `O(1)`.

Вот что ещё работает за `O(1)`:

- арифметика, сравнение, присваивание одного числа;
- обращение к полю структуры и разыменование указателя;
- вызов функции, которая сама делает `O(1)` работы;
- проверка `if` с условием из перечисленного.

А вот что **не** `O(1)`, хотя выглядит как одна операция: `strlen(s)` проходит всю строку, `memcpy` и `memset` копируют `n` байт, `strcmp` сравнивает строки посимвольно.

## Формула вместо цикла

Многие задачи, которые кажутся задачами «на цикл», решаются формулой. Сумма чисел от 1 до `n` — классический пример. Цикл делает `n` сложений, а формула арифметической прогрессии `n(n + 1) / 2` — три операции:

```c
#include <stdio.h>

int main(void) {
    long long n = 1000000000;
    long long sum = n * (n + 1) / 2;
    printf("%lld\n", sum);
    return 0;
}
```

Вывод:

```text
500000000500000000
```

Цикл на миллиард сложений работал бы около секунды, формула — мгновенно. Обратите внимание на тип: `n(n + 1)` при `n = 10⁹` — это 10¹⁸, такое число помещается только в `long long`.

Ещё несколько полезных формул:

| Что нужно                                               | Формула                     |
| ------------------------------------------------------- | --------------------------- |
| сумма чисел от `l` до `r`                               | `(l + r) · (r − l + 1) / 2` |
| сколько чисел от 1 до `n` делятся на `k`                | `n / k`                     |
| последняя цифра числа `x ≥ 0`                           | `x % 10`                    |
| номер строки и столбца клетки `i` в таблице шириной `w` | `i / w` и `i % w`           |
| клетка по строке и столбцу                              | `row · w + col`             |

## Деление отрицательных чисел

Формула `n / k` для количества кратных верна при `n ≥ 0`. Для отрицательных чисел нужно помнить, что в C деление **отбрасывает дробную часть к нулю**, а не округляет вниз:

```c
#include <stdio.h>

static long long floor_div(long long a, long long b) {   // b > 0
    long long q = a / b;
    if (a % b != 0 && a < 0) {
        q--;
    }
    return q;
}

int main(void) {
    printf("%d %d\n", 7 / 2, -7 / 2);
    printf("%d %d\n", 7 % 2, -7 % 2);
    printf("%lld %lld\n", floor_div(7, 2), floor_div(-7, 2));
    return 0;
}
```

Вывод:

```text
3 -3
1 -1
3 -4
```

`-7 / 2` в C равно `-3`, а математическое округление вниз даёт `-4`. Остаток `-7 % 2` тоже отрицательный. Если формула рассчитана на округление вниз, для отрицательных чисел нужна функция вроде `floor_div`.

## Таблица вместо вычисления

Если вход принимает немного разных значений, ответы для всех можно вычислить заранее и сложить в таблицу. Тогда каждый запрос — одно обращение по индексу.

Например, сколько дней прошло до начала каждого месяца в невисокосном году:

```c
#include <stdio.h>

static const int days_before[12] = {
    0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334,
};

int main(void) {
    int day = 9, month = 5;
    printf("%d.%02d — день года %d\n", day, month, days_before[month - 1] + day);
    return 0;
}
```

Вывод:

```text
9.05 — день года 129
```

Таблица занимает 12 чисел, а каждый ответ — одно сложение. Обратите внимание на `month - 1`: месяцы нумеруются с 1, а индексы массива — с 0.

## Прямая адресация

Таблица работает и как «память» о данных. Если значения — небольшие неотрицательные числа, массив `seen` со значением как индексом отвечает на вопрос «встречалось ли число x?» за `O(1)`:

```c
#include <stdio.h>

int main(void) {
    bool seen[1001] = {false};          // значения от 0 до 1000
    int data[] = {5, 42, 7, 42, 1000, 5};
    for (int i = 0; i < 6; i++) {
        if (seen[data[i]]) {
            printf("повтор: %d\n", data[i]);
        }
        seen[data[i]] = true;
    }
    return 0;
}
```

Вывод:

```text
повтор: 42
повтор: 5
```

Без таблицы, чтобы найти повтор, пришлось бы сравнивать каждое число со всеми предыдущими — `O(n²)`. С таблицей — один проход, `O(n)`. Цена — память: массив по размеру **диапазона значений**, а не числа элементов. Для значений до миллиарда так уже не получится — для этого есть хеш-таблицы, о них — в одном из следующих уроков.

<Concept title="O(1) — не зависит от n">

Операция работает за `O(1)`, если её стоимость не зависит от размера входа. Доступ по индексу, формула, обращение к заранее вычисленной таблице — всё это `O(1)`. «Константное» не значит «быстрое»: заполнение таблицы из миллиона элементов — тоже работа, просто она делается один раз, а не на каждом запросе.

</Concept>

## Частые ошибки

<CommonMistake title="Переполнение в формуле">

```c
int n = 100000;
int sum = n * (n + 1) / 2;   // n * (n + 1) = 10 000 100 000 > INT_MAX
```

Формула верна, но промежуточное произведение не помещается в `int` — это неопределённое поведение. Проверяйте, какого размера бывают **промежуточные** значения, и считайте в `long long`.

</CommonMistake>

<CommonMistake title="Индекс с единицы">

Месяц 12 с таблицей `days_before[12]` и индексом `month` вместо `month - 1` — чтение за границей массива. Компилятор не проверяет индексы; AddressSanitizer сообщит о `global-buffer-overflow`.

</CommonMistake>

<CommonMistake title="Отрицательный остаток">

`x % 10` для `x = -17` равно `-7`, а не `3`. Если нужен остаток от 0 до `k − 1`, используйте `((x % k) + k) % k`.

</CommonMistake>

## Практика

1. **Сумма отрезка** — формула вместо цикла.
2. **Кратные на отрезке** — округление вниз для отрицательных чисел.
3. **Найди ошибку: день года** — таблица с неверным индексом.
4. **Шахматные расстояния** — ходы фигур формулами.

## Итоги

- `O(1)` — число шагов не зависит от размера входа.
- Доступ по индексу — `O(1)`: адрес элемента вычисляется формулой.
- `strlen`, `memcpy`, `strcmp` — не `O(1)`: они проходят данные целиком.
- Формула часто заменяет цикл: сумма прогрессии, число кратных, строка и столбец клетки.
- Деление в C округляет к нулю; для округления вниз нужна поправка.
- Таблица заранее вычисленных ответов и прямая адресация дают `O(1)` на запрос ценой памяти.
- Следите за переполнением промежуточных значений в формулах.
