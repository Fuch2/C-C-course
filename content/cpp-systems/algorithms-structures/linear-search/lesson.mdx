## Теория и инвариант

Линейный поиск проверяет элементы в порядке хранения и завершает работу при первом совпадении. Он не требует сортировки, поэтому подходит для маленького или однократно используемого набора. Контракт должен фиксировать поведение при дубликатах: в нашей задаче возвращается первый индекс. Отсутствие кодируется −1, который не является индексом.

Инвариант перед шагом i: ключ не найден в [0,i). Если a[i] равен ключу, ни один более ранний элемент не подходит. Если цикл завершился, просмотрен весь массив. Для поиска всех совпадений ранний выход непригоден. При дорогих сравнениях сначала можно проверять дешёвые признаки, но они не должны исключать истинное совпадение.

## Пошаговый разбор

В [8,3,8] ключ 8 даёт индекс 0 после одного сравнения; ключ 5 — −1 после трёх.

## Реализация и запускаемый пример на C17

Пример не требует stdin. Сначала предскажите результат; затем выполните код и измените данные. Функции демонстрируют алгоритм, а практика ниже требует самостоятельного ввода и обработки граничных состояний.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <limits.h>

static int find_first(const int *a,int n,int target){
    for(int i=0;i<n;++i) if(a[i]==target) return i;
    return -1;
}
int main(void) {
int a[]={8,3,8};printf("%d %d\n",find_first(a,3,8),find_first(a,3,5));
return 0;
}
```

Ожидаемый вывод:

```text
0 -1
```

## Почему реализация корректна

Массив 8, 3, 8 и цель 8 дают индекс 0. Ранний return гарантирует именно первое совпадение. Замена return на присваивание ответа без остановки изменит контракт и даст последний индекс 2. Если цель 7, нужно проверить все три элемента и вернуть −1.

Инвариант перед итерацией i: в диапазоне [0,i) совпадений нет. Поэтому при совпадении на i меньшего допустимого ответа не существует. Для пустого массива цикл не выполняется и возвращает −1. Худший случай требует n сравнений; лучший — одного, но только для непустого массива и цели в первой позиции. Средняя оценка требует предположений о распределении запросов.

## Связь со STL C++

std::find возвращает итератор или end; разыменовывать end нельзя.

Запускаемый вариант C++20:

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
int main(){
std::vector<int> a{8,3,8};auto it=std::find(a.begin(),a.end(),8);std::cout<<(it==a.end()?-1:static_cast<int>(it-a.begin()))<<"\n";
return 0;
}
```

Вывод:

```text
0
```
