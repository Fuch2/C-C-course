## Иерархия вместо цепочки

Массивы и списки хранят элементы **по порядку**: у каждого есть следующий. Но многие данные устроены иерархически: папки и файлы, главы и разделы книги, выражение `(2 + 3) * 4`, где умножение «содержит» сложение. Для них нужна структура, где у элемента может быть несколько «следующих». Это **дерево**.

Термины:

| Термин         | Значение                                                      |
| -------------- | ------------------------------------------------------------- |
| узел           | элемент дерева                                                |
| корень (root)  | единственный узел без родителя — вершина иерархии             |
| дети, родитель | узлы, на которые узел указывает, и тот, кто указывает на него |
| лист (leaf)    | узел без детей                                                |
| поддерево      | узел вместе со всеми его потомками                            |
| глубина узла   | число рёбер от корня до узла                                  |
| высота дерева  | наибольшая глубина листа                                      |

В **бинарном** дереве у каждого узла не больше двух детей — **левый** и **правый**.

```text
          8            глубина 0 — корень
        /   \
       3     10        глубина 1
      / \      \
     1   6      14     глубина 2
        / \
       4   7           глубина 3, высота дерева — 3
```

## Узел и рекурсия

Узел бинарного дерева похож на узел двусвязного списка, только указатели ведут не вперёд и назад, а влево и вправо:

```c
typedef struct Node {
    int value;
    struct Node *left;
    struct Node *right;
} Node;
```

Дерево **рекурсивно** по своей природе: левый и правый ребёнок — это корни поддеревьев, которые сами являются деревьями. Поэтому почти любой алгоритм на дереве записывается как рекурсия: «обработай корень и рекурсивно — оба поддерева». Базовый случай — пустое дерево, `NULL`.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *left;
    struct Node *right;
} Node;

static Node *make(int value, Node *left, Node *right) {
    Node *node = malloc(sizeof *node);
    if (node == NULL) {
        exit(1);
    }
    node->value = value;
    node->left = left;
    node->right = right;
    return node;
}

static int size(const Node *t) {
    return t == NULL ? 0 : 1 + size(t->left) + size(t->right);
}

static int height(const Node *t) {                    // у пустого дерева −1, у одного узла 0
    if (t == NULL) {
        return -1;
    }
    int l = height(t->left), r = height(t->right);
    return 1 + (l > r ? l : r);
}

static int leaves(const Node *t) {
    if (t == NULL) {
        return 0;
    }
    if (t->left == NULL && t->right == NULL) {
        return 1;
    }
    return leaves(t->left) + leaves(t->right);
}

static void destroy(Node *t) {
    if (t == NULL) {
        return;
    }
    destroy(t->left);                                 // сначала дети,
    destroy(t->right);
    free(t);                                          // потом сам узел
}

int main(void) {
    Node *tree = make(8,
                      make(3, make(1, NULL, NULL),
                              make(6, make(4, NULL, NULL), make(7, NULL, NULL))),
                      make(10, NULL, make(14, NULL, NULL)));
    printf("узлов %d, высота %d, листьев %d\n", size(tree), height(tree), leaves(tree));
    destroy(tree);
    return 0;
}
```

Вывод:

```text
узлов 8, высота 3, листьев 4
```

Каждая функция обходит каждый узел один раз — `O(n)`. Глубина рекурсии равна высоте дерева: для «сбалансированного» дерева это около `log₂ n`, а для вырожденного дерева-«палки», где у каждого узла один ребёнок, — `n`.

Освобождение идёт **снизу вверх**: дети освобождаются до родителя. Если сначала освободить узел, его поля `left` и `right` читать уже нельзя.

## Три обхода в глубину

Обойти дерево — посетить каждый узел один раз. Рекурсивный обход может «посетить» корень в трёх местах относительно обхода детей:

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *left;
    struct Node *right;
} Node;

static Node *make(int value, Node *left, Node *right) {
    Node *node = malloc(sizeof *node);
    if (node == NULL) {
        exit(1);
    }
    node->value = value;
    node->left = left;
    node->right = right;
    return node;
}

static void preorder(const Node *t) {      // корень, левое, правое
    if (t == NULL) return;
    printf("%d ", t->value);
    preorder(t->left);
    preorder(t->right);
}

static void inorder(const Node *t) {       // левое, корень, правое
    if (t == NULL) return;
    inorder(t->left);
    printf("%d ", t->value);
    inorder(t->right);
}

static void postorder(const Node *t) {     // левое, правое, корень
    if (t == NULL) return;
    postorder(t->left);
    postorder(t->right);
    printf("%d ", t->value);
}

static void destroy(Node *t) {
    if (t == NULL) return;
    destroy(t->left);
    destroy(t->right);
    free(t);
}

int main(void) {
    Node *tree = make(8,
                      make(3, make(1, NULL, NULL),
                              make(6, make(4, NULL, NULL), make(7, NULL, NULL))),
                      make(10, NULL, make(14, NULL, NULL)));
    printf("прямой:     "); preorder(tree);  printf("\n");
    printf("центральный: "); inorder(tree);  printf("\n");
    printf("обратный:   "); postorder(tree); printf("\n");
    destroy(tree);
    return 0;
}
```

Вывод:

```text
прямой:     8 3 1 6 4 7 10 14
центральный: 1 3 4 6 7 8 10 14
обратный:   1 4 7 6 3 14 10 8
```

У каждого обхода своё назначение:

- **Прямой** (preorder): родитель раньше детей. Так копируют дерево или печатают оглавление: глава, затем её разделы.
- **Центральный** (inorder): левое поддерево, корень, правое. Для этого дерева он дал **отсортированную** последовательность — это не случайность, а свойство дерева поиска из следующего урока.
- **Обратный** (postorder): дети раньше родителя. Так освобождают дерево и вычисляют выражения: чтобы посчитать `(2 + 3) * 4`, сначала нужны значения операндов.

## Обход по уровням

Иногда узлы нужно посетить **по уровням**: корень, затем все узлы глубины 1, затем глубины 2. Рекурсия здесь не помогает — она уходит в глубину. Нужна **очередь**: берём узел из начала, посещаем и ставим в конец его детей. Узлы одного уровня окажутся в очереди раньше узлов следующего.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int value;
    struct Node *left;
    struct Node *right;
} Node;

static Node *make(int value, Node *left, Node *right) {
    Node *node = malloc(sizeof *node);
    if (node == NULL) {
        exit(1);
    }
    node->value = value;
    node->left = left;
    node->right = right;
    return node;
}

int main(void) {
    Node *tree = make(8,
                      make(3, make(1, NULL, NULL),
                              make(6, make(4, NULL, NULL), make(7, NULL, NULL))),
                      make(10, NULL, make(14, NULL, NULL)));
    Node *queue[16];
    int head = 0, tail = 0;
    queue[tail++] = tree;
    while (head < tail) {
        Node *node = queue[head++];
        printf("%d ", node->value);
        if (node->left != NULL) queue[tail++] = node->left;
        if (node->right != NULL) queue[tail++] = node->right;
    }
    printf("\n");
    for (int i = 0; i < tail; i++) {          // в очереди побывали все узлы — освобождаем их
        free(queue[i]);
    }
    return 0;
}
```

Вывод:

```text
8 3 10 1 6 14 4 7
```

Это **поиск в ширину** — тот же алгоритм применяется к графам в последних уроках модуля.

## Дерево в массиве

Если дерево **полное** — все уровни заполнены, кроме, может быть, последнего, заполненного слева направо, — указатели не нужны. Узлы кладут в массив по уровням, и дети узла `i` оказываются в ячейках `2i + 1` и `2i + 2`, а родитель — в `(i − 1) / 2`:

```text
массив:  [8, 3, 10, 1, 6, 9, 14]
индексы:  0  1   2  3  4  5   6

          8(0)
        /      \
     3(1)      10(2)
     /  \      /   \
  1(3)  6(4) 9(5)  14(6)
```

На этом представлении построена **куча** — тема урока после следующего.

<Concept title="Бинарное дерево">

Узел хранит значение и указатели на левого и правого ребёнка; пустое дерево — `NULL`. Алгоритмы на деревьях естественно рекурсивны: результат для дерева складывается из результатов для поддеревьев. Обходы в глубину — прямой, центральный и обратный — различаются моментом посещения корня; обход по уровням использует очередь. Освобождать дерево нужно обратным обходом.

</Concept>

## Частые ошибки

<CommonMistake title="Освобождение родителя раньше детей">

```c
void destroy(Node *t) {
    if (t == NULL) return;
    free(t);
    destroy(t->left);      // поле освобождённого узла
    destroy(t->right);
}
```

После `free(t)` читать `t->left` нельзя — AddressSanitizer сообщит `heap-use-after-free`. Освобождайте обратным обходом.

</CommonMistake>

<CommonMistake title="Высота пустого дерева">

Если считать, что у пустого дерева высота 0, то у дерева из одного узла получится 1 — и формула разойдётся с определением «число рёбер». Выберите соглашение (здесь пустое — −1) и проверьте его на одном узле.

</CommonMistake>

<CommonMistake title="Глубокая рекурсия на вырожденном дереве">

Дерево, построенное из отсортированных данных «в лоб», может оказаться цепочкой высоты `n`. Рекурсивный обход такого дерева из миллиона узлов переполнит стек. Для очень глубоких деревьев используют явный стек или очередь.

</CommonMistake>

## Практика

Во всех задачах дерево задаётся так: первая строка — число узлов `n`, дальше `n` строк `значение левый правый`, где `левый` и `правый` — номера детей (с нуля) или `-1`. Корень — узел 0.

1. **Размер, высота, листья** — рекурсивные функции.
2. **Три обхода** — прямой, центральный, обратный.
3. **Найди ошибку: освобождение дерева** — порядок `free`.
4. **По уровням** — обход с очередью.

## Итоги

- Дерево — иерархия: корень, дети, листья; в бинарном дереве у узла не больше двух детей.
- Алгоритмы на дереве рекурсивны: базовый случай — пустое дерево.
- Прямой обход посещает родителя раньше детей, центральный — между ними, обратный — после.
- Обход по уровням — очередь; это поиск в ширину.
- Освобождают дерево обратным обходом.
- Полное дерево хранится в массиве: дети узла `i` — `2i + 1` и `2i + 2`.
