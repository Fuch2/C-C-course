## Теория и инвариант

В бинарном дереве у узла не более двух детей. Никакого порядка значений это определение не требует. Высоту договоримся считать в узлах: пустое дерево имеет 0, лист 1. Лист — узел без обоих детей; узел с одним ребёнком листом не является.

Обход рекурсивно получает результаты поддеревьев. height=1+max(leftHeight,rightHeight), число листьев — сумма по детям, кроме собственного листа. Время зависит от числа посещённых узлов, память рекурсии — от высоты. Для цепочки высота может стать n, поэтому рекурсивное освобождение произвольного большого дерева требует контроля глубины. В упражнении число позиций ограничено 256.

## Пошаговый разбор

Корень с двумя листьями имеет высоту 2 и два листа. Цепочка из трёх узлов — высоту 3 и один лист.

## Реализация и запускаемый пример на C17

Пример не требует stdin. Сначала предскажите результат; затем выполните код и измените данные. Функции демонстрируют алгоритм, а практика ниже требует самостоятельного ввода и обработки граничных состояний.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <limits.h>

typedef struct Node { int value; struct Node *left,*right; } Node;
static void destroy(Node *root){if(root){destroy(root->left);destroy(root->right);free(root);}}
static Node *build(const int *a,int n,int i,int *ok){
    if(i>=n || a[i]==-9999)return NULL;
    Node *node=malloc(sizeof *node);if(!node){*ok=0;return NULL;}
    *node=(Node){a[i],NULL,NULL};
    node->left=build(a,n,2*i+1,ok);node->right=build(a,n,2*i+2,ok);
    return node;
}
static int height(const Node *root){
    if(!root)return 0;int l=height(root->left),r=height(root->right);return 1+(l>r?l:r);
}
static int leaves(const Node *root){
    if(!root)return 0;
    if(!root->left && !root->right)return 1;
    return leaves(root->left)+leaves(root->right);
}
int main(void) {
int a[]={5,2,8};int ok=1;Node *root=build(a,3,0,&ok);if(!ok){destroy(root);return 1;}printf("%d %d\n",height(root),leaves(root));destroy(root);
return 0;
}
```

Ожидаемый вывод:

```text
2 2
```

## Почему реализация корректна

При хранении входа по уровням индекс i имеет детей 2i+1 и 2i+2. Значение-маркер означает отсутствие узла, поэтому поддерево из этой позиции не строится. Высота пустого дерева принята равной нулю, листа — единице. Для узла высота равна 1+max(высота слева, высота справа), а число листьев суммируется из детей, кроме самого листа.

Во время построения отказ malloc передаётся наружу. Уже созданное частичное дерево всё равно нужно уничтожить. Очистка выполняет postorder: сначала детей, затем узел, иначе ссылки на потомков будут потеряны. Значения узлов не влияют на форму и не обязаны удовлетворять порядку BST.

Размеры в учебном коде ограничены ради безопасного запуска. При анализе представляйте масштабируемый вариант той же структуры; фиксированный тестовый предел не превращает любой алгоритм в полезное «O(1)».

## Cache locality и компромиссы

Указатели удобны для произвольной формы, но размещение по отдельным malloc ухудшает локальность.

Гибкая структура против указателей и сложности владения; плотный массив удобен для почти полного дерева.

## Связь со STL C++

Отдельного общего binary_tree в STL нет; std::map нельзя считать деревом произвольной формы.
