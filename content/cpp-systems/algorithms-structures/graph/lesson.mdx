- Оценить память и компромиссы: Матрица хороша для плотного графа и частых проверок рёбер, списки — для разреженного обхода.

## Теория и инвариант

Граф состоит из вершин и рёбер. Сначала фиксируйте ориентированность, допустимость петель и повторных рёбер, наличие весов. В уроках используется неориентированный мультиграф: каждое ребро хранится двумя дугами, петля тоже даёт вклад 2 в степень. Вершины нумеруются от 0 до V−1.

Матрица смежности требует O(V²) памяти и позволяет проверить конкретное ребро за O(1). Списки смежности занимают O(V+E) и перечисляют только существующих соседей. Реализация хранит дуги в плотном массиве, а цепочки задаёт индексами next: это сокращает аллокации, но не делает соседей каждой вершины физически непрерывными. Для интенсивного обхода полезен CSR, который группирует соседей ценой более дорогих вставок.

</Concept>

## Пошаговый разбор

Рёбра (0,1),(1,2),(1,1) дают степени 1,4,1. Сумма степеней 6 равна 2E.

## Реализация и запускаемый пример на C17

Пример не требует stdin. Сначала предскажите результат; затем выполните код и измените данные. Функции демонстрируют алгоритм, а практика ниже требует самостоятельного ввода и обработки граничных состояний.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <limits.h>

enum { MAX_VERTICES=32, MAX_ARCS=256 };
typedef struct { int to,next; } Edge;
typedef struct { int head[MAX_VERTICES],count; Edge edges[MAX_ARCS]; } Graph;
static void init(Graph *g){for(int i=0;i<MAX_VERTICES;++i)g->head[i]=-1;g->count=0;}
static int connect(Graph *g,int from,int to){
    if(g->count==MAX_ARCS)return 0;
    g->edges[g->count]=(Edge){to,g->head[from]};g->head[from]=g->count++;return 1;
}
static int read_graph(Graph *g,int *vertices){
    int m;if(scanf("%d%d",vertices,&m)!=2 || *vertices<1 || *vertices>32 || m<0 || m>128)return 0;
    init(g);
    for(int i=0;i<m;++i){int a,b;if(scanf("%d%d",&a,&b)!=2 || a<0 || b<0 || a>=*vertices || b>=*vertices)return 0;
        if(!connect(g,a,b) || !connect(g,b,a))return 0;
    }return 1;
}
int main(void) {
Graph g;init(&g);connect(&g,0,1);connect(&g,1,0);connect(&g,1,2);connect(&g,2,1);for(int v=0;v<3;++v){int d=0;for(int e=g.head[v];e!=-1;e=g.edges[e].next)++d;printf("%s%d",v?" ":"",d);}puts("");
return 0;
}
```

Ожидаемый вывод:

```text
1 2 1
```

## Почему реализация корректна

Неориентированное ребро 0—1 хранится двумя дугами: 0→1 и 1→0. Массив head содержит начало цепочки дуг каждой вершины; to — соседа, next — индекс следующей дуги. Добавление в голову меняет порядок обхода соседей, но не множество рёбер.

Петля добавляется дважды и увеличивает степень вершины на два, как определено в условии. Параллельные рёбра также сохраняются. Поэтому вход E≤128 требует вместимости не менее 256 дуг. Перед обращением к head[u] проверяется диапазон вершины. Для очень больших неизменяемых графов CSR уплотняет соседей одной вершины, но добавлять ребро в такое представление сложнее.

## Сложность и память

| Что оцениваем | Гарантия                                                                       |
| ------------- | ------------------------------------------------------------------------------ |
| Время         | Построение и полный обход списков O(V+E); матрицы O(V²).                       |
| Память        | O(V+E) у списков; наш буфер имеет явные верхние границы 32 вершин и 128 рёбер. |

Размеры в учебном коде ограничены ради безопасного запуска. При анализе представляйте масштабируемый вариант той же структуры; фиксированный тестовый предел не превращает любой алгоритм в полезное «O(1)».

## Cache locality и компромиссы

Массив дуг лучше множества malloc, CSR дополнительно делает соседей непрерывными.

Матрица хороша для плотного графа и частых проверок рёбер, списки — для разреженного обхода.

Практическое применение: Связи устройств, зависимости задач, маршруты.

<CommonMistake title="Типичная ошибка">

Оценка O(V+E) предполагает списки; просмотр всей строки матрицы для каждой вершины даёт O(V²).

</CommonMistake>

## Связь со STL C++

Готового универсального graph в STL нет; часто используют vector&lt;vector&lt;int>>, а веса хранят в парах или структурах.

Запускаемый вариант C++20:

```cpp
#include <iostream>
#include <vector>
int main(){
std::vector<std::vector<int>> g(3);g[0].push_back(1);g[1].push_back(0);g[1].push_back(2);g[2].push_back(1);for(std::size_t i=0;i<g.size();++i)std::cout<<(i?" ":"")<<g[i].size();std::cout<<"\n";
return 0;
}
```

Вывод:

```text
1 2 1
```
