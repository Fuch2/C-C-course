## Цели обучения

- Объяснить инвариант: Волна расходится на один шаг за раз; очередь удерживает границу волны.
- Обосновать время: O(V+E) со списками смежности и инициализацией расстояний.
- Оценить память и компромиссы: На широком графе фронт волны требует много памяти; зато даёт кратчайшие невзвешенные пути.

## Теория и инвариант

BFS обрабатывает вершины слоями с помощью очереди FIFO. Источник получает расстояние 0; непосещённые вершины — −1. Соседу впервые назначается расстояние parent+1 и он сразу помечается посещённым, до помещения в очередь. Это не позволяет нескольким родителям добавить его повторно.

В невзвешенном графе первый найденный путь кратчайший по числу рёбер: очередь не позволяет следующему слою обогнать предыдущий. Для произвольных весов этот аргумент не работает. Недостижимые вершины сохраняют −1; BFS из одного источника не обходит автоматически другие компоненты. Очередь вмещает V элементов, если каждая вершина ставится ровно один раз.

## Пошаговый разбор

При рёбрах 0–1,0–2,1–3,2–3 расстояния от 0: 0,1,1,2. Вершина 3 добавляется только первым достигшим её родителем.

## Реализация и запускаемый пример на C17

Пример не требует stdin. Сначала предскажите результат; затем выполните код и измените данные. Функции демонстрируют алгоритм, а практика ниже требует самостоятельного ввода и обработки граничных состояний.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <string.h>
#include <limits.h>

enum { MAX_VERTICES=32, MAX_ARCS=256 };
typedef struct { int to,next; } Edge;
typedef struct { int head[MAX_VERTICES],count; Edge edges[MAX_ARCS]; } Graph;
static void init(Graph *g){for(int i=0;i<MAX_VERTICES;++i)g->head[i]=-1;g->count=0;}
static int connect(Graph *g,int from,int to){
    if(g->count==MAX_ARCS)return 0;
    g->edges[g->count]=(Edge){to,g->head[from]};g->head[from]=g->count++;return 1;
}
static int read_graph(Graph *g,int *vertices){
    int m;if(scanf("%d%d",vertices,&m)!=2 || *vertices<1 || *vertices>32 || m<0 || m>128)return 0;
    init(g);
    for(int i=0;i<m;++i){int a,b;if(scanf("%d%d",&a,&b)!=2 || a<0 || b<0 || a>=*vertices || b>=*vertices)return 0;
        if(!connect(g,a,b) || !connect(g,b,a))return 0;
    }return 1;
}
static void distances(const Graph *g,int n,int start,int *distance){
    int queue[MAX_VERTICES],head=0,tail=0;
    for(int i=0;i<n;++i)distance[i]=-1;
    distance[start]=0;queue[tail++]=start;
    while(head<tail){int v=queue[head++];
        for(int e=g->head[v];e!=-1;e=g->edges[e].next){int to=g->edges[e].to;
            if(distance[to]==-1){distance[to]=distance[v]+1;queue[tail++]=to;}
        }
    }
}
int main(void) {
Graph g;init(&g);connect(&g,0,1);connect(&g,1,0);connect(&g,1,2);connect(&g,2,1);int d[4];distances(&g,4,0,d);for(int i=0;i<4;++i)printf("%s%d",i?" ":"",d[i]);puts("");
return 0;
}
```

Ожидаемый вывод:

```text
0 1 2 -1
```

## Почему реализация корректна

В графе 0—1, 0—2, 1—3, 2—3 сначала очередь содержит только 0 с расстоянием 0. Обработка 0 открывает 1 и 2 с расстоянием 1. Первый из них открывает 3 с расстоянием 2; второй видит уже установленное расстояние и не добавляет 3 повторно.

Метка при постановке в очередь гарантирует не более одной записи на вершину и ограничение очереди V элементами. FIFO обрабатывает расстояния послойно, поэтому первое обнаружение оптимально по числу рёбер. Недостижимые вершины сохраняют −1. Для взвешенных рёбер эта логика не доказывает минимальный суммарный вес; тогда выбирают другой алгоритм.

## Cache locality и компромиссы

Очередь плотная; локальность соседей определяется представлением графа.

На широком графе фронт волны требует много памяти; зато даёт кратчайшие невзвешенные пути.

Практическое применение: Минимальное число переходов в сети и достижимость ближайшего ресурса.

<CommonMistake title="Типичная ошибка">

Пометка лишь при извлечении допускает повторные постановки и переполнение очереди размера V.

</CommonMistake>

## Связь со STL C++

std::queue поддерживает нужную дисциплину; vector&lt;int> хранит расстояния. Это не превращает BFS в алгоритм взвешенных путей.
