## Что такое программа

**Программа** — это последовательность инструкций, которые компьютер выполняет одну за другой. Похоже на рецепт: «налить воду, вскипятить, засыпать макароны, варить 10 минут». Разница в том, что повар понимает, что вы имели в виду, а компьютер — нет. Он выполняет ровно то, что написано, буквально и без догадок.

Если в рецепте написано «посолить», повар возьмёт щепотку соли. Компьютеру нужно указать, сколько именно граммов, из какой банки и в какой момент. Поэтому программирование — это в первую очередь умение разбить задачу на очень маленькие и очень точные шаги.

<Concept title="Главная мысль урока">

Компьютер не понимает намерений. Он выполняет инструкции точно в том порядке и в том виде, в каком они записаны. Почти все ошибки в программах — это места, где написанное отличается от задуманного.

</Concept>

## Из чего состоит компьютер — минимум, который нужен программисту

Чтобы понимать программы на C, достаточно представлять три части компьютера:

| Часть                     | Что делает                                                     | Аналогия               |
| ------------------------- | -------------------------------------------------------------- | ---------------------- |
| Процессор (CPU)           | Выполняет инструкции: складывает, сравнивает, переходит дальше | Повар                  |
| Оперативная память (RAM)  | Хранит данные, с которыми программа работает прямо сейчас      | Рабочий стол с мисками |
| Устройства ввода и вывода | Клавиатура, экран, диск, сеть                                  | Окно выдачи заказов    |

Процессор очень быстрый — миллиарды простых операций в секунду, — но каждая операция крошечная: «сложить два числа», «сравнить два числа», «прочитать число из памяти». Всё сложное поведение программ складывается из огромного количества таких простых шагов.

Память можно представить как длинный ряд пронумерованных ячеек. В каждой ячейке хранится число. Текст, картинки и музыка в памяти — тоже числа, просто программа знает, как их толковать. В уроках про указатели мы вернёмся к этим номерам ячеек — они называются **адресами**.

## Ввод, обработка, вывод

Почти любую программу можно описать схемой из трёх шагов:

1. **Ввод** — получить данные (например, два числа с клавиатуры).
2. **Обработка** — что-то с ними сделать (сложить).
3. **Вывод** — показать результат (напечатать сумму на экране).

Вот программа на C, которая делает именно это. Пока не пытайтесь понять каждую строку — к концу следующих уроков вы будете читать такой код свободно. Сейчас просто найдите глазами три шага.

```c
#include <stdio.h>

int main(void) {
    int a, b;
    scanf("%d %d", &a, &b);   // 1. Ввод: прочитать два целых числа
    int sum = a + b;          // 2. Обработка: сложить их
    printf("%d\n", sum);      // 3. Вывод: напечатать результат
    return 0;
}
```

Ввод:

```text
2 3
```

Вывод:

```text
5
```

Под примером есть поле «Ввод для программы». Впишите туда два числа через пробел, например `40 2`, и нажмите «Запустить». Программа прочитает ваши числа и напечатает их сумму.

Текст после `//` — это **комментарий**. Компьютер его не выполняет; комментарии пишут для людей, чтобы пояснить код.

## Что такое язык программирования

Процессор понимает только **машинный код** — числа, каждое из которых обозначает одну крошечную команду. Писать программы прямо в машинном коде можно, но очень трудно: тысячи чисел вроде `10001011 01000101 11111000` без единого понятного слова.

**Язык программирования** — это способ записать инструкции в виде, удобном для человека, но достаточно строгом, чтобы его можно было автоматически перевести в машинный код. Строка `int sum = a + b;` гораздо понятнее, чем десяток машинных команд, которые она означает.

Перевод из языка C в машинный код делает специальная программа — **компилятор**. Про него следующий урок.

<Tip title="Почему C называют «близким к железу»">

Многие языки (Python, JavaScript) прячут от программиста устройство памяти. В C вы видите её почти напрямую: сколько байт занимает число, где именно оно лежит, когда память освобождается. Это сложнее, но именно поэтому знание C делает вас сильнее в любом другом языке.

</Tip>

## Программа выполняется сверху вниз

Внутри `main` инструкции выполняются по порядку: сначала первая, потом вторая, потом третья. Посмотрите на программу, которая печатает три строки:

```c
#include <stdio.h>

int main(void) {
    printf("Раз\n");
    printf("Два\n");
    printf("Три\n");
    return 0;
}
```

Вывод:

```text
Раз
Два
Три
```

Если поменять строки местами, изменится и порядок вывода. Компьютер не «догадается», что вы хотели посчитать по порядку. Попробуйте это сами: скопируйте пример в песочницу и переставьте строки.

## Как в этом курсе проверяются задачи

Решение задачи проверяется **тестами**. Тест — это пара «входные данные → ожидаемый вывод». Система запускает вашу программу, подаёт ей на вход данные теста и сравнивает то, что программа напечатала, с ожидаемым выводом **символ в символ**.

Часть тестов открыта: вы видите их в условии как «Примеры». Остальные тесты **скрытые** — они проверяют, что программа работает не только на примерах, но и на других данных, включая особые случаи: ноль, отрицательные числа, очень большие значения.

Отсюда три правила, которые сэкономят вам много времени:

1. **Печатайте только то, что требует условие.** Если программа выведет «Введите число:» или «Ответ: 5», а ожидается просто `5`, тест не пройдёт — для проверяющей системы это другой текст.
2. **Следите за пробелами и переводами строк.** `5` и `5` с переводом строки после него — разные выводы. В условиях задач обычно сказано, что в конце нужно перевести строку.
3. **Решайте задачу для всех допустимых данных,** а не только для примеров. Если в ограничениях сказано, что число может быть отрицательным, проверьте этот случай сами.

<Warning title="Самая частая ошибка новичков">

Программа «почти правильная», но выводит лишние слова-подсказки. Человек видит в них заботу о пользователе, а проверяющая система — неверный ответ. В учебных задачах выводите строго по образцу.

</Warning>

## Частые заблуждения

<CommonMistake title="«Компьютер поймёт, что я имел в виду»">

Не поймёт. Если написать `sum = a - b` вместо `sum = a + b`, программа послушно вычтет. Опечатка в одном символе меняет смысл программы.

</CommonMistake>

<CommonMistake title="«Программирование — это знание всех команд наизусть»">

Команд в C немного, и вы выучите их быстро. Главный навык другой — разбивать задачу на шаги и проверять, что каждый шаг делает именно то, что нужно. Ему и посвящён этот курс.

</CommonMistake>

<CommonMistake title="«Если пример прошёл, значит решение верное»">

Пример — только один из тестов. Решение верное, когда оно работает для всех данных из условия, в том числе для граничных.

</CommonMistake>

## Итоги

- Программа — это последовательность точных инструкций; компьютер выполняет их буквально и по порядку.
- Процессор выполняет простые операции, память хранит данные в виде чисел, ввод и вывод связывают программу с внешним миром.
- Большинство программ устроены по схеме «ввод → обработка → вывод».
- Компилятор переводит программу на C в машинный код, понятный процессору.
- Задачи проверяются тестами, вывод сравнивается символ в символ. Печатайте ровно то, что требует условие.
