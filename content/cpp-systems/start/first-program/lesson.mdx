## Традиция «Hello, world!»

С 1978 года, когда вышла книга Брайана Кернигана и Денниса Ритчи «Язык программирования C», изучение почти любого языка начинают с программы, которая печатает фразу «Hello, world!» — «Привет, мир!». Она короткая, но в ней есть всё, что нужно любой программе на C. Разберём её построчно.

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

Вывод:

```text
Hello, world!
```

Нажмите «Запустить» и убедитесь, что программа работает. А теперь разберём каждую строку.

## Строка 1: `#include <stdio.h>`

Язык C сам по себе очень маленький. В нём нет даже встроенной команды «напечатать текст». Всё полезное — вывод на экран, работа с файлами, математические функции — находится в **стандартной библиотеке**: наборе готовых функций, который поставляется вместе с компилятором.

Функции библиотеки разложены по группам. Чтобы воспользоваться группой, её нужно подключить строкой `#include`. Файл `stdio.h` — это описание функций **ст**андартного **в**вода-**в**ывода (**st**andar**d** **i**nput/**o**utput). Окончание `.h` — от слова header, «заголовок».

После `#include <stdio.h>` в программе можно использовать `printf`, `scanf`, `puts` и другие функции ввода-вывода. Без этой строки компилятор не будет знать, что такое `printf`.

## Строка 3: `int main(void) {`

Программа на C состоит из **функций** — именованных блоков кода. Функция `main` особенная: с неё начинается выполнение любой программы на C. Когда вы запускаете программу, операционная система вызывает `main`.

Разберём запись по частям:

- `int` — функция вернёт целое число (от integer). Это и есть код завершения из прошлого урока.
- `main` — имя функции. Оно обязательно должно быть именно таким, маленькими буквами.
- `(void)` — функция не принимает никаких данных. Слово void означает «пусто».
- `{` — начало **тела** функции, то есть инструкций, которые она выполняет.

## Строка 4: `printf("Hello, world!\n");`

Это единственная строка, которая делает что-то заметное: печатает текст.

- `printf` — функция печати из `stdio.h`. Название читается «принт-эф»: print formatted, «печать с форматированием».
- В круглых скобках — то, что мы передаём функции. Здесь это одна **строка** — текст в двойных кавычках.
- `\n` — специальный символ «перевод строки»: после него вывод продолжается с новой строки.
- `;` — точка с запятой завершает **инструкцию**. В C почти каждая инструкция заканчивается точкой с запятой.

Отступ в четыре пробела перед `printf` компилятору не нужен — он нужен людям. Отступы показывают, что строка находится внутри тела функции.

## Строки 5–6: `return 0;` и `}`

`return 0;` завершает функцию `main` и возвращает операционной системе код `0` — «всё прошло успешно». Закрывающая фигурная скобка `}` отмечает конец тела функции. Каждой открывающей скобке должна соответствовать закрывающая.

<Concept title="Скелет любой программы на C">

Почти каждая программа в этом модуле будет начинаться одинаково: подключить `stdio.h`, объявить `int main(void)`, в фигурных скобках написать инструкции, в конце вернуть `0`. Меняться будет только то, что внутри скобок.

</Concept>

## Несколько строк вывода

Чтобы напечатать несколько строк, можно вызвать `printf` несколько раз:

```c
#include <stdio.h>

int main(void) {
    printf("Меня зовут C.\n");
    printf("Мне больше 50 лет.\n");
    printf("Я всё ещё в строю.\n");
    return 0;
}
```

Вывод:

```text
Меня зовут C.
Мне больше 50 лет.
Я всё ещё в строю.
```

А что будет, если забыть `\n`? Тогда следующий текст продолжится на той же строке:

```c
#include <stdio.h>

int main(void) {
    printf("Раз");
    printf("Два");
    printf("Три\n");
    return 0;
}
```

Вывод:

```text
РазДваТри
```

`printf` печатает ровно то, что ему передали, — ни пробелов, ни переводов строки «от себя» он не добавляет. Можно, наоборот, поставить несколько `\n` в одну строку: `printf("A\nB\n")` напечатает две строки.

## Специальные символы: управляющие последовательности

Как напечатать двойную кавычку, если кавычками обозначаются границы строки? Для таких случаев в C есть **управляющие последовательности** — пары символов, начинающиеся с обратной косой черты `\`:

| Запись в коде | Что печатается                          |
| ------------- | --------------------------------------- |
| `\n`          | Перевод строки                          |
| `\t`          | Табуляция — отступ до следующей колонки |
| `\"`          | Двойная кавычка                         |
| `\\`          | Одна обратная косая черта               |

Обратная косая черта как бы говорит компилятору: «следующий символ особенный». Поэтому, чтобы напечатать саму косую черту, её приходится удваивать.

```c
#include <stdio.h>

int main(void) {
    printf("Он сказал: \"Привет!\"\n");
    printf("Путь: C:\\Users\\student\n");
    printf("Имя\tВозраст\n");
    printf("Анна\t20\n");
    return 0;
}
```

Вывод:

```text
Он сказал: "Привет!"
Путь: C:\Users\student
Имя	Возраст
Анна	20
```

Табуляция `\t` выравнивает текст по колонкам шириной обычно в 8 символов. Это удобно для простых таблиц.

## Функция `puts`

Для печати строки без всякого форматирования есть функция попроще — `puts` (put string). Она сама добавляет перевод строки в конце:

```c
#include <stdio.h>

int main(void) {
    puts("Первая строка");
    puts("Вторая строка");
    return 0;
}
```

Вывод:

```text
Первая строка
Вторая строка
```

`puts("текст")` делает то же, что `printf("текст\n")`. В этом курсе мы чаще используем `printf`, потому что он умеет печатать ещё и числа, — этому посвящён урок «Вывод на экран: printf».

## Регистр букв имеет значение

C различает заглавные и строчные буквы. `printf`, `Printf` и `PRINTF` — три разных имени, и только первое существует в стандартной библиотеке. То же касается `main`: функция `Main` не будет считаться точкой входа, и программа не соберётся.

## Частые ошибки

<CommonMistake title="Кавычки-ёлочки или одинарные кавычки">

Строка в C ограничивается только прямыми двойными кавычками `"`. Кавычки «ёлочки» или “лапки”, которые подставляют текстовые редакторы, компилятор не понимает. Одинарные кавычки `'A'` обозначают один символ, а не строку.

</CommonMistake>

<CommonMistake title="Прямая косая черта вместо обратной">

`/n` — это два обычных символа, косая черта и буква n, и они так и будут напечатаны. Перевод строки записывается через обратную косую черту: `\n`.

</CommonMistake>

<CommonMistake title="Точка с запятой после скобки функции">

`int main(void); {` — лишняя точка с запятой превращает начало функции в нечто другое, и компилятор выдаст ошибку. После `)` в заголовке функции сразу идёт `{`.

</CommonMistake>

<CommonMistake title="Забытая закрывающая скобка">

Каждой `{` нужна своя `}`. Аккуратные отступы помогают сразу видеть, какая скобка какую закрывает.

</CommonMistake>

Внимательно сравнивайте свой вывод с примером: каждый пробел и каждый перевод строки важны.

## Итоги

- `#include <stdio.h>` подключает функции ввода-вывода, в том числе `printf` и `puts`.
- Выполнение программы начинается с функции `main`; её тело заключено в фигурные скобки.
- `printf` печатает ровно переданный текст; перевод строки нужно ставить самому через `\n`. `puts` добавляет его автоматически.
- Управляющие последовательности `\n`, `\t`, `\"`, `\\` позволяют печатать специальные символы.
- Инструкции заканчиваются точкой с запятой, регистр букв в именах важен.
