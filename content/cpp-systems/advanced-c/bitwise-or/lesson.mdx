## Теория

Побитовое | устанавливает разряд, если он установлен хотя бы в одном операнде. Операция value | mask включает выбранные флаги, сохраняя остальные. Повторная установка той же маски не меняет результат: операция идемпотентна, что полезно для повторяемых команд настройки.

Это свойство относится к обычному числу, а не автоматически к аппаратному регистру: чтение или запись регистра может иметь специальные эффекты. В составном поле из нескольких битов OR недостаточно для замены значения, потому что старые единицы останутся. Сначала очистите маску поля через AND с инверсией, затем добавьте новое закодированное значение.

<Concept title="Ментальная модель">

OR включает переключатели, не трогая уже включённые соседние.

</Concept>

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>

int main(void) {
    printf("%u\n",8u | 1u);
    return 0;
}
```

## Разбор выполнения

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
9
```
