## Теория

Побитовое & оставляет единицу только там, где оба операнда имеют единицу. Поэтому value & mask выделяет выбранные признаки. Это не логическое &&: побитовая операция сохраняет набор разрядов, логическая даёт 0 или 1 и может не вычислить второй операнд.

Целочисленные продвижения происходят до операции, даже если исходное значение хранится в unsigned char. Для масок выбирайте беззнаковые типы и явно ограничивайте нужную ширину. Проверка наличия хотя бы одного бита выглядит как (value & mask) != 0, всех битов — (value & mask) == mask. При mask=0 вторая проверка истинна: пустой набор требований удовлетворён.

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>

int main(void) {
    printf("%u\n",14u & 3u);
    return 0;
}
```
