## Теория

Исключающее ИЛИ ^ устанавливает бит при различии соответствующих битов. XOR с маской переключает выбранные биты; повтор с той же маской возвращает исходное значение. XOR двух снимков состояния выделяет изменившиеся разряды, после чего AND с новым снимком выделяет включившиеся.

XOR всех байтов даёт простую контрольную сумму, но теряет информацию о порядке и не замечает многие парные изменения. Это не криптографическая защита и не замена CRC там, где важна надёжность обнаружения ошибок. XOR-swap хуже временной переменной для обычного обмена: он менее понятен и ошибочен при совпадении адресов.

<Concept title="Ментальная модель">

XOR — карта различий между двумя наборами битов.

</Concept>

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>

int main(void) {
    printf("%u\n",9u ^ 1u);
    return 0;
}
```

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

