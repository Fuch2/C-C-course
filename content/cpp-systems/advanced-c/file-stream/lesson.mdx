## Теория

FILE \* — указатель на библиотечный поток, содержащий состояние буферизации, позицию и индикаторы конца/ошибки. Это не номер файлового дескриптора. fopen может вернуть NULL; каждый успешно открытый поток должен закрываться ровно один раз. Ошибка записи иногда обнаруживается только при fflush или fclose из-за буферизации.

Режим rb выбирает бинарное чтение, wb создаёт или обнуляет файл. tmpfile создаёт временный бинарный поток для чтения и записи, автоматически удаляемый после закрытия. При переходе от записи к чтению в update-потоке необходима предусмотренная стандартом операция синхронизации или позиционирования. В наших тестах используется fseek к началу, результат которого также проверяется.

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>

int main(void) {
    FILE *f=tmpfile();if(!f)return 1;if(fputs("AB",f)==EOF || fseek(f,0,SEEK_SET)!=0){fclose(f);return 1;}int c=fgetc(f);if(fclose(f)!=0 || c==EOF)return 1;printf("%c\n",c);
    return 0;
}
```

## Разбор выполнения

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
A
```

Поток — курсор плюс буфер и состояние; указатель является дескриптором владения этим ресурсом. Проверьте, какая часть примера задаётся при трансляции, а какая выполняется в main. while (!feof(file)) проверяет прошлое состояние: конец становится известен после попытки чтения.
