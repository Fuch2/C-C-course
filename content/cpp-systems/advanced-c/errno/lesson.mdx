- Проверить решение на нормальных и граничных входах.

## Теория

errno — изменяемый индикатор ошибки, который имеет смысл только согласно контракту вызванной функции. Успешная функция не обязана обнулять старое значение. Поэтому для strtol перед вызовом устанавливают errno=0, после проверяют ERANGE, указатель конца и наличие хотя бы одной цифры.

Проверка end==start отличает отсутствие числа от корректного нуля, а остаток строки — частично разобранный токен от полного. Затем отдельно проверяется диапазон прикладной задачи. Не сравнивайте errno с придуманными числовыми константами: используйте имена из errno.h. Если последующие вызовы могут изменить errno, сохраните его сразу после обнаружения ошибки.

<Concept title="Ментальная модель">

errno — записка о конкретном неудачном вызове, а не общий датчик исправности программы.

</Concept>

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
int main(void) {
    char *end;errno=0;long value=strtol("12x",&end,10);printf("%ld %c\n",value,*end);
    return 0;
}
```

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
12 x
```
