- Проверить решение на нормальных и граничных входах.

## Теория

У static два важных применения. На уровне файла он даёт имени внутреннее связывание: другой объектный файл не обращается к нему как к внешнему символу. У локального объекта static задаёт статическую длительность хранения: объект существует всё выполнение, хотя имя доступно лишь внутри блока.

Локальный static инициализируется один раз, а не при каждом вызове. В C инициализатор такого объекта ограничен константными выражениями; это не произвольная динамическая инициализация C++. Скрытое изменяемое состояние усложняет повторный запуск теста и параллельные вызовы. Если нужно несколько независимых счётчиков, состояние лучше передать через struct, а не помещать в единственный static.

<Concept title="Ментальная модель">

Область видимости — где видно имя; длительность хранения — сколько живёт объект. Это разные координаты.

</Concept>

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>
static int count(void){static int value=10;return ++value;}
int main(void) {
    int first=count();int second=count();printf("%d %d\n",first,second);
    return 0;
}
```

## Разбор выполнения

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
11 12
```

Область видимости — где видно имя; длительность хранения — сколько живёт объект. Это разные координаты. Проверьте, какая часть примера задаётся при трансляции, а какая выполняется в main. Локальный static не создаёт отдельную копию на каждый вызов и не делает ++ атомарным.

## Краткое резюме

Область видимости — где видно имя; длительность хранения — сколько живёт объект. Это разные координаты. Для применения темы «static» фиксируйте контракт до написания кода. Локальный static не создаёт отдельную копию на каждый вызов и не делает ++ атомарным. Успешный пример дополняйте граничными тестами; правильный stdout не отменяет требований языка к типам, времени жизни и ресурсам.
