## Теория

Маска описывает расположение поля, а сдвиг — его позицию. Для чтения трёхбитового поля с позиции 2 вычисляют (value >> 2) & 7u. Для записи сначала очищают старое поле, затем добавляют новое: (value & ~(7u &lt;&lt; 2)) | (field &lt;&lt; 2). Значение field предварительно ограничивают диапазоном 0…7.

Разделите логическое значение поля и его закодированное представление. Функции encode/decode делают преобразование явным и удобным для тестов. Проверяйте, что соседние биты сохраняются, а записанное значение читается обратно. Не полагайтесь на порядок C bit-fields при описании переносимого протокола: явные маски дают контролируемый формат.

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>

int main(void) {
    unsigned packet=28;printf("%u\n",(packet >> 2) & 7u);
    return 0;
}
```
