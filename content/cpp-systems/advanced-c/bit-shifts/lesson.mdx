## Теория

Сдвиг перемещает разряды, но допустимость зависит от продвинутого типа левого операнда и величины сдвига. Отрицательная величина или величина не меньше ширины типа даёт неопределённое поведение. Для битовых алгоритмов используйте unsigned: его левый сдвиг имеет модульную семантику при допустимой величине; правый заполняет старшие разряды нулями.

Для signed правила строже: левый сдвиг отрицательного числа недопустим, а правый сдвиг отрицательного в C17 определяется реализацией. Литерал 1 имеет тип int, поэтому маску удобнее начинать с 1u. Проверка индекса должна предшествовать сдвигу: проверять результат уже поздно.

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>

int main(void) {
    printf("%u\n",32u >> 2);
    return 0;
}
```

## Практическое задание

Ввод k. Если k вне 0…7, выведите ОШИБКА. Иначе выведите 1u &lt;&lt; k.
