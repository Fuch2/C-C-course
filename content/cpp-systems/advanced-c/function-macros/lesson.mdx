## Цели обучения

- Разобраться в теме «Function-like macros» и её границах применимости.
- Объяснить типичную ошибку, а не только запомнить правильную запись.
- Проверить решение на нормальных и граничных входах.

## Теория

Функциональноподобный макрос распознаётся по скобкам непосредственно после имени в определении. Параметры заменяются токенами аргументов. Скобки вокруг каждого аргумента и всего выражения защищают приоритет, но не предотвращают повторное вычисление. SQUARE(x) с двумя употреблениями x дважды подставляет выражение аргумента.

Обычная функция вычисляет каждый аргумент один раз до входа в тело. Поэтому арифметическую операцию с известным типом лучше выразить static inline функцией. Макрос полезен там, где требуется обработка токенов, например строкификация # или склейка ##. Это отдельный уровень абстракции, и его не следует смешивать с обычными вычислениями без необходимости.

<Concept title="Ментальная модель">

Макрос копирует написанное выражение; функция получает уже вычисленное значение.

</Concept>

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>
#define TWICE(x) ((x)+(x))
int main(void) {
    int sample=4;printf("%d\n",TWICE(sample+1));
    return 0;
}
```

## Разбор выполнения

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
10
```

Макрос копирует написанное выражение; функция получает уже вычисленное значение. Проверьте, какая часть примера задаётся при трансляции, а какая выполняется в main. Даже ((x)\*(x)) опасен для SQUARE(i++): скобки не задают последовательность побочных эффектов.

<CommonMistake title="Типичная ошибка">

Даже ((x)\*(x)) опасен для SQUARE(i++): скобки не задают последовательность побочных эффектов.

</CommonMistake>

## Краткое резюме

Макрос копирует написанное выражение; функция получает уже вычисленное значение. Для применения темы «Function-like macros» фиксируйте контракт до написания кода. Даже ((x)\*(x)) опасен для SQUARE(i++): скобки не задают последовательность побочных эффектов. Успешный пример дополняйте граничными тестами; правильный stdout не отменяет требований языка к типам, времени жизни и ресурсам.
