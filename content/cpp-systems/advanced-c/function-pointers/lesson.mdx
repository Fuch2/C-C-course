- Разобраться в теме «Function pointers» и её границах применимости.
- Объяснить типичную ошибку, а не только запомнить правильную запись.
- Проверить решение на нормальных и граничных входах.

## Теория

Указатель на функцию содержит возможность вызвать функцию совместимого типа. В записи int (\*operation)(int, int) скобки отделяют указатель от функции, возвращающей указатель. typedef может дать читаемое имя типу операции. Вызов допустим только при совместимости возвращаемого типа и параметров.

Таблица функций заменяет длинную цепочку выбора, когда обработчики имеют один контракт. Индекс таблицы всё равно нужно проверять, а NULL нельзя вызывать. Не храните указатели на функции в void \* как переносимый C: гарантии преобразования объектных указателей не распространяются автоматически на функции. Хороший интерфейс фиксирует не только тип, но и допустимые диапазоны, эффекты и правила ошибок.

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>
static int negate(int x){return -x;}
int main(void) {
    int (*operation)(int)=negate;printf("%d\n",operation(7));
    return 0;
}
```

## Разбор выполнения

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
-7
```

Таблица диспетчеризации — набор одинаковых разъёмов с разными обработчиками. Проверьте, какая часть примера задаётся при трансляции, а какая выполняется в main. Cast несовместимого указателя не исправляет несовместимость вызова.
