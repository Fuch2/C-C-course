## Теория

void _ переносит адрес объекта без информации о его конкретном типе. Преобразование объектного указателя в void _ и обратно к исходному типу сохраняет возможность доступа. Для разыменования нужен подходящий тип, корректное выравнивание и живой объект. Арифметика void _ не входит в стандарт C17; для обхода представления используют unsigned char _.

Универсальный API обычно передаёт вместе с адресом размер, количество элементов и функцию обработки. Потерянная типовая информация не исчезает из требований языка: её должен восстановить контракт. memcpy копирует представление между неперекрывающимися диапазонами, memmove допускает перекрытие. Они не проверяют, достаточно ли памяти выделено на принимающей стороне.

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>

int main(void) {
    int value=9;void *opaque=&value;int *restored=opaque;printf("%d\n",*restored);
    return 0;
}
```

## Разбор выполнения

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
9
```
