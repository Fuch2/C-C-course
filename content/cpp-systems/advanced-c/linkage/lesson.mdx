## Теория

Связывание определяет, обозначают ли одинаковые имена один объект или функцию. Внешнее связывание объединяет подходящие объявления между единицами трансляции. Внутреннее ограничивает имя одной единицей. Локальные автоматические переменные не имеют связывания: одинаковое имя в двух функциях не объединяет их.

Линкер работает с символами, но совместимость типов — обязанность программы. Сообщение undefined reference обычно означает отсутствие нужного определения в переданных объектных файлах; multiple definition — конкурирующие определения. Не исправляйте их случайной сменой static: сначала решите, должно ли состояние быть общим. Файловый const в C по умолчанию не получает внутреннее связывание, в отличие от привычного правила C++.

<Concept title="Ментальная модель">

Связывание — правило идентичности имён; одинаковая надпись ещё не означает одну сущность.

</Concept>

## Запускаемый пример

Пример не требует stdin. Выполните его кнопкой «Запустить», затем измените одно значение и предскажите новый результат до повторного запуска.

```c
#include <stdio.h>
static int local_value(void){return 6;}
int main(void) {
    printf("%d\n",local_value());
    return 0;
}
```

## Разбор выполнения

Сначала создаются объекты и выбирается операция, затем вычисляется аргумент вывода. Ожидаемый stdout:

```text
6
```
