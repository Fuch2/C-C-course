## Из чего состоит объект

В «Основах C» вы узнали, что у переменной есть адрес — номер её первого байта. Теперь посмотрим внутрь: любая переменная, массив или структура — это **непрерывная последовательность байтов**. Число `int` — четыре байта подряд, `double` — восемь, массив из десяти `int` — сорок байтов без промежутков.

Знать байтовое устройство нужно, чтобы:

- правильно считать размеры при выделении памяти (`malloc` принимает именно байты);
- понимать, что делают `memcpy`, `fread`, `fwrite` и сетевые функции — они копируют байты, а не «числа»;
- находить ошибки, когда программа читает или пишет не тот байт.

## Размер объекта: `sizeof`

Оператор `sizeof` возвращает размер типа или выражения в байтах. Результат имеет тип `size_t` — беззнаковое целое, которое печатают спецификатором `%zu`:

```c
#include <stdio.h>

int main(void) {
    printf("char        %zu\n", sizeof(char));
    printf("short       %zu\n", sizeof(short));
    printf("int         %zu\n", sizeof(int));
    printf("long long   %zu\n", sizeof(long long));
    printf("float       %zu\n", sizeof(float));
    printf("double      %zu\n", sizeof(double));
    printf("int *       %zu\n", sizeof(int *));
    printf("double *    %zu\n", sizeof(double *));
    return 0;
}
```

Вывод:

```text
char        1
short       2
int         4
long long   8
float       4
double      8
int *       8
double *    8
```

Это вывод для 64-битного Linux, на котором работает проверка задач. Стандарт C гарантирует только, что `sizeof(char)` равен 1, а остальные размеры **не меньше** определённых минимумов: `int` может быть и 2 байта на маленьком микроконтроллере. Поэтому в коде никогда не пишут «4» вместо `sizeof(int)`.

Обратите внимание на указатели: `int *` и `double *` одного размера. Указатель хранит адрес, а адрес на этой системе всегда 8 байтов — неважно, на что он указывает.

### `sizeof` от выражения

`sizeof` можно применить к выражению — тогда размер берётся по его типу, а само выражение **не вычисляется**:

```c
#include <stdio.h>

int main(void) {
    double prices[12];
    int count = 0;
    printf("%zu\n", sizeof prices);                       // весь массив
    printf("%zu\n", sizeof prices[0]);                    // один элемент
    printf("%zu\n", sizeof prices / sizeof prices[0]);    // число элементов
    printf("%zu\n", sizeof count++);                      // count++ не выполнится!
    printf("%d\n", count);
    return 0;
}
```

Вывод:

```text
96
8
12
4
0
```

Запись `sizeof prices / sizeof prices[0]` — стандартный способ узнать длину массива. Она работает только для **настоящего массива**: если `prices` передан в функцию, там он уже указатель, и `sizeof` вернёт 8.

## Байты лежат подряд

Адреса элементов массива отличаются ровно на размер элемента. Чтобы увидеть расстояние в байтах, приведём адреса к `char *` — указателю на байты — и вычтем:

```c
#include <stdio.h>

int main(void) {
    int ints[4];
    double reals[4];
    printf("%td\n", (char *)&ints[1] - (char *)&ints[0]);
    printf("%td\n", (char *)&ints[3] - (char *)&ints[0]);
    printf("%td\n", (char *)&reals[3] - (char *)&reals[0]);
    printf("%td\n", &reals[3] - &reals[0]);      // без приведения — в элементах
    return 0;
}
```

Вывод:

```text
4
12
24
3
```

Разность указателей одного типа считается **в элементах** этого типа: `&reals[3] - &reals[0]` равно 3. Разность указателей на `char` — в байтах. Тип разности — `ptrdiff_t`, спецификатор — `%td`.

## Заглядываем внутрь: `unsigned char *`

Язык C разрешает рассматривать **любой** объект как массив байтов через указатель на `unsigned char`. Это единственный тип, через который можно законно читать байты чего угодно:

```c
#include <stdio.h>

int main(void) {
    int value = 0x12345678;
    const unsigned char *bytes = (const unsigned char *)&value;
    for (size_t i = 0; i < sizeof value; i++) {
        printf("%02x ", bytes[i]);
    }
    printf("\n");
    return 0;
}
```

Вывод:

```text
78 56 34 12
```

Число записано в шестнадцатеричной системе: каждые две цифры — один байт (`0x12`, `0x34`, `0x56`, `0x78`). В памяти байты лежат **в обратном порядке**: первым — младший байт `0x78`. Такой порядок называется little-endian, и его используют процессоры x86 и ARM в обычном режиме. Подробно о порядке байтов — в уроке «Endianness».

Спецификатор `%02x` печатает число в шестнадцатеричном виде минимум двумя цифрами с ведущим нулём.

### Почему именно `unsigned`

Тип `char` может быть знаковым. Байт `0xff` через `char` прочитается как `-1`, а `%02x` напечатает `ffffffff`. С `unsigned char` каждый байт — число от 0 до 255, как и положено:

```c
#include <stdio.h>

int main(void) {
    int minus_one = -1;
    int big = 300;
    const unsigned char *a = (const unsigned char *)&minus_one;
    const unsigned char *b = (const unsigned char *)&big;
    printf("%d %d %d %d\n", a[0], a[1], a[2], a[3]);
    printf("%d %d %d %d\n", b[0], b[1], b[2], b[3]);
    return 0;
}
```

Вывод:

```text
255 255 255 255
44 1 0 0
```

`-1` в дополнительном коде — все биты равны единице. `300 = 1 · 256 + 44`: младший байт 44, следующий 1.

## Байты числа с плавающей точкой

`double` устроен совсем иначе, чем целое: знак, порядок и мантисса (стандарт IEEE 754). Его байты мало похожи на десятичную запись:

```c
#include <stdio.h>

int main(void) {
    double one = 1.0;
    double minus_zero = -0.0;
    const unsigned char *p = (const unsigned char *)&one;
    const unsigned char *q = (const unsigned char *)&minus_zero;
    for (size_t i = 0; i < sizeof one; i++) {
        printf("%02x ", p[i]);
    }
    printf("\n");
    for (size_t i = 0; i < sizeof minus_zero; i++) {
        printf("%02x ", q[i]);
    }
    printf("\n%d\n", one == 1 && minus_zero == 0.0);
    return 0;
}
```

Вывод:

```text
00 00 00 00 00 00 f0 3f
00 00 00 00 00 00 00 80
1
```

Интересный факт: `-0.0 == 0.0` истинно, хотя байты разные (у `-0.0` установлен бит знака). Значит, **равенство значений не означает равенства байтов** — это пригодится, когда будем сравнивать структуры.

## `sizeof` структуры — не сумма полей

```c
#include <stdio.h>

struct Sample {
    char tag;
    int value;
};

int main(void) {
    printf("%zu %zu\n", sizeof(char) + sizeof(int), sizeof(struct Sample));
    return 0;
}
```

Вывод:

```text
5 8
```

Компилятор вставил между полями 3 **байта выравнивания**, чтобы `value` начиналось с адреса, кратного 4. Почему так — в уроках «Alignment» и «Padding». Вывод на сейчас: размер структуры всегда узнавайте через `sizeof`, а не складывайте поля вручную.

<Concept title="Объект = байты + тип">

Байты в памяти сами по себе ничего не значат. Четыре байта `00 00 80 3f` — это число `1065353216`, если читать их как `int`, и `1.0`, если как `float`. Смысл байтам придаёт **тип**, через который вы к ним обращаетесь. Поэтому тип указателя так важен.

</Concept>

## Частые ошибки

<CommonMistake title="Числа вместо sizeof">

`malloc(n * 4)` для массива `int` сломается на системе, где `int` — 2 или 8 байтов, и молча испортится, если тип массива поменяют на `double`. Пишите `malloc(n * sizeof *array)` — размер следует за типом автоматически.

</CommonMistake>

<CommonMistake title="sizeof от указателя вместо массива">

```c
void print_all(int a[]) {
    size_t n = sizeof a / sizeof a[0];   // 8 / 4 = 2, а не длина массива
}
```

Параметр-массив — это указатель. Длину массива передавайте в функцию отдельным параметром.

</CommonMistake>

<CommonMistake title="Байты через char">

`char *p = (char *)&x; printf("%02x", p[0]);` печатает `ffffffff` для байта `0xff`, если `char` знаковый. Для работы с байтами используйте `unsigned char`.

</CommonMistake>

<CommonMistake title="Неверный спецификатор для size_t">

`printf("%d", sizeof x)` — несоответствие типов: `%d` ждёт `int`, а `sizeof` даёт `size_t`. Компилятор предупредит. Правильно: `%zu`.

</CommonMistake>

## Практика

1. **Сколько байтов** — вычислить размер массивов разных типов через `sizeof`.
2. **Байты числа** — напечатать байты `unsigned int` в порядке их расположения в памяти.
3. **Единичные биты в представлении** — обойти байты `long long` и подсчитать биты.
4. **Равные значения, разные байты** — сравнить два `double` по значению и побайтно.

## Итоги

- Любой объект — непрерывная последовательность байтов; `sizeof` даёт её длину в `size_t` (печать — `%zu`).
- `sizeof(char)` всегда 1; размеры остальных типов зависят от платформы — не подставляйте числа вручную.
- `sizeof массив / sizeof массив[0]` — длина массива, но только там, где массив не превратился в указатель.
- Любой объект можно читать по байтам через `const unsigned char *`.
- Разность указателей считается в элементах; через `char *` — в байтах.
- Размер структуры может быть больше суммы полей из-за выравнивания; равенство значений не гарантирует равенства байтов.
