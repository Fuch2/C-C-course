## Когда функция должна изменить указатель

Чтобы функция изменила переменную `int` вызывающего кода, ей передают адрес: `int *`. А если изменить нужно **сам указатель** — например, функция выделяет память и должна сообщить адрес нового блока? Тот же принцип: нужен адрес указателя, то есть **указатель на указатель** — `int **`.

Посмотрим, что получится без него:

```c
#include <stdio.h>
#include <stdlib.h>

void allocate_wrong(int *p, int n) {
    p = malloc(n * sizeof *p);     // меняется копия p в кадре функции
    if (p != NULL) {
        p[0] = 42;
    }
    free(p);                        // иначе блок утечёт: адрес знает только копия
}

int main(void) {
    int *data = NULL;
    allocate_wrong(data, 3);
    printf("%s\n", data == NULL ? "data всё ещё NULL" : "data получил блок");
    return 0;
}
```

Вывод:

```text
data всё ещё NULL
```

Параметр `p` — копия значения `data`. Присваивание `p = malloc(...)` меняет копию; `data` в `main` остаётся `NULL`. Без `free` внутри функции блок к тому же утёк бы: его адрес знала только исчезнувшая копия.

## `int **`: адрес указателя

```c
#include <stdio.h>
#include <stdlib.h>

// Выделяет массив 1, 2, …, n и записывает его адрес в *out. Возвращает 0 при успехе.
int make_sequence(int **out, int n) {
    int *block = malloc(n * sizeof *block);
    if (block == NULL) {
        return -1;
    }
    for (int i = 0; i < n; i++) {
        block[i] = i + 1;
    }
    *out = block;               // запись в указатель вызывающего кода
    return 0;
}

int main(void) {
    int *data = NULL;
    if (make_sequence(&data, 4) != 0) {
        return 1;
    }
    printf("%d %d\n", data[0], data[3]);
    free(data);
    return 0;
}
```

Вывод:

```text
1 4
```

`&data` имеет тип `int **` — адрес переменной-указателя. Внутри функции `*out` — это сама переменная `data` из `main`, поэтому `*out = block` меняет её.

<MemoryDiagram title="Перед return в make_sequence (адреса условные)">

| Объект               | Адрес | Значение                     |
| -------------------- | ----- | ---------------------------- |
| `data` (кадр main)   | 2000  | 5000 — записано через `*out` |
| `out` (кадр функции) | 3000  | 2000 — адрес `data`          |
| блок в куче          | 5000  | 1, 2, 3, 4                   |

</MemoryDiagram>

Три уровня: `out` указывает на `data`, `data` указывает на блок. `out` — тип `int **`, `*out` — `int *`, `**out` — `int` (первый элемент блока).

Такой интерфейс — «функция возвращает код ошибки, а результат пишет через выходной параметр» — очень распространён в C: так устроены `getline`, `strtol` (через `char **endptr`), многие системные API.

## Курсор: функция двигает чужой указатель

Указатель на указатель удобен для разбора текста: функция читает очередной элемент и **сдвигает курсор** вызывающего кода.

```c
#include <stdio.h>

// Читает число с позиции *cursor и сдвигает курсор за него и за запятую.
int read_number(const char **cursor) {
    int value = 0;
    while (**cursor >= '0' && **cursor <= '9') {
        value = value * 10 + (**cursor - '0');
        (*cursor)++;                // сдвигаем указатель вызывающего кода
    }
    if (**cursor == ',') {
        (*cursor)++;
    }
    return value;
}

int main(void) {
    const char *text = "12,7,300";
    const char *pos = text;
    int sum = 0;
    while (*pos != '\0') {
        sum += read_number(&pos);
    }
    printf("%d %td\n", sum, pos - text);
    return 0;
}
```

Вывод:

```text
319 8
```

- `*cursor` — текущий указатель вызывающего кода (`pos`);
- `**cursor` — символ, на который он указывает;
- `(*cursor)++` — сдвиг самого `pos`. Скобки обязательны: `*cursor++` сдвинул бы локальную копию `cursor`.

Стандартная функция `strtol` работает так же: через параметр `char **endptr` она сообщает, где закончилось число.

## Массив строк — это `char **`

Массив указателей на строки при передаче в функцию сводится к указателю на первый элемент — к `char **`. Именно так `main` получает аргументы командной строки: `int main(int argc, char **argv)`.

Важное преимущество массива указателей: чтобы переставить строки, достаточно переставить **указатели** — 8 байтов, — а сами символы остаются на месте:

```c
#include <stdio.h>
#include <string.h>

void sort_words(const char **words, int n) {
    for (int i = 1; i < n; i++) {                      // сортировка вставками
        const char *current = words[i];
        int j = i - 1;
        while (j >= 0 && strcmp(words[j], current) > 0) {
            words[j + 1] = words[j];
            j--;
        }
        words[j + 1] = current;
    }
}

int main(void) {
    const char *words[] = {"pear", "apple", "plum", "fig"};
    sort_words(words, 4);
    for (int i = 0; i < 4; i++) {
        printf("%s ", words[i]);
    }
    printf("\n");
    return 0;
}
```

Вывод:

```text
apple fig pear plum
```

Литералы `"pear"`, `"apple"` не сдвинулись ни на байт — изменился только порядок указателей в массиве `words`.

## Динамический массив строк

Если число строк известно только во время работы, массив указателей тоже выделяют в куче — получается `char **`, где каждый элемент указывает на свой блок:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void) {
    const char *source[] = {"alpha", "beta", "gamma"};
    int n = 3;
    char **copies = malloc(n * sizeof *copies);        // массив из n указателей
    if (copies == NULL) {
        return 1;
    }
    for (int i = 0; i < n; i++) {
        copies[i] = malloc(strlen(source[i]) + 1);    // + 1 для '\0'
        if (copies[i] == NULL) {
            return 1;
        }
        strcpy(copies[i], source[i]);
    }
    copies[1][0] = 'B';                                 // копии можно менять
    printf("%s %s %s\n", copies[0], copies[1], copies[2]);
    for (int i = 0; i < n; i++) {
        free(copies[i]);                               // сначала строки
    }
    free(copies);                                      // затем массив указателей
    return 0;
}
```

Вывод:

```text
alpha Beta gamma
```

Порядок освобождения обратен порядку выделения: если сначала освободить `copies`, адреса строк будут потеряны (их больше нельзя читать из освобождённого блока), и строки утекут.

<Concept title="Сколько звёздочек">

Считайте уровни: `T` — значение, `T *` — где лежит значение, `T **` — где лежит указатель на значение. Функции нужно на одну звёздочку больше, чем у объекта, который она должна изменить: чтобы изменить `int` — `int *`, чтобы изменить `int *` — `int **`.

</Concept>

## Частые ошибки

<CommonMistake title="Забытый & при вызове">

`make_sequence(data, 4)` вместо `make_sequence(&data, 4)` — передан `int *` вместо `int **`. Компилятор предупредит `incompatible pointer type`; запуск такой программы запишет адрес блока куда попало.

</CommonMistake>

<CommonMistake title="*p++ вместо (*p)++">

В функции-курсоре `*cursor++` сдвигает локальный `cursor` (указатель на указатель), а не указатель вызывающего кода. Нужно `(*cursor)++`.

</CommonMistake>

<CommonMistake title="Освобождён только внешний массив">

`free(lines)` для `char **lines` с отдельно выделенными строками освобождает лишь массив указателей. Сначала освободите каждую `lines[i]`, затем `lines`.

</CommonMistake>

## Практика

1. **Найти и изменить** — функция сообщает адрес найденного элемента через `int **`.
2. **Разбор чисел курсором** — функция двигает указатель вызывающего кода по строке.
3. **Сортировка указателей** — переставляются адреса, а не символы.
4. **Массив через выходной параметр** — выделение и освобождение на всех ветках, включая ошибки ввода.

## Итоги

- Чтобы функция изменила указатель вызывающего кода, ей передают его адрес — указатель на указатель (`int **`).
- Для `int **pp`: `*pp` — указатель вызывающего кода, `**pp` — значение, на которое он указывает.
- Шаблон «код ошибки + результат через выходной параметр» — основной способ вернуть выделенную память вместе со статусом.
- Курсор `const char **` позволяет функции читать текст и сдвигать позицию вызывающего кода; сдвиг — `(*cursor)++`.
- Массив строк передаётся как `char **`; сортируют указатели, а не символы.
- Динамический массив строк освобождают в обратном порядке: сначала строки, затем массив указателей.
