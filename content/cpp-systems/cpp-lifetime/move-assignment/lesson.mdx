## Заменить, забрав чужое

**Перемещающее присваивание** `T &operator=(T &&other) noexcept` вызывается, когда **существующему** объекту присваивают rvalue: временный объект или результат `std::move`. По сравнению с перемещающим конструктором у него на одну заботу больше: у объекта уже есть свой ресурс, и его нужно освободить.

Порядок работы:

1. освободить собственный ресурс;
2. забрать ресурс `other`;
3. оставить `other` пустым;
4. вернуть `*this`.

И всё это должно корректно работать при **самоперемещении** `a = std::move(a)` — оно редко пишется явно, но возникает в обобщённом коде (например, в алгоритмах перестановки).

```cpp
#include <algorithm>
#include <cstddef>
#include <print>
#include <utility>

class Buffer {
public:
    Buffer(std::size_t size, int fill) : size_(size), data_(new int[size]) {
        std::fill_n(data_, size_, fill);
    }
    Buffer(Buffer &&other) noexcept
        : size_(std::exchange(other.size_, 0)), data_(std::exchange(other.data_, nullptr)) {}
    Buffer &operator=(Buffer &&other) noexcept {
        if (this != &other) {
            delete[] data_;
            size_ = std::exchange(other.size_, 0);
            data_ = std::exchange(other.data_, nullptr);
        }
        return *this;
    }
    Buffer(const Buffer &) = delete;
    Buffer &operator=(const Buffer &) = delete;
    ~Buffer() {
        delete[] data_;
    }

    std::size_t size() const {
        return size_;
    }

private:
    std::size_t size_;
    int *data_;
};

int main() {
    Buffer a(10, 1);
    Buffer b(20, 2);
    b = std::move(a);
    Buffer &same = b;
    b = std::move(same);
    a = Buffer(5, 3);
    std::println("{} {}", a.size(), b.size());
    return 0;
}
```

Вывод:

```text
5 10
```

`b = std::move(a)` освободил 20 чисел `b` и забрал 10 чисел `a`. Самоперемещение не сделало ничего благодаря проверке. `a = Buffer(5, 3)` — присваивание временного объекта: его буфер переходит к `a`, а сам временный умирает пустым.

```text
до:     a.data_ ──▶ [1 … 1] (10)       b.data_ ──▶ [2 … 2] (20)
шаг 1:  delete[] b.data_                 [2 … 2] освобождён
шаг 2:  b.data_ ──▶ [1 … 1] (10)        a.data_ = nullptr, a.size_ = 0
```

## Где работает перемещающее присваивание

Вы редко пишете `a = std::move(b)` сами, но стандартная библиотека делает это постоянно:

- `vector::erase` сдвигает элементы после удалённого **перемещающим присваиванием**;
- `std::ranges::sort`, `std::ranges::remove_if`, `std::swap` переставляют элементы перемещениями;
- присваивание временного результата функции: `text = load_file(path);`.

```cpp
#include <print>
#include <string>
#include <utility>
#include <vector>

struct Tracked {
    static inline int move_assigns = 0;
    std::string v;
    explicit Tracked(std::string s) : v(std::move(s)) {}
    Tracked(Tracked &&) noexcept = default;
    Tracked &operator=(Tracked &&other) noexcept {
        v = std::move(other.v);
        ++move_assigns;
        return *this;
    }
};

int main() {
    std::vector<Tracked> items;
    for (const char *s : {"a", "b", "c", "d", "e"}) {
        items.emplace_back(s);
    }
    items.erase(items.begin() + 1);
    std::println("после erase: {} перемещающих присваиваний", Tracked::move_assigns);
    std::string rest;
    for (const Tracked &t : items) {
        rest += t.v;
    }
    std::println("{}", rest);
    return 0;
}
```

Вывод:

```text
после erase: 3 перемещающих присваиваний
acde
```

Удаление второго элемента из пяти сдвинуло три следующих на место левее — три перемещающих присваивания. Без перемещения каждый сдвиг копировал бы строку целиком.

## Один оператор на оба случая

Есть приём, который заменяет копирующее и перемещающее присваивание одним оператором: принять аргумент **по значению** и обменяться с ним.

```cpp
Buffer &operator=(Buffer other) noexcept {
    std::swap(size_, other.size_);
    std::swap(data_, other.data_);
    return *this;   // старый буфер освободит деструктор other
}
```

Если справа lvalue, параметр создаётся конструктором копирования; если rvalue — перемещающим. Самоприсваивание безопасно, исключения при копировании происходят до изменения `*this`. Цена — одно лишнее перемещение по сравнению с отдельными операторами, а для копирования теряется возможность переиспользовать уже выделенную память. Для большинства классов это приемлемо.

<Concept title="Перемещающее присваивание">

`T &operator=(T &&other) noexcept` освобождает собственный ресурс, забирает ресурс `other`, оставляет `other` пустым и возвращает `*this`; при самоперемещении объект должен остаться корректным. Его используют `vector::erase`, алгоритмы перестановки и присваивание временных значений. Вариант «по значению и обмен» объединяет копирующее и перемещающее присваивание в одном операторе.

</Concept>

## Частые ошибки

<CommonMistake title="Забыли освободить свой ресурс">

`data_ = std::exchange(other.data_, nullptr);` без `delete[] data_` — старый буфер теряется. LeakSanitizer сообщит об утечке при завершении.

</CommonMistake>

<CommonMistake title="Самоперемещение уничтожает данные">

Без проверки `this != &other` порядок «удалить своё, забрать чужое» при `a = std::move(a)` удалит буфер и заберёт уже удалённый указатель. Проверяйте или используйте обмен.

</CommonMistake>

<CommonMistake title="Перемещающее присваивание без noexcept">

Контейнеры и алгоритмы выбирают более медленные и безопасные пути, если перемещение может бросить. Перенос указателей не бросает — объявляйте `noexcept`.

</CommonMistake>

## Практика

1. **Слоты** — полный набор присваиваний для класса-владельца.
2. **Удаление со сдвигом** — сколько перемещающих присваиваний делают `erase` и `erase_if`.
3. **Найди ошибку: потерянный буфер** — присваивание, которое не освобождает своё.
4. **Дескрипторы** — перемещаемый некопируемый владелец, который закрывает свой ресурс при замене.

## Итоги

- Перемещающее присваивание освобождает своё, забирает чужое и обнуляет источник.
- Самоперемещение должно оставлять объект корректным: проверка адреса или обмен.
- `vector::erase`, сортировка и `std::swap` работают перемещающими присваиваниями.
- Присваивание «по значению и обмен» объединяет копирующую и перемещающую версии.
- Перемещающее присваивание объявляют `noexcept`.
