## std::move ничего не перемещает

Вы уже знаете, что `std::move(x)` — всего лишь приведение к rvalue-ссылке. Вся её реализация в стандартной библиотеке умещается в одну строку:

```cpp
template <class T>
constexpr std::remove_reference_t<T> &&move(T &&t) noexcept {
    return static_cast<std::remove_reference_t<T> &&>(t);
}
```

Перемещает конструктор или оператор присваивания, который выбран благодаря этому приведению. Поэтому `std::move` — это **обещание**: «после этой строки содержимое переменной мне не нужно». Компилятор верит обещанию на слово и не проверяет его. Этот урок — о том, где такое обещание давать.

## Где std::move нужен

**Последнее использование переменной.** Если значение больше не понадобится, его можно отдать — в контейнер, в поле, в другую функцию:

```cpp
#include <print>
#include <string>
#include <string_view>
#include <utility>
#include <vector>

int main() {
    std::vector<std::string> lines;
    std::string current;
    for (const char *word : {"раз", "два", "|", "три", "|"}) {
        if (std::string_view(word) == "|") {
            lines.push_back(std::move(current));
            current.clear();
        } else {
            current += current.empty() ? "" : " ";
            current += word;
        }
    }
    std::println("{} строки: «{}», «{}»", lines.size(), lines[0], lines[1]);
    return 0;
}
```

Вывод:

```text
2 строки: «раз два», «три»
```

Строка `current` отдаёт буфер вектору, а `clear()` возвращает её в известное пустое состояние — метод без предусловий можно вызывать после перемещения.

**Параметр-приёмник.** Если функция или конструктор **сохраняет** аргумент, его принимают по значению и перемещают на место хранения. Тогда вызывающий платит ровно одну копию, если передал переменную, и ни одной, если передал временное значение:

```cpp
#include <print>
#include <string>
#include <utility>

struct Tracker {
    std::string v;
    explicit Tracker(std::string s) : v(std::move(s)) {}
    Tracker(const Tracker &o) : v(o.v) {
        std::println("копия");
    }
    Tracker(Tracker &&o) noexcept : v(std::move(o.v)) {
        std::println("перемещение");
    }
};

class Person {
public:
    explicit Person(Tracker name) : name_(std::move(name)) {}

private:
    Tracker name_;
};

int main() {
    Tracker ada("Ада");
    std::println("— из переменной:");
    const Person a(ada);
    std::println("— из временного:");
    const Person b(Tracker("Алан"));
    std::println("— с std::move:");
    const Person c(std::move(ada));
    return 0;
}
```

Вывод:

```text
— из переменной:
копия
перемещение
— из временного:
перемещение
— с std::move:
перемещение
перемещение
```

Одна сигнатура вместо двух перегрузок `const Tracker &` и `Tracker &&` — ценой одного дешёвого перемещения. Для строк, векторов и других типов с быстрым перемещением это обычный современный стиль.

**Перенос диапазона.** Алгоритм `std::ranges::move` перемещает элементы, а представление `std::views::as_rvalue` (C++23) превращает каждый элемент в rvalue — например, чтобы собрать новый контейнер перемещением:

```cpp
#include <print>
#include <ranges>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> source{"длинная строка номер один", "длинная строка номер два"};
    const char *first = source[0].data();
    auto target = source | std::views::as_rvalue | std::ranges::to<std::vector>();
    std::println("{} {}", target.size(), target[0].data() == first);
    source.clear();
    return 0;
}
```

Вывод:

```text
2 true
```

Буфер первой строки переехал в `target` без копирования символов. Строки в `source` остались перемещёнными — их надёжнее сразу удалить.

## Где std::move вреден или бесполезен

| Код                                         | Что не так                                        |
| ------------------------------------------- | ------------------------------------------------- |
| `return std::move(local);`                  | мешает NRVO; `return local;` и так перемещает     |
| `std::move(константа)`                      | выбирается копирование: из `const` забрать нельзя |
| `std::move(x)`, а потом `x` снова читается  | содержимое `x` не определено                      |
| `std::move` для `int`, `double`, указателей | перемещение равно копированию — только шум        |
| `std::move` в аргумент `const T &`          | ничего не меняет: функция всё равно не забирает   |

<Concept title="std::move">

`std::move` — приведение к rvalue-ссылке, обещание не использовать содержимое переменной дальше; перемещает выбранный благодаря ему конструктор или оператор. Его используют при последнем использовании переменной, для параметров-приёмников (принять по значению, переместить в поле) и для переноса диапазонов (`std::ranges::move`, `std::views::as_rvalue`). Он вреден в `return` локальной переменной, бесполезен для константных объектов и простых типов, опасен, если переменную читают после него.

</Concept>

## Частые ошибки

<CommonMistake title="Перемещение элемента, который ещё нужен">

`best = std::move(words[i]);` внутри поиска оставляет в векторе пустую строку. Перемещайте только то, что действительно отдаёте.

</CommonMistake>

<CommonMistake title="Перемещение из константы">

`const std::vector<int> data = load(); store(std::move(data));` — молчаливая копия. Если объект нужно отдать, он не должен быть `const`.

</CommonMistake>

<CommonMistake title="std::move в return">

`return std::move(result);` — пессимизация. Пишите `return result;`; `-Wpessimizing-move` предупреждает о таком коде.

</CommonMistake>

## Практика

1. **Параметр-приёмник** — сколько копий стоит каждая форма вызова.
2. **Список дел** — перенос строк между контейнерами.
3. **Найди ошибку: пустое слово** — перемещение элемента, который ещё нужен.
4. **Слияние без копий** — алгоритмы, которые только перемещают.

## Итоги

- `std::move` — приведение типа и обещание не использовать содержимое; перемещает конструктор или присваивание.
- Используйте его при последнем использовании переменной и для параметров-приёмников.
- Диапазоны переносят `std::ranges::move` и `std::views::as_rvalue`.
- Не пишите `return std::move(local)`, не перемещайте константы и простые типы.
- После перемещения переменную либо уничтожают, либо присваивают ей новое значение.
