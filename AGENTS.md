# Разработка «Код / Система»

Все пользовательские тексты и учебные материалы — на русском. Код и идентификаторы — на английском. Контент авторский; внешняя документация служит для проверки технических фактов.

Основа платформы: один локальный пользователь без регистрации, девять опубликованных модулей с 226 уроками, графитовая тёмная тема со спокойным оливковым акцентом. Используйте канонические маршруты `/course/[courseId]`, `/lesson/[lessonId]`, `/playground`. Файловый движок, схемы, Markdown/MDX, поиск, grading и прогресс реализованы.

Перед крупным этапом прочитайте текущие файлы, обновите `TODO.md` и запишите технический план. После этапа выполните `npm run format:check`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:integration` и `npm run build`. Исправьте ошибки перед продолжением.

Строгий TypeScript; границы API проверяются Zod. Ответы публичного API не содержат скрытые тесты, правильные ответы на quiz или решения до явного запроса разбора. Прогресс хранится в SQLite через Prisma.

Никогда не запускайте присланный пользователем или учебный C/C++ код на хосте либо в веб-сервисе. Компиляция и выполнение разрешены только через `apps/runner` в ограниченном Docker-контейнере. Не ослабляйте ограничения для прохождения тестов. Docker socket доступен только доверенному runner.

Контроль времени и выводов остаётся вне sandbox. Не переносите бинарные файлы на хост и не разделяйте контейнер между тестами. При изменениях runner выполняйте реальные `npm run test:runner` и `npm run test:solutions`, проверяйте cleanup. Сохраняйте Node ESM-совместимые `.js` импорты общего пакета и их разрешение в Next.js; integration suite запускает также собранный runner.

Модуль «Память и указатели в C» использует фиксированные режимы ASan/UBSan и Valgrind. Режим проверки задаёт доверенный сервер из метаданных упражнения; публичный запрос ученика не может его менять. При изменении модуля выполняйте `npm run test:memory`, проверяющий все решения и примеры в Docker. Не отключайте диагностику ради успешного stdout.

Не добавляйте фиктивные кнопки, мок выполнения, критические TODO или делегирование без запроса пользователя. Храните зависимости в общем lockfile. Не коммитьте базы, секреты и артефакты сборки.

Модуль «Углублённый C» содержит 28 уроков и три проекта; уроки Make, CMake, GDB, LLDB и санитайзеров перенесены в «Инструменты разработчика». При изменениях выполняйте `npm run test:advanced`: решения GCC/Clang и примеры Clang проверяются с ASan/UBSan в sandbox; отчёт — `docs/verification/advanced.json`.
